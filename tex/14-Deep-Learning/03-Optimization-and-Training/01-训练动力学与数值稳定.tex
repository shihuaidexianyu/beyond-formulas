\section{训练动力学与数值稳定}
\label{sec:14-Deep-Learning/03-Optimization-and-Training/01}

梯度检查通过了。数值差商和自动微分对到第六位有效数字，反向传播的实现没有问题。于是你按下训练：第一次 loss 从 2.30 开始上下振荡，第二次平得像结冰的湖面，第三次先降到 1.4，然后日志最后一行是 NaN。三次运行的代码一个字符都没改，只改了学习率。

这时再去核对梯度公式是浪费时间。三种失败共用一个来源：梯度告诉你在当前点朝哪个方向走，不告诉你走多远仍然安全，也不保证沿途每个中间量都留在浮点数能表示的窗口里。训练是数学目标、随机采样和有限精度算术共同定义的一个动态系统，任何一方都能单独毁掉另外两方。

深度模型把``选择表示''从人工设计变成可优化的对象，代价在这里显形：表示是学出来的，而学习过程本身几乎没有可以事先验证的保证，你只能通过监控它的运行状态判断它是否还健康。本节讲的是训练现场——怎样从曲线和张量里看出故障，以及每种补救手段各自堵住了哪一个漏洞。数学上的下降引理、鞍点与随机噪声平台属于另一条线，见\hyperref[ch:078]{``非凸与随机优化：能下降不等于找到全局解''}。

\subsection{Mini-batch 梯度无偏，但单步不承诺下降}

设经验风险为
\[
\widehat R(\theta)=\frac1n\sum_{i=1}^n\ell_i(\theta).
\]
在百万级样本上，每步都扫全量数据不现实。均匀抽取 mini-batch \(\mathcal B_t\)，用
\[
\widehat g_t=\frac1{\abs{\mathcal B_t}}\sum_{i\in\mathcal B_t}\nabla\ell_i(\theta_t)
\]
代替真实梯度，条件期望上它是无偏的：\(\E[\widehat g_t\given\theta_t]=\nabla\widehat R(\theta_t)\)。

无偏保证的是长期平均方向正确，与单步是否下降无关。做一次条件对账就清楚了。若 \(\widehat R\) 的梯度 \(L\)-Lipschitz，对确定性梯度有
\[
\begin{aligned}
\widehat R(\theta-\eta\nabla\widehat R(\theta))
&\le \widehat R(\theta)-\eta\norm{\nabla\widehat R(\theta)}^2+\frac{L\eta^2}{2}\norm{\nabla\widehat R(\theta)}^2\\
&=\widehat R(\theta)-\eta\Bigl(1-\frac{L\eta}{2}\Bigr)\norm{\nabla\widehat R(\theta)}^2,
\end{aligned}
\]
只要 \(\eta<2/L\) 就必然下降。换成随机梯度，这条不等式只在取期望后成立，右端还多出一项正比于 \(\eta^2\E\norm{\widehat g_t-\nabla\widehat R}^2\) 的噪声代价。两个前提在深度网络里都站不住：\(L\) 未知且随位置剧烈变化，噪声方差随参数移动而改变。于是你手上没有可用的安全步长公式，只剩经验规律。

具体感受一下这些经验规律的量级。取一个小型卷积网络在 CIFAR-10 上跑 SGD：学习率 1.0 时第一步 loss 就跳成 NaN；学习率 0.001 时 300 个 epoch 后 loss 从 2.30 挪到 2.10；学习率 0.1 时 30 个 epoch 内降到 0.8 并继续走低。三者相差不到三个数量级，结果却横跨``立刻爆炸''、``几乎不动''与``正常工作''。敏感度来自局部曲率：梯度的长度本身不含曲率信息，而曲率决定了线性近似在多大半径内还可信。

batch size 的作用同样容易被误读。方差大致随 \(\abs{\mathcal B}\) 增大而减小，但代价是单步计算量成比例上升，而且同一个 epoch 下更新次数按比例减少——batch size 从 10 换到 50，一个 epoch 的更新次数从 10 步掉到 2 步，优化进展根本不是同一个量。归一化层的统计量、隐式正则化强度也跟着变。所以调大 batch size 不等于变好，它换掉的是整组相互牵制的动力学。

warmup 就长在这个缝隙上。训练最初几百步，参数还在初始化附近，各层激活的尺度尚未互相匹配，自适应优化器的二阶矩估计也基于极少的样本，此时的曲率估计和梯度噪声估计都最不可靠。把学习率从接近零线性升到目标值，等于在这段最危险的区间里主动缩小步长，等统计量稳定下来再放开。它没有对应定理，只有一条经验：模型越深、batch 越大、优化器越依赖历史统计量，缺了 warmup 越容易在前期崩掉。后期的余弦或阶梯衰减服务于另一件事——随机梯度的噪声底噪正比于学习率，想让 loss 停在更低的平台，就得把步长降下来。

\subsection{深度让尺度按指数漂移，而浮点窗口是有限的}

前向传播是一层层乘权重矩阵、过激活函数。设每层权重独立同分布、均值零、方差 \(\sigma_w^2\)，输入方差 \(\sigma_x^2\)，宽度 \(d\)。一次线性变换后每个分量是 \(d\) 个乘积之和，方差约为 \(d\,\sigma_w^2\sigma_x^2\)；ReLU 再把一半分量置零，方差折半；tanh 在零附近近似恒等，输入稍大就饱和、导数趋零。

关键在于这些因子是层层相乘的。记每层的方差放大倍数为 \(c\)，\(k\) 层后总放大是 \(c^{k}\)。\(c=1.5\) 时十层放大 57 倍，\(c=2\) 时十层放大 1024 倍，\(c=0.7\) 时十层只剩原来的 \(2.8\%\)。反向传播走的是同一串矩阵的转置乘积，梯度经历对称的命运。指数增长撞上浮点上界就是 inf，指数衰减撞上下界就是精确的零，而零梯度对应参数永久冻结。

\emph{每层一个固定的放大倍数，在对数坐标下就是一条直线；浮点格式给出的是两条水平边界，深度决定了直线什么时候撞上它们。}

图里那两个圈住的交点是全部麻烦的所在。梯度范数在层与层之间以固定比例变化时，对数坐标下是一条斜率为 \(\log_{10}c\) 的直线，而 float16 只提供大约十二个数量级的可用带宽。斜率 \(0.45\) 的那条线在第十一层左右穿出上边界，斜率 \(-0.65\) 的那条在第十二层触底。换成 float32 带宽扩到约七十个数量级，同样的斜率能多撑几十层——但只要 \(c\ne1\)，撞线是时间问题，加深就是在往边界推进。

Xavier 与 He 初始化针对的正是斜率而非带宽。Xavier 面向 sigmoid 与 tanh，取权重方差 \(2/(\text{fan\_in}+\text{fan\_out})\)，让前向与反向的方差都尽量不变；He 面向 ReLU，取 \(2/\text{fan\_in}\)，其中的因子 2 补偿 ReLU 置零一半。两者都依赖激活函数的局部线性近似以及权重与输入独立——训练几步之后这两条假设都不再严格成立，所以它们做到的是把 \(c\) 从明显偏离 1 拉回 1 附近，把指数漂移压成缓慢漂移，而不是消除漂移。

因此训练开始的头几十步值得盯住几个量：逐层激活的均值与方差是否成比例地放大或缩小；ReLU 输出为零的比例是否逼近 1（若某个单元对全部训练样本都输出零，它再也收不到梯度，参数就此冻结）；逐层梯度范数在对数坐标下是否呈直线；参数范数是否在几步内翻了几倍。这些量在 loss 曲线出问题之前很久就已经异常，而 loss 是它们的高度压缩的标量摘要。

梯度裁剪按上界 \(\tau\) 把更新向量缩放为 \(\min\{1,\tau/\norm{\widehat g}\}\,\widehat g\)，它限制的是单步位移的长度，对循环网络中沿时间累积的爆炸尤其管用。但它改变的是幅度，不是方向，也不改变逐层的 \(c\)：裁剪是紧急刹车，装了刹车不等于修好了传动系统。

\subsection{实数域的等式在浮点下会失效}

softmax 的定义清爽：
\[
p_k=\frac{e^{z_k}}{\sum_j e^{z_j}}.
\]
输入 logits 为 \((1000,1001)\) 时，float32 下 \(e^{1000}\approx10^{434}\) 直接溢出成 inf，inf 除以 inf 得 NaN，训练终结——尽管每一步数学推导都无可指摘。

修复靠一个恒等变换：softmax 对 logits 的整体平移不敏感，分子分母同除 \(e^m\) 不改变比值。取 \(m=\max_j z_j\)，
\[
p_k=\frac{e^{z_k-m}}{\sum_j e^{z_j-m}},
\]
所有指数的自变量不大于零，最大项恰为 1，最小项趋零而不溢出。同一手法给出稳定的对数归一化项
\[
\logsumexp(z)=\log\sum_j e^{z_j}=m+\log\sum_j e^{z_j-m},
\]
这是交叉熵与各类对数似然里反复出现的那一项。次序很要紧：先减最大值再取指数，和先取指数再补救，差别在于后者的张量里已经写进了 inf，之后无论取什么对数都救不回来。二元交叉熵、log-softmax 以及各类概率模型的似然都应当有各自的融合稳定实现。给概率手工加一个 \(10^{-7}\) 量级的 \(\varepsilon\) 能躲开 \(\log 0\)，但它同时改写了目标函数在极端处的梯度，还可能盖住更深处的 NaN 源头。对数域中的稳定计算见\hyperref[sec:08-Numerical-Analysis/07-Numerical-Methods-for-ML/01]{``在对数域中稳定计算概率''}。

混合精度训练用 float16 做前向与反向、用 float32 保存主权重副本。float16 的动态范围很窄：最小正规数约 \(6\times10^{-8}\)，最大约 \(6.6\times10^{4}\)。上一小节那张图里的下边界就是这里——小梯度下溢成零，对应参数从此停更。损失缩放为此而设：前向算出损失后先乘一个大常数（例如 \(2^{16}\)），把整条反向链上的梯度平移到 float16 能表示的区间；更新权重前再除回同一个常数。由于缩放是线性的，数学上的梯度不变，改变的只是它落在浮点栅格上的位置。实现里还要检测本次反向是否出现 inf 或 NaN，若出现就跳过这次更新并调低缩放因子，形成一个自动搜索合适缩放量的反馈环。损失缩放挪动的是表示窗口，它对病态的条件数和写错的代码一概无效。

顺带把两个常被混同的概念分开。数值稳定性说的是计算过程：稳定算法给出的结果，是某个与原问题邻近的问题的精确解，舍入不会让答案离谱。条件数说的是问题本身：输入的微小扰动被放大多少倍传到输出。稳定算法解一个病态问题，仍然会得到对扰动极其敏感的答案。前者归实现管，后者归建模管，把两者混起来会导致反复更换实现却始终不见好转。

\subsection{诊断顺序决定你能不能定位故障}

面对一个新模型，最不划算的做法是反复试学习率。更可靠的路径是先把复杂度压到最低，让故障无处藏身。

第一步是在几十到几百个样本上把训练 loss 压到接近零。这一关过不去，问题必定在形状、标签、损失、梯度或容量之中，与泛化、正则和 batch size 无关；此时加任何组件都只是往一个已经坏掉的系统里添噪声。常见的拦路虎有：标签与输出的形状对不上；损失的 reduction 用了求和而非取平均，梯度整体差一个 batch 大小的因子；最后一层激活选错，二分类用了 softmax 或多分类用了 sigmoid；归一化的统计量在划分数据集之前就已经算过，训练信息泄漏到了验证集。

第二步是用不带动量的 SGD 建立一条优化基线，同时把监控铺开。数据损失与正则损失要分开记录，否则总损失下降可能只是权重衰减在缩小参数范数，预测质量反而更差。验证指标要独立于训练损失记录，训练降而验证升是泛化问题，不属于优化范畴。逐层的梯度范数与参数范数的比值最值得看：这个比值在 \(10^{-3}\) 到 \(10^{-2}\) 之间大致对应``一步走动参数的千分之几''，高过 \(10^{-1}\) 说明单步位移过大，低于 \(10^{-5}\) 说明这一层几乎没在学。激活的均值、方差与饱和比例给出前向侧的对照。NaN 与 inf 要定位到首次出现的算子和层，而不是等日志末尾看到 NaN 再回头猜。最后，用两三个随机种子重跑同一配置：曲线差异巨大意味着优化景观或初始化不稳定，单个种子上的好结果不能当作结论。

有一个几行代码的检查值得每次都做。取一个远小于正常值的步长 \(\eta\)（比如正常学习率的 \(10^{-3}\) 倍），按一阶展开预测
\[
L(\theta-\eta g)\approx L(\theta)-\eta\norm{g}^2,
\]
再与实际测量值比对。若实际 loss 不降反升，可能的原因只有几种：梯度符号搞反；两次前向之间随机层的状态不同（dropout 掩码或批归一化的滑动统计量在变），比较的根本不是同一个函数；损失的归约少乘了某个因子。这个检查能在训练跑出几百步再爆 NaN 之前，把方向性错误提前暴露出来。

第三步才是把正则化项、学习率调度、数据增强和更复杂的架构组件逐个加回来，每次只加一个，并确认基线的训练动态没被破坏。顺序颠倒的代价是，故障出现时你无法把它归因到任何单一改动。

最后一条分诊原则需要反复对自己重申。训练损失低而验证恶化，是泛化问题，不该叫做``没收敛''；上线后指标滑坡而离线指标不动，是分布漂移；概率输出系统性偏高或偏低，是校准问题。三者的干预手段互不相通，而加大训练量只对第一类里的一部分情形有效。把优化、统计与部署三层混在一起谈，是训练日志上最常见的误诊，这条边界的展开见\hyperref[sec:09-Convex-Optimization/08-Nonconvex-and-Stochastic-Optimization/06]{``优化误差、统计误差与泛化不能混为一谈''}。

到这里为止，讨论的都是原始随机梯度。实际训练几乎总要在这一步之上再叠一层历史信息——动量记住过去的方向，Adam 还记住过去的波动幅度。下一节把这两种记忆各自在平均什么拆开来看。
