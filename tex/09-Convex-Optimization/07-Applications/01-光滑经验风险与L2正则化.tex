\section{\texorpdfstring{光滑经验风险与 \(L_2\) 正则化}{光滑经验风险与 L_2 正则化}}
\label{sec:09-Convex-Optimization/07-Applications/01}

监督学习的核心是一个优化问题：

\[
\min_w
\frac1n\sum_{i=1}^n
\ell(y_i,w^{\trans}x_i)
+\lambda R(w).
\]

线性预测 \(w^{\trans}x_i\) 是骨架，损失 \(\ell\) 决定模型怎么看待预测误差，正则项 \(R\) 决定模型偏好什么样的参数形状。损失和正则项一起决定了凸性、曲率和你能用的算法。

没有正则项时，Hessian 完全由数据决定。数据不足、特征共线或样本少于特征数时，Hessian 会有零特征值方向——在这些方向上目标完全平坦，最优解不唯一，优化可以飘到任何地方而不改变训练损失。从统计角度看，这些方向上的参数被数据完全约束不住，方差可以任意大。

你可能会想：那就加个惩罚项，限制参数不要跑得太远。但惩罚的具体形式——\(L_2\)？\(L_1\)？两者混合？——会彻底改变最优解的形状、求解的难度和泛化的行为。这一节先从最光滑的 \(L_2\) 正则开始。

\subsection{Ridge 回归让平坦方向获得曲率}

把 \(n\) 个样本按行堆成设计矩阵 \(X\)（第 \(i\) 行为 \(x_i^{\trans}\)），响应堆成向量 \(y\)。平方损失加 \(L_2\) 正则给出

\[
\min_w
\frac{1}{2n}\norm{ Xw-y}_2^2
+\frac\lambda2\norm{ w}_2^2.
\]

这里 \(1/(2n)\) 让损失变为每样本平均，\(\lambda/2\) 让导数恰好是 \(\lambda w\)。求二阶导数，Hessian 为

\[
\frac1nX^{\trans}X+\lambda I.
\]

\(\frac1n X^{\trans}X\) 是数据提供的曲率——样本协方差矩阵。它在某些方向可能为零（特征共线时），某些方向可能曲率极弱（近乎共线时）。\(\lambda I\) 给每一个方向注入大小为 \(\lambda\) 的底曲率。整个 Hessian 的每个特征值至少为 \(\lambda\)，目标从``凸但不一定强凸''变为 \(\lambda\)-强凸。

这带来两层好处。优化层面：解唯一，梯度下降和共轭梯度的收敛速率都有确切的常数界——由 \(\lambda\) 和 \(L\) 共同决定的条件数直接控制收敛。统计层面：Hessian 条件数改善意味着解对数据微小扰动不再那么敏感。\(X\) 中某一行稍微变动，解的变动被 Hessian 的条件数所限制——条件数越小，解越稳定。

一阶条件给出正规方程：

\[
\left(\frac1nX^{\trans}X+\lambda I\right)w = \frac1nX^{\trans}y.
\]

实现时应解这个线性系统——Cholesky 分解（\(X^{\trans}X+\lambda I\) 正定且对称）、QR 分解（更稳定，直接作用在 \(X\) 上）、SVD（可复用不同 \(\lambda\) 的值）、或共轭梯度（大规模时）——绝不要算逆矩阵。还有一个等价的增广形式：

\[
\min_w \frac{1}{2n}\norm{ \begin{bmatrix}X\\ \sqrt{n\lambda}I\end{bmatrix}w - \begin{bmatrix}y\\0\end{bmatrix}}_2^2,
\]

它把正则化问题重新写成标准的最小二乘（虚拟样本 \(w=0\) 被附加了权重 \(\sqrt{n\lambda}\)），让任何最小二乘求解器直接复用。

\(L_2\) 缩小所有系数的幅度，但极少把任何一个精确压到零。如果目标是变量选择——从几百个特征中挑出真正相关的那几个——Ridge 无能为力。你需要下一节的 \(L_1\) 几何。但如果目标只是控制方差和共线性问题，Ridge 往往是更稳定、更易求解、数学性质更简单的选择。

\subsection{Logistic 回归从概率模型得到凸损失}

二分类时，标签取 \(y_i\in\{-1,1\}\)，令 margin 为

\[
t_i=y_i(w^{\trans}x_i+b).
\]

margin 为正意味着正确分类且置信度高；margin 为负意味着错分。logistic 损失是

\[
\ell(t)=\log(1+e^{-t}).
\]

理解它的形状：当 \(t\to\infty\)（极其自信的正确分类），\(e^{-t}\to0\)，\(\ell(t)\to0\)，且导数 \(\ell'(t)\to0\)——模型已经自信地对，不再被这个样本驱动。当 \(t\to-\infty\)（极其严重的错分），\(e^{-t}\to\infty\)，\(\ell(t)\approx -t\)——损失随错分程度线性增长，不会像平方损失那样对离群点呈二次爆炸。当 \(t=0\)（margin 为零，正好在决策边界上），\(\ell(0)=\log 2\approx 0.693\)。

二阶导数 \(\ell''(t) = \frac{e^t}{(1+e^t)^2}\)。代入任意 \(t\)，这个值是 \(\sigma(t)(1-\sigma(t))\)——注意它关于 \(t\) 是偶函数，在 \(t=0\) 处取最大值 \(1/4\)，向两侧衰减至零。由于处处非负，与仿射 margin 复合后对 \(w\) 仍为凸。加总平均后训练目标凸。

若用 \(y_i\in\{0,1\}\) 编码和概率形式：

\[
p_i=\sigma(w^{\trans}x_i+b),\qquad
\sigma(z)=\frac1{1+e^{-z}},
\]

负对数似然为 \(-y_i\log p_i-(1-y_i)\log(1-p_i)\)。用 \(\sigma\) 的定义展开 \(\log p_i\) 和 \(\log(1-p_i)\)：

\[
\log p_i = z_i - \log(1+e^{z_i}),\qquad
\log(1-p_i) = -\log(1+e^{z_i}).
\]

代入并整理，两种标签编码给出同样的函数形式：

\[
\log(1+e^{z_i})-y_i z_i,\qquad z_i=w^{\trans}x_i+b.
\]

softplus 减去线性项，仍然凸。两种编码的数学等价性意味着你可以用更方便的那一个推导，再在实现中切换到数值更稳定的形式。

实现时有一个关键细节。不要直接算 \(e^{z_i}\) 然后取 log——\(z_i\) 大到 100 时 \(e^{100}\) 直接溢出。用稳定的 log-sum-exp 公式：

\[
\log(1+e^{z_i}) = \max(0, z_i) + \log(1+e^{-|z_i|}).
\]

同样，不要先算概率 \(\sigma(z_i)\) 再取对数——当 \(z_i\) 负得很厉害时 \(\sigma(z_i)\) 接近零，再取对数就下溢。

\subsection{Hessian 揭示数据怎样提供信息}

对单个样本求 \(w\) 的二阶导：

\[
\frac{\partial^2}{\partial w^2}\ell(t_i) = \ell''(t_i)\, x_ix_i^{\trans}.
\]

两种标签编码下 \(\ell''(t_i)\) 的值相同，都是 \(p_i(1-p_i)\)。对各样本求和并平均，加正则后 Hessian 可写成

\[
\frac1nX^{\trans}WX+\lambda I,
\]

其中 \(W\) 是对角矩阵，第 \(i\) 个对角元为 \(p_i(1-p_i)\ge0\)。

这个形式能读出不只是一般性质的二阶信息。\(p_i(1-p_i)\) 是伯努利方差——单个样本预测的``不确定度''。在 \(p_i=1/2\) 时取最大值 \(1/4\)：模型最摇摆不定的样本，对 Hessian 的贡献最大。在 \(p_i\approx0\) 或 \(p_i\approx1\) 时趋于零：已经被模型极其自信地（无论对错）分类的样本，几乎不贡献曲率。

这意味着什么？曲率的主要来源是决策边界附近的样本。那些被远抛在边界之外的多数类样本，虽在损失函数值和梯度中占重头，在曲率中却几乎消失。如果你的数据严重不平衡，有效曲率只来自一小撮边界附近的样本——少数类和多数类中贴近边界的那部分。Hessian 条件数可能比样本数比例所暗示的要差得多。

Newton 法和迭代重加权最小二乘（IRLS）在每一步求解的正是这个加权最小二乘系统。算法的过程是循环：当前参数决定预测概率，预测概率决定权重矩阵 \(W\)，\(W\) 定义下一步的加权最小二乘子问题，求解后得到新参数，概率更新，如此迭代。权重在自适应地重新分配不同样本的``信息贡献''。

还有一个容易被忽略的数学事实。如果数据完全线性可分且不加正则化，logistic 损失的下确界是零，但最优参数序列的范数趋于无穷——有限处没有参数取到下确界。凸性保证了下确界的全局可达性，不能保证它在一个有界区域内被取到。加入 \(L_2\) 正则后，\(\norm{ w}\to\infty\) 时目标趋于无穷（强制性成立），连续函数在有界闭集上的极小值定理恢复——最优解在有限处达到且唯一。这一条对理论和实现同等重要：不加正则的 logistic 回归可以在训练过程中参数无限增长、梯度永远不归零、但损失持续下降——你永远等不到``收敛''，除非你加正则或提前停止。

\subsection{约束形式与惩罚形式}

把数据拟合项整体记为 \(\ell(w)\)，Ridge 有两种等价的写法：

惩罚形式：
\[
\min_w \ell(w)+\lambda\norm{ w}_2^2,
\]

约束形式：
\[
\min_w\ell(w) \quad\text{s.t.}\quad \norm{ w}_2^2\le t.
\]

两种形式通过 Lagrange 乘子理论联系。在适当凸性和约束资格下，每个约束半径 \(t\) 对应某个非负乘子 \(\lambda(t)\)——它恰好是约束形式最优值对 \(t\) 的负导数的绝对值，即放宽约束一个单位的``边际收益''。但这个对应是隐式且非线性的：\(\lambda\) 不能写成 \(1/t\) 的简单公式。解和数据的结构决定了每一对 \((t,\lambda)\) 的具体数值。当约束不活跃——无约束最优解天然落在球内时——对应的 \(\lambda=0\)，约束形同虚设。当解不唯一时，同一个 \(\lambda\) 可能对应多个不同的 \(w^\star\)，不同的 \(t\) 值。

应用中选哪种写法取决于场景。约束形式适合你对参数范数有物理意义的预算时（``系数能量不超过某值''）。惩罚形式更适合用交叉验证选正则化强度——网格搜索 \(\lambda\) 比搜索 \(t\) 更常见，部分也是历史惯性。

\subsection{优化完成后还没有完成学习}

KKT 残差接近零和对偶间隙接近零，说明训练目标已接近全局最优。但这只是优化收敛，不是学习完成。优化把损失压低了；泛化要求的却是损失在一个你没见过的分布上也不高——那是两件只有弱相关的事。

以下几个步骤在优化之后仍不可跳过：

\begin{itemize}
\tightlist
\item
  用独立验证数据选 \(\lambda\)——训练集上的最优参数不是泛化意义上的最优参数；\(\lambda\) 越小训练损失越低，但验证损失呈 U 形曲线，最优 \(\lambda\) 在底点。
\item
  统一特征尺度——同一个 \(L_2\) 惩罚对以米计和以毫米计的特征不公平。尺度大的特征被不成比例地压制，因为要产生同样的预测效果只需更小的系数，而正则项惩罚的是系数本身。
\item
  决定截距是否应惩罚——通常不应惩罚截距。截距平移整个预测函数，不乘任何特征值，惩罚它等于强迫模型过原点，丧失了灵活性。
\item
  检查类别不平衡——多数类的损失和梯度主导整个优化过程，少数类被系统性地忽略，即使少数类的错分代价在实际应用中远高于多数类。
\item
  检查异常值和数据泄漏——异常值扭曲损失和 Hessian；数据泄漏（训练集中混入了本应不可知的未来信息）会让所有验证指标虚高。
\item
  评估概率校准而不仅看分类准确率——一个参数精确收敛的模型可能输出系统性地过度自信的概率（比如所有预测都在 0.9 以上），在风险敏感的应用中这是致命的。
\item
  区分优化误差、统计误差和数据漂移——三者的来源和解决方法完全不同，把优化误差归零不解决后两者。
\end{itemize}

一个精确求解的错误损失函数，仍然是错误模型。优化负责把选定的目标压到尽可能低——它不负责、也无法替你判断目标是不是对的那个。把这两个角色分开，是这个领域中最重要的元认知之一。
