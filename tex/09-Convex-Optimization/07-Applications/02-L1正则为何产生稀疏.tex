\section{\texorpdfstring{\(L_1\) 正则为何产生稀疏}{L_1 正则为何产生稀疏}}
\label{sec:09-Convex-Optimization/07-Applications/02}

上节的 Ridge 把系数均匀缩小，但几乎从不产生精确的零。你用 Ridge 跑一个几百维特征的问题，跑完之后所有系数都是非零的小数——你不知道哪些真正有用、哪些是噪音。手工挑阈值来截断？那等于承认正则项没做好变量选择这件事。

你真正想要的是：模型自动把无关和冗余特征的系数压到恰好为零，留下一个稀疏的参数向量，其中只有少数几个非零系数——每个对应一个``真的在起作用''的特征。

Lasso 回归写成

\[
\min_w
\frac12\norm{ Xw-y}_2^2
+\lambda\norm{ w}_1.
\]

还是凸问题，还是最小二乘骨架，唯独惩罚项从 \(\norm{ w}_2^2\) 换成了 \(\norm{ w}_1\)。就这一个替换——平方换绝对值——解的性质发生了质变。当 \(\lambda\) 足够大时，大量坐标被精确置零，而不是缩小到近乎零。怎么做到的？

\subsection{约束几何让等高线容易碰到坐标轴}

把惩罚形式转换成等价的约束形式：

\[
\min_w\frac12\norm{ Xw-y}_2^2
\quad\text{subject to}\quad
\norm{ w}_1\le t.
\]

在二维平面上画出两个约束区域。\(L_2\) 球 \(\norm{ w}_2\le\sqrt{t}\) 是圆——边界处处光滑，每一点有唯一切平面。\(L_1\) 球 \(\norm{ w}_1\le t\) 是旋转了 \(45^\circ\) 的正方形（菱形）——四条边是直线段，四个顶点恰好落在坐标轴上。

平方损失的等高线是一组椭圆，中心在无约束最小二乘解 \(w_{\text{OLS}}\)。现在想象约束球从零开始膨胀。当球膨胀到刚好碰到最内层椭圆时，接触点就是约束问题的解。

对于圆约束：接触点可以是圆周上任意位置——这取决于椭圆的方向和长短轴。椭圆恰好让接触点精确落在坐标轴上的概率近乎为零。所以 Ridge 几乎从不产生零系数。

对于菱形约束：菱形的四个顶点是尖的——它们向外凸出，且恰好位于坐标轴上。当椭圆从内部向外扩张时，第一个接触点极大概率是某个顶点。理由很几何：顶点比边更靠近椭圆中心吗？不是——顶点是离中心最远的点。但椭圆在沿着坐标轴的方向上可能拉得比较长；菱形的边和椭圆可能已经大面积接触，但顶点作为``刺出''的部分，会率先碰到那些沿着斜向延伸得不够远的椭圆。

更精确的说法是：在高维中 \(\ell_1\) 球有 \(2p\) 个顶点（每个坐标轴的正负两端各一个），而 \(\ell_2\) 球没有顶点——整个球面都是光滑的。尖点充当了稀疏性的``锚点''：损失等高线在约束区域上优化时，最优解倾向于落在这些尖点上。每个尖点位于某个坐标超平面上（\(w_j=0\) 对某个 \(j\)），所以尖点意味着某些坐标精确为零。高维中同时落在多个坐标超平面交线上的顶点，意味着多个坐标同时为零。

这是稀疏的几何直觉。它不证明稀疏一定发生——椭圆方向足够特殊时也可能先碰到菱形边——但它解释了为什么 \(L_1\) 倾向于产生稀疏而 \(L_2\) 不会。尖点负责稀疏。光滑的 \(L_2\) 球没有尖点，最优解总在光滑边界上，系数极少恰好为零。

\subsection{KKT 条件给出精确的零阈值}

几何直觉之后需要解析条件。Lasso 的目标函数中 \(\norm{ w}_1\) 在零点不可微——这就是尖点在函数层面的表现。\(\norm{ w}_1\) 在零点的次梯度是整段区间 \([-1,1]\)：你可以选择 \([-1,1]\) 中的任何值来满足最优性条件。这正是尖点``能吸收相关性''的解析表达。

对各坐标写出 KKT 条件：

\[
0\in X^{\trans}(Xw-y)+\lambda\partial\norm{ w}_1.
\]

记 \(x_j\) 为 \(X\) 的第 \(j\) 列（第 \(j\) 个特征在各样本的取值）。对第 \(j\) 个坐标，分三种情况：

\begin{itemize}
\item
  若 \(w_j>0\)，\(\partial|w_j|=\{+1\}\)。一阶条件变为
  \[
  x_j^{\trans}(Xw-y)+\lambda=0,
  \]
  即该特征与残差的相关性必须精确等于 \(-\lambda\)（一个负值，推动 \(w_j\) 向零移动但不跨过零）。

\item
  若 \(w_j<0\)，\(\partial|w_j|=\{-1\}\)。一阶条件变为
  \[
  x_j^{\trans}(Xw-y)-\lambda=0,
  \]
  即相关性必须精确等于 \(+\lambda\)（推动 \(w_j\) 向零移动）。

\item
  若 \(w_j=0\)，\(\partial|w_j|=[-1,1]\)。一阶条件只要求
  \[
  |x_j^{\trans}(Xw-y)|\le\lambda.
  \]
  存在某个次梯度值（在 \([-1,1]\) 内）使等式成立即可，不需要相关性取特定值——只需要它不超出带宽 \(\lambda\)。
\end{itemize}

零坐标的条件是全文最关键的一句：当某个特征与当前残差的相关性的绝对值不超过 \(\lambda\) 时，零就是一个满足 KKT 条件的合法值。尖点处的整段次梯度区间像一个``缓冲区''——只要相关性落在这个区间内，算法不需要把零坐标推开去适应数据，相关性被次梯度的灵活性吸收了。

光滑的 \(L_2\) 在零点的导数是零——次梯度区间退化为单点 \(\{0\}\)。相关性只要非零就会推开零坐标，无论多小。两者的一阶条件差异，完美对应了几何上``有没有尖点''的差异。

\subsection{正交设计下出现软阈值}

如果特征之间完全不相干——\(X^{\trans}X=I\)（正交设计）——每个特征的效应可以被独立识别。令 \(z=X^{\trans}y\) 为各特征与响应的最小二乘相关量（即逐特征做一元回归得到的相关系数）。由于 \(X^{\trans}X=I\)，目标中不同坐标的交叉项全部消失：

\[
\frac12\norm{ Xw-y}_2^2
= \frac12\norm{ w-z}_2^2 + \text{常数}.
\]

加上 \(L_1\) 惩罚项后，目标完全按坐标分离：

\[
\sum_j
\left[
\frac12(w_j-z_j)^2+\lambda|w_j|
\right]
+\text{常数}.
\]

每个坐标是一个独立的一维 Lasso 问题：最小化 \((w_j-z_j)^2/2 + \lambda|w_j|\)。做一下分段求导（对 \(w_j>0\) 和 \(w_j<0\) 分别求），解得

\[
w_j^\star = \sign(z_j)
\max\{|z_j|-\lambda,0\}.
\]

这就是软阈值（soft thresholding）。逐个坐标解读：如果第 \(j\) 个特征与 \(y\) 的原始相关性 \(|z_j|\) 大于 \(\lambda\)，系数取同号，但大小被向零压缩了 \(\lambda\)——软阈值的``软''就是这层压缩。如果 \(|z_j|\) 小于等于 \(\lambda\)，系数直接被置零——``不足够相关就被淘汰''。

读出 \(\lambda\) 的语义：它是``入选门槛''。\(\lambda=0\) 时恢复普通最小二乘解；\(\lambda\) 越大，幸存的特征越少。在 \(\lambda\) 增大过程中，特征逐个出局——这是正则化路径（regularization path）的核心结构。

极端情况提供了一个锚点：若
\[
\lambda\ge\norm{ X^{\trans}y}_\infty = \max_j |z_j|,
\]
那么对所有 \(j\) 都有 \(|z_j|\le\lambda\)，\(w^\star=0\) 满足 KKT 条件——全零解最优。这个 \(\lambda_{\max}\) 是正则化路径的自然起点：从 \(\lambda_{\max}\) 开始逐步减小 \(\lambda\)，特征按相关性大小逐个被``激活''进入模型。

一般设计矩阵下，坐标不再独立——\(X^{\trans}X\) 的非对角元让各坐标的最优 KKT 条件相互耦合。但坐标下降算法每次只更新一个坐标（固定其他所有坐标），在每一步中面对的子问题恰好是这个一维 Lasso，解就是软阈值——只是 \(z_j\) 被替换为考虑其他坐标当前值后的``部分残差相关量''。近端梯度（proximal gradient）算法则以整个向量为单位应用软阈值——每次沿梯度下降一步后再对所有坐标同步做软阈值收缩。

\subsection{稀疏不等于稳定解释}

Lasso 挑出了一个稀疏解，但不等于被挑中的特征具有因果意义，也不等于这个稀疏模式会被另一组相似的数据重现。

当两个特征高度相关时，Lasso 可能随意选择其中一个进入模型，把另一个压到零。两组几乎相同的数据可能选出不同的特征——不是因为这些特征的预测能力有任何本质差异，而是因为在高度相关的特征集合中，损失函数沿某个方向的曲率极弱，一点点数据扰动就改变了解落入的尖点。

如果设计矩阵 \(X\) 不满足某些较严格的条件——如 restricted eigenvalue condition、compatibility condition 或 irrepresentable condition——解甚至可能不唯一。同一组数据、同一个 \(\lambda\)，允许存在多个不同的最优解，它们的稀疏模式和系数值可能完全不同。Lasso 的报告只是这些解中的一个，由具体算法和初始值决定。

Elastic Net 试图软化这个不稳定问题：

\[
\frac12\norm{ Xw-y}_2^2
+\lambda_1\norm{ w}_1
+\frac{\lambda_2}{2}\norm{ w}_2^2.
\]

\(L_1\) 保留稀疏机制——尖点仍在。\(L_2\) 注入额外的强凸性——每个方向的曲率至少为 \(\lambda_2\)，使得高度相关的特征群体被更均衡地对待（倾向于一起进入或一起出局）。代价是额外超参数 \(\lambda_2\) 需要用验证数据调节，偏差结构也不再是单纯的软阈值——但实际稳定性通常优于纯 Lasso。

特征标准化在这一节比在 Ridge 中更关键。\(L_1\) 惩罚对系数的绝对值一视同仁：如果某个特征以米为单位、另一个以毫米为单位表达同一物理量，产生相同预测效果的系数值差 \(10^3\)，统一的 \(\lambda\) 会不成比例地惩罚毫米单位的特征，把它优先压成零。所有特征在建模前应被标准化到可比尺度（常见的做法是减均值除以标准差），截距不参与惩罚。

\subsection{从稀疏回归到一般稀疏优化}

\(L_1\) 范数可以从一个更高的视角理解：它是零范数的凸替代。定义零范数为非零坐标的计数：

\[
\norm{ w}_0 = \#\{j:w_j\ne0\}.
\]

如果你直接约束 \(\norm{ w}_0\le s\)——限制模型最多使用 \(s\) 个特征——这是一个组合选择问题：从 \(p\) 个特征中选最多 \(s\) 个。组合数 \(\binom{p}{s}\) 在 \(p\) 和 \(s\) 稍大时直接爆炸，全局最优搜索是 NP-hard。

\(L_1\) 范数是在约束 \(\norm{ w}_\infty\le 1\) 下 \(\norm{ w}_0\) 的最大凸下界函数——数学术语叫凸包络（convex envelope）。在原点附近，\(L_1\) 和 \(\norm{ w}_0\) 对单个坐标的惩罚完全一致（都是 \(|w_j|\) vs 1，如果 \(w_j\neq0\)）；在远离原点时 \(L_1\) 的惩罚过度——它随 \(|w_j|\) 线性增长，而 \(\norm{ w}_0\) 始终是 0 或 1。将 \(\norm{ w}_0\) 松弛为它的凸包络，NP-hard 的组合问题退化为一个凸优化问题——可求解，可保证全局最优，可用本章讨论的梯度、次梯度、坐标下降等工具高效处理。

这个松弛在什么条件下是``紧''的——即 \(L_1\) 的最优解恰好具有真实的稀疏模式？压缩感知理论给出了明确的答案：当设计矩阵满足受限等距性（restricted isometry property，RIP）或类似的不相干性条件时，\(L_1\) 松弛可以精确恢复真实的稀疏解。没有这些条件时，\(L_1\) 只是一个有偏的代理——比 \(\norm{ w}_0\) 容易算、有全局最优保证，但不保证恢复真实的支持集。

这一套思想泛化到许多其他结构化稀疏问题。组稀疏：不是单个系数为零，而是整组系数同时为零——group lasso 对每组施加 \(L_2\) 范数，再对各组求和。矩阵低秩：秩是奇异值的 \(\norm{\cdot}_0\)——非零奇异值的个数——它的凸包络是核范数，即奇异值之和。图结构稀疏、树结构稀疏、融合 lasso（相邻系数趋于相等）都遵循同一策略：找到你真正关心的复杂度度量的凸包络或支持函数，把它放进目标，再用近端算法或对偶结构求解。

每次这样做的同时，都需要清醒地知道：凸松弛改变了惩罚的形状。最优解不再是你最初想要的那一个——它只是一个能高效算出来的替代品，其与真实目标的距离取决于问题是否满足相应的结构性条件。
