\section{弦在图像上方意味着什么}
\label{sec:09-Convex-Optimization/03-Convex-Functions/01}

取 \(f(x)=x^2\)，在图像上挑两个点：\((1,1)\) 和 \((3,9)\)。用直线把它们连起来。在 \(x=2\) 处，弦的高度是 \(0.5\cdot1+0.5\cdot9=5\)，而函数值 \(f(2)=4\)。弦在函数值的上方——\(5>4\)。换别的点试试：\((0,0)\) 和 \((4,16)\)，在 \(x=2\) 处弦高 \(8\)，函数值 \(4\)，还是弦在上。再换 \(\theta=0.3\) 在 \(x=1\) 和 \(x=3\) 之间：弦高 \(0.7\cdot1+0.3\cdot9=3.4\)，函数值 \(f(1.6)=2.56\)，弦依然在上。

这似乎是一个普遍规律：对于 \(x^2\) 的图像，任取两点连成的弦，总是落在函数图像的上方。换个函数试试。

取 \(f(x)=\sin x\)，在 \([0,2\pi]\) 上取 \((0,0)\) 和 \((2\pi,0)\)。弦就是 \(x\) 轴本身（高度始终为零）。但在 \(x=\pi\) 处，\(\sin\pi=0\)，弦高也是零——看起来还好。换两个点：\((\pi/2,1)\) 和 \((3\pi/2,-1)\)。在 \(x=\pi\) 处，弦高 \(0.5\cdot1+0.5\cdot(-1)=0\)，而 \(\sin\pi=0\)——又是平手。再试试 \((\pi/4,\sqrt2/2)\) 和 \((3\pi/4,\sqrt2/2)\)：中点 \(x=\pi/2\) 处，弦高 \(0.5\cdot\sqrt2/2+0.5\cdot\sqrt2/2\approx0.707\)，函数值 \(\sin(\pi/2)=1\)。这次弦在函数值\textbf{下方}——\(0.707<1\)。

同一个 \(\sin x\)，有的弦在上，有的弦在下。它不是凸函数。

\subsection{把弦的现象写成不等式}

把反复试验总结成一个形式定义。设函数 \(f:\R^n\to\R\) 的定义域是凸集。若对任意 \(x,y\) 和任意 \(0\le\theta\le1\)，

\[
f(\theta x+(1-\theta)y)
\le
\theta f(x)+(1-\theta)f(y),
\]

则称 \(f\) 为\textbf{凸函数}。

左边是``先在输入空间里混合，再评价函数''；右边是``先评价两个端点，再混合函数值''。凸性说：混合方案的代价不会超过端点代价的线性插值。用上一节投资组合的语言翻译：两种配置各自有成本，混合配置的成本不会超过两种成本的加权平均——混合不会让你付出额外的代价。

\subsection{定义域必须一起考虑}

判断一个函数是否凸，不能只看公式。表达式 \(1/x\) 在正半轴 \((0,\infty)\) 上二阶导数为正，因此是凸的（二阶导数判据将在\hyperref[sec:09-Convex-Optimization/03-Convex-Functions/03]{``曲率区分凸、严格凸与强凸''}一节严格建立）；在负半轴 \((-\infty,0)\) 上二阶导数为负，因此是凹的。如果把定义域写成 \(\R\setminus\{0\}\)，这个定义域本身不是凸集——取 \(x=-1\) 和 \(y=1\)，它们的凸组合 \(0\) 不在定义域内。连定义域都不凸，更谈不上函数在其上是否凸。

优化中常使用\textbf{扩展值函数}，把约束吸收进目标里：

\[
I_C(x)=
\begin{cases}
0,&x\in C,\\
+\infty,&x\notin C.
\end{cases}
\]

当 \(C\) 是凸集时，指标函数 \(I_C\) 是扩展值意义下的凸函数。于是

\[
\min_{x\in C}f(x)
\]

可以等价地写成无显式约束的形式

\[
\min_x f(x)+I_C(x).
\]

这个写法把``目标''和``可行性''统一为凸函数之和，约束信息完整保留；后面的近端方法会直接利用这一形式。

\subsection{Jensen 不等式：从两点推广到任意平均}

反复应用两点的定义（对点数做归纳），就得到有限形式的 Jensen 不等式：

\[
f\left(\sum_{i=1}^k\theta_i x_i\right)
\le
\sum_{i=1}^k\theta_i f(x_i),
\qquad
\theta_i\ge0,\quad\sum_i\theta_i=1.
\]

概率形式更进一步：

\[
f(\E[X])\le\E[f(X)],
\]

只要期望存在且 \(X\) 落在定义域中。它说的是：对凸损失而言，``先平均再评价''永远不会比``先评价再平均''更大。

这个不等式在统计和机器学习中无处不在，只是常常换了一副面孔出现。取 \(f(x)=x^2\)：

\[
(\E X)^2\le\E[X^2],
\]

移项正是 \(\Var(X)=\E[X^2]-(\E X)^2\ge0\)——方差非负不过是 Jensen 的一句注脚。再取 \(f(x)=-\log x\)（凸函数，定义域 \(x>0\)），代进 Jensen：

\[
-\log\left(\sum_i\theta_i x_i\right)\le -\sum_i\theta_i\log x_i,
\]

整理即得加权算术--几何平均不等式。取 \(f(x)=e^x\)，则 \(\exp(\E[X])\le\E[e^X]\)，形式虽简单，却是大量尾概率界的起点。

每一次你看到一个期望跑到了非线性函数的里面和外面，Jensen 都在告诉你不等式朝哪个方向开口。

\subsection{上境图：把函数问题变成集合问题}

函数有时候不好直接摆弄，不如看它的``上方区域''。定义 \(f\) 的\textbf{上境图}为

\[
\operatorname{epi}f = \{(x,t):t\ge f(x)\}.
\]

它包含函数图像本身，以及图像上方的所有点。现在来一条关键的等价关系：

\[
\text{\(f\) 是凸函数 \(\Longleftrightarrow\) \(\operatorname{epi}f\) 是凸集合。}
\]

两个方向的验证都很直接。若 \((x,t)\) 与 \((y,s)\) 位于上境图中，即 \(t\ge f(x)\)、\(s\ge f(y)\)，凸性给出

\[
f(\theta x+(1-\theta)y)
\le
\theta f(x)+(1-\theta)f(y)
\le
\theta t+(1-\theta)s,
\]

所以混合点仍在 \(\operatorname{epi}f\) 中。反向只需取边界点 \((x,f(x))\) 与 \((y,f(y))\)，混合点落在上境图内意味着 \(f(\theta x+(1-\theta)y)\le\theta f(x)+(1-\theta)f(y)\)，恰好回到凸函数的定义。

这个视角非常实用，因为它把许多关于函数的构造规则转换成了关于集合的交、仿射像或投影——而集合的操作我们已经在前一个单元里熟悉了。例如逐点最大值

\[
f(x)=\max_i f_i(x)
\]

的上境图是各个 \(\operatorname{epi}f_i\) 的交，因此只要每个 \(f_i\) 凸，它们的最大值也凸——一行论证就完成了。

\subsection{次水平集只提供单向判据}

凸函数的次水平集

\[
\{x:f(x)\le\alpha\}
\]

一定是凸集。若 \(x,y\) 都在其中，凸性给出完整的不等式链：

\[
f(\theta x+(1-\theta)y)
\le
\theta f(x)+(1-\theta)f(y)
\le
\theta\alpha+(1-\theta)\alpha=\alpha.
\]

但反过来不成立：所有次水平集都是凸集，不足以推出函数是凸的——这只说明函数是\textbf{拟凸}的。一元单调函数就是一个典型反例：它的次水平集都是区间（因而是凸的），但它可能完全不满足弦不等式。

别把``碗形的等高线''和凸函数本身混为一谈。次水平集凸只能保证``不太差''的部分是连通的，不能保证弦不会穿透函数图像。

\subsection{基本例子与边界}

以下函数在自然定义域上是凸的，值得记在脑子里作为构造更复杂函数的积木块：

\begin{itemize}
\tightlist
\item
  仿射函数 \(a^{\trans}x+b\)，弦不等式恰好取等号——它是凸与凹的交界；
\item
  任意范数 \(\norm{ x}\)，三角不等式直接给出凸性；
\item
  二次函数 \(\frac12x^{\trans}Qx+a^{\trans}x+b\)，当且仅当 \(Q\succeq0\) 时凸；
\item
  指数函数 \(e^x\)，在整个实线上严格凸；
\item
  负对数 \(-\log x\)，定义域 \(x>0\)，在信息论和最大似然中反复出现；
\item
  log-sum-exp：\(\log\sum_i e^{x_i}\)，一个光滑且处处严格凸的函数（凸性证明见\hyperref[sec:09-Convex-Optimization/03-Convex-Functions/04]{``怎样识别和构造凸函数''}一节），它是最大值函数的光滑近似。
\end{itemize}

反过来，\(-x^2\) 是凹函数——它的弦在图像下方。\(\sin x\) 在整个实线上既不凸也不凹，但在某些受限区间上可以具有单一的曲率方向。每次判断凸性时，必须同时给出定义域；离开定义域谈凸性是没意义的。
