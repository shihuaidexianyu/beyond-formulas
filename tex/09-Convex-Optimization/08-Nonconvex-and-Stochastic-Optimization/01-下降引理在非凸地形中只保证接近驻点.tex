\section{下降引理在非凸地形中只保证接近驻点}
\label{sec:09-Convex-Optimization/08-Nonconvex-and-Stochastic-Optimization/01}

\hyperref[sec:09-Convex-Optimization/06-Optimization-Algorithms/01]{``梯度下降真正难在步长''}中推导下降引理时，仔细回顾你会发现：从光滑性假设出发，到得出每步函数值下降的不等式，中间每一步运算都没有用到凸性。凸性的角色在后面——把``每步下降的量''翻译成``离全局最优的距离''。

现在把这小段推导单独抽出来审视。只要 \(f\) 是 \(L\)-光滑的——梯度 Lipschitz 连续——更新

\[
x_{k+1}=x_k-\eta\nabla f(x_k)
\]

就必然满足

\[
f(x_{k+1})
\le
f(x_k)
-\eta\left(1-\frac{L\eta}{2}\right)
\norm{\nabla f(x_k)}^2.
\]

选 \(\eta\le 1/L\)，括号项为正，每一步目标值确定下降——除非梯度已经是零。这个事实不依赖凸性。光滑性单独保证了局部下降。

这对非凸优化的意义重大：即使损失曲面上到处是鞍点、局部极小、平坦高原和蜿蜒谷地，只要函数是光滑的且有下界，梯度下降至少能保证每步都往下走。``往下走''这三个字在非凸情形中就是你唯一能廉价获得的确定性信息。

但失去凸性后，``下降最终通向全局最优''这个推理链条断了。凸函数中任意两点的函数值差异被连接它们直线上的梯度所控制——这是一个全局几何约束，让局部梯度信息具有了全局解释力。非凸函数没有这个性质。你只知道每步在往下走——可能走向深谷，可能走向浅鞍，可能走向一个平坦的高原，甚至可能沿着一个无尽向下但永不到底的斜坡滑下去。下降本身不能告诉你走到了哪里。

\subsection{把每一步下降累加起来}

即使不知道终点在哪，只要函数有下界——不会一路掉到负无穷——至少能从下降累加中榨出一个数学保证：不可能无穷无尽地大步下降，梯度必定在某个时刻变得很小。函数下降的总量有天花板，而每一步下降的量与梯度范数平方成正比——两个事实合在一起，强制大部分步骤的梯度必须小。

设 \(f\) 有有限下界 \(f_{\inf}>-\infty\)，取 \(\eta\le 1/L\)。此时括号项最小为 \(1/2\)（当 \(\eta=1/L\) 时），下降不等式简化为

\[
f(x_{k+1})
\le
f(x_k)-\frac\eta2\norm{\nabla f(x_k)}^2.
\]

把等式从 \(k=0\) 累加到 \(T-1\)。关键的telescoping：中间的 \(f(x_1), f(x_2), \ldots, f(x_{T-1})\) 在求和时作为相邻两项的正负部分恰好对消：

\[
\frac\eta2
\sum_{k=0}^{T-1}\norm{\nabla f(x_k)}^2
\le
f(x_0)-f(x_T)
\le
f(x_0)-f_{\inf}.
\]

左边是所有梯度平方的累积——由下降驱动的全部``动能''。右边是一个常数：初始函数值到最低可能值的总落差除以步长。这个常数不能靠参数调整或改变算法来增大——它是问题固有的。初始值选得好，\(f(x_0)\) 接近下界，累积梯度平方的上界就小——但这同时也意味着从一开始就已经在一个不错的区域里，没什么好降的。

这个不等式隐含着一个统计直觉：在 \(T\) 步中，平均的梯度平方不超过 \(\frac{2(f(x_0)-f_{\inf})}{\eta T}\)。因为平均值被一个 \(O(1/T)\) 的上界控制，最小值必然更小：

\[
\min_{0\le k<T}\norm{\nabla f(x_k)}^2
\le
\frac1T\sum_{k=0}^{T-1}\norm{\nabla f(x_k)}^2
\le
\frac{2(f(x_0)-f_{\inf})}{\eta T}.
\]

前 \(T\) 步中碰到的最小梯度范数平方按 \(O(1/T)\) 衰减。梯度范数本身（开方后）按 \(O(1/\sqrt{T})\) 衰减。

这就是一阶驻点复杂度的完整含义：花 \(O(1/\varepsilon^2)\) 步能保证找到一个梯度范数不大于 \(\varepsilon\) 的点。这个复杂度单位——梯度范数 \(\varepsilon\) 对应 \(1/\varepsilon^2\) 次迭代——是光滑非凸优化最基本的理论基准。注意它说的是``存在某个 \(k<T\)''而非``序列极限''——算法可能在访问到这个小梯度点之后又走开了，梯度可能又变大。

\subsection{结论准确地说了什么}

上面这个结论是一把非常具体、也非常狭窄的尺子。把它拆开，看清楚它保证的边界线画在哪里，边界之外的事它一概不管。

它保证的是：给定足够多迭代，一定能在访问过的点中找到某个梯度很小的点。

它没有保证的内容：

\begin{itemize}
\tightlist
\item
  整个序列 \(x_k\) 收敛到同一个点。它可能在高原上游走——各点梯度都很小，但彼此之间距离很远。梯度小只意味着地形平，不意味着位置近。在高维中，高原的直径可能极大。
\item
  梯度小的点就是局部极小。高维中的鞍点远比局部极小普遍：\(n\) 维问题中，随机临界点为局部极小的概率随 \(n\) 指数衰减。鞍点处梯度为零，一阶条件完全通过。但沿着某个负曲率方向继续走，函数值还能再降——鞍点不是终点。
\item
  该点的函数值接近全局最优。函数可能在参数空间的另一个完全不同的区域有一个深得多的谷，梯度下降从未访问过那里。未访问的原因可能是初始值太远、地形中分水岭的存在拦住了所有下降路径、或者那个谷的``吸引域''太小。
\item
  下界 \(f_{\inf}\) 在某有限点被取到。有些函数（如 \(e^{-x}\)、可分 logistic 回归）有下确界但在有限处永远达不到。
\item
  实现中实际使用的随机梯度或 mini-batch 梯度满足同一个确定性不等式。随机梯度梯度的方差引入额外的波动项——波动不仅使分析变复杂，在非凸情形下噪声还可能帮助逃离浅的局部极小和鞍点，但也可能把算法推出一个好的盆地。
\end{itemize}

这些缺口中的每一个，都不能靠``loss 一直在下降''这一个观察来补齐。每个缺口需要各自不同的额外假设：紧致性保证收敛子列存在，负曲率检测或随机噪声帮助逃离鞍点，PL（Polyak--Lojasiewicz）条件或其他 error bound 条件把梯度范数翻译成函数值误差界，随机梯度方差需要被单独上界控制。

\subsection{小梯度也可能来自逃向无穷}

下面这个一维例子把所有梯度假象都暴露出来：

\[
f(x)=\arctan x.
\]

它是光滑的——任意阶导数存在且有界，二阶导数 \(f''(x)=-2x/(1+x^2)^2\) 在 \(x\to-\infty\) 时趋于零，光滑常数 \(L\) 可在全实线上取为 1。有严格有限下界 \(-\pi/2\approx -1.5708\)。导数

\[
f'(x)=\frac1{1+x^2}.
\]

数值上追踪：在 \(x=0\) 时 \(f'(0)=1\)，在 \(x=-10\) 时 \(f'(-10)\approx 0.01\)，在 \(x=-100\) 时 \(f'(-100)\approx 10^{-4}\)，在 \(x=-1000\) 时 \(f'(-1000)\approx 10^{-6}\)。梯度在持续变小——不是因为接近了什么最优解，而是因为正在一片无限延伸的缓坡上越走越远，从 \(-10\) 到 \(-1000\)，函数值从 \(\arctan(-1000)\approx -1.5698\) 到 \(\arctan(-10000)\approx -1.5707\)，每步的增益越来越微薄。

现在假设你跑梯度下降，停止条件是梯度范数小于 \(10^{-5}\)。在 \(x\approx -300\) 处，\(f'(x)\approx 1.1\times10^{-5}\)，停止条件触发，算法报告``收敛''。此时的函数值约为 \(-1.567\)，离理论下确界 \(-\pi/2\approx -1.571\) 还差约 0.004。看起来不多？但``解''并不在一个有限点——它是 \(x\to-\infty\) 的极限行为。你没有一个可返回的参数向量可以拿来做预测。

可分 logistic 回归（没有加正则化时）存在完全同质的现象。当数据线性可分时，logistic 损失的下确界是零。但达到零需要 margin 对所有样本趋于正无穷——这要求 \(\norm{ w}\to\infty\) 沿某个特定方向。参数范数持续增长，训练损失持续递减逼近零，梯度持续变小。把这三条线索——损失下降、梯度变小、参数范数增长——分开看，每一条单看都像``训练在收敛''；合在一起看，结论是``参数在逃向无穷''。这解释了为什么在可分 logistic 回归中，不加正则的训练永远停不下来：梯度永远非零，参数越跑越远。

加 \(L_2\) 正则或提前停止是解决这类逃逸的标准做法。两者在可分 logistic 回归的极限中具有某种等价性。

在这种情形下，梯度范数衡量的是``当前地形有多平坦''，而不是``离一个有限的最优解有多近''。用一个只测量局部平坦度的指标来认证全局收敛，是维度错配——就像用车速表来判断离目的地还有多远。

\subsection{局部光滑性与回溯仍然有用}

回到实战场合：一个非凸的神经网络损失函数。不知道全局的 \(L\)——它可能在 \(10^2\) 到 \(10^6\) 之间波动，取决于你在参数空间的哪个区域。甚至局部 \(L\) 也随参数位置剧烈变化：某些层的梯度可能比另一些层大几个数量级（梯度消失和爆炸问题），某些方向曲率极大（批归一化层附近的 Hessian 谱很宽）。前面的下降理论——尤其是下降引理中依赖的全局光滑常数 \(L\)——在这种条件下等于废纸。

但局部光滑性就够了。虽然全空间的 supermum Lipschitz 常数可能极大，但在算法实际经过的局部邻域内，可能每一点都存在一个局部的 Lipschitz 控制。回溯线搜索正是为这种情况设计的：它不需要知道任何全局常数，只是沿着当前方向逐步试探——从某个初始猜测开始（比如上一次的步长），不满足 Armijo 条件就乘收缩因子（如 0.5），直到找到能用的步长。

回溯与凸性和全局 \(L\) 都无关。它只依赖局部信息：当前点的函数值和方向导数，以及沿方向试走一段后的函数值。三样东西的局部可得性在非凸情形中没有任何缩减。

但这里有一个关键的降级需要说清楚。在凸问题中，线搜索找到的下降步被凸性放大为全局进展——局部下降的量，通过凸函数的几何关系（梯度不等式），翻译为到最优解的欧氏距离的缩小。在非凸问题中，线搜索只认证了``这一步函数值确实下降了''——不附带关于最终目的地的任何声明。线搜索认证了方向的大致正确性，但正确性仅限于这一步的范围。下一步的方向又需要重新认证。

同样，梯度范数可以告诉你``一阶必要条件是否接近满足''——这是一个局部诊断。但它不应单独决定模型是否训练完成。以下几个信号需要一起看：

\begin{itemize}
\tightlist
\item
  参数变化量是否已经远小于参数自身的典型尺度？如果是，说明更新已经几乎没有效果；
\item
  函数值下降是否已经饱和？如果在过去几百步中损失几乎没有变化，继续训练的意义存疑；
\item
  Hessian 是否有显著的负特征值方向？如果有，说明当前位置连局部极小都不是——还有沿着负曲率方向的下降空间；
\item
  验证集风险是否还在改善？这是最诚实的指标，但与优化目标的关联是间接的；
\item
  还愿意投入多少额外计算预算换取可能微小的进一步提升？
\end{itemize}

这些指标回答的是不同维度的问题——收敛性（参数稳定了？）、最优性（梯度是否接近零？）、泛化（验证损失是否在降？）、和效率（是否还值得继续算？）。不要用其中任何一个单独做法官。
