一张用户对电影的评分表：十万行、两万列，大半格子空着。你想知道这堆数字背后是不是只有十几条主线——偏爱科幻、偏爱文艺、只看院线大片——足以把十万个人和两万部片子同时装进一个小得多的空间。手边最像样的结构工具是特征分解，可它第一步就写不下去：\(Av=\lambda v\) 要求等号两边住在同一个空间，而这张表把两万维送进十万维。

方阵这个前提，数据矩阵基本不满足。即便凑巧是方阵，特征分解还要求它可对角化，而且特征方向未必正交，\hyperref[sec:03-Linear-Algebra/05-Eigenvalues-and-Eigenvectors/03]{``对角化失败与 Jordan 形：独立特征方向不够时怎么办''}里的例子说明这并非罕见情形。

奇异值分解把这些门槛全部拿掉。它对任何矩阵成立，不问方不方、满不满秩、对不对称，交出的结构永远是同一句话：先把输入换到一组正交坐标，沿各坐标独立伸缩，再把结果摆进输出空间的另一组正交坐标。两侧的正交变换不改变长度，矩阵所有的放大、压缩与信息丢失，全部落在中间那串伸缩因子上——它们叫奇异值，并且从大到小排好了队。

排好队这件事比看上去要紧。奇异值一旦有序，``只保留前 \(k\) 个''就变成一个带最优性保证的动作：Eckart--Young 定理说，在所有秩不超过 \(k\) 的矩阵里，找不到比这个截断更接近原矩阵的。图像压缩、信号去噪、降维可视化、推荐系统里的矩阵补全、大模型微调时的低秩适配，共用的都是这一条定理。

队尾那些接近零的奇异值则从另一头制造麻烦。反解时要除以它们，于是数据里千分之一的噪声能把回归系数推出几十倍。伪逆、截断与岭回归处理的是同一件事：不去除以那些几乎为零的数。

\subsection{四篇的分工}

\begin{itemize}
\tightlist
\item \hyperref[sec:03-Linear-Algebra/07-SVD-and-Data-Applications/01]{``任意矩阵的奇异值分解''}：把``旋转—伸缩—旋转''这句几何观察坐实成矩阵等式，并读出一个映射保留了哪些方向、消灭了哪些方向。
\item \hyperref[sec:03-Linear-Algebra/07-SVD-and-Data-Applications/02]{``伪逆与病态问题''}：无解时取最小二乘、多解时取最小范数，两种情形被同一个公式统一；小奇异值则决定了这个解值不值得信。
\item \hyperref[sec:03-Linear-Algebra/07-SVD-and-Data-Applications/03]{``低秩近似：用少数方向保留主要结构''}：截断为什么最优，以及最优的前提有多窄。
\item \hyperref[sec:03-Linear-Algebra/07-SVD-and-Data-Applications/04]{``从数据矩阵到 PCA''}：同一个分解换成样本的语言，以及中心化这一步为什么不能省。
\end{itemize}

前置只有两处：对称矩阵的谱定理（\hyperref[sec:03-Linear-Algebra/06-Symmetric-and-Positive-Definite-Matrices/01]{``对称矩阵与谱定理：什么时候特征方向一定正交''}）给出推导的全部弹药，而\hyperref[sec:03-Linear-Algebra/03-Orthogonality/03]{``最小二乘：为无解方程寻找最佳近似''}提供第二篇要接手的问题。若你是带着一个具体困惑进来的，直接翻到最接近的一篇，再沿链接回补也行。
