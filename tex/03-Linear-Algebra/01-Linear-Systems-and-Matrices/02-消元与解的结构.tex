\section{消元与解的结构：从计算答案到看见约束}
\label{sec:03-Linear-Algebra/01-Linear-Systems-and-Matrices/02}

\subsection{一个让人愣住的方程组}

你面前有三个式子：

\[
\begin{aligned}
x+2y+z&=4,\\
3x+8y+5z&=18,\\
2x+4y+2z&=8.
\end{aligned}
\]

中学套路：从第一个式子解出 \(x=4-2y-z\)，代入第二个……等一下，你注意到了吗？第三个方程刚好是第一个的两倍：\(2x+4y+2z=8\) 就是 \(2(x+2y+z)=2\cdot4\)。第三个方程没有告诉你任何新东西——它只是把第一个方程换了个音量又说了一遍。

这就引出了一个你在中学可能没认真想过的问题：当你写下三个方程时，你以为自己有三个独立约束，但实际上你可能只有两个、甚至一个。方程的数量不等于信息的数量。

再来一个：

\[
\begin{aligned}
x+2y+z&=4,\\
3x+8y+5z&=18,\\
2x+4y+2z&=9.
\end{aligned}
\]

第三式左边仍是第一式的两倍，但右边是 9 而不是 8。前两式要求 \(2x+4y+2z=2\cdot4=8\)，第三式却坚持 \(2x+4y+2z=9\)。\(8=9\)？不可能。这个系统是自相矛盾的，答案不存在。

你可能会想：那我把方程都列出来，老老实实消元不就行了？对，但你需要一套系统化的方法，不仅能算出答案，还能在读矩阵的时候\emph{看见}哪些约束是独立的、哪些是多余的、哪些在互相打架。这套方法就是 Gaussian 消元。

\subsection{哪些操作不会偷偷改答案}

先确立底线：我们对增广矩阵 \([A\mid b]\) 可以做三类初等行操作，每一步都保证不改变解集：

\begin{enumerate}
\tightlist
\item 交换两行——显然，写方程的顺序无所谓；
\item 把一行乘以非零常数——等式两边同乘一个数，解不变；
\item 把一行的倍数加到另一行——两个等式左右分别相加，新等式是被旧等式蕴含的。
\end{enumerate}

每种操作都可逆：交换可以再交换回来，乘 \(c\neq0\) 可以乘 \(1/c\) 撤销，加的可以再减回去。可逆性意味着新旧方程组\emph{完全等价}——你没有丢失任何信息，也没有偷偷加入新信息。

把这三条记住就够了。它们的内在含义是：行操作改变的是你\emph{用什么方程来描述约束}，而不是约束本身。后面把行操作写成初等矩阵时，可逆性会变成初等矩阵的可逆性——那是同一件事的代数面孔。

\subsection{主元：新信息第一次出现的位置}

从左到右扫描矩阵，在你尚未处理的部分中找一个非零元素做\emph{主元}（pivot），用它把同列下方的元素全部消为零。重复这个过程，最终得到\emph{行阶梯形}（row echelon form, REF）。

用一个干净的 \(2\times2\) 看流程：

\[
\left(
\begin{array}{cc|c}
1&2&3\\
2&5&8
\end{array}
\right).
\]

第一列、第一行的 1 作为第一个主元。第二行减去第一行的两倍：

\[
\left(
\begin{array}{cc|c}
1&2&3\\
0&1&2
\end{array}
\right).
\]

第二行第二列的 1 是第二个主元。现在矩阵呈上三角形状，从下往上回代：第二行直接说 \(y=2\)，代入第一行得 \(x+4=3\)，即 \(x=-1\)。两个未知量各有一个主元，没有自由变量，解唯一。

再拿那个``三个方程但只有两个独立信息''的系统实践一下：

\[
\left(
\begin{array}{ccc|c}
1&2&1&4\\
3&8&5&18\\
2&4&2&8
\end{array}
\right).
\]

第一步：第一行第一列的 1 做第一个主元。\(R_2\leftarrow R_2-3R_1\)，\(R_3\leftarrow R_3-2R_1\)：

\[
\left(
\begin{array}{ccc|c}
1&2&1&4\\
0&2&2&6\\
0&0&0&0
\end{array}
\right).
\]

第二行第二列的 2 成为第二个主元。第三行全零——干净利落地告诉我们：第三个方程没有带来任何新信息。下一步消元时，第三行不会再提供主元。你可以继续用第二个主元消去它上方的元素，但这里暂时打住。

第三列没有主元出现，意味着 \(z\) 是自由变量。令 \(z=t\)，从第二行得 \(2y+2t=6\) 即 \(y=3-t\)，代入第一行得 \(x+2(3-t)+t=4\) 即 \(x=-2+t\)。全部解为

\[
\begin{pmatrix}x\\y\\z\end{pmatrix}
=
\begin{pmatrix}-2\\3\\0\end{pmatrix}
+t\begin{pmatrix}1\\-1\\1\end{pmatrix},
\quad t\in\R.
\]

你在中学可能学到``无穷多解''就停下来了。但现在你看到的不只是``有无穷多解''这个结论——你看到了一条穿过三维空间的直线，参数 \(t\) 告诉你沿哪个方向移动不改变方程的成立。

主元个数就是矩阵的\emph{秩}（rank）。在这个工作定义中，秩 = 消元后非零主元的个数。它衡量矩阵中真正独立的方向或约束数量——不是矩阵有多少行、多少列，而是有多少个``说了新东西''的位置。后面在向量空间单元中，我们会用列空间的维数给出更深刻的等价定义，并证明两者相等。

\subsection{自由变量从哪来：当消元消出了空行}

自由变量不是凭空出现的——它是某些列没抢到主元的结果。每出现一个没有主元的列，就多一个可以自由取值的维度。

再练一个三元系统，这次的阵势不同：

\[
\begin{aligned}
x+2y-z&=1,\\
2x+4y+z&=5,\\
-x-2y+2z&=0.
\end{aligned}
\]

增广矩阵：

\[
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
2&4&1&5\\
-1&-2&2&0
\end{array}
\right).
\]

做 \(R_2\leftarrow R_2-2R_1\)，\(R_3\leftarrow R_3+R_1\)：

\[
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
0&0&3&3\\
0&0&1&1
\end{array}
\right).
\]

注意：第二行和第三行的前两列都是零。第一列有主元（1），但第二列在前两行之后，剩余位置全是零——第二列没有主元。第三列在剩余两行中有非零元素（3 和 1），可以选 3 作为第二个主元。

用第二行（主元 3）消去第三行：\(R_3\leftarrow R_3-\frac{1}{3}R_2\)，得到

\[
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
0&0&3&3\\
0&0&0&0
\end{array}
\right).
\]

第三行全零——三个方程中有一个是冗余的。第二列没有主元，所以 \(y\) 可以自由选择。令 \(y=t\)，从第二行得 \(3z=3\) 即 \(z=1\)，代入第一行得 \(x+2t-1=1\) 即 \(x=2-2t\)。全部解：

\[
\begin{pmatrix}x\\ y\\ z\end{pmatrix}
=
\begin{pmatrix}2\\0\\1\end{pmatrix}
+t\begin{pmatrix}-2\\1\\0\end{pmatrix}.
\]

第一项是一个具体的解（令 \(t=0\) 即可），第二项告诉你：沿 \((-2,1,0)^{\trans}\) 方向移动不改变右端。解集是一条不穿过原点的直线——这是后面要讲的重头结构。

\subsection{全部解 = 特解 + 零空间：消元后浮现的结构}

上面的表达式不是偶然的。它揭示了一个在所有线性系统中普遍成立的模式。

先考虑\emph{齐次}系统 \(Az=0\)。满足它的全体向量构成 \(A\) 的\emph{零空间}（null space），记作 \(\mathcal N(A)\)。齐次解集有两个关键性质：如果 \(z_1,z_2\) 都是解，那么 \(A(z_1+z_2)=Az_1+Az_2=0\)，所以相加仍是解；如果 \(z\) 是解，\(c\) 是任意数，那么 \(A(cz)=cAz=0\)，数乘后仍是解。零空间对加法和数乘封闭——它是一条（或多条）穿过原点的``直线''或``平面''。

现在回到非齐次系统 \(Ax=b\)。假设你找到了一个特解 \(x_p\)（怎么找到的不重要，消元、猜测均可）。如果 \(z\in\mathcal N(A)\)，那么

\[
A(x_p+z)=Ax_p+Az=b+0=b.
\]

特解加上零空间中的任意向量仍然是解。反过来，如果 \(x\) 也是 \(Ax=b\) 的解，那么

\[
A(x-x_p)=Ax-Ax_p=b-b=0,
\]

所以 \(x-x_p\in\mathcal N(A)\)，即 \(x=x_p+z\) 对于某个 \(z\in\mathcal N(A)\) 成立。

因此，\emph{全体解}恰好是

\[
x_p+\mathcal N(A)=\{x_p+z:z\in\mathcal N(A)\}.
\]

非齐次解集是零空间的一个平移。它和零空间有完全相同的方向结构，但一般不过原点，因此不是子空间（零向量不在里面）。这个``特解 + 齐次解''的分解结构会在微分方程、优化约束、统计模型中反复出现——凡是遇到``一个特解加一个齐次解''的场合，你见到的都是同一个线性代数原理的不同面孔。

\subsection{矛盾怎样在消元中暴露：当 \(b\) 不在列空间}

现在看那个自相矛盾的系统。把上个例子的第三个方程右端从 0 改成 1：

\[
\begin{aligned}
x+2y-z&=1,\\
2x+4y+z&=5,\\
-x-2y+2z&=1.
\end{aligned}
\]

增广矩阵，做同样操作：

\[
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
2&4&1&5\\
-1&-2&2&1
\end{array}
\right)
\xrightarrow{R_2-2R_1,\; R_3+R_1}
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
0&0&3&3\\
0&0&1&2
\end{array}
\right).
\]

第二行说 \(0\cdot x+0\cdot y+3z=3\) 即 \(z=1\)。第三行说 \(0\cdot x+0\cdot y+1\cdot z=2\) 即 \(z=2\)。\(z\) 不可能同时是 1 和 2。继续消元：\(R_3\leftarrow R_3-\frac{1}{3}R_2\)：

\[
\left(
\begin{array}{ccc|c}
1&2&-1&1\\
0&0&3&3\\
0&0&0&1
\end{array}
\right).
\]

第三行变成了

\[
0\cdot x+0\cdot y+0\cdot z=1,
\]

也就是 \(0=1\)。荒谬的行一旦出现，系统就无解——不管你剩下的方程多么和谐。

用秩的语言表达相容条件：如果增广矩阵的秩大于系数矩阵的秩，即

\[
\rank(A)<\rank([A\mid b]),
\]

说明 \(b\) 这一列制造了一个新的``方向''——它是列空间够不到的地方。在上一节的列视角里，这等价于 \(b\notin\operatorname{Col}(A)\)。消元不过是把这个几何事实用代数语言报告出来：\([0\;\cdots\;0\mid c]\) 且 \(c\neq0\)。

\subsection{三种情形，一个统一判据}

对 \(m\times n\) 系统 \(Ax=b\)，消元之后按以下顺序判断：

\begin{itemize}
\tightlist
\item 先看是否有矛盾行：如果出现形如 \([0\;\cdots\;0\mid c]\) 的行且 \(c\neq0\)，系统无解——\(b\) 不在列空间中；
\item 如果没有矛盾行，再看主元覆盖情况：如果每个未知量列都有主元（秩 = 列数），每个变量都被``锁定''，解唯一；
\item 如果没有矛盾行，但存在没有主元的列（秩 < 列数），则对应的变量是自由变量——有无穷多解。
\end{itemize}

注意一个常见陷阱：方程数等于未知量数\emph{不等于}唯一解。方阵也可能有重复约束（行之间线性相关）导致秩不足，或矛盾行导致无解。唯一性取决于每一列是否都有主元，而不是方阵的尺寸。

齐次系统 \(Ax=0\) 永远至少有零解 \(x=0\)。若列数大于秩（必然存在非主元列），则存在自由变量，也就存在非零齐次解——零空间不平凡。

\subsection{行阶梯形与简化行阶梯形：两个层次的化简}

Gaussian 消元只消主元下方，然后通过回代求解。这得到行阶梯形（REF）。Gauss--Jordan 消元多走一步：把每个主元归一化为 1，并消去主元\emph{上方}的元素，最终得到简化行阶梯形（RREF）。

同一个矩阵的 RREF 是唯一的——不管你怎么选主元、按什么顺序消，最后的样子都一样。而 REF 不是唯一的（取决于主元的选取和缩放）。手工研究解的结构时，RREF 最直观——解可以直接从矩阵读出来。但实际在计算机上求解大型方阵时，停在 REF 并回代就够了：从 REF 到 RREF 的额外消元会多花计算量，而回代已经能完成任务。

有一个容易被忽略的区别：行操作保持方程的解集，也保持了行空间（各行张成的空间），因为行只被替换为彼此的可逆线性组合，张成范围不变。但行操作\emph{不}保持列空间中的具体列向量——消元会改变列的内容。所以你不能从化简后的矩阵里直接拿出原矩阵列空间的基；你只能根据 REF 中主元所在的列号，回到\emph{原矩阵}的对应列去取基向量。

\subsection{浮点计算中的陷阱：小主元放大误差}

以上讨论假设你在做精确算术——每个数字都是有理数，消元不产生舍入误差。但在计算机上，实数用有限精度的浮点数表示，每一步计算都可能引入微小的舍入错误。

举个有代表性的场景。假设你在消元过程中遇到一个很小但非零的候选主元——比如 \(10^{-16}\)。从纯代数的角度看，用它做主元毫无问题。但用它去除其他行会怎样？消元乘子将达到 \(10^{16}\) 的量级，原矩阵中量级正常的元素被放大后可能淹没有效数字。本来精确到小数点后 15 位的数字，经过这样的放大，很多有效位被丢弃了。

解决策略是\emph{部分选主元}（partial pivoting）：在当前列尚未处理的候选行中，挑选绝对值最大的元素换到主元位置。如果 \(10^{-16}\) 旁边有个 1.5，那就交换行，让 1.5 做主元。

这解释了为什么行交换不仅仅是应对零主元的保险措施——在浮点计算中，即使主元非零，只要它比同列其他候选小得多，你也应该换掉它。行交换是数值稳定性的基本防线。下一节讲到 \(PA=LU\) 分解时，\(P\) 记录的正是这些交换——有些是为了避开零主元，更多的是为了数值稳定。

\subsection{诚实边界：消元不能告诉你什么}

Gaussian 消元能精确判断有解还是无解、有几个自由变量，但它不直接告诉你这些事：

\begin{itemize}
\tightlist
\item 当系统接近奇异时（行列式接近于零），消元程序会顺利完成并给出一个``解''，但这个解对 \(b\) 中的微小扰动可能极端敏感。消元不会主动提醒你条件数很大——你需要额外的手段来评估解的可靠性。
\item 消元产生的主元序列依赖于你选主元的策略。不同的选主元方式产生不同的 REF，只有 RREF 才唯一。
\item 行变换不保留原矩阵的列空间，所以不要在化简后的矩阵上做列空间的推理——回到原矩阵，找到主元列。
\end{itemize}

这些不是消元的缺陷，而是它作为工具的定位：消元解决``结构是什么''的问题（有没有解、解的自由度），不解决``解有多可靠''的问题。后者属于数值分析的领地，需要条件数、向后误差分析等概念。
