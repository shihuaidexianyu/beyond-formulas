\section{逆矩阵与 LU 分解：撤销变换并复用消元}
\label{sec:03-Linear-Algebra/01-Linear-Systems-and-Matrices/03}

同一个电阻网络，拓扑不变，你要试上百组输入电压。同一个刚度矩阵，几十种载荷。同一批特征，模型每轮迭代换一个右端。这些场景有一个共同形状：\(A\) 固定不动，\(b\) 一直在换。

老实对每个 \(b\) 跑一遍消元，跑到第三遍你就会发现，前面的动作几乎一模一样——清第一列、清第二列，唯一变化的是最后那一栏。既然与 \(b\) 无关的工作占了绝大部分，它就该被拿出来只做一次。

有两条路。一条是求出 \(A^{-1}\)，此后每次写 \(x=A^{-1}b\)；另一条是把消元过程本身存成两个三角矩阵。第一条在公式里更好看，第二条在机器上更实用，而两者的落差恰好说明了一件事：``理论上的解法''和``可以交付的算法''不是同一个东西。

\subsection{什么样的变换可以撤销}

对方阵 \(A\in\R^{n\times n}\)，若存在 \(B\) 使得 \(AB=BA=I\)，就说 \(A\) 可逆，并把 \(B\) 记作 \(A^{-1}\)。唯一性一行带过：若 \(B_1\) 与 \(B_2\) 都合格，则 \(B_1=B_1(AB_2)=(B_1A)B_2=B_2\)。

不可逆是怎么发生的？看

\[
A=\begin{pmatrix}1&2\\2&4\end{pmatrix}.
\]

两列共线，列空间塌成一条直线，输出永远够不到平面上其余的点。与此同时 \((-2,1)^{\trans}\) 被送到零，于是 \(x\) 与 \(x+t(-2,1)^{\trans}\) 的像完全一致——不同的输入撞成了同一个输出。

一旦存在非零的 \(z\) 满足 \(Az=0\)，逆就不可能存在：假设 \(BA=I\)，那么 \(BAz\) 一方面等于 \(Iz=z\neq0\)，另一方面等于 \(B\cdot0=0\)。

于是下面这些说法其实在说同一件事。对 \(n\times n\) 方阵 \(A\)：

\begin{itemize}
\tightlist
\item \(A\) 可逆；
\item 消元后 \(n\) 列全部拿到主元，即 \(\rank(A)=n\)；
\item \(\nullsp(A)=\set{0}\)；
\item 对每个 \(b\in\R^n\)，\(Ax=b\) 有唯一解；
\item \(\det A\neq0\)。
\end{itemize}

把它们串起来的不是五段各自独立的证明，而是一句账：方阵的``压缩''和``够不到''是同一个量。消元每落空一列，零空间就多出一个方向；零空间多一个方向，值域就少一维，也就少覆盖 \(\R^n\) 的一块。所以没有压缩（零空间平凡）、没有遗漏（各列填满 \(\R^n\)）、主元不缺（满秩）三者必然同进同退，而行列式不过是把这笔账压成一个数——它为零，恰好表示体积被压扁了，见 \hyperref[sec:03-Linear-Algebra/04-Determinants/01]{``行列式与体积：线性变换是放大、翻转，还是压扁空间''}。逐条互推需要维数定理，等 \hyperref[ch:018]{``向量空间、基与线性变换''} 把工具备齐后会一次做完；此刻要带走的是它们为什么必须同真同假。

顺便清掉两个常见误会。逆矩阵不是逐元素取倒数：\(\begin{pmatrix}2&1\\1&1\end{pmatrix}\) 的逆是 \(\begin{pmatrix}1&-1\\-1&2\end{pmatrix}\)，跟原来的数字看不出倒数关系，因为求逆依赖的是各列之间的整体配合，不是单个格子的大小。另一个是复合的逆要反转顺序，

\[
(AB)^{-1}=B^{-1}A^{-1},
\]

先穿外套再穿雨衣，脱的时候得反着来；代数上把 \((AB)(B^{-1}A^{-1})\) 中间的 \(BB^{-1}\) 抵消掉即可。

\subsection{把消元存下来}

消元的每一步都能写成一次左乘。对单位矩阵做一次行操作，得到的矩阵叫初等矩阵；用它左乘任意矩阵，就在后者身上复制同一次行操作。比如``第二行减去第一行的两倍''对应

\[
E=\begin{pmatrix}1&0\\-2&1\end{pmatrix}.
\]

假定整个消元过程不需要换行，那么这条流水线就是 \(E_k\cdots E_2E_1A=U\)，\(U\) 上三角。每个 \(E_i\) 都可逆——减掉的加回来即可——移到等号右边得

\[
A=(E_1^{-1}E_2^{-1}\cdots E_k^{-1})U=LU.
\]

下三角矩阵的逆与乘积仍是下三角，所以 \(L\) 是下三角，对角线全为 1，非对角位置存的正是各步的消元乘子。这里藏着一个符号陷阱：\(E\) 里写的是乘子的相反数，\(L\) 里写的是乘子本身。实现时可以边消元边把乘子填进 \(L\) 那些原本要置零的位置，不额外占内存。

举个小到不会分心的例子。\(A=\begin{pmatrix}2&1\\4&3\end{pmatrix}\) 消一步得 \(U=\begin{pmatrix}2&1\\0&1\end{pmatrix}\)，用掉的乘子是 2，于是 \(L=\begin{pmatrix}1&0\\2&1\end{pmatrix}\)，验一下确实有 \(A=LU\)。

\subsection{分解一次，喂给多少右端都行}

有了 \(A=LU\)，方程 \(Ax=b\) 拆成两个三角系统：先由 \(Ly=b\) 前代求出 \(y\)，再由 \(Ux=y\) 回代求出 \(x\)。三角系统之所以好解，是因为每一行只剩一个新的未知量，从上往下（或从下往上）逐行填就完了。

\emph{昂贵的那一步在上面，只做一次；下面的通道可以走任意多个右端。右端越多，分摊到每次求解的成本越接近纯粹的三角回代。}
\end{center}

账算得很清楚。稠密 \(n\times n\) 矩阵的分解约需 \(\tfrac{2}{3}n^3\) 次浮点运算，此后每个右端只要两次三角求解，约 \(2n^2\) 次。\(n=1000\) 时前者是六亿多次，后者是两百万次，相差三百多倍。

那直接求逆呢？\(A^{-1}\) 本身约需 \(2n^3\) 次运算，是分解的三倍；算出来通常还比 \(L\) 和 \(U\) 稠密得多，存储和相乘都更贵；更要紧的是 \(A^{-1}b\) 在浮点下的误差一般大于直接做三角求解。所以数值软件里的求解例程从不先求逆。写 \(x=A^{-1}b\) 是记号，不是指令——这条区分在 \hyperref[sec:08-Numerical-Analysis/05-Numerical-Linear-Algebra/01]{``线性方程为何分解而不求逆''} 里会被彻底讲开。

\subsection{\texorpdfstring{换行不是例外：\(PA=LU\)}{换行不是例外：PA=LU}}

矩阵 \(\begin{pmatrix}0&1\\1&1\end{pmatrix}\) 明明可逆，却做不出无换行的 LU：左上角是 0，第一个主元根本取不到。交换两行即可解决。把这些交换记进一个置换矩阵 \(P\)（每行每列恰有一个 1，左乘的效果就是重排行），一般的分解写成

\[
PA=LU.
\]

解方程时两边同时左乘 \(P\)，得 \(LUx=Pb\)，仍旧是前代加回代，只是右端先被重排一次。

而且，正如上一节所说，实际发生的交换里多数不是为了救零主元，而是为了避开小主元。部分选主元每一列都把绝对值最大的候选换上来，哪怕当前主元在精确算术中完全够用。所以 \(P\) 记录的大半是出于精度的决定。

无换行的 \(A=LU\) 什么时候存在？充要条件是所有顺序主子式非零。对称正定矩阵满足得更彻底，还能进一步写成 \(LL^{\trans}\)，存储与运算各省一半，见 \hyperref[sec:03-Linear-Algebra/06-Symmetric-and-Positive-Definite-Matrices/03]{``Cholesky 分解：把正能量写成平方和''}。

稀疏矩阵那边，置换还要兼顾第三个目标。顺序选得不好，分解过程会在原本为零的位置上生出大量非零元，把稀疏的 \(L\) 与 \(U\) 填成稠密的，内存瞬间吃紧。真实的稀疏求解器要在数值稳定与控制填充之间折中，比``挑最大的''复杂得多。

\subsection{可逆不等于可信}

最后收一条边界。可逆是代数性质，回答``精确解是否存在且唯一''；对扰动敏不敏感是另一笔账，回答``算出来的这个解值不值得相信''。两者互不蕴含。

Hilbert 矩阵是标准反例，它的第 \(i\) 行第 \(j\) 列是 \(1/(i+j-1)\)：

\[
H_3=\begin{pmatrix}
1&1/2&1/3\\
1/2&1/3&1/4\\
1/3&1/4&1/5
\end{pmatrix}.
\]

行列式不为零，精确可逆，可它的各列几乎线性相关。给 \(b\) 加上百万分之一的扰动，解可以变一个数量级。更容易骗人的是残差：\(\norm{Ax-b}\) 很小，只说明你找到的 \(x\) 把 \(b\) 复现得不错，不说明它靠近真解。在病态系统上，残差小和解准是两回事，这是把``模型拟合得好''误当作``参数估准了''的线性代数版本。

衡量这种敏感性的量是条件数，即最大奇异值与最小奇异值之比。正式定义在 \hyperref[sec:08-Numerical-Analysis/01-Floating-Point-and-Error/03]{``条件数衡量问题本身的敏感性''}；至于矩阵干脆秩亏、逆根本不存在时该怎么办，要等 \hyperref[sec:03-Linear-Algebra/07-SVD-and-Data-Applications/02]{``伪逆与病态问题''}。

本章到此把 \(Ax=b\) 拆了三遍：写成矩阵、化成阶梯形、存成三角分解。撑起这三步的一直是同几个词——主元、秩、零空间、列空间——但它们眼下的定义还绑在消元这个具体过程上，换一种消法似乎就得重讲一次。下一章 \hyperref[ch:018]{``向量空间、基与线性变换''} 改从子空间、基与维数出发，回头证明这些词跟你怎么消元毫无关系。
