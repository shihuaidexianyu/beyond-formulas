\section{生成函数、矩母函数与特征函数}
\label{sec:05-Probability/07-Transforms-and-Bounds/01}

你手里有两个独立随机变量：\(X\sim\mathrm{Binomial}(n=100,p=0.3)\)，\(Y\sim\mathrm{Poisson}(\lambda=5)\)。想知道 \(X+Y\) 的分布。直接走卷积：对每个可能的和 \(k\)，

\[
P(X+Y=k) = \sum_{j=0}^{k} P(X=j)\,P(Y=k-j),
\]

二项式 PMF 乘 Poisson PMF，求和。单算一个 \(k\) 就要累加几十项，遍历所有可能取值要重复上百次。这还是两个变量。如果变量数量涨到五个、十个，卷积的嵌套层数能让最耐心的人放弃。

但有一个思路可以把``独立和''的困难从卷积变成乘法。这个思路的直觉来自对数：\(\log(ab)=\log a+\log b\)——把乘法变成加法。我们需要的变换是把独立随机变量的加法变成变换后函数的乘法。概率论里有三种常规武器，各管一片领地。

\subsection{概率母函数：离散计数的幂级数仓库}

若 \(X\) 取值在非负整数 \(\{0,1,2,\ldots\}\)，定义概率母函数（PGF）：

\[
G_X(z) = \E[z^X] = \sum_{k=0}^{\infty} P(X=k)\,z^k.
\]

这个构造把整张概率质量表打包成一个幂级数——\(z^k\) 的系数就是 \(P(X=k)\)。要取回某个概率，只需要读出对应次幂的系数：

\[
P(X=k) = [z^k]\,G_X(z).
\]

矩也能从 PGF 的导数里抠出来。在 \(z=1\) 处（\(G_X(1)=\sum_k P(X=k)=1\)，收敛不成问题）：

\[
G_X'(1) = \E[X],\qquad
G_X''(1) = \E[X(X-1)].
\]

于是方差随手可得：

\[
\Var(X) = G_X''(1) + G_X'(1) - (G_X'(1))^2.
\]

真正让 PGF 发光的是独立和的属性：

\[
G_{\sum_i X_i}(z) = \prod_i G_{X_i}(z).
\]

独立随机变量相加，对应它们的 PGF 相乘——卷积变成了多项式乘法。Bernoulli(\(p\)) 的 PGF 只有两项：\(1-p+pz\)。\(n\) 个独立 Bernoulli 之和的 PGF 因此是

\[
(1-p+pz)^n,
\]

按二项式定理展开，\(z^k\) 的系数正是 \(\binom{n}{k}p^k(1-p)^{n-k}\)——你不再需要逐个枚举求和次序，变换替你一步完成了所有组合计数。

这个机制的适用范围远比教科书上的例题广。你邀请七个朋友参加聚会，每个人到场的概率各不相同——\(p_1,\ldots,p_7\)。假设各人决定相互独立，到场总人数 \(N=\sum_j I_j\) 的 PGF 为

\[
G_N(z) = \prod_{j=1}^7 (1-p_j+p_j z).
\]

展开后 \(z^k\) 的系数精确给出恰有 \(k\) 人到场的概率。但这些 \(p_j\) 和独立性假设，是建模者自己拍进去的。一场大雨、一趟晚点的列车可能让三四个人同时缺席——这时把 PGF 乘在一起已经不能代表真实的总人数分布。PGF 把独立和的运算代价降到最低，但它不能替你检验独立是否成立。设备故障分析是同一个结构的专业版本：共享电源、温度或生产批次会让部件故障同时出现，每个部件的边缘 PGF 相乘之前，需要先确认独立性不是仅存在于假设里的一句声明。

PGF 的势力范围清晰：非负整数变量。超出这个范围——连续变量、可取负值的变量——它就无能为力了。

\subsection{矩母函数：指数权重下的矩提取器}

矩母函数（MGF）把 PGF 的 \(z^X\) 换成 \(e^{tX}\)：

\[
M_X(t) = \E[e^{tX}].
\]

如果这个期望在 \(t=0\) 的某个邻域内有限，逐阶求导就能拽出所有矩：

\[
M_X^{(k)}(0) = \E[X^k].
\]

机制是求导把 \(X\) 从指数里乘出来：\(M_X'(t)=\E[X e^{tX}]\)，代入 \(t=0\) 即得 \(\E[X]\)。二阶导同理：\(M_X''(0)=\E[X^2]\)，以此类推。``矩母函数''这个名字就是它功能的自述。

独立和转乘积的性质照旧：

\[
M_{X+Y}(t) = M_X(t)\,M_Y(t).
\]

独立 Gaussian 之和的 MGF 具有示范级的简洁。\(X\sim\mathcal N(\mu,\sigma^2)\) 的 MGF 为

\[
M_X(t) = \exp\Bigl(\mu t + \frac12\sigma^2 t^2\Bigr).
\]

两个独立 Gaussian 的 MGF 相乘，指数上的二次多项式相加，结果仍然是同一形式——只是 \(\mu\) 和 \(\sigma^2\) 分别累加。由 MGF 唯一决定分布（在 MGF 存在的范围内），和仍然是 Gaussian。

但这个``在 MGF 存在的范围内''是一个硬条件，不能一掠而过。MGF 不总存在。重尾分布常对一切 \(t>0\) 有 \(\E[e^{tX}]=\infty\)。典型病例是对数正态分布（\(\log X\sim\mathcal N(\mu,\sigma^2)\)）：所有正整数矩都有限，但 MGF 在任何正 \(t\) 处发散。

为什么？直觉演示：写 \(X=e^Y\)，\(Y\) 为 Gaussian，则 \(\E[e^{tX}] = \E[e^{t e^Y}]\)。\(t e^y\) 随 \(y\) 的增长是双重的——首先是 \(e^y\) 的指数，然后外面再包一层指数。Gaussian 密度自身的 \(e^{-y^2/(2\sigma^2)}\) 衰减根本追不上 \(e^{t e^y}\) 的爆炸，积分发散。不能见到``矩母函数''这个名字就假设它对任何分布都存在。

\subsection{特征函数：永远在场的 Fourier 变换}

特征函数用虚指数绕过了 MGF 的存在性陷阱：

\[
\varphi_X(t) = \E[e^{itX}],\qquad i^2=-1.
\]

因为 \(|e^{itX}|=1\) 对一切实数 \(t,X\) 成立，这个期望永远有限。不需要任何矩条件，不需要尾部假设。

乘法性质仍然完好：

\[
\varphi_{X+Y}(t) = \varphi_X(t)\,\varphi_Y(t).
\]

特征函数是 Fourier 变换在概率论中的形态，因此继承了 Fourier 分析的全部力量：唯一决定分布，有反演公式可以``逆变换''回密度或分布函数。中心极限定理的经典证明正是走的特征函数路线——把独立和的分布收敛转化为特征函数的逐点收敛。

矩的恢复需要额外条件。若 \(\E|X|^k<\infty\)，则

\[
\varphi_X^{(k)}(0) = i^k\,\E[X^k].
\]

注意区分：特征函数处处存在，和它处处可导，是两回事。可导性仍然需要相应的矩条件。

\subsection{累积量：把独立和变成加法}

如果 MGF 存在，对它取对数定义累积量生成函数：

\[
K_X(t) = \log M_X(t).
\]

独立和在这个层面实现彻底的线性：

\[
K_{X+Y}(t) = K_X(t) + K_Y(t).
\]

前两阶累积量恰好是均值和方差：由 \(M_X(0)=1\)，

\[
K_X'(0) = \frac{M_X'(0)}{M_X(0)} = \E[X],\qquad
K_X''(0) = \frac{M_X''(0)M_X(0)-M_X'(0)^2}{M_X(0)^2} = \Var(X).
\]

更高阶累积量捕捉分布的形状特征——偏斜、尾厚——这些是方差描述不了的信息。

Gaussian 的累积量生成函数只有两项：\(K_X(t)=\mu t+\frac12\sigma^2 t^2\)，三阶及以上累积量全部为零。一个分布的三阶及以上累积量为零，等价于它是 Gaussian——这是 Gaussian 在线性组合下保持 Gaussian 的代数根源：独立 Gaussian 之和的累积量生成函数仍然是二次多项式。

\subsection{三者怎么选}

三种变换是同一棵观念树上的三个杈，而非三套不相干的公式：

\[
M_X(t)=G_X(e^t),\qquad
\varphi_X(t)=G_X(e^{it}),
\]

只要相应表达式有意义。

选择指南：

\begin{itemize}
\tightlist
\item 非负整数计数、需要读系数或递推——PGF；
\item 需要矩、指数尾界，且零附近 MGF 确实存在——MGF；
\item 一般分布、Fourier 分析、严格的分布收敛证明——特征函数。
\end{itemize}

三种变换的价值不在公式本身，而在同一个操作：把概率论里的``加''变成代数里的``乘''。一旦完成这个转换，独立和的分析就从积分变成了多项式、指数或 Fourier 分量的乘法——工具变了，难度降了。

下一篇暂时不追求完整分布。我们会问一个更基本的问题：只知道零碎的低阶信息——一个均值、一个方差——能对一个坏事件的概率说出什么？
