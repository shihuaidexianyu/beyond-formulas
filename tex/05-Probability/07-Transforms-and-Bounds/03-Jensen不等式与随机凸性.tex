\section{Jensen 不等式与随机凸性}
\label{sec:05-Probability/07-Transforms-and-Bounds/03}

你骑自行车上班。从家到公司正好 \(1\) 公里。状态好时能以 \(30\) 公里/小时飞奔，状态差时只能骑 \(10\) 公里/小时。两种状态各占一半。

问：骑一次平均花多长时间？

直觉算法：平均速度 = \((30+10)/2 = 20\) km/h，距离 \(1\) km，所以时间 = \(1/20 = 0.05\) 小时 \(= 3\) 分钟。

但如果你真的去骑了：状态好那次花 \(1/30\approx 0.033\) 小时（2 分钟），状态差那次花 \(1/10 = 0.1\) 小时（6 分钟）。平均时间 = \((2+6)/2 = 4\) 分钟。

差了整整一分钟。不是四舍五入，是方向性低估——你用平均速度算时间，系统性地漏掉了速度波动对耗时的惩罚。

错在哪一步？你把``期望''穿过了 \(1/x\) 函数：

\[
\frac{1}{\E[X]} \neq \E\!\left[\frac{1}{X}\right].
\]

这个错误的方向不是中性的：\(\E[1/X]\) 总是大于等于 \(1/\E[X]\)。直觉上可以接受——低速端对时间的贡献更重，所以波动拉高了平均耗时。但为什么方向是确定的？为什么不会在某些分布下反过来？这需要一个关于函数弯曲方向的系统性结论。

\subsection{从平方开始：最简单的非平凡函数}

先别看 \(1/x\)，试一个更简单的函数：\(\varphi(x)=x^2\)。

设 \(X\) 以各半概率取值 \(1\) 和 \(3\)。那么 \(\E[X]=2\)。

\[
(\E[X])^2 = 2^2 = 4,\qquad
\E[X^2] = \frac{1^2+3^2}{2} = \frac{1+9}{2} = 5.
\]

先平均再平方得到 \(4\)，先平方再平均得到 \(5\)。平方函数的图像向上拱——在 \(x=1\) 和 \(x=3\) 之间，曲线的上升在加速。把两端的输出拉高之后，它们的平均比中点处的输出更大。

现在画一张图。横轴标上 \(1\) 和 \(3\)，在平方曲线 \(y=x^2\) 上找到 \((1,1)\) 和 \((3,9)\) 两个点，连一条弦。\(x=2\) 处的弦高是 \((1+9)/2 = 5\)，正是 \(\E[X^2]\)。\(x=2\) 处的曲线高是 \(2^2=4\)，正是 \((\E[X])^2\)。弦在曲线上方，所以``先映射再平均''比``先平均再映射''大。

你可以用同样的逻辑测试任意两个点和任意概率权重。对 \(p\) 和 \(1-p\) 两个概率，重心在 \(p\cdot 1 + (1-p)\cdot 3\)，弦上对应高度是 \(p\cdot 1 + (1-p)\cdot 9\)，曲线高度是 \((p\cdot 1+(1-p)\cdot 3)^2\)。无论 \(p\) 取何值，弦高都大于等于曲线高——等号只在 \(p=0\) 或 \(1\)（退化为单点）时成立。

再对比一个直线函数 \(\varphi(x)=ax+b\)：

\[
\E[aX+b] = a\E[X] + b = \varphi(\E[X]).
\]

期望完美穿过线性函数。问题只在非线性——曲线一旦弯曲，平均和映射的先后顺序就开始打架。

但``弯曲''两个字不够精确。\(x^3\) 也弯——在 \(x>0\) 向上拱（像平方），在 \(x<0\) 向下拱（像倒扣的碗）。对一个均值为零、在正负区域都有概率的变量，\(\E[X^3]\) 和 \((\E[X])^3=0\) 谁大谁小？如果正半轴的分布更重（右偏），则 \(\E[X^3]>0\)；如果负半轴更重（左偏），则 \(\E[X^3]<0\)；如果对称则恰好相等。方向不由``是否弯曲''决定，而是由``弯曲方向在整个支撑区间上是否一致''决定。

这就引出一对精确概念：凸函数和凹函数。

\subsection{凸的几何含义：弦永远在曲线上方}

函数 \(\varphi\) 称为凸的，如果对于定义域内任意两点 \(x,y\) 和任意 \(\lambda\in[0,1]\)，

\[
\varphi(\lambda x + (1-\lambda) y) \le \lambda\varphi(x) + (1-\lambda)\varphi(y).
\]

左边：先取两点的加权平均（位于 \(x,y\) 之间的某点），再映射到函数值。右边：先映射两个点到函数值，再取加权平均。凸函数意味着弦在曲线上方——先平均再映射不超过先映射再平均。

这就是 Jensen 不等式的离散原型。把两点推广到任意概率分布：用随机变量 \(X\) 的取值代替离散点，用概率权重代替 \(\lambda\)，得到

\[
\boxed{
\varphi(\E[X]) \le \E[\varphi(X)]
}.
\]

凹函数的不等号反过来：\(\varphi(\E[X]) \ge \E[\varphi(X)]\)。

一个函数是凹的当且仅当它的负是凸的，所以所有关于凸函数的陈述都可以通过取负号翻译为凹函数版本。

\subsection{为什么切线能证明这件事}

如果 \(\varphi\) 可微，凸性还有一个等价的解析定义：图像始终位于任意一点的切线之上。

\[
\varphi(x) \ge \varphi(m) + \varphi'(m)(x-m),\qquad \forall x,m.
\]

取 \(m = \E[X]\)，再令 \(x = X\) 是随机变量。两边取期望：

\[
\E[\varphi(X)] \ge \varphi(\E[X]) + \varphi'(\E[X])\cdot \E[X - \E[X]].
\]

\(\E[X - \E[X]] = 0\)，线性项整个消失，剩下 Jensen。

这条三行证明抓住了全部几何。切线是函数在 \(\E[X]\) 处的``线性化''——在这一点附近用直线逼近原函数。凸性保证真实函数值不低于线性逼近（直线兜不住曲线的上拱），所以函数值的平均不低于线性逼近的平均。而线性逼近的平均恰好等于 \(\varphi\) 在均值处的取值（因为线性函数的期望等于期望的线性函数）。二者一比对，不等号就出来了。

若 \(\varphi\) 不可微（比如 ReLU \(x\mapsto\max(0,x)\) 在原点有折角），用次梯度代替导数，同样的逻辑仍然成立。次梯度是所有支撑线斜率的集合，凸性等价于该集合非空。取任一次梯度 \(g \in \partial\varphi(\E[X])\)，不等式 \(\varphi(x) \ge \varphi(\E[X]) + g(x-\E[X])\) 成立，取期望即得 Jensen。

\subsection{五个例子，把不等号方向对号入座}

\textbf{平方}。\(\varphi(x)=x^2\)，二阶导数 \(\varphi''(x)=2>0\)，在整个实轴上严格凸。

\[
\E[X^2] \ge (\E[X])^2.
\]

两边减去 \((\E[X])^2\)：\(\Var(X) = \E[X^2] - (\E[X])^2 \ge 0\)。方差的非负性就是 Jensen 不等式用平方函数写出来的版本。这个事实太基本以至于你平常不会往 Jensen 上想，但它确实属于同一个几何。注意：平方函数的凸性还意味着标准差不是线性算子——\(\sqrt{\E[X^2]} \ge \E[|X|]\)（取平方根保持不等号），但 \(\sqrt{\E[X^2]}\)（RMS）与 \(\E[|X|]\)（平均绝对值）的关系取决于分布。

\textbf{倒数（正变量）}。对 \(x>0\)，\(\varphi(x)=1/x\)，\(\varphi''(x)=2/x^3>0\)，严格凸。

\[
\frac{1}{\E[X]} \le \E\!\left[\frac{1}{X}\right].
\]

回到自行车。不取一半取具体数据：假设你记录了一个月的骑行，速度分布是 \(10,15,20,25,30\) 各出现均匀概率。\(\E[X]=20\)。直接换算时间 \(1/\E[X]=0.05\) 小时 \(=3\) 分钟。但逐个算：\(1/10+1/15+1/20+1/25+1/30 = 0.1+0.0667+0.05+0.04+0.0333 = 0.29\)，除以 \(5\) 得 \(\E[1/X]=0.058\) 小时 \(\approx 3.48\) 分钟。半天差出半分钟，换成一年通勤足以累积出可感知的偏差。

根本原因是 \(1/x\) 在低速区陡得多。速度从 \(10\) 升到 \(15\)，单位距离耗时从 \(6\) 分钟降到 \(4\) 分钟，省了 \(2\) 分钟；从 \(25\) 升到 \(30\)，耗时从 \(2.4\) 分钟降到 \(2\) 分钟，只省 \(0.4\) 分钟。同样的绝对速度差，在低速端对时间的冲击大得多。所以波动在时间维度上有不对称的影响力——低速样本把你的平均耗时往上拽的力量大于高速样本往下拉的力量。

类似的逻辑适用于：固定大小文件的传输时间（带宽波动\(\to\)平均传输时间大于直接用平均带宽的估计）、固定工作量的完成时间（效率波动\(\to\)平均完成时间被低效日拉长）、并联电阻的等效阻值（电阻值波动\(\to\)平均等效电阻大于直接用平均电阻的倒数公式计算的结果）。

但注意：这些场景要求``路程固定''或``文件大小固定''。如果每次骑行距离不同，或者传输的文件大小与速率相关，分析框架就变了——那时你不再是在比较 \(1/\E[X]\) 和 \(\E[1/X]\)，而是在比较不同的总耗时期望。Jensen 只对``同一批 X 的两种计算顺序''负责。

\textbf{对数}。\(\varphi(x)=\log x\)（\(x>0\)），\(\varphi''(x)=-1/x^2<0\)，严格凹。

\[
\E[\log X] \le \log \E[X].
\]

这个不等式在信息论里反复出现。最大似然估计的 Jensen 下界、EM 算法的单调性保证、变分推断的 ELBO 推导——每一次你用到 \(\log\) 的凹性时，都是在套用 Jensen。

一个具体数字：\(X\) 等概率取 \(0.1\) 和 \(10\)。\(\E[X]=5.05\)，\(\log\E[X]\approx 1.62\)。\(\E[\log X] = (\log 0.1 + \log 10)/2 = (-2.30 + 2.30)/2 = 0\)。果然 \(0 \le 1.62\)。对数把大值压扁、把小值放大（\(\log 0.1 = -2.30\)，但 \(0.1\) 本身只偏离均值 \(4.95\)；\(\log 10 = 2.30\)，而 \(10\) 偏离均值 \(4.95\)——对数对乘法关系的反映是线性的），小值在 log 空间里负向很远，把对数均值拉低。

\textbf{指数}。\(\varphi(x)=e^x\)，\(\varphi''(x)=e^x>0\)，严格凸。

\[
e^{\E[X]} \le \E[e^X].
\]

右端正是矩母函数 \(M_X(t)\) 在 \(t=1\) 处的值。这个不等式说的是：矩母函数至少不会小于``均值处的指数函数值''。下一节 Chernoff 方法会反过来利用 \(M_X(t)\)：先用指数函数放大偏差，再用 Markov 压住尾部，最后优化指数参数 \(t\)。Jensen 给了 \(M_X(t)\) 的一个下界，Chernoff 把它变成精确的尾部控制。

这条不等式也是为什么对数正态变量的均值不同于取对数的均值：若 \(Y=e^X\) 且 \(X\sim\mathcal{N}(\mu,\sigma^2)\)，则 \(\E[Y]=e^{\mu+\sigma^2/2} > e^{\mu} = e^{\E[X]}\)。\(e^{\mu}\) 是几何平均性质的量（中位数），\(\E[Y]\) 被波动放大了 \(e^{\sigma^2/2}\) 倍，Jensen 正好抓住了这个放大——且具体多少由指数凸性和方差共同决定。

\textbf{算术--几何平均}。令 \(X\) 等概率取正数 \(x_1,\ldots,x_n\)。对凹函数 \(\log\) 写出 Jensen：

\[
\frac{1}{n}\sum_{i=1}^n \log x_i \le \log\!\left(\frac{1}{n}\sum_{i=1}^n x_i\right).
\]

两边取指数：

\[
\left(\prod_{i=1}^n x_i\right)^{\!1/n} \le \frac{1}{n}\sum_{i=1}^n x_i.
\]

几何平均不超过算术平均。几百年来被独立发现并重新证明的不等式，只是 Jensen + \(\log\)。

数值验证：\(2\) 和 \(8\)。算术平均 \(=5\)，几何平均 \(=\sqrt{2\times 8}=4\)。\(4<5\)，因为 \(\log 2+\log 8=\log 16\)，平均后是 \(\frac{1}{2}\log 16=\log 4\)；而 \(\log 5 > \log 4\)。三数版：\(2,4,8\)。算术平均 \(=14/3\approx 4.67\)，几何平均 \(=\sqrt[3]{64}=4\)。对数均值 \(=(\log 2+\log 4+\log 8)/3 = (\log 64)/3 = \log 4\)，所以几何平均是 \(4\)，仍小于算术平均 \(4.67\)。每次你需要证明某个平均不等式，先问：函数是凸是凹？如果正好对上号，Jensen 当场给出结论。

\subsection{何时取等：不只是常数那么简单}

若 \(\varphi\) 严格凸（图像上没有任何直线段），Jensen 取等通常要求 \(X\) 几乎必然为某个常数。只要分布质量散落在至少两个不同的点上，连接它们的弦就严格高于曲线，从而 \(\E[\varphi(X)] > \varphi(\E[X])\)。

但``通常''不等于``总是''。若 \(\varphi\) 在某段区间上是线性的——比如 \(\varphi(x)=\max(x,0)\) 在 \(x\le 0\) 的半条线上恒为零——而 \(X\) 的支撑又恰好完全落在那段线性区里，即使 \(X\) 不是常数也可能取等。完整说法要同时看函数的弯曲区域和分布的支撑范围：等号 \(\varphi(\E[X]) = \E[\varphi(X)]\) 成立当且仅当 \(\varphi\) 在 \(X\) 的支撑的凸包上几乎必然是仿射（线性）的。

反过来，凹函数的 Jensen 取等逻辑对称：函数图像在分布支撑上的线性程度决定了不等号能否变等号。

\subsection{条件 Jensen：把信息放进去}

条件期望版本的 Jensen 为

\[
\varphi(\E[X\mid Y]) \le \E[\varphi(X)\mid Y]
\]

几乎必然成立。这里有时间顺序的味道：你有了信息 \(Y\) 之后，先求最优预测 \(\E[X\mid Y]\)，再对预测做凸映射。这个结果不会超过``先对原始 \(X\) 做凸映射、再基于 \(Y\) 求条件期望''。条件期望是最小均方误差预测，凸映射之后再预测会把不必要的变化引入。

两边再取一次全期望。左端外层的 \(\E\) 穿过了 \(\varphi\)——又多一层 Jensen。内层是 \(\E[\varphi(X)\mid Y]\) 取全期望就回到 \(\E[\varphi(X)]\)。于是无条件 Jensen 作为条件 Jensen 的特例恢复出来。这条路径也说明了条件 Jensen 是更基础的形式：无条件不等式是条件版本对平凡 \(\sigma\)-代数取全期望的结果。

条件 Jensen 在条件方差分解（\(\Var(X)=\E[\Var(X\mid Y)]+\Var(\E[X\mid Y])\)，其中证明的第一步对 \(\E[X\mid Y]\) 使用 Jensen 的平方版本）以及信息论的条件熵、Rao--Blackwell 定理的证明中都是核心一步。

\subsection{别只凭函数形状猜方向}

使用 Jensen 之前必须确认四件事：

\begin{itemize}
\tightlist
\item
  函数在 \(X\) 的整个取值区间上是否一致凸或一致凹。\(x^3\) 在含正负值的区间上就过不了这一关——它在 \(x<0\) 凹、在 \(x>0\) 凸，拐点在零。
\item
  所需期望是否存在。若 \(\E[\varphi(X)]=\infty\)，不等式虽然形式上成立（\(+\infty \ge\) 任何有限数），但不再提供有用的定量信息。
\item
  \(X\) 几乎必然落在函数的定义域内。\(\log X\) 要求 \(X>0\) a.s.，\(1/X\) 要求 \(X\neq 0\) a.s.。若取值偶尔跑出定义域，期望可能根本不存在。
\item
  你的实际问题是否真能写成 \(\varphi(\E[X])\) 与 \(\E[\varphi(X)]\) 的比较形式。有些场景天然是``均值加惩罚项''的结构（如方差 = 二阶矩减去一阶矩的平方），这时 Jensen 直接给出符号；有些场景需要在中间加一步变换才能对上 Jensen 的模具。
\end{itemize}

一个常见的陷阱：以为``函数有弯就适用 Jensen''。\(x^3\) 在 \(x=0\) 附近改变弯曲方向——假如分布均值为零且对称，则 \(\E[X^3]=0=(\E[X])^3\)，不是 Jensen 的结论，只是对称抵消了。换个偏斜分布，方向得重新看密度重心落在凸区还是凹区。对于只在部分区间凸、部分区间凹的函数，没有统一不等号——你只能把定义域切分成凸段和凹段分别讨论。

\subsection{一个金融风险中的 Jensen：凸损失惩罚不确定性}

考虑一个简单的投资场景。你投资 \(1\) 元到一个有风险的资产，明年的随机回报率为 \(R\)。你的效用函数是 \(u(x) = \log x\)（对数效用，相对风险厌恶系数为 \(1\) 的 CRRA 效用），你关心最终财富的期望效用的确定性等价。

确定性等价 \(C\) 是满足 \(u(C) = \E[u(W)]\) 的那个确定的财富量，其中 \(W = 1+R\) 是随机最终财富。对于凹效用函数，Jensen 给出

\[
\log C = \E[\log W] \le \log \E[W],
\]

即 \(C \le \E[W]\)。不确定性让你``感受到''的财富低于实际期望财富。两者的差 \(\E[W]-C\) 就是风险溢价——你愿意放弃多少期望收益来换取确定性。

如果 \(W\) 等概率取 \(0.5\) 和 \(2.0\)（即 \(R\) 等概率取 \(-50\%\) 和 \(+100\%\)），\(\E[W]=1.25\)。\(\E[\log W] = (\log 0.5 + \log 2.0)/2 = (\log 1.0)/2 = 0\)，所以 \(C = e^0 = 1\)。风险溢价为 \(0.25\)——你愿意放弃 \(20\%\) 的期望收益来回避这个波动。这 \(0.25\) 就是 Jensen 不等式凹性的量化：\(\log\) 把大收益压扁、把大亏损放大的不对称性，直接转化为愿意支付的保险费。

类似地，如果效用函数是凸的（风险偏好），相应的 Jensen 方向会给波动赋予正价值——赌徒之所以进入赌场，部分可以用凸效用函数的 Jensen 来描述（但现实中更准确的模型包括概率权重扭曲，不仅仅是不等号方向的问题）。

\subsection{Jensen 的威力：一条不等式，多个领域的骨架}

回顾 Jensen 不等式涉足的领域：

\begin{itemize}
\tightlist
\item
  \textbf{概率论}：方差非负、矩母函数下界、条件方差分解。在条件 Jensen 中嵌套全期望公式得到 \(\E[\varphi(\E[X|Y])] \le \E[\varphi(X)]\)——Rao--Blackwell 定理的证明直接依赖这个方向。
\item
  \textbf{信息论}：\(\E[\log X] \le \log\E[X]\) 是 KL 散度非负（Gibbs 不等式）的 Jensen 视角：\(D(P\|Q) = \E_P[\log(P/Q)] = -\E_P[\log(Q/P)] \ge -\log\E_P[Q/P]\)——但这不够紧，实际证明需要凸性更强的处理。更直接的 Jensen 应用在互信息的非负性和数据处理不等式。
\item
  \textbf{优化}：凸函数加期望的 Jensen 保证了随机梯度下降中损失函数值在平均意义下不增，为收敛分析提供基础。EM 算法的每一步最大化 \(Q\)-函数正是基于对数似然的 Jensen 下界构造。
\item
  \textbf{经济学}：风险厌恶（凹效用 \(\to\) 风险溢价为正）、期权定价的 Jensen 不等式项（凸 payoff 的期望不低于期望 payoff——解释了为什么波动率越高期权越贵）。
\item
  \textbf{机器学习}：变分自编码器（VAE）的 ELBO 中的重构误差期望和 KL 正则项；策略梯度方法中 baseline 的无偏性依赖于线性函数的 Jensen 退化情况。
\end{itemize}

Jensen 不等式不是一条孤立的公式，而是一个方向性的认识工具。一旦你在一个系统中识别出了``凸函数''和``取期望''这两个元素，不等号方向就被锁定，剩下的只是具体计算。反过来，如果你发现实际不等号方向与 Jensen 预测的相反，那说明要么函数在支撑区间上并非一致凸/凹，要么你正在比较的两个量并不是 \(\varphi(\E[X])\) 和 \(\E[\varphi(X)]\) 的关系——排查这两种可能性本身就能帮你理清问题的结构。

下一节的设计正好用到了 Jensen 给出的方向：\(e^{\E[tX]} \le \E[e^{tX}]\) 告诉你矩母函数至少是指数均值。Chernoff 方法反过来把这件事当武器——用指数放大偏差，用 Markov 卡住尾部概率，再优化那个被放大出来的指数参数 \(t\)。Jensen 负责告诉我们指数函数是凸的，Chernoff 负责把凸性变成尾部指数衰减的证明。拿到一个凸函数用 Markov，再对自由参数求极值——这条思路从 Jensen 出发，贯穿了整个高级概率不等式体系。
