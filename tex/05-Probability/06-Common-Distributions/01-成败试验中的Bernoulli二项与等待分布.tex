\section{成败试验中的 Bernoulli、二项与等待分布}
\label{sec:05-Probability/06-Common-Distributions/01}

一条生产线。每加工一个零件，合格的概率是 p，不合格的概率是 \(1-p\)。任何人都可以在抽检记录本上查到这两个数字。但你发现，不同质检员拿同一批数据会算出完全不同的分布——因为他们问的问题不一样。

质检员 A：``我抽检 100 个，其中有多少不合格？''
质检员 B：``我持续抽检，直到发现第一个不合格品。大概要检多少个？''
质检员 C：``我持续抽检，直到攒够 5 个不合格品。一共要检多少个？''

同一个 p，同一批零件。不同的问题，不同分布的答案。这是初学分布时最容易踩到的坑——看公式名字而不是背后的停止规则。

\subsection{一次试验：Bernoulli——一切计数的原子}

一个随机变量 X，只取两个值：

\[
X=
\begin{cases}
1, & \text{成功（合格）},\\
0, & \text{失败（不合格）}.
\end{cases}
\]

这就是 Bernoulli(\(p\)) 分布：

\[
P(X=1)=p,\qquad P(X=0)=1-p.
\]

太简单了，简单到让人觉得不配叫``分布''。但它是一切后续计数的原子。后面会看到：成功总数是若干 Bernoulli 之和，等待时间也可以从 Bernoulli 序列中读出来。

因为是示性变量（\(X^2=X\)），均值和方差快速得到：

\[
\E[X]=p,
\]

\[
\Var(X)=\E[X^2]-(\E[X])^2 = p - p^2 = p(1-p).
\]

方差在 \(p=0.5\) 时最大，在 \(p\to0\) 或 \(p\to1\) 时趋于零——当结果几乎确定时，没什么可波动的。

\subsection{固定做 n 次，数成功：Binomial}

质检员 A 的问题。独立重复 n 次 Bernoulli 试验，每次成功概率相同为 p。令 \(S_n\) 为成功总次数。

为什么不是简单的 \(p^n\) 或 \(np\)？因为 \(S_n=k\) 可以发生在很多不同的位置组合上。考虑 \(k=1,n=3\)：成功可以是第 1 次、第 2 次或第 3 次。每种具体序列的概率都是 \(p^k(1-p)^{n-k}\) = \(p(1-p)^2\)。有 \(\binom{3}{1}=3\) 种不同的位置选择方式。

推广到任意 k：n 次试验中选出 k 个位置放成功，其余 n-k 个位置放失败。每种特定成功-失败序列的概率是 \(p^k(1-p)^{n-k}\)。不同序列对应的事件互斥。因此

\[
P(S_n=k)=\binom{n}{k}\,p^k(1-p)^{n-k},\qquad k=0,1,\ldots,n.
\]

这就是 Binomial(\(n,p\)) 分布。\(\binom{n}{k}\) 数的是成功位置的选择方式，\(p^k(1-p)^{n-k}\) 是任意一种指定模式的概率。

三个前提缺一不可：

\begin{itemize}
\tightlist
\item
  试验次数固定为 n——不能中途因为前面结果好或坏就停止；
\item
  每次只有两个可能结果——成功或失败；
\item
  各次独立且成功概率相同。
\end{itemize}

均值和方差直接来自独立 Bernoulli 之和的性质：

\[
\E[S_n]=np,\qquad
\Var(S_n)=np(1-p).
\]

如果各次试验的成功概率不同但仍独立——比如不同零件型号的合格率不同——总成功次数就不再是标准 Binomial，而是一个更复杂的分布，叫 Poisson-binomial。如果抽样不放回——比如从一批有限产品中逐个抽取——各次成功概率会随历史改变，引出下一节的 Hypergeometric 分布。

\subsection{等到第一次成功：Geometric——随机的是试验次数}

质检员 B 的问题。不再固定试验次数，而是持续试验直到第一次成功。随机变量 T 记录成功出现时的试验编号。

要让 T = k：前 k-1 次全是失败，第 k 次成功。每次独立，概率直接相乘：

\[
P(T=k)=(1-p)^{k-1}p,\qquad k=1,2,\ldots
\]

期望和方差：

\[
\E[T]=\frac1p,\qquad
\Var(T)=\frac{1-p}{p^2}.
\]

期望的直觉：如果 \(p=0.2\)，平均五次试验有一次成功，所以平均要等五次才能碰到第一次成功。p 越小，等得越久；p 接近 1，几乎第一次就成功。

这里有个让很多人掉坑里的参数化问题。有些教科书定义的 Geometric 随机变量不是试验次数 T，而是成功之前的失败次数 \(F=T-1\)。F 的支撑从 0 开始，PMF 是 \((1-p)^k p\)（\(k\ge0\)），期望是 \((1-p)/p\)。两个公式长得像，但随机变量含义不同。用之前必须核实：你的变量代表的是``第几次试验成功''还是``成功前失败了几次''。写答案要注明是哪种参数化，一个含糊就能让正确公式变成错误答案。

Geometric 分布有一个独特的性质——无记忆性：

\[
P(T > s+t \mid T > s) = P(T > t).
\]

验证只需要一步。先求生存函数：\(P(T>k)=(1-p)^k\)——前 k 次全部失败。然后

\[
P(T>s+t\mid T>s)=\frac{P(T>s+t)}{P(T>s)}
=\frac{(1-p)^{s+t}}{(1-p)^s}
=(1-p)^t
=P(T>t).
\]

已经连续失败了 s 次，接下来还要等多久的分布，和一个全新的过程从头开始等，一模一样。过去的失败不累积任何``该成功了''的势头——每次试验都是独立的、同分布的，历史在概率层面被完全擦除。

这个性质在离散分布中只有 Geometric 满足。它是好的：如果你模拟的等待过程真的无记忆（比如理想硬币、理想骰子），它完全适用。它也是危险的：现实中的等待——设备老化、操作员学习、队列积压——往往有记忆。用无记忆模型去拟合有记忆过程，尾部预测会严重失准。

\subsection{等到第 r 次成功：Negative Binomial}

质检员 C 的问题。耐心等，直到第 r 次成功出现。记 \(T_r\) 为此时已进行的试验总数。

要在第 k 次试验时恰好达到第 r 次成功，必须满足两个条件同时成立：

\begin{itemize}
\tightlist
\item
  前 \(k-1\) 次试验中恰好有 \(r-1\) 次成功；
\item
  第 k 次试验是成功。
\end{itemize}

前 \(k-1\) 次中 \(r-1\) 次成功的位置选择有 \(\binom{k-1}{r-1}\) 种。每种序列概率为 \(p^{r-1}(1-p)^{(k-1)-(r-1)} = p^{r-1}(1-p)^{k-r}\)。再乘最后一次成功的 p：

\[
P(T_r=k)=\binom{k-1}{r-1}\,p^r(1-p)^{k-r},\qquad k=r,r+1,\ldots
\]

这就是 Negative Binomial 分布。名字来自二项式系数的推广形式 \((1-p)^{-r}\) 的级数展开，但理解它的最好方式不是名字，而是它的构造逻辑。

均值和方差：

\[
\E[T_r]=\frac{r}{p},\qquad
\Var(T_r)=\frac{r(1-p)}{p^2}.
\]

把 \(r\) 个独立且同分布的 Geometric 等待时间加在一起会怎样？每次成功之后，等待下一次成功的过程和第一次完全一样——独立的 Geometric 序列。所以

\[
T_r = G_1 + G_2 + \cdots + G_r,
\]

其中每个 \(G_i\) 独立且服从 Geometric(\(p\))。和的期望是期望的和：\(r \cdot (1/p) = r/p\)。和的方差（独立时）是方差的和：\(r\cdot(1-p)/p^2\)。这和直接计算的结果吻合——两种推导相互印证。

同样，Negative Binomial 也有参数化陷阱。部分文献让变量记录成功前的失败次数 \(F=T_r-r\)，支撑从 0 开始。使用前反复检查变量定义和支撑范围，是跟这个分布家族打交道的必要习惯。

\subsection{四个分布的选择：停止规则决定一切}

面对成败试验场景时，先问这一个问题：停止规则是什么？

\begin{itemize}
\tightlist
\item
  \textbf{只看一次结果}：Bernoulli。连试都不算多试，就是一次。
\item
  \textbf{固定做 n 次，数成功次数}：Binomial。n 是你定的，随机的是成功次数。
\item
  \textbf{做到第一次成功，数试验次数}：Geometric。成功在哪次出现，不确定。
\item
  \textbf{做到第 r 次成功，数试验次数}：Negative Binomial。相当于 r 个 Geometric 串联。
\end{itemize}

初学时最常见的一类错误是把``有 n 次试验，其中有 k 次成功''（Binomial 场景）和``等到 n 次成功，其间做了 k 次试验''（Negative Binomial 场景）搞混。前者固定 n，随机 k；后者固定 k（成功数），随机 n（试验数）。虽然都用到了 p 和计数，两个随机变量的角色完全不同。

同一系列试验，不同的问题，不同的分布。P 是同一个 P，但你的观测方案（停止规则）定义了随机变量的含义——也定义了你要用哪个公式。
