\section{概率公理与概率空间}
\label{sec:05-Probability/01-Probability-Spaces/02}

你正在设计一个桌游。玩家掷两枚骰子，你需要给每种点数组合分配一个``出现的机会''。你先凭感觉列了几条规则：

\begin{itemize}
\tightlist
\item 每个结果的机会在 \(0\) 和 \(1\) 之间；
\item 所有结果的机会加起来等于 \(1\)；
\item 如果两个事件不可能同时发生，它们的机会可以相加。
\end{itemize}

听起来合理。但你很快发现一个问题：当样本空间有无穷多个结果时——比如``反复掷骰直到第一次出现 \(6\)，等待次数是几''——你的第三条规则只覆盖了有限个事件的相加，而等待次数可以是任意正整数，对应无穷多个互不相容的事件。你的直觉规则够不够用？如果不够，缺了什么？

\subsection{从一个具体困境出发}

先回到一个有限但能暴露结构性问题的小例子。假设你同意规则可以自己定，但必须自洽。你写下以下几条：

\begin{enumerate}
\tightlist
\item \(P(A)\ge0\) 对所有事件 \(A\) 成立。
\item \(P(\Omega)=1\)。
\item 若 \(A\cap B=\varnothing\)，则 \(P(A\cup B)=P(A)+P(B)\)。
\item 若 \(A\subseteq B\)，则 \(P(A)\le P(B)\)。
\item \(P(A^c)=1-P(A)\)。
\end{enumerate}

这五条看上去都很自然，每一条都来自日常直觉。但仔细想想：第4条能从前面几条推出来吗？第5条呢？如果它们已经是前三条的推论，你就是在重复声明同一个东西，而不是真正扩充了规则体系。更糟的是，如果有两条互相矛盾，你写的规则集合在逻辑上就炸了。

你可能会想：那我干脆只保留前三条，后面需要用的时候临时补。但临时补的规则会不会和已经成立的规则冲突？没法保证。

Kolmogorov 在1933年给出的答案是：只需要三条公理。其他的都是定理，可以从这三条机械地推出来。他用的是第三条的一个强化版——不只允许有限个互斥事件相加，允许可数无穷个。

\subsection{概率空间的三个零件}

在给出三条公理之前，先把概率模型的三个零件看清楚。一个概率空间写作

\[
(\Omega,\mathcal F,P).
\]

三个符号各管一件事。

\(\Omega\) 是样本空间——你脑子里所有可能发生的基本结果。掷一枚骰子，\(\Omega=\{1,2,3,4,5,6\}\)；测量明天中午的温度，\(\Omega\) 是某个实数区间。

\(\mathcal F\) 是事件的集合——但这里有一个微妙的点：你并不总能给 \(\Omega\) 的每一个子集都定义概率。在有限样本空间里没问题，取 \(\mathcal F=2^\Omega\)，所有子集都算事件。连续空间就出事了：如果在 \([0,1]\) 上要求每一个子集都有一个与长度概念相容的概率，数学上做不到。所以退一步，把 \(\mathcal F\) 取为一个 \(\sigma\)-代数：对补集封闭，对可数并封闭，并且包含空集和全集。这保证了只要你能讨论 \(A\) 的概率，你也能讨论``非 \(A\)''、``\(A\) 或 \(B\)''、``无穷多个事件的并''的概率。

初学时你不必把 \(\sigma\)-代数的全部性质背下来。但要在心里留一个位置给 \(\mathcal F\)：它规定了在你的模型里，哪些问题是``有概率可言的''。

\(P\) 是一个从 \(\mathcal F\) 到 \([0,1]\) 的函数，给每个事件分配一个数。这就是概率。

\subsection{三条公理：只有三条}

概率测度 \(P\) 满足：

\begin{enumerate}
\item
  \textbf{非负性}

  \[
  P(A)\ge0.
  \]

  概率不可能是负数。你没法说某个事件有``\(-0.3\) 的发生机会''。

\item
  \textbf{规范化}

  \[
  P(\Omega)=1.
  \]

  样本空间里总有一个结果会发生。给整个空间分配概率 \(1\)，相当于把总预算定为 \(1\)。如果你把 \(\Omega\) 想象成一块面积为一的正方形，每个事件就是其中的一块区域。

\item
  \textbf{可数可加性}：若 \(A_1,A_2,\ldots\) 两两互斥，则

  \[
  P\left(\bigcup_{i=1}^{\infty}A_i\right)
  =\sum_{i=1}^{\infty}P(A_i).
  \]

  这里的关键词是``可数''。有限个互斥事件的概率可以相加，这条公理说无穷个也可以——只要你能把它们排成一列一个一个地数。不可数的并（比如连续区间中每一个单点的概率之和）不在此列；实际上，你会看到不可数个零加起来可以是正数，这正是连续概率的根源。
\end{enumerate}

第三条不是第二条的简单拉长。它让你能处理``等待时间最终是某个正整数''这类事件——它由可数无穷多个互斥事件（等待1次、等待2次、等待3次……）拼成，每个都有概率，而可数可加性保证它们的总和有意义。

你可能会想：为什么要费劲区分可数无穷和不可数无穷？因为概率论里很多反直觉的事——比如概率为零的事件确实发生了——都和这个区分有关。先把问题放在这里，读到后面连续分布时再回头看。

\subsection{从公理走到日常公式}

公理只给出了最少的承诺。但你真正想用到的公式——补事件概率、容斥原理、单调性——都要从这三条推出来。下面用具体数字追踪每一步，让你看到公理是怎么``运行''的。

\textbf{第一步：空事件的概率是零。}

先别觉得这太显然。公理没直接说 \(P(\varnothing)=0\)。你只有可数可加性。怎么用？

把 \(\Omega\) 写成

\[
\Omega=\Omega\cup\varnothing\cup\varnothing\cup\varnothing\cup\cdots.
\]

右边这些事件两两互斥（\(\varnothing\) 和谁都互斥，因为它里面根本没有元素）。由可数可加性，

\[
P(\Omega)=P(\Omega)+P(\varnothing)+P(\varnothing)+\cdots.
\]

左端是 \(1\)。右端是一个无穷级数，每一项都是非负的。一个非负级数要收敛到有限数 \(1\)，后面的项必须趋近于零；而这里每一项都是同样的 \(P(\varnothing)\)，所以只能

\[
P(\varnothing)=0.
\]

如果你只假设了有限可加性，这个推导做不出来。可数可加性的第一个回报：连空事件的概率都靠它保证。

\textbf{第二步：补事件概率。}

把 \(\Omega\) 拆成 \(A\) 和 \(A^c\)。它们互斥，并为 \(\Omega\)。由有限可加性（可从可数可加性推出：有限个互斥事件后面接无穷多个空事件即可），

\[
1=P(\Omega)=P(A)+P(A^c),
\]

所以

\[
P(A^c)=1-P(A).
\]

用数字验证一下：如果 \(P(A)=0.3\)，那么 \(P(A^c)=0.7\)。加起来正好回到总预算 \(1\)。你不会得到 \(P(A)+P(A^c)=1.2\) 或 \(0.9\)，因为总预算就这么多。

\textbf{第三步：子集的概率不大于全集。}

若 \(A\subseteq B\)，把 \(B\) 写成

\[
B=A\cup(B\setminus A),
\]

右端两项互斥（\(A\) 中的元素不在 \(B\setminus A\) 中，反之亦然）。由有限可加性，

\[
P(B)=P(A)+P(B\setminus A)\ge P(A).
\]

最后的不等号来自非负性：\(P(B\setminus A)\ge0\)。所以 \(P(A)\le1\) 也一并到手了——\(A\subseteq\Omega\)，所以 \(P(A)\le P(\Omega)=1\)。概率不会超过 \(1\)，但这不是一条新公理，它是前三条的推论。

\textbf{第四步：两个不一定互斥的事件怎么并。}

如果直接算 \(P(A)+P(B)\)，交集被数了两遍——一遍在 \(A\) 里，一遍在 \(B\) 里。所以要扣掉一次。

严格写出来：先把 \(A\cup B\) 拆成互斥的两块，

\[
A\cup B=A\cup(B\setminus A),
\]

所以

\[
P(A\cup B)=P(A)+P(B\setminus A).
\]

再把 \(B\) 也拆成互斥的两块，

\[
B=(A\cap B)\cup(B\setminus A),
\]

所以

\[
P(B\setminus A)=P(B)-P(A\cap B).
\]

代入得到

\[
P(A\cup B)=P(A)+P(B)-P(A\cap B).
\]

用一组具体数字感受一下：如果 \(P(A)=0.4\)，\(P(B)=0.3\)，\(P(A\cap B)=0.1\)，那么 \(P(A\cup B)=0.4+0.3-0.1=0.6\)。直接数：\(A\) 占 \(0.4\)，\(B\) 的 \(0.3\) 中有 \(0.1\) 已经在 \(A\) 里了，所以新增 \(0.2\)，总共 \(0.6\)。两个算法吻合。

这些推导看起来像在证明一些``本来就对''的事情。但关键不在于你有没有猜对结论——几乎每个人都猜得对这些结论——而在于你只需要三条公理做起点。额外的每一条``直觉规则''要么是定理，要么和现存公理冲突；Kolmogorov 替你排除了后一种可能。

\subsection{一个会让你算到崩溃的问题}

掷四次公平骰子，至少出现一次 \(6\) 的概率是多少？

你可能会想：把``恰好一次 \(6\)''、``恰好两次 \(6\)''、``恰好三次 \(6\)''、``恰好四次 \(6\)''的概率分别算出来，再加起来。让我们试试。

恰好一次 \(6\)：选哪一次是 \(6\) 有四种选择，每次的概率是 \((1/6)\times(5/6)^3\)，所以 \(4\times(1/6)\times(5/6)^3\)。

恰好两次 \(6\)：选哪两次有 \(\binom{4}{2}=6\) 种，概率 \(6\times(1/6)^2\times(5/6)^2\)。

恰好三次 \(6\)：\(\binom{4}{3}\times(1/6)^3\times(5/6)\)。

恰好四次 \(6\)：\((1/6)^4\)。

把这些加在一起……你已经开始觉得不对劲了。四次的组合尚且不算太多，如果是掷一百次呢？如果每次的概率不是 \(1/6\) 而是某个 \(p\) 呢？正面枚举的劳动量随着次数疯涨。

但你注意到一个更轻巧的路径：``至少一次 \(6\)''的补事件是``一次 \(6\) 都没有''。一次 \(6\) 都没有，意味着四次全部都不是 \(6\)，在独立假设下概率为 \((5/6)^4\)。所以

\[
P(\text{至少一个 }6)
=1-\left(\frac56\right)^4.
\]

补事件公式 \(P(A^c)=1-P(A)\) 不是闲着好看的：它在这里实实在在替你省掉了一堆计算。``至少一个''型的问题几乎总是该走补事件：把``至少一个''翻译成``不是零个''，然后算零个的概率，再用一去减。

代入数字：\((5/6)^4=625/1296\approx0.482\)，所以 \(P(\text{至少一个 }6)\approx0.518\)。稍微过半。如果你在赌桌上凭感觉觉得``四次里总该有一次 \(6\) 吧''，这个数字告诉你：确实略高于一半，但远没到稳操胜券的程度。

这里用到了独立性的假设——每次掷骰的结果互不影响。独立性的精确定义在下一章给出。现在你先认可直觉：各次掷骰互不干扰，概率可以相乘。这个假设本身是不是成立的，取决于骰子是不是公平、每次掷骰之间有没有物理上的依赖，但在理想化的数学模型中，它是一个我们需要显式写出的承诺。

\subsection{概率为零不等于不可能}

第一节已经预告过这个反直觉的现象。现在有了公理体系，可以把它看得更清楚。

在 \([0,1]\) 上均匀地随机选一个实数。任意一个特定的单点——比如 \(0.5\)——它被选中的概率是多少？

你可能会想：\([0,1]\) 里有不可数个点，如果每个点的概率都是某个正数 \(\varepsilon\)，不管 \(\varepsilon\) 多小，你只需要取 \(1/\varepsilon\) 个点，概率和就已经超过 \(1\) 了，违反规范化公理。所以单点的概率只能是零。

但实验做完，总会产生一个具体的实数——而这个实数的概率是零。概率为零的事件发生了。

这不是公理出了 bug。可数可加性只承诺可数个零加起来还是零；不可数个零加起来，什么都有可能。连续区间的概率不是靠把单点概率加出来的，而是靠长度（或面积、体积）来度量——每个单点的长度为零，整个区间的长度为一。这就像问``线段上每一个点的长度是多少''——答案是零，但你不能把不可数个零加起来得到线段的长度。

反过来也一样：概率为一不意味着逻辑必然。在 \([0,1]\) 上随机选一点，选到无理数的概率为一。因为有理数只有可数个，每个概率为零，可数个零加起来是零。所以 \(P(\text{无理数})=1-P(\text{有理数})=1-0=1\)。但选到 \(1/2\) 并不是逻辑上不可能的——\(1/2\) 确实在区间里。

概率论给这种``概率为一但并非必然''的情况专门起了个名字：\textbf{几乎必然}（almost surely）。你会在这个词的阴影下走很远——大数定律说样本均值几乎必然收敛到期望，中心极限定理说标准化后的分布几乎必然如何如何——每一次``几乎必然''都在提醒你：连续概率中，概率为零和不可能之间存在一道细缝。

这个细缝不是瑕疵，而是连续模型能工作的代价。如果你拒绝接受``单点概率为零''，你就没法在连续区间上定义一个符合直觉的均匀分布。接受它，换来的是能用微积分处理概率。

这个话题在\hyperref[sec:05-Probability/08-Limit-Theorems/01]{``随机变量的多种收敛''}中还会再次出现，届时不同的收敛模式（几乎必然、依概率、依分布）之间的精细关系，根源就在这道细缝里。

\subsection{连续性：事件慢慢涨大，概率跟着靠近}

假设你有一串事件，一个套一个：

\[
A_1\subseteq A_2\subseteq\cdots,
\]

它们的并集记作 \(A=\bigcup_{n=1}^\infty A_n\)。直觉上，随着 \(n\) 变大，\(A_n\) 越来越接近 \(A\)，概率也应该越来越接近 \(P(A)\)。这条直觉对不对？

对的。而且它也是可数可加性的推论，不需要新增公理。

证明思路是把``越来越大''的事件拆成互斥的``增量''：令 \(B_1=A_1\)，\(B_2=A_2\setminus A_1\)，\(B_3=A_3\setminus A_2\)，等等。这些 \(B_i\) 两两互斥，前 \(n\) 个的并恰好是 \(A_n\)，所有 \(B_i\) 的并恰好是 \(A\)。由可数可加性，

\[
P(A)=\sum_{i=1}^\infty P(B_i)
=\lim_{n\to\infty}\sum_{i=1}^n P(B_i)
=\lim_{n\to\infty}P(A_n).
\]

用具体数字感受：令 \(A_n\) 表示在 \([0,1]\) 上均匀随机选点，落到 \([0,1-1/n]\) 内的概率。\(P(A_n)=1-1/n\)。随着 \(n\) 增长，\(A_n\) 越来越大，极限是 \([0,1)\)，概率趋近于 \(1\)。\(P(\lim A_n)=\lim P(A_n)\)，连续性成立。

这条连续性在后面的极限定理中反复登场，而且几乎从不被显式引用——你只是在默默地用。每次你说``当 \(n\) 很大时概率接近某某值''，背后都有连续性在担保，极限号可以穿过概率函数。

\subsection{公理告诉你的和不告诉你的}

三条公理能做三件事：

\begin{itemize}
\tightlist
\item 保证任何一个合法概率模型内部不会自相矛盾；
\item 让你从几个基本事实推导出所有常用的概率恒等式；
\item 把有限和无限、离散和连续统一在同一个框架下。
\end{itemize}

三条公理不做的事：

\begin{itemize}
\tightlist
\item 不告诉你硬币是否公平。\(P(\text{正面})\) 可以是 \(0.5\)，也可以是 \(0.37\)，公理都接受。公理管的是``给定某个概率分配后推理是否合法''，不管``概率分配本身对不对''。
\item 不告诉你事件之间是否独立。两个事件的概率和它们的交的概率之间，公理只要求 \(P(A\cap B)\le\min(P(A),P(B))\)，但不规定等号何时成立。独立是额外加在模型上的结构，不是公理的推论。
\item 不帮你选择样本空间。同一个现实场景可以对应多个样本空间——掷两枚硬币时可以区分 \(HT\) 和 \(TH\)，也可以不区分——选哪一个取决于你想问什么问题。公理不替你做这个选择。
\end{itemize}

下一节会直面最后这个问题：拿到一个现实问题，怎么把它翻译成一个概率空间？那个翻译过程没有公理可以代劳。
