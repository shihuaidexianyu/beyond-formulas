风控报表上有一行字：``单日损失的 \(95\%\) 分位数是 2.3 万元。''这句话里既没有样本空间，也没有事件，可它说的确实是概率的事。若照上一单元的办法办，你得先圈出``损失超过 2.3 万''那一类结果，再去量它的概率；换个阈值，重圈一次。报表显然不是这么生成的。

中间少的零件叫随机变量。它把样本空间里彼此无法比较的结果 \(\omega\) 送到数轴上，于是``某类结果发生''改写成``某个数落进某个集合''。数轴上的集合能取交并、能量长度、能做积分——微积分和线性代数的整套工具，从这一步起才接得进概率论。损失也在同一步产生：结果被压成一个数以后，同一个数背后的不同结果就再也分不开了。

四篇沿一条线索排。第一篇立住``随机变量是函数''，并说明事件的概率为什么从此可以写成数值落在某个集合里的概率。第二篇处理取值可数的情形，概率质量直接摆在点上。第三篇转向连续情形，那里每个单点的概率都是零，密度接手——而密度不是概率，它可以大于 1。第四篇把箭头掉转：已知 \(X\) 的分布求 \(g(X)\) 的分布，以及更有用的那半边，怎样只用均匀随机数造出任意分布的样本。

\subsection{\texorpdfstring{统一离散与连续的那个对象是 \(F\)}{统一离散与连续的那个对象是 F}}

PMF 只在离散时可用，PDF 只在连续时可用，而分布函数 \(F(x)=P(X\le x)\) 对两者都有定义，对二者的混合同样有定义。保险理赔里大量保单赔付为零、其余在正实数上连续分布，这种数据用 PMF 或 PDF 都拼不完整，用 \(F\) 一次写完：竖直的跳跃是点质量，倾斜的上升是连续部分。

\(F\) 的逆——分位数——在实践中出现的频率还要高于密度。尾部风险取 \(0.95\) 或 \(0.99\) 分位数，模型校准检查预测分位数与实际频率是否对得上，分位数回归干脆把整条 \(F\) 的形状当成建模目标。第四篇会看到，同一个逆函数还把``生成任意分布的样本''化归成``生成一个均匀随机数''，几乎所有采样器的底层都踩在这一步上。

\subsection{本单元篇目}

\begin{itemize}
\tightlist
\item \hyperref[sec:05-Probability/03-Random-Variables/01]{``随机变量是样本空间上的函数''}：把``会随机变化的字母''换成``定义在随机结果上的确定函数''，事件随之变成数轴上集合的原像；
\item \hyperref[sec:05-Probability/03-Random-Variables/02]{``离散分布与概率质量函数''}：取值可数时把质量放在点上，并看清 CDF 的跳跃高度就是单点概率；
\item \hyperref[sec:05-Probability/03-Random-Variables/03]{``连续分布、密度与分位数''}：单点概率为零而密度可以大于 1，分位数把``给位置求概率''反着问；
\item \hyperref[sec:05-Probability/03-Random-Variables/04]{``随机变量变换与逆变换抽样''}：Jacobian 是密度的伸缩因子，反过来用就是采样算法。
\end{itemize}

读的时候留意四层对象别混：样本点 \(\omega\)、函数 \(X\)、这一次实验得到的实现值 \(x\)、以及数轴上那份概率分配 \(P_X\)。说两个随机变量``同分布''，只断言了最后一层相同，对前三层什么也没说——本单元第一篇会用一对边缘完全一样、联合天差地别的变量把这件事钉死。

分布记录了 \(X\) 的全部概率信息，但一份完整分布不便于比较、汇报和放进公式。随后的\hyperref[ch:040]{``期望与矩：怎样用少量数字概括一个分布''}把它再压一层，只留下位置、波动与关联这几个数值摘要。
