\section{条件概率与乘法法则}
\label{sec:05-Probability/02-Conditional-Probability/01}

邻居家有两个孩子，你一个都没见过。物业翻了登记表，只肯透露一句：``至少有一个是女孩。''那么两个都是女孩的概率是多少？

脱口而出的答案通常是 \(1/2\)——另一个孩子非男即女嘛。把四种等可能的组合摆出来却不是这么回事：男男、男女、女男、女女。那句话只划掉了``男男''，剩下三种依旧等可能，其中只有一种是``女女''。答案是 \(1/3\)。

\(1/2\) 并不是凭空来的，它回答的是另一道题——``已知老大是女孩''。这句话划掉的是两种组合而非一种，剩下女男与女女，才轮到 \(1/2\)。两句话听起来差不多，截掉的东西不一样，剩下的世界也就不一样。

条件概率做的全部事情就在这里：按已知信息把样本空间截掉一块，再把留下的部分整体放大，让它自己的概率回到 \(1\)。

\subsection{定义只是把这两步写成一个分式}

\begin{definition}
设 \(P(B)>0\)。在 \(B\) 已发生的条件下，\(A\) 的条件概率为
\[
P(A\given B)=\frac{P(A\cap B)}{P(B)}.
\]
\end{definition}

分子执行删除，分母执行放大。少了分母会怎样？把 \(B\) 内部一组互不相容、合起来正好填满 \(B\) 的子事件挨个算 \(P(A\cap B)\) 再相加，得到的是 \(P(B)\)，不是 \(1\)——新全集没有被当作全集对待。除以 \(P(B)\) 补的就是这一步，它保证条件概率仍然满足\hyperref[sec:05-Probability/01-Probability-Spaces/02]{``概率公理与概率空间''}里的那几条公理，因而后面所有关于概率的结论对它一律有效。

回头核一遍开场。\(B\) 是``至少一个女孩''，占四种情形中的三种，\(P(B)=3/4\)；\(A\cap B\) 是``女女''，占一种，\(P(A\cap B)=1/4\)。相除得 \(1/3\)。数字很轻，动作很重。

\subsection{乘法法则：沿时间线把联合概率拆开}

把定义移项，得到
\[
P(A\cap B)=P(B)P(A\given B)=P(A)P(B\given A).
\]
代数上这只是换了个写法，用起来却对应一种很自然的计算方式：分步实验先算第一步，再算第一步之后第二步的概率。

袋里三红二蓝，不放回取两只，两只都红的概率是 \((3/5)\times(2/4)=0.3\)。第二个因子是 \(2/4\) 而不是 \(3/5\)，因为第一次已经改变了残局。若写成 \(0.6\times0.6=0.36\)，你实际建模的是取完放回并重新摇匀——这是另一个实验。

链条可以任意长：
\[
P\left(\bigcap_{i=1}^{n}A_i\right)=P(A_1)\prod_{i=2}^{n}P\left(A_i\given A_1\cap\cdots\cap A_{i-1}\right),
\]
只要中间每一步的条件事件概率都不为零。

这条链式法则不假设任何东西——不要求独立，不要求同分布，不要求对称。它无非是把条件概率的定义连用了 \(n-1\) 次，把``联合''换算成一串``逐步更新''。语言模型逐个 token 预测下一个词、滤波器逐时刻推进状态估计，骨架都是它。独立性会让其中某些因子塌缩成无条件概率，但那是模型另外加上的假设，不是链式法则自带的赠品。

\subsection{竖线两边不能对调}

法庭上有一类反复出现的失误。某项物证在人群中随机出现的频率是十万分之一，检方据此宣称：被告无辜的可能性只有十万分之一。

两个数被悄悄换了位置。十万分之一是 \(P(\text{匹配}\given\text{无辜})\)；辩护要问的是 \(P(\text{无辜}\given\text{匹配})\)。若嫌疑范围是一座五百万人口的城市，期望中大约有 \(50\) 人同样匹配。除非还有别的证据把范围收窄，单凭这一项，被告从五百万分之一被抬到大约五十分之一——离``几乎肯定有罪''差得很远。这个错误有个专名，检察官谬误。

同样的结构换个场合就是对模型输出的误读。一个告警系统在真实故障上的召回率 \(99\%\)，说的是 \(P(\text{报警}\given\text{真故障})\)；值班的人半夜被叫醒时想知道的却是 \(P(\text{真故障}\given\text{报警})\)。两者之间隔着故障本身有多罕见，而这个差距可以大到让人对告警彻底麻木。下一节把这笔账算到底。

\begin{remark}
开场那句话是怎么来的，会改变答案。物业查过登记表后如实回答``是否至少有一个女孩''，上面的算法成立。但假如你只是在楼道里偶遇了其中一个孩子、恰好是女孩，那就该按``能遇到女孩''的可能性给四种组合重新加权：男女与女男各只算一半，女女算满，答案回到 \(1/2\)。条件概率算的是``已知 \(B\) 发生''，而 \(B\) 究竟是哪个事件，取决于信息是怎样产生的。下一节的 Monty Hall 问题会把这一点演得更极端。
\end{remark}

\subsection{分母为零的地方要另想办法}

定义写着 \(P(B)>0\)。可概率论里到处是``给定 \(X=x\)''，而连续随机变量取任何特定值的概率恰好是零，比值公式当场失效。

补救的思路是不除概率而除密度：有联合密度时用 \(f_{Y\given X}(y\given x)=f_{X,Y}(x,y)/f_X(x)\)，更一般的情形靠正则条件概率或取极限来定义，具体见\hyperref[sec:05-Probability/05-Joint-Distributions/01]{``联合、边缘与条件分布''}。眼下带走两句话就够：比值定义要求分母非零；实践中最常用的那种条件化恰恰越过了这条线，越线之后有严格的替代方案，但不能照抄比值公式。

\subsection{下一站：把竖线倒过来}

你手上现成的，往往是``原因到结果''那个方向的概率——检测的技术指标、机器的次品率、模型在已知标签下的表现。你要的却是反方向：报告阳性了，我到底怎么样。这两个方向不能互换，中间需要一座桥。下一节搭这座桥，顺带解释一件让很多人不安的事：一个准确率高达 \(99\%\) 的筛查，用在罕见病上，阳性报告十之八九是虚惊。
