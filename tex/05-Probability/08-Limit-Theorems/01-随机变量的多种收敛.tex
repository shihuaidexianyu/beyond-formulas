\section{随机变量的多种收敛}
\label{sec:05-Probability/08-Limit-Theorems/01}

你的 Monte Carlo 模拟跑了 \(n=10^6\) 次。样本均值离真值只差 0.0003。你在组会上说：``已经收敛了。''

同事问你：你说的收敛，是再跑一遍也会得到差不多这个数；还是说即使把运行次数翻倍，偏差大概率不会反弹；还是偏差平方的期望已经小于某个阈值？他问的不是你的措辞是否规范——他问的是你的结论到底能做什么保证。

三种回答对应了三种不同的收敛定义。而如果测度论功底足够深，你会知道还有第四种：分布的形状是否逼近一个已知分布。同一个模拟序列，可以在某些意义上收敛、另一些意义上失败；用错了定义，证明链条就从这里断开。

这就是本节要厘清的事：随机变量的``靠近''有哪几种合法含义，它们之间谁强谁弱，以及在你关心的场景里该用哪一种。

\subsection{同一个极限，四个不同的问题}

先把问题放在最具体的场景里。你在估计一个未知量 \(\theta\)，跑了 \(n\) 次独立的重复实验，得到序列 \(X_1,X_2,\ldots,X_n\)。你说``序列收敛到 \(\theta\)''。这句话至少有四种截然不同的解读：

\begin{enumerate}
\tightlist
\item
  \textbf{路径稳定}：固定一条具体的随机种子跑下去，从某个 \(N\) 以后，所有的 \(X_n\) 都待在 \(\theta\) 的 \(\varepsilon\) 邻域里，再也不会跑远。你关心的是这一条轨迹的长期行为。
\item
  \textbf{大概率接近}：换一个随机种子重新初始化，跑 \(n\) 次后偏差超过 \(\varepsilon\) 的概率已经很小。你关心的是每次独立运行的失败概率是否可控。
\item
  \textbf{平均误差消失}：偏差平方的期望值——把很多次独立运行的平均平方误差算出来——已经低于容忍阈值。你关心的是平均意义上的精度，而不是某一次是否偏得离谱。
\item
  \textbf{分布形状}：你并不关心某次具体的 \(X_n\) 离 \(\theta\) 有多远。你只想知道估计量的抽样分布直方图长什么样，能不能用 Gaussian 密度曲线近似，以便构造置信区间。
\end{enumerate}

这四个问题分别对应几乎处处收敛、依概率收敛、\(L^p\) 收敛和依分布收敛。它们不是同一概念的不同叫法——它们是四个不同的保证，各有各的用途。在正式定义之前，先用三组具体序列感受一下它们的差异。

取极限为 \(X \equiv 0\)。构造三组序列：

\begin{itemize}
\tightlist
\item
  序列 A：\(X_n = 1/n\)。没有随机性，就是普通的数列收敛。四种收敛全部成立——路径逐点趋于零、大偏差概率为零、期望趋于零、CDF 收敛到退化分布 \(\delta_0\)。数列收敛是随机变量收敛的一个真子集。
\item
  序列 B：\(X_n = n\) 以概率 \(1/n\)，否则 \(X_n = 0\)。\(P(|X_n| > \varepsilon) = 1/n \to 0\)，依概率收敛通过。但 \(\E[X_n] = 1\)，不趋于零——\(L^1\) 收敛失败。几乎处处收敛的判断需要精细分析：对于几乎每个 \(\omega\)，\(X_n(\omega)\) 在绝大多数 \(n\) 上是零，但偶尔爆出一个 \(n\)；这些尖峰最终会不会停止，取决于它们出现的频率是否随 \(n\) 下降得足够快。
\item
  序列 C：\(X_n \sim \mathcal{N}(0, 1/n)\)。方差趋于零，四种收敛全部成立。
\end{itemize}

序列 B 已经揭示了第一道裂缝：概率上的接近不保证期望上的接近。接下来逐个精确定义每种收敛，你会看到它们之间的差异最终可以追溯到量词排列方式的不同。

\subsection{几乎处处收敛：逐条路径的保证}

若

\[
P\bigl(\{\omega : X_n(\omega) \to X(\omega)\}\bigr) = 1,
\]

称 \(X_n \xrightarrow{\text{a.s.}} X\)。a.s. 是 ``almost surely''，中文常译为``几乎必然''或``以概率一''。

这个定义要求你先固定住样本点 \(\omega\)。对每个固定在概率一集合中的 \(\omega\)，普通数列 \(X_1(\omega), X_2(\omega), \ldots\) 按实数收敛的意义趋于 \(X(\omega)\)。概率空间上那些病态的 \(\omega\)——比如无穷次抛硬币永远不出现正面的那条序列——恰好落在那个概率为零的例外集合里，不影响结论。

``几乎''二字不可省。在不可数样本空间上，要求对所有 \(\omega\) 都收敛通常需要代数上极度精细的构造，极少成为实用目标。概率论中能期望的最强路径结论就是 a.s.。

一条等价的刻画更方便验证和使用。\(X_n \xrightarrow{\text{a.s.}} X\) 当且仅当对每个 \(\varepsilon > 0\)，

\[
\lim_{N\to\infty} P\!\left(\sup_{n\ge N}|X_n - X| > \varepsilon\right) = 0.
\]

这里的关键是 \(\sup_{n \ge N}\)。它把``从某个时刻起之后的所有偏差''打包成一个事件。概率趋于一的意思是：从足够远的未来开始，整条尾部的偏差都不超过 \(\varepsilon\)。这个等价刻画与 Borel--Cantelli 引理紧密相连：若对每个 \(\varepsilon > 0\) 有 \(\sum_n P(|X_n - X| > \varepsilon) < \infty\)，则 Borel--Cantelli 告诉我们，以概率一，\(|X_n - X| > \varepsilon\) 只发生有限多次，从而尾部的上确界最终落入 \(\varepsilon\) 以内。但 Borel--Cantelli 给出的是充分条件而非必要条件——a.s. 收敛可以成立即便概率和发散，只要坏事件不独立。

\subsection{依概率收敛：允许坏路径集合的移动}

若对每个 \(\varepsilon > 0\)，

\[
P(|X_n - X| > \varepsilon) \to 0,
\]

称 \(X_n \xrightarrow{P} X\)。

仔细比较量词结构。几乎处处收敛说的是：存在一个全局固定的零测例外集，只要 \(\omega\) 不在里面，它的整条轨迹就从某个时刻起一直待在极限附近。依概率收敛不要求存在这样一个全局例外集。它只要求对每一个固定的 \(n\)，坏集合 \(B_n = \{\omega : |X_n(\omega) - X(\omega)| > \varepsilon\}\) 的概率趋于零。

这个区别可以更显式地写出来。a.s. 收敛等价于：

\[
P\!\left(\bigcap_{k=1}^{\infty} \bigcup_{N=1}^{\infty} \bigcap_{n=N}^{\infty} \{\omega : |X_n(\omega) - X(\omega)| \le 1/k\}\right) = 1.
\]

依概率收敛则只要求：对每个固定的 \(\varepsilon > 0\)，

\[
\lim_{n\to\infty} P(\{\omega : |X_n(\omega) - X(\omega)| \le \varepsilon\}) = 1.
\]

注意 a.s. 版本中，交集和并集的嵌套结构把无穷多个 \(n\) 联合管了起来——``存在 \(N\)，对所有的 \(n \ge N\) 都接近''。依概率收敛中只有一层 ``\(\lim_{n\to\infty}\)''——每次只看一个 \(n\)。同一个 \(\omega\) 可以反复在不同时刻落入坏集合。它只要不在坏集合里``待得太久''就行——但依概率收敛的定义根本就没有监视同一条 \(\omega\) 在不同 \(n\) 之间的行为。它只关心每一列的坏集合大小是否在缩小，不关心这些坏集合是否在样本空间上移动。

所以 a.s. 蕴含 P——这个方向是显然的：如果几乎每条路径最终收敛，那么对任意 \(\varepsilon\)，从足够大的 \(n\) 开始，偏离超过 \(\varepsilon\) 的事件概率必定趋于零。但 P 不蕴含 a.s.，下文的反例会清楚地展示这一点。

一个关键的桥接结果频繁出现在极限定理证明中：若 \(X_n \xrightarrow{P} X\)，则存在子序列 \(X_{n_k}\) 使得 \(X_{n_k} \xrightarrow{\text{a.s.}} X\)。构造子序列的标准方法是选择 \(n_k\) 使得 \(P(|X_{n_k} - X| > 2^{-k}) < 2^{-k}\)——这总是可能的因为对每个阈值，概率最终趋于零。然后 \(\sum_k P(|X_{n_k} - X| > 2^{-k}) < \infty\)，由 Borel--Cantelli 引理，以概率一，事件 \(|X_{n_k} - X| > 2^{-k}\) 只需发生有限多次，从而沿子序列 a.s. 收敛。这个技巧让你在需要从``大概率接近''升级为``路径接近''时有一个标准出口。基本上每个涉及依概率收敛的深层定理都会在某处调用这个子序列引理。

\subsection{\(L^p\) 收敛：平均误差的消失}

若

\[
\E[|X_n - X|^p] \to 0,\qquad p \ge 1,
\]

称 \(X_n\) 在 \(L^p\) 中收敛到 \(X\)。\(p = 2\) 即均方收敛：

\[
\E[(X_n - X)^2] \to 0.
\]

从 \(L^p\) 到依概率收敛的桥梁只有一行：Markov 不等式。\(|X_n - X|^p\) 非负，取阈值 \(\varepsilon^p\)：

\[
P(|X_n - X| > \varepsilon) = P(|X_n - X|^p > \varepsilon^p) \le \frac{\E[|X_n - X|^p]}{\varepsilon^p} \to 0.
\]

这行不等式在后面会被反复调用。它建立了``平均误差消失 \(\Rightarrow\) 大偏差概率消失''的单向通道。

反向通道不通。光有依概率收敛，期望可能纹丝不动。下面这个反例把原因钉死。

设 \(\Omega = (0, 1]\)，赋予均匀概率。令

\[
X_n(\omega) = \begin{cases}
n, & 0 < \omega \le 1/n,\\[2pt]
0, & \text{否则}.
\end{cases}
\]

\(P(|X_n| > \varepsilon) = 1/n \to 0\)，依概率收敛到 \(0\) 通过。但

\[
\E[X_n] = n \cdot (1/n) = 1,
\]

对任何 \(n\) 都不趋于零。进一步，\(\E[|X_n|^p] = n^p \cdot (1/n) = n^{p-1}\)：\(p = 1\) 时恒为 \(1\)，不趋于零；\(p > 1\) 时甚至发散到无穷。一个越来越罕见但越来越高的尖峰——概率缩小的速度刚好被幅度增长的速度抵消，使得期望贡献不消失。

这个反例同时解释了为什么 a.s. 收敛不蕴含 \(L^p\) 收敛。一条路径上，尖峰出现的频率可以随 \(n\) 下降得足够快，使得对几乎每个 \(\omega\)，从某个时刻起尖峰不再出现——a.s. 收敛成立。但如果每次尖峰的幅度增长得足够猛，它对期望的贡献不会随概率缩小而消失。这正是\hyperref[sec:12-Real-Analysis-Support/05-Measure-Integration-and-Conditional-Expectation/06]{``一致可积性阻止期望质量逃逸''}要系统回答的问题：在什么额外条件下，路径收敛能提升为期望收敛。

推进这个问题的分析需要一致可积性的概念。粗略地说，一组随机变量是一致可积的，如果

\[
\lim_{M\to\infty} \sup_n \E[|X_n|\,\mathbf{1}_{|X_n| > M}] = 0.
\]

这个条件说：所有 \(X_n\) 的尾概率质量——大值区域的期望贡献——被一致地控制住了，没有一个 \(X_n\) 会把过多概率质量藏在极端大的取值里。在上面的反例中，\(\E[X_n \mathbf{1}_{X_n > M}] = 1\) 对所有足够大的 \(n\) 和所有 \(M < n\) 都成立——尾质量不受控制。把一致可积性和依概率收敛合在一起，就可以推出 \(L^1\) 收敛。这就是 Scheffé 引理区域的标准结果，后续实分析支撑章节会给出完整证明。

在概率空间上（总测度有限），\(L^p\) 空间之间有嵌套关系。由 Hölder 不等式：若 \(p < q\)，则

\[
\E[|Y|^p] \le (\E[|Y|^q])^{p/q},
\]

令 \(Y = X_n - X\)，右侧趋于零则左侧也趋于零。所以均方收敛（\(p = 2\)）自动给出 \(L^1\) 收敛，但反过来不行——平方可积的函数一定可积，可积的函数不一定平方可积。

\subsection{依分布收敛：只看直方图，不管路径}

若在极限 CDF \(F_X\) 的每个连续点 \(x\) 上，

\[
F_{X_n}(x) \to F_X(x),
\]

称 \(X_n \xrightarrow{d} X\)。

这一定义最不依赖路径。\(X_n\) 和 \(X\) 甚至不需要定义在同一个概率空间上——你只比较它们的 CDF 在连续点上的极限行为。它只关心随机变量的``统计长相''是否趋于一致，完全不管在某条具体的 \(\omega\) 上 \(X_n(\omega)\) 和 \(X(\omega)\) 是否靠近。

定义中``在每个连续点 \(x\) 上''这一限制排除了极限 CDF 跳跃点处的边界麻烦。例如 \(X_n \equiv 1 + 1/n\) 依分布收敛到常数 \(X \equiv 1\)，但在跳跃点 \(x = 1\) 处：\(F_{X_n}(1) = \mathbf{1}_{1/n \le 0} \to 0\)，而 \(F_X(1) = 1\)，不收敛。如果不在定义中排除跳跃点，常数序列反倒``不收敛''了——这显然不是我们想要的概念。

还有其他等价刻画。依分布收敛等价于：对任何有界连续函数 \(g\)，有 \(\E[g(X_n)] \to \E[g(X)]\)。这个刻画对应了测度论中弱收敛的 portfolio 定义，也是 Helly--Bray 定理的核心。它也等价于：特征函数逐点收敛。选择用哪个等价形式，取决于具体证明中哪个操作着最顺手。

依概率收敛推出依分布收敛。直觉：如果 \(X_n\) 大概率靠近 \(X\)，那么 \(X_n\) 超过某阈值的概率应当接近 \(X\) 超过该阈值的概率——至少在阈值对应的 CDF 连续点上。正式论证需要一趟 \(\varepsilon\)-\(\delta\) 追逐：对 CDF 连续点 \(x\) 和任意 \(\delta > 0\)，

\[
F_{X_n}(x) = P(X_n \le x) \le P(X \le x + \varepsilon) + P(|X_n - X| > \varepsilon) = F_X(x + \varepsilon) + o(1).
\]

令 \(\varepsilon \to 0\) 并利用 \(F_X\) 在 \(x\) 处的连续性，得 \(\limsup_n F_{X_n}(x) \le F_X(x)\)。下界用类似方法求得。

反向一般不成立。找一个最简单的反例就够了：让所有 \(X_n\) 都与 \(X\) 同分布，且独立于 \(X\)。CDF 处处相同，依分布收敛平凡成立。但 \(X_n - X\) 的分布不随 \(n\) 缩小——除非共同分布退化成常数。

有一个重要例外值得记住：当极限 \(X = c\) 为常数时，依分布收敛与依概率收敛等价。因为常数极限的 CDF 只在 \(c\) 点有一个跳跃，对任意 \(\varepsilon > 0\)，\(x = c \pm \varepsilon\) 都是连续点，依分布收敛给出 \(P(X_n \le c - \varepsilon) \to 0\) 和 \(P(X_n \le c + \varepsilon) \to 1\)，二者合起来就是 \(P(|X_n - c| > \varepsilon) \to 0\)。这个等价性是 Slutsky 定理等渐近工具链中的基础组件——它让你可以把依分布收敛的序列和依概率收敛到常数的序列拼在一起操作。

\subsection{一个反例：在区间上不停游走的尖峰}

这个经典构造让依概率收敛和几乎处处收敛的差别变得触手可及。

样本空间取 \((0, 1]\) 配均匀概率。把区间逐层细分并循环扫过：

\begin{itemize}
\tightlist
\item
  \(A_1 = (0, 1]\)；
\item
  \(A_2 = (0, \tfrac12]\), \(A_3 = (\tfrac12, 1]\)；
\item
  \(A_4 = (0, \tfrac13]\), \(A_5 = (\tfrac13, \tfrac23]\), \(A_6 = (\tfrac23, 1]\)；
\end{itemize}

一般地，第 \(k\) 组包含 \(k\) 个长度为 \(1/k\) 的区间，从左到右拼满整个 \((0, 1]\)。当 \(n\) 落入第 \(k\) 组时，\(P(A_n) = 1/k\)。组的大小 \(k\) 随 \(n\) 增长：\(n = 1\) 对应 \(k = 1\)；\(n = 2, 3\) 对应 \(k = 2\)；\(n = 4, 5, 6\) 对应 \(k = 3\)；以此类推。更精确地，第 \(k\) 组覆盖的 \(n\) 范围是从 \(\frac{k(k-1)}{2} + 1\) 到 \(\frac{k(k+1)}{2}\)。

令 \(X_n = \mathbf{1}_{A_n}\)，即指示变量——\(\omega\) 落在 \(A_n\) 上取 \(1\)，否则取 \(0\)。

随着 \(n \to \infty\)，\(P(A_n) = 1/k(n) \to 0\)（其中 \(k(n) \sim \sqrt{2n}\)），所以

\[
P(|X_n| > \tfrac12) = P(A_n) \to 0,
\]

即 \(X_n \xrightarrow{P} 0\)。依概率收敛成立。

现在看路径。在每一组 \(k\) 中，所有 \(k\) 个区间恰好拼满整个 \((0, 1]\)——每个 \(\omega\) 在每一组中恰好被一个区间覆盖。所以对于每一个固定的 \(\omega\)，序列 \(X_n(\omega)\) 包含无穷多个 \(1\)（每组各出现一次）和许多 \(0\)。它永远在 \(0\) 和 \(1\) 之间反复弹跳，对任何 \(\omega\) 都不收敛。

几乎处处收敛失败得干干净净——不是``绝大多数路径收敛''，而是没有一条路径收敛。

两个量词结构在此并排：

\begin{itemize}
\tightlist
\item
  几乎处处收敛：对几乎每个 \(\omega\)，存在 \(N(\omega)\)，当 \(n > N(\omega)\) 后 \(|X_n(\omega) - X(\omega)| < \varepsilon\)。全局例外集固定。
\item
  依概率收敛：对每个固定的 \(n\)，坏集合 \(B_n\) 的概率趋于零。坏集合可以随 \(n\) 移动——移动的尖峰正是如此。
\end{itemize}

这个反例还说明了一件事：极限符号和概率符号不能随意交换。在反例中，\(\lim_{n\to\infty}P(|X_n| > \varepsilon) = 0\)，但 \(P(\lim_{n\to\infty}|X_n| = 0) = 0\)。``先取极限再算概率''和``先算概率再取极限''给出了相反的答案。这不是定义在捉弄人，而是提醒你：交换极限和概率需要额外理由，通常来自单调收敛、支配收敛或一致可积性。习惯先积分再取极限的人，在这里需要一个明确的警告。

\subsection{关系全景：谁蕴含谁，谁独立于谁}

四条常用蕴含关系构成骨架：

\[
L^p\text{ 收敛} \Longrightarrow \text{依概率收敛} \Longrightarrow \text{依分布收敛},
\]

\[
\text{几乎处处收敛} \Longrightarrow \text{依概率收敛}.
\]

\(L^p\) 与 a.s.\ 之间没有直接的双向蕴含。a.s.\ 不能保证期望收敛——尖峰可以大到让期望发散，只要它们对路径的影响最终消停。\(L^p\) 也不能保证 a.s.\ 收敛——想象 \([0, 1]\) 上的振动序列：频率递增，振幅递减使得均方趋于零，但在任何给定点上振动永不停止，路径不收敛。

两条常用的子序列结果在证明中频繁进出：

\begin{itemize}
\tightlist
\item
  若 \(X_n \xrightarrow{P} X\)，则存在子序列 \(X_{n_k} \xrightarrow{\text{a.s.}} X\)。从弱收敛中提取强收敛片段的标准化操作。使用 Borel--Cantelli 构造子序列的证明骨架在前文已给出。
\item
  若 \(X_n \xrightarrow{d} c\)（常数极限），则 \(X_n \xrightarrow{P} c\)。前面已论证。
\end{itemize}

\subsection{每种收敛保护什么结论}

选择收敛模式不是做抽象分类题——它决定你的定理能保护什么实际判断：

\begin{itemize}
\tightlist
\item
  \textbf{一致性}——估计量随样本量增大趋近真值——标准表述是依概率收敛。``一致估计量''的定义就是依概率收敛到真值。你只需要控制错误决策的概率，不需要保证每条路径都最终稳定。几乎所有 MLE 和矩估计的一致性定理都以依概率收敛为结论。
\item
  \textbf{风险收敛}——均方误差是否趋于零——需要 \(L^2\) 收敛。依概率收敛不能保证 \(\E[X_n] \to \E[X]\)。反例 B 已经演示了：尖峰 \(n\) 以概率 \(1/n\) 出现，依概率收敛到 \(0\) 但期望恒为 \(1\)。如果你的损失函数涉及平方误差的期望，单有依概率收敛不够。
\item
  \textbf{长期路径行为}——一条具体轨迹最终是否稳定——需要 a.s.\ 收敛。强大数定律和遍历定理的结论都是 a.s.\ 的。你在一台计算机上只能跑一条路径；a.s.\ 收敛向你保证：你看到的这一条，就是极限。对于在线学习、随机优化和 MCMC 诊断，a.s. 收敛保证了你实际观察到的那条轨迹不会永远偏离目标。
\item
  \textbf{近似分布}——用 Gaussian 近似构造假设检验或置信区间——需要依分布收敛。CLT 给的就是这个。它不保证任意给定样本中 \(\bar X_n\) 接近 \(\mu\)；它只保证标准化误差的分布像 Gaussian。这是四种收敛中最弱的一种，但也是应用最广的一种——因为实践中你经常只需要一个近似的抽样分布，而不是对某条具体路径的保证。
\end{itemize}

如果最终目标是让 \(\E[X_n]\) 收敛到 \(\E[X]\)，仅有依概率收敛或 a.s.\ 收敛都还不够。需要加上一致可积性。这正是\hyperref[sec:12-Real-Analysis-Support/05-Measure-Integration-and-Conditional-Expectation/06]{``一致可积性阻止期望质量逃逸''}的主题：一致可积与依概率收敛怎样联合给出 \(L^1\) 收敛，以及为何单有 \(L^1\) 范数有界不能阻止概率质量向零测集逃逸的移动尖峰模式。

这些收敛关系不是抽象趣味题。你会在后续极限定理的证明中反复穿越这些蕴含箭头：从 a.s. 下降到 P，从 P 提取 a.s. 子列，从 \(L^2\) 推到 P，从 P 加上一致可积推到 \(L^1\)。Delta method 依赖依分布收敛与依概率收敛的联合操作；Slutsky 定理依赖依分布收敛和常数极限的等价性；连续映射定理把你从一种收敛模式带到另一种。每一层的桥接都依赖本节建立的蕴含网。弄不清哪条路通哪条路不通，证明就会在不可通行的方向上硬走。
