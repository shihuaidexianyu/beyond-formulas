抛一枚硬币，结果不可预测。抛一万次，正面比例几乎一定落在 \(0.49\) 到 \(0.51\) 之间。单次的彻底无序和总体的高度规整是同一个模型的两面，本章就在处理这件事。

麻烦在于日常语言把这种规整说得太顺口了。``样本多了就准了''这句话里至少压着三个需要分别兑现的承诺：准到哪里去（收敛的目标是什么）、以什么方式准（哪一种收敛）、准到什么程度（误差多大、形状如何）。三个承诺各有各的前提，而前提塌掉时的表现完全不同——有的是收敛变慢，有的是压根不收敛，还有的是收敛得又快又稳，只是稳在了错误的答案上。

本章要立住的判断有三条。

第一，``收敛''在概率里不是一个词。几乎必然、依概率、\(L^p\)、依分布，四种收敛强弱分明且都有反例把它们隔开。分这么细不是术语癖：弱大数定律和强大数定律给的是不同层级的承诺，而你在一台机器上只跑一条轨迹这件事，恰好只有强的那一级管得着。

第二，样本均值收敛到期望是有前提的，最硬的一条是期望必须存在。Cauchy 分布的样本均值取多少个都不变窄，而实际数据里的重尾——请求延迟、金融收益、流量峰值——是这条前提的温和版本。``平均值总会稳定下来''值得当作一个待检验的假设，而不是背景常识。

第三，中心极限定理说的是波动的形状，不是均值的位置。误差按 \(1/\sqrt n\) 收缩，形状渐近正态，这两条把置信区间和 A/B 实验的显著性判断变成了可计算的量。但它要求方差有限，收敛速度由偏度决定，而且在尾部最不准——偏偏尾部正是 \(p\) 值和分位数所在的地方。

\subsection{本章篇目}

\begin{itemize}
\tightlist
\item \hyperref[sec:05-Probability/08-Limit-Theorems/01]{``随机变量的多种收敛''}：把``收敛了''这句话拆成四种互不等价的承诺，并用滑动窗口等反例说明谁也替不了谁。
\item \hyperref[sec:05-Probability/08-Limit-Theorems/02]{``大数定律与长期平均''}：弱版本三行可证，强版本换来路径级保证；同时列清前提塌掉的几种方式。
\item \hyperref[sec:05-Probability/08-Limit-Theorems/03]{``中心极限定理与 Gaussian 近似''}：把塌缩的误差放大 \(\sqrt n\) 倍看形状，以及这套近似在什么位置开始不可信。
\item \hyperref[sec:05-Probability/08-Limit-Theorems/04]{``特征函数怎样证明中心极限定理''}：为什么正确的工具是特征函数而不是矩母函数，以及证明骨架的四步分工。
\item \hyperref[sec:05-Probability/08-Limit-Theorems/05]{``Monte Carlo：从随机样本到数值答案''}：把前两条定理反过来当计算工具，误差与维数脱钩的代价与边界。
\end{itemize}

首读走前三篇即可，它们提供的是判断力：知道自己说的是哪一种收敛，知道均值稳不稳定要先看什么，知道误差范围从哪来。第四篇适合第二遍阅读，它解释的是机制——为什么原始分布的细节会在极限里消失。第五篇是应用闭环，值得连同抽样机制、方差和误差报告一起读。

有一条线索贯穿全章：这些定理保护的从来不是数据本身，而是你基于数据作出的判断。它们能消灭随机波动，不能修正抽样设计、依赖结构或模型设定上的偏差。样本量增大只让前一类问题变小，同时让后一类问题看上去更可信——这一点在每一篇里都会以不同面貌再出现一次。
