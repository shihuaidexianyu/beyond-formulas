\section{特征函数怎样证明中心极限定理}
\label{sec:05-Probability/08-Limit-Theorems/04}

前面两节给了你两个陈述。一个陈述是大数定律——样本平均趋近期望。另一个陈述是中心极限定理——独立同分布、有限非零方差变量的标准化和在样本量增大时，分布趋向标准 Gaussian。两个陈述摆在那里，像路标告诉你目的地，却没有告诉你脚下的路是怎么走过去的。

大数定律可以靠 Chebyshev 不等式直接摁住：方差有限，摊到 \(n\) 上就压下去了。但中心极限定理的证明要困难得多。它不是某个矩被压下去的问题，而是整个分布的形状在极限下变成了同一条钟形曲线——无论原始分布是均匀的、Bernoulli 的还是指数衰减的，极限都是同一个 \(e^{-x^2/2}/\sqrt{2\pi}\)。

前面在\hyperref[sec:05-Probability/05-Joint-Distributions/03]{``随机变量之和与卷积''}里提到过一个直觉：独立和的密度是各分量密度的卷积，而卷积操作像反复涂抹，让形状越来越圆。拿两个均匀分布的密度卷积，出来一个三角形；再卷积一次，三角形的尖角被磨圆，接近钟形。这个画面很有说服力，但它不是证明——你不能靠画图论证``继续卷积下去就变成 Gaussian''。

我们缺的是一台机器：能把``卷积越来越圆''这个粗糙直觉翻译成精确代数，然后干净地算出极限到底是谁。

\subsection{困境：独立和的分布太难直接写}

一个具体的困境能帮你体会这件事的难度。取 \(X_1,\ldots,X_n\) 各自独立服从 \(\operatorname{Uniform}(0,1)\)，令 \(S_n = X_1 + \cdots + X_n\)。\(S_n\) 的密度是什么？

两个均匀变量的和的密度是个分段线性函数——三角形，你也许可以硬写。三个呢？分段二次。\(n\) 个呢？分段 \(n-1\) 次多项式，分段点越来越多。对一般的母分布，你连这个分段多项式的闭式都写不出来。想直接对 \(S_n\) 的分布函数取极限然后认出 Gaussian，这条路在代数上就是自杀。

问题出在卷积。独立和的密度是卷积，卷积的极限不好算，因为卷积把分布揉在一起的方式很复杂。

\subsection{换个思路：把卷积变乘法}

如果你能把``分布''编码成某种函数，使得独立和的编码变成函数的乘积而非卷积，极限就好算了。因为乘法有对数、有 Taylor 展开、有标准极限 \((1+x_n/n)^n\to e^x\)——这些都是你从微积分里带来的老朋友。

特征函数恰好做这件事。定义回顾一下（详见\hyperref[sec:05-Probability/07-Transforms-and-Bounds/01]{``生成函数、矩母函数与特征函数''}）：

\[
\varphi_X(t) = \E[e^{itX}] = \int e^{itx}\,dF_X(x).
\]

对独立变量 \(X\) 与 \(Y\)：

\[
\varphi_{X+Y}(t) = \E[e^{it(X+Y)}] = \E[e^{itX}]\E[e^{itY}] = \varphi_X(t)\varphi_Y(t).
\]

独立和的特征函数是乘积。这就是你要的翻译器——卷积不见了。

特征函数还有两条你在同一节里已经见过的性质：它总是存在（被积函数的模长是 1，积分一定有限）；它唯一确定分布（特征函数相同则分布相同）。这两条是整个证明的地基。

\subsection{Lévy 连续性定理：函数收敛翻译回分布收敛}

还缺一个环节。你算出特征函数的极限是 \(e^{-t^2/2}\)，怎么知道对应的分布就是 \(\mathcal N(0,1)\)？唯一性只告诉你：如果极限确实是某个分布的特征函数，那个分布就是 Gaussian。但你需要先确认极限函数确实对应某个分布，而且收敛是够强的。

Lévy 连续性定理补上这个环节：

\medskip
\noindent\textbf{Lévy 连续性定理.} 随机变量列 \(X_n\) 依分布收敛到 \(X\)，当且仅当它们的特征函数逐点收敛：\(\varphi_{X_n}(t)\to\varphi_X(t)\) 对每个实数 \(t\) 成立。
\medskip

这个定理把``分布形状接近''（依分布收敛，见\hyperref[sec:05-Probability/08-Limit-Theorems/01]{``随机变量的多种收敛''}）翻译成函数值的逐点收敛。逐点收敛是普通分析对象——你可以对每个固定的 \(t\)，用 Taylor 展开和标准极限去算。翻译回去则靠连续性定理。

本节的证明策略因此只有四步：写出特征函数，展开它，取极限，认出极限是谁的特征函数。下面把这四步的代数全部摊开。

\subsection{把 CLT 的代数全部算出来}

设 \(X_1,\ldots,X_n\) 独立同分布，\(\E X_i=\mu\)，\(\Var(X_i)=\sigma^2<\infty\)。先把变量中心化并标准化：令 \(Y_i=(X_i-\mu)/\sigma\)，则

\[
\E Y_i=0,\qquad \E[Y_i^2]=1.
\]

标准化和为

\[
Z_n=\frac1{\sqrt n}\sum_{i=1}^n Y_i.
\]

\medskip
\noindent\textbf{第一步：乘积出现。} 独立和的特征函数是乘积，缩放自变量的效果是：

\[
\varphi_{Z_n}(t)
= \prod_{i=1}^n \varphi_{Y_i}\!\left(\frac{t}{\sqrt n}\right)
= \left[\varphi_Y\!\left(\frac{t}{\sqrt n}\right)\right]^n,
\]

其中 \(\varphi_Y\) 是 \(Y_i\) 共同的特征函数（同分布让所有因子相同）。

\medskip
\noindent\textbf{第二步：Taylor 展开。} 对 \(\varphi_Y\) 在原点展开。由 \(\varphi_Y^{(k)}(0) = i^k\E[Y^k]\)（\hyperref[sec:05-Probability/07-Transforms-and-Bounds/01]{``生成函数、矩母函数与特征函数''}中已建立），代入 \(\E Y=0\) 与 \(\E[Y^2]=1\)：

\[
\varphi_Y(s) = \varphi_Y(0) + \varphi_Y'(0)s + \frac{\varphi_Y''(0)}{2}s^2 + o(s^2)
= 1 + 0 - \frac{s^2}{2} + o(s^2),\qquad s\to0.
\]

这里 \(\varphi_Y(0)=\E[e^{i\cdot0\cdot Y}]=\E[1]=1\)，一阶项因为均值为零而消失，二阶项贡献了 \(-s^2/2\)。余项是 \(o(s^2)\)，意味着比 \(s^2\) 消失得更快。

代入 \(s = t/\sqrt n\)：

\[
\varphi_Y\!\left(\frac{t}{\sqrt n}\right)
= 1 - \frac{t^2}{2n} + o\!\left(\frac{1}{n}\right).
\]

这里 \(o(1/n)\) 表示除以 \(1/n\) 后趋于零的项。

\medskip
\noindent\textbf{第三步：取 \(n\) 次幂的极限。} 标准极限公式 \((1 + x_n/n)^n \to e^x\)（当 \(n x_n \to x\)）出场。令 \(x_n = -t^2/2 + o(1)\)，则 \(n x_n \to -t^2/2\)，于是

\[
\varphi_{Z_n}(t)
= \left[1 - \frac{t^2/2 + o(1)}{n}\right]^n
\longrightarrow e^{-t^2/2}.
\]

这里 \(o(1)\) 是当 \(n\to\infty\) 时趋于零的量，被塞进了分子的 \(t^2/2 + o(1)\) 里。极限只保留了主导项 \(-t^2/2\)。

\medskip
\noindent\textbf{第四步：认出极限。} 标准正态 \(Z\sim\mathcal N(0,1)\) 的特征函数是

\[
\varphi_Z(t) = \frac1{\sqrt{2\pi}} \int e^{itx} e^{-x^2/2}\,dx = e^{-t^2/2},
\]

可以通过配方并把积分路径在复平面上平移（或者利用矩母函数在虚轴上的解析延拓）得到。于是 \(\varphi_{Z_n}(t) \to \varphi_Z(t)\) 对每个固定 \(t\) 成立。Lévy 连续性定理给出

\[
Z_n \xrightarrow{d} \mathcal N(0,1).
\]

\medskip
四步分工很清楚：独立让乘积出现，有限方差让二阶展开合法，标准极限把幂变成指数，连续性定理把函数收敛翻译回分布收敛。Gaussian 是极限的唯一候选，因为 \(e^{-t^2/2}\) 正是它的特征函数——而那个指数恰好是 \((1 - t^2/(2n))^n\) 在 \(n\to\infty\) 时的极限。

你可以停下来欣赏一下发生了什么。证明的核心不是卷积的形状、不是密度的显式，而是一句代数：特征函数把卷积变成乘法，乘法的极限用一阶 Taylor 展开就算出来了。整件事的难度从``分析卷积序列的极限''降低到了``算一个 \((1-\text{某小量}/n)^n\) 的极限''——这是大一微积分的内容。

\subsection{每一步的条件各防住了什么失败}

证明的四步对应四个前提。任一前提不成立，机器就卡住。

\begin{itemize}
\tightlist
\item
  \textbf{独立性}让特征函数相乘。如果只假设不相关而联合分布任意，第一步就断了——和的分布不由边缘决定，特征函数也就不能简单地写成乘积。不独立时，和的特征函数里会夹着交叉项 \(\E[e^{it(X+Y)}]\neq\E[e^{itX}]\E[e^{itY}]\)，整个代数无从展开。
\item
  \textbf{有限方差}让 Taylor 展开到二阶。Cauchy 分布——密度 \(1/[\pi(1+x^2)]\)——的均值与方差都不存在。它的特征函数是 \(e^{-|t|}\)，在 \(t=0\) 不可导：一阶导数就不存在，上面的展开第一步就失败。实际上，Cauchy 样本平均经过同样的``特征函数相乘再缩放''操作后，特征函数仍然是 \(e^{-|t|}\)，平均还是 Cauchy，不会变窄。有限方差不是一个技术性假设，它画出了 CLT 的疆界——疆界之外的分布属于稳定律的世界。
\item
  \textbf{同分布}让所有因子相同，乘积是 \(n\) 次幂。不同分布时，和的标准化仍可能收敛到 Gaussian（Lindeberg 条件），但代数不再是``同一个因子取 \(n\) 次方''这么干净。你需要逐项控制每个因子的展开，保证没有单独的项主导极限——Lindeberg 条件正是防止这种``某一个体决定全局''的机制。
\end{itemize}

证明还暗示了 Berry--Esseen 界的入口。如果把展开做到三阶或更高阶，并小心估计余项随 \(n\) 衰减的速度，就能得到有限 \(n\) 时的误差界，而不是仅仅``当 \(n\) 足够大时收敛''这样的定性陈述。Berry--Esseen 定理告诉你，误差以 \(1/\sqrt n\) 的速度缩小，比例常数由标准化三阶矩控制——这正是上一节引用的结论的来源。证明的骨架是同一个 Taylor 展开，只是这次你没有扔掉高阶项，而是把它们绑起来做误差估计。

\subsection{同样的机器还证明什么}

特征函数加连续性定理是分布极限的通用机器，CLT 是它最著名的产出，但不是唯一产出：

\begin{itemize}
\tightlist
\item
  \textbf{Poisson 极限定理}：Binomial\((n,\lambda/n)\) 的特征函数是
  \[
  \left(1 - \frac{\lambda}{n} + \frac{\lambda e^{it}}{n}\right)^n
  \longrightarrow \exp(\lambda(e^{it}-1)),
  \]
  正是 Poisson\((\lambda)\) 的特征函数。``稀有事件在大量试验中趋向 Poisson''这一直觉由此得到严格证明——和 CLT 完全相同的``写成幂、展开、取极限''流程。
\item
  \textbf{大数定律（弱形式）}：若 \(\E|X|<\infty\) 且 \(\mu=\E[X]\)，展开到一阶：\(\varphi_X(u)=1+i\mu u+o(u)\)。因此
  \[
  \varphi_{\bar X_n}(t) = [\varphi_X(t/n)]^n \to e^{i t \mu},
  \]
  即 \(\bar X_n\) 依分布收敛到常数 \(\mu\)，也就依概率收敛到 \(\mu\)。从特征函数的角度看，大数定律是``只展开到一阶''的特殊情形；CLT 是``展开到二阶''的情形——方差的存在让你有资格多留一项。
\item
  \textbf{稳定律}：无限方差时，展开到二阶不合法。但如果你展开到分数阶——比如 \(\alpha\) 阶，\(1<\alpha<2\)——幂的极限不再是 \(e^{-t^2/2}\)，而是 \(e^{-c|t|^\alpha}\)（对称稳定律），或带有编码偏斜的附加相位项（非对称稳定律）。对称 Cauchy 正是 \(\alpha=1\) 的成员。CLT 的 Gaussian 极限其实是稳定律家族中 \(\alpha=2\) 的特例——它是唯一一个方差有限的情形。
\end{itemize}

同一条``乘法—展开—认形''的程序覆盖这些定理，差异只在展开到哪一阶、极限指数长什么样。把这台机器装进工具箱后，以后你看到任何``某分布收敛到某分布''的命题，都可以先问一句：它的特征函数长什么样，能在原点附近展开到哪一阶？

\subsection{边界清单}

\begin{itemize}
\tightlist
\item
  连续性定理要求对每个固定 \(t\) 逐点收敛到极限特征函数。不需要导数一致收敛，也不需要在整个实轴上一致收敛，但它不是只检查某一个 \(t\) 就完事。
\item
  逐点收敛的极限必须是某个合法分布的特征函数。若极限函数在 \(t=0\) 处不连续，说明质量可能已经``逃到无穷远''。例如 \(X_n\sim\operatorname{Uniform}(-n,n)\)，特征函数
  \[
  \varphi_{X_n}(t) = \frac{\sin(nt)}{nt}
  \]
  当 \(n\to\infty\) 时趋于一个在 \(t=0\) 为 1、其余点为 0 的函数——这不是任何分布的特征函数（特征函数必须处处连续）。此时分布不收敛，概率质量散逸到了 \(\pm\infty\)。
\item
  特征函数证明给的是极限陈述，不给有限 \(n\) 的误差界。误差界需要 Berry--Esseen 或 Edgeworth 展开来单独估计余项，不是把证明里丢掉的 \(o(\cdot)\) 捡回来就能自动得到的。
\item
  二阶展开要求二阶矩存在；更高阶展开要求更高阶矩。矩不存在的区域是稳定律的地盘，不是``证明失效了''这样的意外——它告诉你，在那个区域有不同的法则在运作。
\end{itemize}

回顾整条线索：变换工具（上一单元讲生成函数、矩母函数、特征函数）不只是计算技巧——它还是极限定理的证明引擎。CLT 的证明不是魔术，是把卷积换成乘法，然后对一个简单函数做 Taylor 展开。你现在可以自己动手验证：任取一个你熟悉的分布（指数、均匀、Bernoulli），写出它的特征函数，按上面的四步走一遍，你会看到同一个 \(e^{-t^2/2}\) 从完全不同的起点冒出来。
