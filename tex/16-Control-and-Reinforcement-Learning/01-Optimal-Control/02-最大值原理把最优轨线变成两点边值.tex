\section{最大值原理：把最优轨线变成两点边值}
\label{sec:16-Control-and-Reinforcement-Learning/01-Optimal-Control/02}

送货无人机要从仓库飞到五公里外的取件点，电池标称续航八分钟，实测六分半。飞控里已经有一套稳得住的姿态回路——上一节那种反馈，风一吹能拉回来。可现在的问题换了一种：飞高一点省不省电？中途爬升还是全程平飞？最后一段是滑行进场还是持续推力？这些问题没有对应的旋钮可拧，它们问的是整条航迹该长什么样，而反馈回路只管把偏差消掉。稳住只是及格线，及格线以上还有无数条能到达终点的路径，得从中挑一条。

\subsection{把``好''写成一个数，问题才有资格被优化}

挑之前先说清挑的标准。四个零件缺一不可。

第一是状态方程。无人机的位置、速度、电量记成向量 \(x\)，油门与姿态指令记成 \(u\)，动力学写成 \(\dot x = f(x,u)\)，初值 \(x(0)=x_0\) 已知。这个接口比它看起来宽：化学反应器的浓度与温度、投资组合的仓位、种群模型的个体数，只要能写成这个形状，后面的推导一字不改地适用。

第二是控制的可行范围。电机不会无限出力，\(u(t)\in U\)，\(U\) 常常是 \([u_{\min},u_{\max}]\) 这样的紧集。这是物理世界绑住你的手。

第三是终端代价 \(\Phi(x(T))\)。到不了取件点、或者到了但电量见底无法返航，都要在终点结算成数字。

第四是运行代价 \(L(x,u)\)。沿途的耗电、机身振动、乘客的不适，逐时刻累积。

四件拼成一个泛函：

\[
J(u) = \Phi(x(T)) + \int_0^T L(x(t),u(t))\, dt.
\]

在所有满足动力学和约束的 \(u(\cdot)\) 里，找让 \(J\) 最小的那一条。

麻烦藏在自变量的类型上。\(u(\cdot)\) 是一整条函数，不是一个数，也不是一个有限维向量。微积分课里``求导、令零、解方程''的三步走没法直接搬——导数是对什么求的？函数空间上的梯度需要重新定义，最优性条件也需要重新写。

\subsection{把时间剁碎的路走得通，但代价压在维数上}

一个自然的念头：计算机反正只能处理离散，那就把 \([0,T]\) 切成 \(N\) 段，在每个格点上做动态规划，让 \(N\) 越切越细去逼近连续解。这条路是通的，下一节会沿它走到底。

它的代价出现在状态空间那一侧。动态规划要在状态空间的每一点上都存一个值，两维的位置---速度还能画成一张网格图；换成四轴飞行器的十二维状态，每维取一百个格点就是 \(10^{24}\) 个数，硬盘先崩溃。切得细的是时间轴，爆炸的是状态轴。

于是换一个问法：能不能不去遍历整个状态空间，只沿一条候选轨线，写出它若要最优必须满足的条件？

\subsection{扰动最优轨线，会撞上一个甩不掉的影子}

设 \(u^*\) 已经是最优控制，\(x^*\) 是它生成的状态轨线。最优意味着任何微小扰动都不能让代价再降。

给控制加一个微扰 \(u^* + \varepsilon\eta(t)\)，状态跟着偏移 \(x^* + \varepsilon\,\delta x(t) + o(\varepsilon)\)。把动力学在最优轨线处线性化：

\[
\dot{\delta x} = f_x\, \delta x + f_u\, \eta, \qquad \delta x(0) = 0,
\]

其中 \(f_x\)、\(f_u\) 都是沿 \(x^*, u^*\) 取值的 Jacobian。代价的一阶变分随之写成

\[
\delta J = \frac{\partial\Phi}{\partial x}\big(x^*(T)\big)\cdot \delta x(T)
+ \int_0^T \big( L_x\cdot \delta x + L_u\cdot \eta \big)\, dt.
\]

到这里卡住了。\(\eta\) 是你亲手加的扰动，形状完全由你掌控；\(\delta x\) 却不是——它由上面那个线性微分方程决定，要知道某一时刻的 \(\delta x\)，得把 \(\eta\) 从 0 积到那一刻。两个量纠缠在同一个积分里，一个可控一个不可控，最优性条件写不干净。

\subsection{乘上一个任意函数再积分，影子就被换掉了}

用一个看起来多此一举的操作。沿任何满足动力学的轨线，恒等式 \(\dot x - f(x,u) = 0\) 在每一时刻都成立。随便取一个可微函数 \(\lambda(t)\)，做内积再积分：

\[
\int_0^T \lambda(t)^{\trans}\big(\dot x - f(x,u)\big)\, dt = 0.
\]

加到 \(J\) 上不改变 \(J\) 的任何取值——加的是零。但零也有形状。这个零里含着 \(\dot{\delta x}\)，而分部积分能把导数从 \(\delta x\) 身上搬到 \(\lambda\) 身上：

\[
\int_0^T \lambda^{\trans}\dot{\delta x}\, dt
= \lambda(T)^{\trans}\delta x(T) - \int_0^T \dot\lambda^{\trans}\delta x\, dt .
\]

搬完之后整理，\(\delta x\) 在积分里的系数汇成一项，在终点处的系数汇成另一项。而 \(\lambda\) 是你随便取的——现在把这份自由用掉：指定它的演化方程和终端值，专门让这两处系数都归零。

系数一归零，\(\delta x\) 从表达式里整个消失，剩下的被积项只含 \(\eta\)。\(\eta\) 任意，它前面的系数就必须处处为零。最优控制的逐点特征由此落地。

协态（costate，也译伴随变量、adjoint）就是这样来的。它不是物理量，也不是先验存在的东西——它是为了把 \(\delta x\) 从必要条件里解耦掉而临时招募的辅助函数。招募的手法平平无奇，效果却把整个障碍搬开了。

\subsection{必要条件把无穷维寻优压成逐点选择}

定义 Hamiltonian

\[
H(x,u,\lambda) = \lambda^{\trans} f(x,u) - L(x,u).
\]

\begin{theorem}[Pontryagin 最大值原理]
设 \(u^*\) 是最优控制，\(x^*\) 是对应状态轨线，\(U\) 紧，\(f\)、\(L\)、\(\Phi\) 对 \(x\) 连续可微。则存在协态 \(\lambda(\cdot)\) 使得
\[
\dot\lambda = -\frac{\partial H}{\partial x},
\qquad
\lambda(T) = -\frac{\partial\Phi}{\partial x}\big(x^*(T)\big),
\]
并且在几乎每个时刻 \(t\)，
\[
u^*(t) \in \argmax_{u\in U} H\big(x^*(t), u, \lambda(t)\big).
\]
\end{theorem}

证明骨架就是上面四步：线性化得到 \(\delta x\) 的方程，用 \(\lambda\) 乘零式并分部积分，选 \(\lambda\) 消掉 \(\delta x\) 的两处系数，最后用 \(\eta\) 的任意性得到逐点条件。条件对账也值得单列：\(U\) 的紧性保证逐点的 \(\argmax\) 取得到；对 \(x\) 的可微性保证 \(f_x\)、\(L_x\) 存在；注意条件里没有要求 \(H\) 对 \(u\) 可微，逐点最大化是在集合 \(U\) 上做的，因此 \(u\) 落在边界上完全合法。这一点后面会兑现成 bang-bang 结构。

符号约定有一处需要交代。另一种同样通行的写法是 \(H = L + \lambda^{\trans} f\)，逐点取最小，协态整体差一个符号。两种陈述数学上等价。本节沿用``最大值''这个名字对应的约定；下一节切到取最小的那一套，因为在那里协态恰好等于值函数的梯度，读起来更顺。

定理的分量在结构转换上。原问题是整条时间轴上的全局寻优，自变量无穷维；结论把它换成了每一时刻在 \(U\) 上的一次有限维寻优，\(U\) 是区间时甚至能直接读出答案。换来的负担是 \(x^*\) 与 \(\lambda\) 必须同时解出，而这两条轨线互相缠绕。

\subsection{协态是状态的边际价格}

若只看它的出身，协态像个没有含义的中间变量。换到取最小的那套约定（协态变号，终端条件成为 \(\lambda(T) = \partial\Phi/\partial x\)），含义就露出来了。

\(\lambda(t)\) 度量的是：在时刻 \(t\) 给状态一个微小的正向推动，剩余的最优总代价会变化多少。它是状态对未来的边际价值。这与 \hyperref[sec:09-Convex-Optimization/05-Duality/04]{``对偶变量是约束的影子价格''} 里的读法一致——约束松一单位，目标改善多少。

伴随方程 \(\dot\lambda = -\partial H/\partial x\) 于是有了念法：边际价值沿最优轨线按``当前状态对远期代价的边际影响''折旧。Hamiltonian 里的 \(\lambda^{\trans} f\) 也有了念法：选控制时不只看眼下要付的 \(L\)，还要看这个控制把状态推向哪个方向，在边际价值这把尺子下往值钱的方向推就加分。

\subsection{两条积分方向相反，问题落成两点边值}

把条件摞起来看骨架。状态方程从左端的已知初值 \(x(0)=x_0\) 向前积；伴随方程从右端的已知终端值 \(\lambda(T)\) 向后积；每一时刻的 \(u\) 由逐点最大化决定，而这次最大化同时用到该时刻的 \(x\) 与 \(\lambda\)。

图里那两个``未知''是全部困难所在。\(x(0)\) 有了，\(\lambda(T)\) 有了，可 \(\lambda(0)\) 和 \(x(T)\) 都没有，没法从任何一端一口气积到底。这类结构叫两点边值问题，正是 \hyperref[sec:08-Numerical-Analysis/06-ODE/04]{``边值问题：从打靶到全局离散''} 的对象。打靶法猜一个 \(\lambda(0)\)，正向积到 \(T\)，看终端条件差多少，据此修正猜测；多重打靶把时间轴切成若干段，每段的初值都当作未知量，缓解长区间上的敏感性；配置法则把整条轨线离散成多项式系数，一次性求解一个大方程组。

优化的困难被换成了解方程的困难，解方程的困难再转交给数值方法。每一次转手都收费，也每一次都换回一点可计算性。

\subsection{Bang-bang 让解的形状先于解本身出现}

最大值原理有时先交出解的形状，具体数值轨线可以往后放。最速停车是经典例子：动力学 \(\ddot y = u\)，控制受限 \(\abs{u}\le 1\)，要求从任意初始状态用最短时间到达原点并停住。只计时间的代价即 \(L\equiv 1\)，Hamiltonian 为

\[
H = \lambda_1 x_2 + \lambda_2 u - 1, \qquad x_1 = y,\; x_2 = \dot y .
\]

\(H\) 对 \(u\) 是线性的，而线性函数在区间上的最大值只能落在端点：

\[
u^*(t) = \sign\lambda_2(t).
\]

控制只取 \(\pm 1\)，从不停留在中间。要么满推，要么满刹。名字里的 bang-bang 由此而来。

切换次数也能读出来。伴随方程给 \(\dot\lambda_1 = 0\)、\(\dot\lambda_2 = -\lambda_1\)，于是 \(\lambda_2\) 是时间的一次函数，至多跨零一次。整条最优轨线因此至多切换一次：先满推一段，再满刹一段，停在原点。

这些结论没有积过任何一个初值问题。回头看上图那道中间的虚线连接——逐点最大化每一次都只是在 \(U\) 上比大小，比的对象是 \(\lambda_2\) 的符号，符号的变化次数又被伴随方程的阶数卡死。结构信息就这样从必要条件里直接掉出来，具体轨线可以晚一点再算。

\subsection{必要条件不保证最优，也不覆盖所有情形}

最大值原理给的是必要条件。满足它的轨线称为极值轨线，可能最优，也可能只是驻点式的候选。动力学或代价非凸时，极值轨线可以有好几条，得逐一比较代价，或者补上充分性条件，才敢断言全局最优。

终端条件的形态也要看具体问题。终点自由且无终端代价时，条件退化为 \(\lambda(T)=0\)；终点被硬性钉在某个值上时，会另外生出一组乘子，此时不能把自由终点的公式照抄。

再往里还有两处更隐蔽的地方。控制取值集非紧、或状态方程对 \(u\) 不连续时，原始陈述的前提失效。奇异弧是另一类：切换函数在一整段区间上恒为零，逐点最大化在那段时间里给不出唯一的 \(u\)，需要对切换函数继续求导才能定出控制，这已经超出上面那套推导的射程。

把这些边界摆清楚之后，还剩一个问题最大值原理答不上来。它算出的是一条最优轨线，绑定在某一个初值 \(x_0\) 上；换个初值，全套两点边值问题得重解一遍。风一吹把无人机推离预定航迹，手里那条精心算出的轨线立刻失效——这不正是上一节说的开环困境吗。要得到一条对任意状态都能立即给出动作的规则，得换一个提问方式：从任意状态出发，剩下的最优代价是多少？下一节从这个问题出发。
