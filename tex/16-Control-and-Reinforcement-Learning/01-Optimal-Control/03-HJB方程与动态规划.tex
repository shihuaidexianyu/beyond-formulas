\section{HJB 方程与动态规划}
\label{sec:16-Control-and-Reinforcement-Learning/01-Optimal-Control/03}

四轴无人机的状态是十二维：位置三维、速度三维、姿态角三维、角速度三维，控制是四个旋翼的推力。动力学、代价权重、终端罚项都齐了，按上一节的办法解一个两点边值问题，打靶法跑几轮，最优轨线和配套的控制序列拿到手。飞到第 \(3.7\) 秒，一阵侧风推过来，位置偏了 \(0.4\) 米，速度方向也变了。手上那条控制序列是用旧初值算出来的，当前状态已经不在那条轨线上；把原序列接着往下播，代价不再最优。要拿到从新状态出发的最优控制，十二维的边值问题得整个重解一遍——而控制循环每十毫秒转一圈。缺的并不是更快的求解器，是另一种形态的解。

\subsection{值函数把整个未来压成一个数}

要的东西是一个函数 \(u^*(t,x)\)：喂给它当前时刻与当前状态，立刻吐出该打的控制。风把系统推到哪儿都无所谓，查一次就行。

通往它的中间量是值函数。从时刻 \(t\)、状态 \(x\) 出发，此后一路采取最优控制，剩余代价的下确界记为

\[
V(t,x) = \inf_{u(\cdot)}
\Bigl\{ \Phi(x(T)) + \int_t^T L(x(s),u(s))\, ds \Bigr\},
\]

其中 \(\dot x = f(x,u)\) 约束着整条积分路径，终点 \(x(T)\) 是所选的 \(u(\cdot)\) 从 \((t,x)\) 推到的地方。终端条件是显然的：

\[
V(T,x) = \Phi(x).
\]

到了终点没有过程可言，只剩终值代价。

定义里没有算法。它只是一个下确界——能遍历全部控制函数的话，这是能做到的最好结果。任何具体策略给出的代价都是 \(V(t,x)\) 的上界，打不破它。

手机导航的``预计剩余时间''是它的日常版本：根据你此刻所在的路口和当下的路况，估计从这里到目的地的最短耗时。你之前开了多久不单独立项，那些都已经沉淀进当前位置里了。原定路线突然封路，旧计划过期，但当前状态仍然装着继续决策所需的全部信息，重查一次即可。

再想深一层。两个路口眼下都堵着一分钟，一个后面接畅通主路，另一个后面还是长队。这一步的代价相同，值函数却不同——它衡量的是整条剩余未来的分量。这也是 \(V\) 与沿具体轨线定义的 \(J\) 的分界：\(J\) 针对一条给定的控制函数，哪怕那条控制很糟也照样算得出一个数；\(V\) 对全部可能的控制取最值，度量的是那个位置本身的潜力。

\subsection{尾巴不能有更优的替法}

从 \((t,x)\) 出发的最优策略，先走极短的一小段 \(h\)，到达 \(x(t+h)\)。从那个新状态往后，剩下的控制不可能比最优更好——否则把更好的那截尾巴换上去，整条策略的代价就压过了原来那个``最优''，自相矛盾。写成等式：

\[
V(t,x) = \inf_{u \text{ 在 } [t,t+h]}
\Bigl\{ \int_t^{t+h} L(x(s),u(s))\, ds + V\bigl(t+h, x(t+h)\bigr) \Bigr\}.
\]

Bellman 最优性原理说的就是这句话：全局最优路径的任意一截尾部，从它自己的起点看也必须最优。

它给的是一个自洽条件，不是计算公式。与上一节对照着看：最大值原理扰动整条轨线做一阶变分，得到一组必要条件；Bellman 原理切掉最开头一小截，得到一个递归结构。两条路从不同方向逼近同一个最优解，沿最优轨线给出等价的信息。

\subsection{让 \texorpdfstring{\(h\to0\)}{h 趋于 0}，递归就变成偏微分方程}

假设 \(V\) 光滑。在 \([t,t+h]\) 上把控制冻结为常值 \(u\)，一阶展开：

\[
\begin{aligned}
x(t+h) &= x + h f(x,u) + o(h), \\
\int_t^{t+h} L\, ds &= h L(x,u) + o(h), \\
V\bigl(t+h,x(t+h)\bigr) &= V(t,x) + h\,\partial_t V + h\,\nabla_x V\cdot f(x,u) + o(h).
\end{aligned}
\]

代回 Bellman 等式，两边的 \(V(t,x)\) 相消，除以 \(h\) 并令 \(h\to 0\)：

\[
-\partial_t V(t,x) = \min_{u\in U}
\Bigl\{ L(x,u) + \nabla_x V(t,x)\cdot f(x,u) \Bigr\},
\qquad V(T,x) = \Phi(x).
\]

这条方程叫 Hamilton--Jacobi--Bellman 方程，简称 HJB。它是一阶非线性偏微分方程，自变量有 \(n+1\) 个（\(n\) 个状态加时间），时间方向从 \(T\) 倒着走向 \(0\)。解出 \(V\) 之后，最优反馈律从内部那次逐点最小化里直接读：

\[
u^*(t,x) \in \argmin_{u\in U}
\Bigl\{ L(x,u) + \nabla_x V(t,x)\cdot f(x,u) \Bigr\}.
\]

\subsection{协态就是值函数的梯度，两条路线在这里交汇}

留意 \(\nabla_x V\) 的含义：状态朝某个方向挪一单位，未来代价省下多少。上一节的协态 \(\lambda\) 扮演的正是这个角色。沿最优轨线取 \(\lambda(t) = \nabla_x V\bigl(t, x^*(t)\bigr)\)，对 HJB 关于 \(x\) 求导，恢复出来的就是伴随方程 \(\dot\lambda = -\partial H/\partial x\)。一条从全局值函数出发，一条从单条轨线的一阶必要条件出发，交汇于同一个最优解。

交汇不等于等价，两边付出的计算形态不同。最大值原理解一个 \(2n\) 维的两点边值问题，只服务一个初值，扰动一来就得重解；HJB 解一个 \(n+1\) 维非线性偏微分方程，换来一张覆盖全状态空间的反馈表。上图里的两幅画就是这份交换的图示：一条线换一张地图，账单记在维数上。

\subsection{二次假设把 PDE 压成一个矩阵 ODE}

退到一个能完整算到底的情形。线性动力学配二次代价，即线性二次调节器（LQR）：

\[
\dot x = Ax + Bu, \qquad
J = \tfrac12 x(T)^{\trans} S\, x(T)
+ \tfrac12 \int_0^T \bigl( x^{\trans} Q x + u^{\trans} R u \bigr)\, dt,
\]

其中 \(Q, S \succeq 0\)，\(R \succ 0\)。偏离要付钱，用力也要付钱，都按二次计价。

猜值函数同样是二次型：\(V(t,x) = \tfrac12 x^{\trans} P(t) x\)，\(P(t)\) 对称待定，于是 \(\nabla_x V = P(t)x\)。HJB 右端与 \(u\) 有关的部分是

\[
\tfrac12 u^{\trans} R u + x^{\trans} P B u,
\]

对 \(u\) 求梯度置零得 \(Ru + B^{\trans}Px = 0\)，即

\[
u^*(t,x) = -R^{-1}B^{\trans}P(t)\, x, \qquad K(t) = R^{-1}B^{\trans}P(t).
\]

最优控制自动落成状态的线性反馈。\(R\succ 0\) 保证这个驻点是极小而非极大，也保证 \(R^{-1}\) 存在。在线运行时不必再做任何逐点最小化，代数结构已经锁死，剩下的问题只是定出 \(P(t)\)。

把最优值代回。最小值处的那两项合成 \(-\tfrac12 x^{\trans} P B R^{-1} B^{\trans} P x\)，再补上 \(\tfrac12 x^{\trans}Qx\) 与 \(x^{\trans}PAx = \tfrac12 x^{\trans}(A^{\trans}P + PA)x\)，左端是 \(-\tfrac12 x^{\trans}\dot P x\)。二次型对一切 \(x\) 相等，系数矩阵就得相等：

\[
-\dot P = Q + A^{\trans}P + PA - P B R^{-1} B^{\trans} P, \qquad P(T) = S.
\]

Riccati 微分方程。跨越 \((t,x)\) 的非线性偏微分方程，被二次假设压成了只依赖 \(t\) 的矩阵常微分方程。\(P\) 是 \(n\times n\) 对称矩阵，含 \(n(n+1)/2\) 个独立标量方程；\(n=12\) 的无人机是 78 个方程，从 \(T\) 倒着积到 \(0\)，几毫秒跑完。

运算因此分成两段。离线那段从 \(P(T)=S\) 倒积 Riccati 方程，把增益 \(K(t)\) 存成一张表。在线那段只是一次矩阵乘向量：\(u^* = -K(t)x\)。被风吹偏了？\(x\) 变了，拿新的 \(x\) 再乘一次。反馈以采样频率持续产出新控制，再也不用回头跑优化。

\subsection{标量例子把权衡铸成两个数}

取最简系统 \(\dot x = u\)，无穷时域，

\[
J = \tfrac12\int_0^\infty \bigl( q x(t)^2 + r u(t)^2 \bigr)\, dt, \qquad q>0,\ r>0.
\]

稳态下值函数与 \(t\) 无关，写成 \(V(x) = \tfrac12 P x^2\)，\(P\ge 0\) 是标量。稳态 HJB 为

\[
0 = \min_u \Bigl\{ \tfrac12 q x^2 + \tfrac12 r u^2 + P x u \Bigr\}.
\]

最小化给 \(ru + Px = 0\)，即 \(u^* = -(P/r)x\)。代回化简得 \(q - P^2/r = 0\)，取非负根 \(P=\sqrt{qr}\)，于是

\[
u^* = -\sqrt{q/r}\; x, \qquad V(x) = \tfrac12\sqrt{qr}\; x^2 .
\]

两个数把整套权衡铸了进去。把 \(q\) 调大（偏离更不能忍），\(\sqrt{q/r}\) 变大，控制更激进，同时 \(V\) 也变大——犯同样的错变贵了。把 \(r\) 调大（更心疼能耗），\(\sqrt{q/r}\) 变小，控制更克制，\(V\) 照样变大——省下的控制量要用更大的偏离去换。

LQR 比手调 PID 多出来的是这一层建模依据。你先说清``偏离一单位''与``多用一单位控制''的相对价格，Riccati 方程再推出与之匹配的增益。价格仍然是你的判断，数学不替你定；但判断一旦落定，给出的反馈律在所有策略中让二次代价取到最小。

\subsection{二维例子让位置增益与阻尼增益一次成型}

丰富一层。双积分器 \(\ddot y = u\) 写成状态空间：

\[
\dot x_1 = x_2, \quad \dot x_2 = u, \qquad
J = \tfrac12\int_0^\infty \bigl( q x_1^2 + r u^2 \bigr)\, dt .
\]

代价里只罚位置，不直接罚速度。矩阵形式为

\[
A = \begin{bmatrix} 0 & 1 \\ 0 & 0\end{bmatrix},\quad
B = \begin{bmatrix} 0 \\ 1\end{bmatrix},\quad
Q = \begin{bmatrix} q & 0 \\ 0 & 0\end{bmatrix},\quad
R = [\,r\,].
\]

设 \(P = \begin{bmatrix} p_{11} & p_{12} \\ p_{12} & p_{22}\end{bmatrix}\)，代入稳态 Riccati 方程 \(0 = Q + A^{\trans}P + PA - PBR^{-1}B^{\trans}P\)，逐元素比较：

\[
\begin{aligned}
(1,1):&\quad q - p_{12}^2/r = 0 &&\Longrightarrow\quad p_{12} = \sqrt{qr}, \\
(1,2):&\quad p_{11} - p_{12}p_{22}/r = 0 &&\Longrightarrow\quad p_{11} = p_{12}p_{22}/r, \\
(2,2):&\quad 2p_{12} - p_{22}^2/r = 0 &&\Longrightarrow\quad p_{22} = \sqrt{2 r p_{12}} .
\end{aligned}
\]

增益随之落定：

\[
K = R^{-1}B^{\trans}P = \frac1r \begin{bmatrix} p_{12} & p_{22}\end{bmatrix}
= \begin{bmatrix} \sqrt{q/r} & \sqrt{2}\,(q/r)^{1/4} \end{bmatrix},
\]

\[
u^* = -\sqrt{q/r}\; x_1 - \sqrt{2}\,(q/r)^{1/4}\, x_2 .
\]

两项分工明确：位置偏离触发纠正，速度过快触发阻尼。代价函数里一个字都没提速度，阻尼项却自己长了出来——因为位置的未来偏离由当前速度决定，值函数把这层关系吸收了进去。手工整定要分别调两个旋钮再猜它们的耦合效应，Riccati 方程一次给出整套协调方案。

\subsection{切换面上，值函数会拐出尖角}

上面每一步都假定 \(V\) 可微。可最优控制的解常在策略切换处折断：上一节的 bang-bang 就是标本，控制从最大正向直接跳到最大反向，值函数在切换面上拐了个尖。尖点处偏导数不存在，经典 HJB 逐点套用不了。

黏性解框架就是为这里准备的。在不可微点，用局部光滑的测试函数从上方或下方接触 \(V\)，把等式条件松弛成一对不等式条件。\(V\) 光滑时黏性解退回经典解，不光滑时仍保有唯一性，且能被单调有限差分格式稳定逼近。

LQR 碰不上这个麻烦，二次型天生光滑。但只要加上控制饱和 \(u_{\min}\le u\le u_{\max}\)，或者加上避障之类的状态约束，逐点最小化就变成带约束的优化，值函数不再是单个二次型，HJB 也降不成 Riccati。谈论那一类问题的``解''时，黏性解是绕不开的语言。

\subsection{全状态地图的格点数按维数指数增长}

回头看上图右边那张地图。它的好处一目了然：每个状态上都备着答案。它的账单同样一目了然——每个状态上都得存一个数。\(d\) 维空间每维取 \(m\) 个格点，共 \(m^d\) 个格点，每个格点上还要跑一次最小化、与邻居耦合。取 \(m=100\)、\(d=6\)，格点数就是 \(10^{12}\)，超出任何现成算力。

这不是方法没设计好。动态规划如实承接了``同时为所有可能状态求最优代价''这个要求的成本，要求本身就贵。

LQR 的价值因此不在通用性，而在它精确圈出了一块算得动的子空间：线性动力学、二次代价、无约束控制。在这块子空间里值函数被一个 \(n\times n\) 对称矩阵完整参数化，存储量从 \(O(m^d)\) 坍缩到 \(O(n^2)\)。

三条路可以摆在一起看。最大值原理绕开状态网格，只求一条轨线，丢掉的是反馈。HJB 画出整张地图，拿到反馈，承担维数爆炸。LQR 两样都要，前提是三个强假设同时成立。假设一旦被现实拿走一个，工具就得跟着换：\hyperref[ch:136]{``强化学习：模型未知时怎样逼近最优决策''} 拿走的是``模型已知''这一条——转移函数上的精确期望做不了，就从一条条采样里逼近值函数。Bellman 递归的骨架仍在，承载它的计算从精确积分换成了采样与函数逼近的组合。
