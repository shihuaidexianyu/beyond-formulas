\section{MDP 把决策问题写成随机过程}
\label{sec:16-Control-and-Reinforcement-Learning/02-Reinforcement-Learning/01}

一台机器人在仓库通道口站着。向左可能更快到货架，但那段路常堵叉车；向右稳定但多绕 15 米；原地等几秒也许能避开即将经过的运输车。如果只看眼前一步，``向左少走两米''似乎最好。但这一步会把它带到新的位置，改变下一步能选什么，也改变未来会遇到怎样的拥堵。

这个问题的要害是：动作不只是拿到眼前的收益，它还会改变你\emph{站在哪里}做下一个决策。一条好的决策规则必须穿透时间的连锁效应，不能只比较当下这一步。Markov 决策过程（MDP）把这条因果链压成五个对象，为后面的所有算法提供统一的数学模型。

\subsection{五个对象与一条交互链}

一个折扣 MDP 记作

\[
(\mathcal S,\mathcal A,P,R,\gamma).
\]

\begin{itemize}
\tightlist
\item
  状态空间 \(\mathcal S\)：当前决策所需的全部信息；
\item
  动作空间 \(\mathcal A\)：智能体可选的输入；
\item
  转移核 \(P(s'\mid s,a)\)：在状态 \(s\) 执行动作 \(a\) 后到达 \(s'\) 的概率；
\item
  奖励 \(R\)：一次转移带来的即时评价，可写成 \(R(s,a,s')\) 或其条件期望；
\item
  折扣率 \(0\le\gamma<1\)：未来奖励相对当前奖励的折合权重。
\end{itemize}

交互在离散时间上循环推进：

\[
S_t
\xrightarrow{\ A_t}
(R_{t+1},S_{t+1})
\xrightarrow{\ A_{t+1}}
\cdots .
\]

这里奖励记成 \(R_{t+1}\)，因为它由时刻 \(t\) 的状态与动作触发，与下一状态一起返回。文献也有写 \(R_t\) 的——只要整篇索引一致，两种约定没有本质差异，但你读不同来源时得先看一眼下标习惯。

如果拿掉动作，转移只剩 \(P(s'\mid s)\)，MDP 就退化成\hyperref[sec:06-Random-Processes/03-Markov-Chains/01]{Markov 链}。动作的加入使转移矩阵不再是固定的——策略每选一个动作，就选了下一步概率规律的一部分。

\subsection{Markov 性质不是``世界没记忆''}

MDP 要求

\[
P(S_{t+1},R_{t+1}\mid S_0,A_0,\ldots,S_t,A_t)
=
P(S_{t+1},R_{t+1}\mid S_t,A_t).
\]

这句话的意思是：给定当前状态与动作之后，更早的历史不再\emph{额外}改变下一步的概率分布。世界当然可以有记忆。状态的任务就是把对未来仍有影响的那部分历史\emph{装进来}。

恒温控制是最容易出错的例子。状态只记当前温度，不记加热器内部仍在升高的热惯性——同样的 23 度，``刚关加热器''和``刚开加热器''的未来温度走向完全不同。此时 Markov 性质已经失败了。修法是：把加热器内部温度、上一动作或必要的历史摘要一起塞进状态，不能假装历史无关。

状态是为了预测未来而选择的信息压缩，不是随便罗列几个传感器读数就能满足 Markov 性质。你需要检验：给定你选的状态之后，更早的观测是否还携带对未来回报或下一状态的额外信息。如果有，状态还不够。

若真实状态无法完整观测，智能体只看到观测 \(O_t\)，问题退化为部分可观测 MDP（POMDP）。此时可以用整个观测历史、循环神经网络的状态或对隐藏状态的信念分布作为决策依据。把非 Markov 的观测当成状态直接用，标准 Bellman 递归的前提就已经被破坏，后面的算法跑得再勤也答非所问。

\subsection{策略把 MDP 压回 Markov 链}

策略 \(\pi(a\mid s)\) 给出在状态 \(s\) 选动作 \(a\) 的概率。确定性策略是特殊情形，可写为 \(a=\pi(s)\)。策略一旦固定，动作的不确定性被吸收到转移中：

\[
P^\pi(s'\mid s)
=
\sum_a \pi(a\mid s)P(s'\mid s,a),
\]

于是受控过程重新变成一条普通的 Markov 链。评价一个策略，就是评价由这个策略诱导出的随机过程。这条推理链很实用：你把策略的好坏转化成了链的长程行为。

只依赖当前状态而不显式依赖时间的策略叫平稳 Markov 策略。对有限状态动作的无限时域折扣 MDP，存在确定性的平稳最优策略——这不是自明的，需要证明，但确实成立。有限时域问题则通常需要把剩余时间写进策略，或把时间本身并入状态。不能把无限时域的结论不加说明地搬到所有任务上去。

\subsection{从即时奖励到长期回报}

如果只最大化下一步奖励，算法会变得短视。定义从时刻 \(t\) 起的折扣回报：

\[
G_t
=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots
=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}.
\]

睡前纠结``再看一集''还是``现在睡觉''就是这个结构：多看一集立刻放松，少睡的疲劳却要到起床和第二天工作时才兑现。如果评价标准只停在下一步，未来的困倦根本进不了今晚的决策。\(G_t\) 把随后发生的全部后果沿时间轴折叠回当前——这正是折扣率 \(\gamma\) 扮演的角色。

把 \(\gamma\) 调小，等于在评价标准里真的减轻了明天相对于今天的权重，不只是让算法跑得快一点。若奖励有界且 \(\gamma<1\)，级数绝对收敛。折扣常见的三种理解：

\begin{itemize}
\tightlist
\item
  时间偏好：越早的奖励越要紧；
\item
  随机终止：每一步以概率 \(1-\gamma\) 结束，\(\gamma^k\) 就是任务活过 \(k\) 步的概率；
\item
  数学正则化：使 Bellman 算子成为压缩映射，保证值函数唯一、迭代收敛。
\end{itemize}

折扣不是无害的技术旋钮。\(\gamma\) 靠近 0 会真的改变最优策略，让它更重视近处；接近 1 则延长有效规划时域，但让远期的估计误差传播更远、收敛更慢。对自然终止且期望长度有限的 episodic 任务，可以取 \(\gamma=1\)；对持续任务则常改用长期平均奖励，理论和算法都要重新表述。

\subsection{两个值函数回答两种问题}

策略 \(\pi\) 的状态值定义为

\[
V^\pi(s)
=
\E_\pi\left[G_t\mid S_t=s\right],
\]

``到达状态 \(s\) 后一直按 \(\pi\) 走，预期能拿到多少回报''。动作值定义为

\[
Q^\pi(s,a)
=
\E_\pi\left[G_t\mid S_t=s,A_t=a\right],
\]

``当前强制先做动作 \(a\)，之后再按 \(\pi\) 走''。两个值的关系：

\[
V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a).
\]

状态值适合评价处境，动作值适合直接比较选择。如果模型已知，从 \(V\) 可以用一步前瞻比较动作；如果模型未知，\(Q\) 的优势是选动作时不依赖显式的转移概率——Q 学习的入口就在这里。

\subsection{奖励设计会改写问题，不只是加速学习}

仓库机器人若每走一步奖励 \(-1\)、到达目标奖励 \(0\)，最大化回报等价于偏好更短路径。若碰撞罚得不够重，机器人可能走高风险捷径；若只在到达时给正奖励而没有步数代价，在 \(\gamma=1\) 下所有最终能到的路线可能同样好。奖励不是模型的装饰——它\emph{定义}了什么叫最优。

奖励塑形可以缓解稀疏反馈，却可能诱发钻空子：按``接近目标的距离减少''给奖励，智能体也许在两个位置之间来回刷分；只奖励点击率，推荐系统可能牺牲长期满意度。只有特定形式的势函数塑形

\[
F(s,a,s')=\gamma\Phi(s')-\Phi(s)
\]

能在标准条件下保持最优策略不变。任意加减奖励项都可能重写任务。``学得更快''和``目标没变''是两回事，不能混在一起说。

\subsection{模型已知与模型未知的分界}

如果 \(P\) 和期望奖励都已知，可以对所有下一状态做精确求和，直接解 Bellman 方程——这属于动态规划。如果它们未知但可以交互采样，便只能观察

\[
(S_t,A_t,R_{t+1},S_{t+1})
\]

这样的单步样本，用样本平均或随机逼近替代模型的期望——这才进入强化学习。两者优化的是同一个 MDP，差别在信息条件和计算方式。

库存系统能说明``可以观察单步样本''这句话也需要仔细解释。设 \(I_t\) 是现有库存，\(q_t\) 是订单，潜在需求为 \(D_t\)，下一期库存近似满足

\[
I_{t+1}=(I_t+q_t-D_t)_+.
\]

数据库真正记录的销量却只有

\[
S_t=\min\{D_t,I_t+q_t\}.
\]

订单 \(q_t\) 不只改变下一状态，还决定了缺货时有多少需求根本观测不到。如果状态里没记录缺货标志、在途订单和历史促销，转移样本就撑不起你写的 Markov 模型。叫算法 model-free 不会让删失需求或遗漏状态自动消失——它只表示更新时没有显式使用一张已知的转移表，不代表你可以忽略数据是怎么来的。

MDP 还默认转移和奖励规律在学习期间大致稳定。如果环境因其他学习者的策略变化、季节效应、设备磨损而持续漂移，过去的样本和当前规律不再是同分布，固定的 Bellman 方程本身就在移动。此时需要在线追踪、显式建模非平稳性或重新定义状态——让算法多训练几轮不能修复一个正在改变的问题。
