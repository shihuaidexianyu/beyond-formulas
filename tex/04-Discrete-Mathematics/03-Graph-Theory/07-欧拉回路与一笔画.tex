\section{欧拉回路与一笔画}
\label{sec:04-Discrete-Mathematics/03-Graph-Theory/07}

走遍每条边的全局问题，被``每次进入必须成对离开''压缩成局部度数奇偶。充分性证明又能直接变成拼接回路的构造算法——判定与构造在这里是同一件事。

\subsection{Königsberg 的七座桥：试不出来，就必须推理}

18 世纪的 Königsberg（今俄罗斯 Kaliningrad）被 Pregel 河切成四块陆地：河心两座岛，外加南北两岸。七座桥把它们连在一起。当地流传一个问题：能不能从某处出发，把每座桥恰好走一遍，最后回到出发点？

无数人尝试过。走法换了一条又一条，每次不是漏了某座桥，就是某座桥走了两遍。但``没人走出来''并不等于``走不出来''——尝试只能覆盖有限条路线，而可能的路线是天文数字。要断言一件事不可能，靠试是不够的。数学在这里找到了它最该登场的缝隙：当枚举不可能时，必须找到一种不依赖枚举的推理。

\subsection{Euler 的第一步：扔掉一切不改变答案的东西}

Euler 在 1736 年给出的推理，第一步是极端的简化。他注意到：陆地有多大、桥有多长、走路快慢、桥是石砌还是木搭——全都不影响答案。唯一要紧的是``哪块陆地跟哪块陆地之间有桥、有几座''。

于是每块陆地缩成一个点，每座桥画成一条线。Königsberg 变成了一张只有 4 个顶点、7 条边的图。顶点的地理坐标消失了，边的曲直消失了，但连接模式被完整保留。一个看似关于城市和散步的问题，答案只依赖``谁跟谁相连''这一个抽象性质。图论作为一门学科从此诞生。

有两点值得记下。第一，这座桥图不是简单图：南岸和东岛之间并排着两座桥，也就是两条平行边。本节允许平行边（即讨论的是多重图），计算度数时每条平行边各算一次。第二，四块陆地的度数算出来分别是 \(5, 3, 3, 3\)——全部是奇数。这个奇偶事实很快就将成为全部推理的支点。

\subsection{把``走不走得通''翻译成进出计数}

沿桥行走，经过一块陆地时必然沿一座桥进入、沿另一座桥离开。桥被进出成对地消耗。于是三个互斥的情形浮现：

\begin{itemize}
\tightlist
\item
  中途经过的陆地：每次经过消耗两座桥，所以它的度数必须是偶数，桥才能恰好配成对。
\item
  起点和终点不同：起点比别的陆地多一次``只出不进''，终点多一次``只进不出''——恰好这两处的度数为奇数。
\item
  起点和终点相同（闭合行程）：首次离开与最终返回也配成一对，起点同样是偶度。
\end{itemize}

Königsberg 的四块陆地度数全是奇数——\((5,3,3,3)\)——落不进上面任何一条。散步难题因此有了确定的否定答案：无论怎么走，这样的路线不存在。结论不依赖任何一次具体尝试，只依赖一次奇偶计数。

这不只是一个七桥游戏的终结。Euler 做的是把``能否遍历所有边''这个全局的、路径级别的问题，压缩成了``每个顶点度数奇偶''这个局部的、可逐点检查的条件。全局问题被局部条件完全刻画——这在数学中并不多见，每一次出现都值得停下来多看两眼。

\subsection{定理：连通且全偶，不多不少}

把问题一般化。经过每条边恰好一次的闭合迹叫欧拉回路（Euler 回路），不闭合的叫欧拉通路。中文里更形象的说法是一笔画：笔尖不离纸，每条线恰好描一次。\hyperref[sec:04-Discrete-Mathematics/03-Graph-Theory/02]{``路径、环与连通性''}已经给出过判据，本节负责补上它的来历、完整证明与用法。

欧拉定理：无向图中所有非零度顶点属于同一连通分量时，它存在欧拉回路，当且仅当每个顶点的度数为偶数。

这里措辞很小心——没有粗略地写成``图连通''。一个孤立点没有任何关联边，它完全不会妨碍你走遍其他所有的边；要求它也必须被连进同一个分量是不必要的过度约束。如果没有孤立点，条件就自然地简化成通常所说的``连通且度数全偶''。若图一条边也没有，空的闭合游走可视为平凡情形——它是否符合欧拉回路的定义取决于教材约定，但不影响非空图的判据。

必要性方向就是上文计数逻辑的形式化：沿欧拉回路行进，每进入一个顶点就必沿另一条边离开，关联边被一进一出配成对。起点呢？首次出发和最后返回恰好也配成一对进出。所以每个顶点度数均为偶数。

\subsection{充分性：证明本身就是一个构造算法}

充分性是更有意思的一半——它不只是宣布存在，而是手把手教你找出来。

设图连通且全偶。从任意一个非零度顶点 \(v_0\) 出发，沿没走过的边随意走，走过的边随即标记为``已用''。关键的观察是：除了 \(v_0\)，任何顶点一旦你走进去，它的偶度数保证至少还有一条没走过的边可以让你走出去。所以这种随意行进只有回到 \(v_0\) 时才会被迫停下——因为只有 \(v_0\) 的初始出发没有对应的``进入''来消耗一条邻边。于是你得到一条闭合回路 \(C\)。

如果 \(C\) 已经用完了所有边，故事结束——你已经找到了欧拉回路。

否则，删去 \(C\) 上所有的边。每个顶点每被 \(C\) 经过一次就损失两条关联边，所以剩余图的度数仍旧全是偶数。由原图连通，剩余边中必有一条的端点落在 \(C\) 上——否则从剩余边走到 \(v_0\) 的路径会在进入 \(C\) 之前就中断。

从这样一个公共顶点 \(u\) 出发，在剩余图中重复同样的随意行进，必然再次回到 \(u\)，得新回路 \(C'\)。把 \(C'\) 在 \(u\) 处拼进 \(C\)：沿 \(C\) 走到 \(u\) 时，先绕完 \(C'\) 一圈再继续走 \(C\) 的剩余部分。合并后的回路更长，而剩余度数依然全偶。重复这个过程——找回路、拼接回路——直到没有边剩下。最终的闭合回路经过每条边恰好一次，即欧拉回路。

有两点值得强调。其一，判据只数度数，跟图画成什么样子毫无关系；自环为度数贡献 \(2\)，也不干扰奇偶判断。其二，这个证明本身就是一个算法：不断找小回路、不断把新回路拼接到旧回路上。判定与构造是同一枚硬币的两面——欧拉回路不仅存在，而且可以高效地找出来。

\subsection{把证明执行出来：Hierholzer 算法}

上面的构造在算法文献中称为 Hierholzer 算法。直接按描述实现效率不高——每拼一个小回路就把整条路线重抄一遍太浪费。更聪明的做法是维护一个栈：

\begin{enumerate}
\tightlist
\item
  把任意一个非零度顶点压入栈；
\item
  如果栈顶顶点还有未使用的关联边，沿这条边走到新顶点，新顶点压栈，同时删除这条边；
\item
  如果栈顶顶点已经没有未使用的边可走，把它弹出并追加到答案序列的末尾；
\item
  重复直到栈空，最后把答案序列反转。
\end{enumerate}

为什么``无路可走时才输出''？因为那一刻说明，从这个顶点出发的所有边都已经被嵌进了某个闭合段，它在最终路线中的后继位置已经确定。栈里还没弹出的顶点则是还可能被新回路插入的骨架——它们尚在路线``内部''，等待被后续找到的回路在它们的位置上拼接进来。这个数据结构恰好实现了证明中的逻辑：找回路、记拼接点、插进去。

用邻接表存图，每条边在使用时只删除一次，整个过程的时间复杂度是

\[
O(|V|+|E|),
\]

与读入图本身的成本同阶。如果只需要判断存在与否，检查非零度顶点的连通性并统计奇度顶点也是线性时间。这里的``容易''有两层含义：有简洁的充要定理，且定理的构造可以在输入规模的线性时间内完成。

\subsection{一个微型反例：为什么``一直走没走过的边''不够}

考虑这样的图：两个三角形只共享一个顶点 \(v\)。三个``外围''顶点度数各为 \(2\)，\(v\) 度数为 \(4\)——全偶且连通，一定存在欧拉回路。

假设你从一个三角形出发，沿它绕了一圈回到 \(v\)，``眼前似乎已经闭合了''——但另一个三角形原封未动。这不是失败。从 \(v\) 出发，再去绕第二个三角形，然后把新回路在你第一次经过 \(v\) 的位置插进去。合并后：先进第一个三角形的一半，到达 \(v\) 时暂时离开去绕第二个三角形一圈，回到 \(v\) 再走完第一个三角形的剩余半边。

这个小例子精确地解释了为什么``一直选没走过的边、走通为止''还不是完整算法。随意行进保证形成闭合回路，却不保证第一次闭合就覆盖全图。必须保留在旧回路的任意顶点处插入新回路的机制。Hierholzer 的栈干的就是这件事：记下待拼接的位置。

另一个经典算法是 Fleury 算法：每一步尽量不走割边，除非已经没有别的选择。直觉是不要过早把剩余的图切成两半。它适合手算解释，但朴素实现需要反复判断割边，比 Hierholzer 慢得多。两条路都能找到欧拉路线：Fleury 适合解释``怎么不把自己困住''，Hierholzer 适合真正的程序实现。

构造完成后也应验证答案。若输出顶点序列是

\[
v_0, v_1, \ldots, v_m,
\]

则相邻顶点必须对应原图中尚未被使用过的某一条边，序列长度 \(m\) 必须等于 \(|E|\)；闭合情形还需要 \(v_m = v_0\)。多重图中仅核对端点对不够——同一对端点之间可能有平行边，程序或手算都应为每条边独立编号。这个检查是线性的，却能抓住漏边、重边和错误闭合三类高频失误。

还有一个隐蔽的联系值得指出。握手定理说每条边贡献两个端点度数，因此奇度顶点总数必为偶数。欧拉回路要求奇度顶点数为 0，欧拉通路允许其中两个成为边界——恰好用尽了握手定理允许的偶数个奇度顶点。图内部的所有进出相互抵消，只有路线边界留下失衡度数。这种``内部抵消、边界留下''的思考方式还会在流、散度与离散 Stokes 型公式中一再重现。

\subsection{不回到起点：奇度顶点刚好两个}

不要求闭合时，进出计数只在起点和终点两处放宽。于是奇度顶点的个数必须是 0 或 2——握手定理早已保证它是偶数（见\hyperref[sec:04-Discrete-Mathematics/03-Graph-Theory/01]{``图的语言与度数''}），欧拉通路的判据正好用尽了这两个``配额''。

对应定理：无向图中所有非零度顶点属于同一连通分量时，存在非闭合的欧拉通路，当且仅当奇度顶点恰有两个；并且通路的两端必定是这两个奇度顶点，别无选择。

证明用一个干净的``补边''技巧。在两个奇度顶点 \(s, t\) 之间添一条新边（如果它们原本已相邻，就再加一条平行边）。新图中所有顶点度数全变为偶数，于是存在欧拉回路。从回路中删去这条新边，剩下的恰好是一条从 \(s\) 到 \(t\) 的欧拉通路。反方向由端点计数直接得到——如果存在从 \(s\) 到 \(t\) 的欧拉通路，除两端外每点进出平衡，所以只有 \(s\) 和 \(t\) 可能奇度。

完整图景因此极为清晰：

\begin{itemize}
\tightlist
\item
  奇度顶点 0 个：可以一笔画并回到起点，起点任意选择；
\item
  奇度顶点 2 个：可以一笔画，但起点与终点被钉死在这两处；
\item
  奇度顶点超过 2 个（握手定理下至少 4 个）：无论如何动笔都不可能，连开放通路也不存在。
\end{itemize}

Königsberg 有 4 块奇度陆地，落在第三类——连``不必回家''的走法都不存在。判据把七桥问题一锤定音。

由此得到一套不会漏条件的判断顺序：先忽略孤立点，检查所有含边顶点是否连通（不连通意味着一支笔不可能从一个含边分量跳到另一个）；再数奇度顶点个数——0 个有闭合回路，2 个有开放通路，更多则无解；若要构造，闭合情形从任意非零度顶点出发，开放情形必须从两个奇度顶点之一出发。

只查奇偶忘记连通性会得到假结论：两个互不相连的三角形中每个顶点度数都是 2，奇偶全合格，但没有任何一条连续路线能跨越两个孤立的含边分量。只查连通性也不够——Königsberg 就是连通但奇偶失败的标准教材案例。

\subsection{有向图：``进出配对''翻译成入度等于出度}

如果桥是单行道，边有了方向，度数的奇偶就不再是正确的语言。闭合行程中每沿一条有向边进入顶点，必须沿另一条有向边离开，因此必要条件变成

\[
\deg^+(v) = \deg^-(v)
\qquad\text{对每个顶点 } v.
\]

此外，所有非零度顶点必须落在同一个强连通结构中：沿边方向既能从一处走到另一处，也能走回来。更精确的表述是：删去孤立点后，有向图存在有向欧拉回路，当且仅当每个顶点的入度等于出度，且所有含边顶点属于同一个强连通分量。

开放的有向欧拉通路允许两个端点出现失衡：起点 \(\deg^+ = \deg^- + 1\)（多一次离开），终点 \(\deg^- = \deg^+ + 1\)（多一次进入），其余顶点入度等于出度；再配以可达性条件即可。无向图中的``两个奇度顶点''在有向图中被替换为``一处多一次离开，一处多一次进入''。思想的骨架没有变：给每一次进入寻找一次配对的离开。

\subsection{应用与边界：当判据失败时}

欧拉回路回答的问题是``能不能不重复地覆盖所有的边''。街道巡视、铲雪路线、电路板钻孔走线、展馆参观流线——只要不可遗漏的对象是边（路段、连线、管段），先检查连通性和度数奇偶，答案几乎瞬间可得，无需搜索。

但现实更常遇到的是判据失败的情形。一个邮递员必须把辖区内每条街道至少走一遍，而图里偏偏有奇度顶点——重复走路不可避免。问题从``能不能不重复''变成``怎样重复才能使总路程最短''。

这就是中国邮路问题，因管梅谷 1962 年的研究得名。核心观察是：把一条边多走一遍，等价于在它的两个端点之间添一条平行边。为了让全图度数全变偶数，需要复制的那些边必须恰好把奇度顶点两两配对。最优方案由此得出：在所有奇度顶点之间求一组配对，使得配对两端之间最短路长度之和最小，然后把这些最短路径上的边各复制一遍。奇偶计数再一次把``走法''问题化归为纯粹的图上计算。

看清模型的边界和看清模型本身同样重要：

\begin{itemize}
\tightlist
\item
  欧拉模型要求``服务对象是边''——每条街、每段管廊或每条链路都要被覆盖。如果任务是访问每个客户一次，而客户位于顶点上，欧拉回路不仅答错了问题，连问题类型都搞错了：那是哈密顿问题，难度等级完全不同。
\item
  如果边有长度或代价，重复路段的成本不是简单的``重数乘以单位长度''——重复上坡和重复下坡的代价可能截然不同，模型需要引入边权。
\item
  如果道路有方向，必须使用有向版本的入度出度平衡条件，奇偶不再有意义。
\item
  如果图动态变化（道路维修、新桥开通），奇偶检查必须重新运行——一次判据的结果不对应于变化后的图。
\end{itemize}

一个实用的建模速查只需一个问题：不可遗漏的对象到底是边还是顶点？一旦答案是边，度数和进出配对往往是正确的第一站；一旦答案是顶点，你将面对哈密顿问题的 NP 困难。两类问题在字面上只差一个字，在计算上却隔着一个复杂度阶级。
