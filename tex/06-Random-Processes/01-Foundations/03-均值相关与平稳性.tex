\section{均值、相关与平稳性}
\label{sec:06-Random-Processes/01-Foundations/03}

你手上是一条长度 1000 的序列：某台服务器过去一千分钟的响应延迟。上一节说完整描述一个过程要交出全部有限维分布，那就试着从这条序列里估一个五维联合分布看看——把五个相邻时刻的取值当成 \(\R^5\) 里的一个点，你总共只有不到 1000 个点，散在五维空间里，任何一个直方格里都是空的。三维已经勉强，十维根本不必谈。

于是实践中的做法是再退一步，只保留前两阶：

\[
m_X(t) = \E[X_t],
\qquad
R_X(s,t) = \E[X_s X_t],
\qquad
C_X(s,t) = \Cov(X_s, X_t) = R_X(s,t) - m_X(s)\,m_X(t).
\]

均值函数 \(m_X(t)\) 是把无穷多条轨道叠起来取平均得到的那条曲线，它描述截面的位置。自协方差函数 \(C_X(s,t)\) 描述两个截面的联动：两个时刻各自偏离自身期望多少，这些偏离倾向于同号还是反号。自相关函数 \(R_X\) 是没有去均值的版本，两者只差一个 \(m_X(s)m_X(t)\)。

这三个函数估起来现实得多——一条序列就能给出所有滞后上的样本自协方差。代价是它们看不见三阶以上的结构，所以下面每一条结论都要问一句：它是对全部分布成立，还是只对前两阶成立。

\subsection{自协方差不能随手指定}

看起来光滑、衰减的函数未必能当自协方差。约束来自一个两行的推导。取任意有限个时刻 \(t_1,\ldots,t_n\) 和任意实系数 \(a_1,\ldots,a_n\)，

\[
\begin{aligned}
\sum_{i,j} a_i a_j\, C_X(t_i,t_j)
&= \Var\!\left(\sum_{i=1}^{n} a_i X_{t_i}\right)\\
&\ge 0.
\end{aligned}
\]

等号那一步是协方差的双线性性，把和的方差展成两两协方差之和，纯代数恒等式；不等号那一步是方差非负。合起来就是：对任意有限时刻集，矩阵 \([C_X(t_i,t_j)]\) 必须半正定。随手在某个滞后上塞一个很大的正值，往往就会造出负特征值，这样的``自相关函数''不对应任何过程。

另外两条性质在日常检查时够用：\(C_X(s,t)=C_X(t,s)\)，因为协方差本身对称；以及由 Cauchy--Schwarz 不等式

\[
\abs{C_X(s,t)} \le \sqrt{C_X(s,s)\,C_X(t,t)},
\]

也就是任意一对时刻之间的相关系数都落在 \([-1,1]\) 里。

\subsection{严平稳说的是截面分布经得起平移}

上一节的图里，截线可以画在任何位置。平稳性回答的问题是：把截线沿时间轴滑动，读到的东西会不会变。

最彻底的版本是严平稳：对任意 \(n\)、任意时刻组合和任意平移量 \(h\)，

\[
(X_{t_1}, X_{t_2}, \ldots, X_{t_n}) \overset{d}{=} (X_{t_1+h}, X_{t_2+h}, \ldots, X_{t_n+h}).
\]

整族有限维分布对时间平移不变。取 \(n=1\) 就得到边缘分布与 \(t\) 无关，若期望存在则 \(\E[X_t]=\mu\) 是常数；取 \(n=2\) 并令 \(h=-s\) 得到 \((X_s,X_t)\overset{d}{=}(X_0,X_{t-s})\)，若二阶矩存在则 \(C_X(s,t)\) 只依赖时差。这两条推论正是实践中真正被使用的部分，前提是相应的矩存在——不存在的矩不在讨论范围内。

反过来问什么会破坏严平稳，答案就是任何与绝对时间挂钩的统计特征：均值逐年漂移、波动率时聚时散、销量按月起伏。注意平稳不要求过程安静，它只要求起伏的统计规律不随时间改变。对做线上系统的人来说，这一条正好是分布漂移检测的零假设：你比较本周和上周的特征分布，隐含的假设就是在没有漂移的情况下这两个截面同分布。检测到差异，等价于拒绝平稳。

严平稳涉及全部有限维分布，检验它需要的数据量和刚才那个五维直方图一样不现实。所以更常用的是宽平稳（也叫二阶平稳或协方差平稳），它只要求两件事：均值 \(m_X(t)=\mu\) 为常数；自协方差只依赖时差，\(C_X(s,t)=\gamma_X(t-s)\)。

第二条顺带引入了一个记号。原来的 \(C_X\) 吃两个绝对时刻，宽平稳之下它退化成只吃差值的一元函数，记作 \(\gamma_X(\tau)=\Cov(X_t, X_{t+\tau})\)，与 \(t\) 无关，\(\tau\) 叫滞后。后文里 \(C_X\) 一律指二元版本，\(\gamma_X\) 指一元滞后版本。

两种平稳之间的关系不对称。严平稳加上二阶矩有限，自动给出宽平稳。反过来不成立：均值和协方差可以稳如磐石，而三阶及以上的联合结构随时间变化。Gaussian 过程是这条缝上的桥——上一节说过它的有限维分布由 \(m\) 与 \(K\) 完全决定，所以对 Gaussian 过程，宽平稳就是严平稳。

\subsection{平稳与平稳增量是两码事}

上一节把平稳增量当作构造规则用过，这里要和过程本身的平稳性对照一次。设 \(Z_1,Z_2,\ldots\) 独立同分布，随机游走 \(S_n = Z_1+\cdots+Z_n\)，\(S_0=0\)。增量 \(S_n - S_{n-1} = Z_n\) 独立同分布，所以过程有平稳独立增量。但

\[
\Var(S_n) = n\,\Var(Z_1)
\]

随 \(n\) 线性增长，而宽平稳要求方差恒定。随机游走越走越散，水平值的分布在膨胀。

反向的蕴含倒是成立：严平稳的过程，其增量自动平稳，因为平移之后整个联合分布不变，差分自然也不变。所以两个词描述的是不同的对象——``过程平稳''说水平值的统计性质不随时间变，``增量平稳''说变化量的统计性质与起点无关。看到一条序列在做无方向的漫游，先想到的应该是后者。

\subsection{平稳保证不了你能用一条轨道估期望}

现在到了本章落差最大的地方。平稳性保证截面分布不随时间变化，可你手上只有一条轨道，只能算时间平均。平稳能不能保证时间平均有意义？

不能。第一节那个随机水平线 \(X_t = Z\)（\(Z\sim\mathcal N(0,1)\)）是最干净的反例。它严平稳：所有时刻都等于同一个随机常数，任意有限维分布在平移下纹丝不动。总体均值 \(\E[X_t]=\E[Z]=0\)。可一旦固定了 \(Z=z\)，这条轨道上的时间平均

\[
\lim_{T\to\infty} \frac{1}{T}\int_0^{T} X_t\,dt = z
\]

等于该次实现抽到的那个常数，通常不是 0。时间平均确实收敛了，但它收敛到一个随机变量，不是收敛到总体均值。

\emph{一个平稳却不遍历的过程：轨道从一开始就被分进两层，之后永不相交。每条轨道自己看是平稳的，时间平均落在自己那一层；截面分布是双峰的，集合平均 1.5 落在两峰之间，而没有任何一条轨道到过那个高度。只观测其中一条，你会以为总体均值是 2.2 或 0.8。}

这就是遍历性缺失的样子。平稳管的是竖直方向：截线滑到哪里，读到的分布都一样。遍历管的是横竖两个方向能不能互换：沿一条轨道求的长期平均，等不等于沿一条截线求的集合平均。

\begin{theorem}[遍历定理的骨架]
设 \(\set{X_t}\) 严平稳且 \(\E\abs{X_0}<\infty\)。则时间平均 \(\frac{1}{n}\sum_{t=1}^{n} X_t\) 几乎必然收敛，极限为 \(\E[X_0 \given \mathcal I]\)，其中 \(\mathcal I\) 是过程的不变 \(\sigma\)-代数（那些平移过后不改变的事件）。若过程遍历，即 \(\mathcal I\) 中每个事件的概率非 0 即 1，则极限退化为常数 \(\E[X_0]\)。
\end{theorem}

两个条件各挡一种失效，值得分开记。平稳加可积保证极限\emph{存在}；遍历保证这个极限是一个数，而不是一个随机变量。随机水平线满足前者不满足后者：事件``\(Z>0\)''平移之后还是它自己，落在 \(\mathcal I\) 里而概率是 \(1/2\)，于是条件期望没有塌成常数，极限就是 \(Z\) 本身。上面那张图是同一件事的画法，两层轨道对应 \(\mathcal I\) 里那个概率既非 0 也非 1 的事件。

Markov 链上这个条件有很直白的对应物：状态空间若分成几个互不相通的类，链一旦落进某个类就出不来，时间平均只反映那个类的情况，起点在哪个类是随机的。所以``不可约''这个词在遍历性讨论里出现得如此频繁——它就是把 \(\mathcal I\) 压平的条件。周期性还会再挡一道，细节见\hyperref[sec:06-Random-Processes/03-Markov-Chains/02]{``可达、通信类与周期性''}与\hyperref[sec:06-Random-Processes/03-Markov-Chains/04]{``平稳分布、可逆性与遍历收敛''}。

这件事离实用比它看起来近得多。你只有一只股票过去十年的日收益，没有十年重跑一万次的平行世界；你只有一条线上服务的延迟序列，没有一万个同构集群同时开跑。凡是拿一条长序列去估期望、方差、分位数的操作，背后都站着遍历性这个假设。最典型的例子是 MCMC：它构造一条 Markov 链，让链的平稳分布等于你想采样的目标分布，然后拿链上的样本求平均。这个平均之所以能逼近目标分布下的期望，靠的正是遍历定理，而不是样本独立——链上相邻样本高度相关，独立性从一开始就不成立。相应地，链没跑通（存在难以跨越的模态之间的势垒，事实上把状态空间分成了近似不相通的区域）时，你得到的就是本节这张图：平均值稳定、看起来收敛了，其实只探索了一个峰。诊断手段见\hyperref[sec:13-Machine-Learning/08-Sampling-and-Inference/02]{``MCMC 在无法独立采样时构造平稳链''}。

\subsection{把非平稳序列掰成平稳的，要知道自己动了什么}

建模流程里常见的第一步是把非平稳序列变换成平稳序列，手段无非两类：拟合一条趋势曲线再减掉，或者改用一阶差分 \(X_t - X_{t-1}\)。前者对付确定性趋势，后者对付随机游走型的漂移。

风险在于它们只修一个方面。减去线性趋势可以让均值看起来稳定，方差、自相关结构、季节成分却可能仍在随时间变化；对已经平稳的序列再做一次差分，则会人为造出负自相关，同时抹掉有价值的低频信息。变换用错方向比不变换更难察觉，因为变换后的序列往往``看起来更平稳了''。

检查值得逐项做，而且都能落到刚才那三个函数上：滑动平均是否在漂移，不同时间窗内的波动幅度是否可比，分段估计的自相关函数是否重合，是否存在周期成分或结构突变。还有一项不在数据内部却直接改变数据的统计面貌——观测机制本身有没有变过。采样频率调整、传感器更换、指标定义修订，这些都会在序列上留下一个突变点，而它与被观测的现象无关。差分与建模怎样配合，见\hyperref[sec:06-Random-Processes/06-ARMA-and-ARIMA/03]{``ARIMA：非平稳序列的差分处理''}。

平稳是一个可检验、可被推翻的工作假设，不是时间序列的默认属性；遍历是另一个假设，而且更隐蔽，因为没有任何单条序列的统计量能直接暴露它失效。判断遍历性靠的是对机制的理解：这个系统有没有可能被初始条件锁进某一层，从此再也出不来。

本章到此给出的是一套通用词汇，还没有任何一个具体模型。下一章开始填内容，从最容易看清楚的一类过程入手：事件一个接一个到达，状态只是``到目前为止来了多少个''。
