要预测一个序列的下一步，最诚实的做法是把整段历史写进条件。诚实的后果是参数量随历史长度指数增长，任何数据集都填不满。这一章处理的共同困难就是这个：怎样把``必须记住全部历史''压缩成``只需记住当前状态''，以及这个压缩在什么条件下是合法的。

Markov 性质给出的正是这样一句压缩承诺——给定当前状态，未来与过去条件独立。它常被念成``未来只依赖现在''，但这个念法容易让人以为它在描述世界。它描述的其实是你的状态表示：同一个系统，状态取得太粗就不是 Markov 的，把泄漏出去的历史并回状态里就又是了。所以本章第一个、也是实践中最有用的判断，是``状态定义得够不够''，而不是``这个过程本身是不是 Markov 的''。

承诺一旦成立，一步转移规则就决定了全部。剩下的问题都关于长期：链会走到哪里去，会不会走回来，走多久才算走够。这三个问题分别由转移图的连通结构、返回时间的分布、以及转移矩阵的谱来回答，五节的顺序也就是这个顺序。

\begin{itemize}
\tightlist
\item \hyperref[sec:06-Random-Processes/03-Markov-Chains/01]{``Markov 性质、转移矩阵与多步演化''}：把压缩承诺写成条件独立，并说明状态设计怎样决定它成立与否；
\item \hyperref[sec:06-Random-Processes/03-Markov-Chains/02]{``可达、通信类与周期性''}：在解任何方程之前，先从转移图上读出链会不会被困住、会不会踩着节拍振荡；
\item \hyperref[sec:06-Random-Processes/03-Markov-Chains/03]{``常返、暂留与返回时间''}：存在一条回去的路，与真的会走回去，是两件事；
\item \hyperref[sec:06-Random-Processes/03-Markov-Chains/04]{``平稳分布、可逆性与遍历收敛''}：最大特征值 \(1\) 给出平稳分布，第二大特征值的模决定收敛快慢，细致平衡则让你不解方程也能造出想要的链；
\item \hyperref[sec:06-Random-Processes/03-Markov-Chains/05]{``首步分析、击中时间与吸收链''}：把无穷远处的问题拉回有限时间，问最终落在哪、之前平均走多久。
\end{itemize}

有三条判断值得先记住，读的时候可以拿它们当路标。其一，平稳分布是转移算子的固定点，方程有解不代表链会走过去——不可约与非周期各挡一种失效，缺一个结论就变形。其二，逐时刻分布的收敛和单条路径的时间平均是两条不同的定理，前者要非周期，后者不要；MCMC 靠的是后者。其三，收敛速度不由平稳分布决定，而由谱间隙决定，采样器``跑够了没有''这个问题的答案藏在那里。

进入本章前，最好先读过\hyperref[sec:05-Probability/02-Conditional-Probability/04]{``条件独立与信息结构''}，Markov 性质就是那里的链结构在时间轴上的重复使用；第四节大量借用\hyperref[ch:021]{``特征值、对角化与动力系统''}的语言，若对特征值分解已经生疏，可以先回去翻一翻对角化那一篇。

若你的目标是把工具用起来——工单流转、留存分析、吸收概率——重点在第一、五两节，中间三节按需回补。若你要进入 MCMC、PageRank 或强化学习，第四节是必读的一节，谱间隙与细致平衡是那些方法的全部理论保障。无限状态链的返回性分类可以留到真正遇到无限状态时再深入。
