\section{可达、通信类与周期性}
\label{sec:06-Random-Processes/03-Markov-Chains/02}

你写了一个采样器，目标分布明明有两个峰。跑满十万步，画出直方图，只有一个峰，另一个完全没被访问过。链没有报错，每一步都在合法地转移。

问题不在代码，在链的结构。两种病会造成类似的症状：链根本走不到另一个峰去，或者链走得到、却踩着固定节拍在几处之间来回跳、永远不肯散开。前者是可约，后者是周期。这两件事都不由平稳方程 \(\pi=\pi P\) 回答——那个方程照样有解，只是解没有你以为的含义。

再看一个小到能一眼看穿的例子：状态 \(A\) 和 \(B\) 各自吸收（\(P_{AA}=P_{BB}=1\)），状态 \(C\) 各以一半概率跳向 \(A\) 或 \(B\)。解 \(\pi=\pi P\) 会给出一整族解，\(\delta_A\) 与 \(\delta_B\) 的任意凸组合都平稳。哪一个是``长期分布''？取决于你从哪里出发，以及路上那一次抛硬币。方程本身对此一言不发。

所以顺序应该反过来：先看图，再解方程。

\subsection{可达与通信：先把地图画出来}

称 \(j\) 从 \(i\) 可达，若存在某个 \(n\ge0\) 使 \((P^n)_{ij}>0\)，记作 \(i\to j\)。允许 \(n=0\) 是为了让每个状态到自身总是可达——零步就已经在那里了。

若 \(i\to j\) 且 \(j\to i\)，称两者通信，记作 \(i\leftrightarrow j\)。通信不要求一步之内往返，只要求两个方向都存在某条正概率的有限路径，来回的步数可以差得很远。

通信是等价关系：自反由零步路径给出，对称由定义给出，传递则是把两段正概率路径首尾拼接，正反向各拼一次。于是状态空间被划成互不重叠的通信类，类内彼此可达，类与类之间至多单向可达。

若一个通信类``进去就出不来''，即从类内任何状态出发都到不了类外，称为闭类。单个吸收状态是最简单的闭类；多个状态组成的闭类则像有入口没出口的迷宫，链在里面可以一直转，就是走不出去。若整个状态空间只有一个通信类，链称为不可约。

有限链上这些概念有现成的算法：转移图的强连通分量恰好是通信类，没有出边指向分量外的那些分量就是闭类。分解转移矩阵这件事可以完全交给图论例程。

\subsection{多个闭类意味着平稳分布不唯一}

上图把代数事实翻译成了几何事实。\(\delta_A\) 与 \(\delta_B\) 各自满足平稳方程，\(0.3\delta_A+0.7\delta_B\) 也满足。方程给出的是一个解集的线性结构，图给出的是这些解的来源：哪个闭类会``赢''，取决于初值和路上的随机选择，与转移矩阵的代数性质无关。

采样器里遇到的多半是这件事的软化版本。目标分布的两个峰之间不是完全没有通路，而是通路要穿过一片概率极低的区域，提议分布几乎从不跨过去。链在数学上不可约，实际上跟可约没什么区别——十万步里一次也没跨过。这种``近可约''不会被任何不可约性检查抓住，它只体现在收敛速度上，本单元第四节的谱间隙才是量化它的工具。

\subsection{周期：返回步数的最大公约数}

即使链不可约，也可能永远不安定下来。状态 \(i\) 的周期定义为

\[
d(i)=\gcd\set{n\ge1:(P^n)_{ii}>0}.
\]

它是所有可能返回步数的最大公约数：你能回到 \(i\) 的时刻都是 \(d(i)\) 的倍数。\(d(i)=1\) 称非周期，\(d(i)>1\) 则说明返回被锁在某种节拍上，比如只能在偶数步回来。

同一通信类里所有状态周期相同：取 \(i\to j\) 与 \(j\to i\) 的两条路径，从 \(i\) 出发的任何回路都可以改绕经 \(j\) 再回来，两边返回步数集合的最大公约数因此一致。所以谈论``一个不可约链的周期''是合法的，不必指明是哪个状态。

最干净的周期例子是两状态确定交替，\(P_{12}=P_{21}=1\)。从状态 1 出发，分布在 \((1,0)\) 与 \((0,1)\) 之间永远弹来弹去。它确实有平稳分布 \((1/2,1/2)\)，但从来没有靠近过它。

\subsection{加一点自环就够了}

想让不可约链非周期，最省事的办法是给某个状态加自环：只要有一个 \(i\) 满足 \(P_{ii}>0\)，一步即可返回，该状态周期为 1，整条不可约链随之非周期。

MCMC 里常用的``懒化''就是把这件事做到每个状态上：

\[
P_{\text{lazy}}=\tfrac12(I+P),
\]

每步以一半概率原地不动。它保持平稳分布不变，因为 \(\pi P=\pi\) 时 \(\pi P_{\text{lazy}}=\tfrac12(\pi+\pi P)=\pi\)。代价是有一半的步数花在踏步上，混合变慢。Metropolis--Hastings 采样器天然带自环——提议被拒绝时就停在原地——所以它一般不需要额外懒化。

自环不是非周期的必要条件。若某状态既能两步返回又能三步返回，\(\gcd(2,3)=1\)，照样非周期。判据始终是返回步数集合的最大公约数，而不是某个单独的步数等不等于一。

\subsection{可约链不能只报一个周期}

不同通信类的周期可以各不相同：一个吸收态周期为 1，另一个类可能周期为 3，而暂留状态若根本没有返回路径，周期对它无定义。所以``这条链周期为二''这种说法只在不可约的前提下才完整，否则必须说清是哪个类。这也解释了为什么诊断采样器时应该先分解通信类：结构没看清之前，任何关于收敛的陈述都可能只对状态空间的一角成立。

可达性只保证存在一条正概率路径。下一节追问一个更严的问题：这条路径会不会真的被走上——链离开一个状态之后，究竟是必然回来，还是有可能一去不返。
