\section{常返、暂留与返回时间}
\label{sec:06-Random-Processes/03-Markov-Chains/03}

上一节定义了可达性：存在一条正概率路径让你从 \(i\) 走到 \(j\)。但这只说``有可能''。更紧迫的问题是：链真的会走那条路吗？

设想一个状态 \(i\) 有多条回旋路径通向自身——\(P_{ii}>0\) 也好，多步绕行也好。你从 \(i\) 出发，若干步后会不会回来？答案不总是''会''。有些状态虽然有返回路径，链却可能一去不返——路径存在不等于路径被走。

\subsection{首次返回：概率一才叫常返}

从状态 \(i\) 出发，定义首次返回时刻

\[
T_i^+=\inf\{n\ge1:X_n=i\}.
\]

注意 \(n\ge1\)——你不算``已经在 \(i\)''的那个零时刻。下标 \(i\) 在概率符号中表示初始条件：\(P_i(\cdot)=P(\cdot\mid X_0=i)\)，后文的 \(\E_i\) 同理。

若

\[
P_i(T_i^+<\infty)=1,
\]

即从 \(i\) 出发最终回来的概率为 1，称 \(i\) 为常返状态。若这个概率严格小于 1，称暂留状态——有正概率永远离开，不再回头。

\subsection{回来一次等于回来无穷多次}

Markov 性质在这里发挥了关键作用。假设 \(i\) 是常返——你确定会回来一次。回来的时刻 \(T_i^+\) 是一个随机停止时间；在那一刻，链重新处于 \(i\)，而强 Markov 性质保证接下来的行为和你第一次从 \(i\) 出发时一模一样——``再次返回''的概率仍然是 1。

归纳下去：返回至少 1 次的概率是 1，至少 2 次的概率也是 1，至少 \(k\) 次对任意 \(k\) 都是 1。取极限，常返状态以概率 1 被访问无穷多次。

暂留状态则相反。设 \(\rho=P_i(T_i^+<\infty)<1\)。每次访问后，过程以概率 \(1-\rho\) 永远离开。期望访问次数是几何级数

\[
1+\rho+\rho^2+\cdots=\frac{1}{1-\rho}<\infty.
\]

暂留状态可能被访问很多次，但期望上次数有限。

\subsection{级数判据：一个求和决定常返还是暂留}

直接判断 \(P_i(T_i^+<\infty)=1\) 需要对无穷多条路径做概率求和。但有一个更简洁的等价条件：

\[
\sum_{n=0}^{\infty}(P^n)_{ii}.
\]

若该无穷级数发散，\(i\) 常返；若收敛，\(i\) 暂留。

为什么？\((P^n)_{ii}\) 是第 \(n\) 步恰好在 \(i\) 的概率。对所有 \(n\) 求和，就是从 \(i\) 出发访问 \(i\) 的期望总次数。刚才的几何级数分析说明：期望总次数有限 \(\iff\) \(\rho<1\) \(\iff\) 暂留；期望总次数无限 \(\iff\) \(\rho=1\) \(\iff\) 常返。

这个判据把``最终是否回来''转化为矩阵幂的逐项求和——你不需要知道 \(\rho\) 的具体值，只需要检查 \(\sum_n(P^n)_{ii}\) 的敛散性。

\subsection{常返性是通信类属性}

若 \(i\leftrightarrow j\)（同一个通信类），它们要么都常返，要么都暂留。证明：取 \(m,n\) 使得 \((P^m)_{ij}>0\)、\((P^n)_{ji}>0\)，则

\[
(P^{m+k+n})_{jj}\ge(P^n)_{ji}(P^k)_{ii}(P^m)_{ij}.
\]

右边是正常数乘以 \((P^k)_{ii}\)。于是 \(\sum_k(P^k)_{jj}\) 被 \(\sum_k(P^k)_{ii}\) 控制（差一个常数因子）；反过来同样成立。两级数同敛散，得出同类状态常返性相同。

因此常返性与暂留性是类的标签，不是单个状态的私人属性。有限 Markov 链中：

\begin{itemize}
\tightlist
\item
  每个闭通信类都是常返的——困在有限闭集里，不可能永远不回到某个状态；
\item
  不属于任何闭类的状态是暂留的——从它们出发，链最终会落入某个闭类并不再回来；
\item
  有限不可约链中所有状态正常返（定义见下一小节）。
\end{itemize}

``有限''是关键。无限状态不可约链可能全部暂留——空间无穷大提供了``永远漂流''的可能。

\subsection{正常返与零常返：回来但平均要等多久}

常返状态进一步分两种：
\begin{itemize}
\tightlist
\item
  正常返：\(\E_i[T_i^+]<\infty\)——不仅一定会回来，而且平均等待时间有限；
\item
  零常返：\(\E_i[T_i^+]=\infty\)——虽然以概率 1 回来，但等待时间的期望无穷。
\end{itemize}

零常返是一种微妙的中间地带：你确定会回来，但可能等得极其漫长——返回时间分布的尾部太重，拖散了期望。简单对称随机游走在整数线上就是著名的零常返例子：它会回到原点，但平均返回时间无穷。

随机游走在不同维度中表现出截然不同的常返行为。在 \(\Z^d\) 格点上每步等概率走向相邻格点：

\begin{itemize}
\tightlist
\item
  \(d=1,2\)：原点常返（二维也是！但需要更精细的分析）；
\item
  \(d\ge3\)：原点暂留——空间太大，游走者有一定概率永远找不到回家的路。
\end{itemize}

一个流传已久的物理直觉：``醉汉总能找到回家的路，但醉酒的信鸽可能永远迷失在天空中。''高维提供了太多逃离方向，每步无偏不等于总会回来。这个结论提醒我们，``每步公平''离``最终返回''还有一段距离。后面\hyperref[sec:06-Random-Processes/04-Applications/01]{``随机游走：从局部步进到整体尺度''}一章会进一步讨论击中概率与尺度。

\subsection{Kac 公式：平稳概率与平均返回时间互为倒数}

在不可约正常返链中存在唯一平稳分布 \(\pi\)，并且有一个优美的关系：

\[
\E_i[T_i^+]=\frac1{\pi_i}.
\]

Kac 公式把两个看似独立的概念直接联系起来：长期占用概率越高，平均返回时间越短。如果 \(\pi_i=0.2\)，从 \(i\) 出发平均每 5 步左右回到 \(i\) 一次。

这个``5 步''是长期平均，不保证每 5 步固定返回——变异性可能很大。但它给出了直觉：平稳分布不是抽象的代数解，而是返回频率的倒数。你在状态 \(i\) 的时间占比，就是返回所需步数的调和量度。

反过来，无限不可约链如果所有状态零常返，就不存在总和为 1 的平稳概率分布。可能存在``不变测度''——满足 \(\mu=\mu P\) 但总质量无限——但它不能归一化为概率分布。

\subsection{返回、击中、访问与停留不是一回事}

这些概念容易混淆，但它们回答不同的问题：
\begin{itemize}
\tightlist
\item
  返回时间 \(T_i^+\)：从 \(i\) 出发，至少走一步后首次再回到 \(i\)；
\item
  击中时间：从某个状态出发首次到达某个目标集合（目标可以包含出发状态，但不需要从目标出发再回来，与返回不同）；
\item
  访问次数：某个状态被经过的总次数；
\item
  停留时间：在连续时间 Markov 链中还包含每次进入后在当前状态的驻留时长。
\end{itemize}

定义中 \(n\ge1\) 与 \(n\ge0\) 的区分至关重要。如果允许零步，从目标状态出发的击中时间退化等于 0——还没出发就已经``击中''了，无法研究首次真正到达的问题。
