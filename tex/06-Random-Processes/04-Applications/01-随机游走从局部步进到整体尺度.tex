\section{随机游走：从局部步进到整体尺度}
\label{sec:06-Random-Processes/04-Applications/01}

最简单的随机游走从 \(S_0=0\) 开始，每步独立地扔一枚硬币：

\[
Z_n=
\begin{cases}
+1,&\text{概率 }p,\\
-1,&\text{概率 }q=1-p.
\end{cases}
\]

前 \(n\) 步累积位置为

\[
S_n=\sum_{k=1}^{n}Z_k.
\]

单步只上下挪动一格，一条路径只记录一连串 \(+1\) 和 \(-1\)。但就这个模型，它的长时行为连接着扩散方程、排队系统、金融价格、搜索算法和偏微分方程的数值解。局部规则极其简单，整体行为却远非显然。

\subsection{偏差极小，累积效应不小}

先算单步的两个最基本统计量。均值和方差：

\[
\E[Z]=p-q=2p-1,
\]

\[
\Var(Z)=\E[Z^2]-(\E[Z])^2=1-(p-q)^2=4pq,
\]

中间用了 \(\E[Z^2]=p+q=1\)，因为 \(Z^2\) 不论取 \(+1\) 还是 \(-1\)，平方后永远是 \(1\)。由期望的线性性和增量的独立性，

\[
\E[S_n]=n(p-q),
\]

\[
\Var(S_n)=4npq.
\]

现在看清楚局部如何变整体。当 \(p\neq 1/2\)，期望值以 \(n\) 的速度线性漂移——一千步后，平均漂了 \(1000(p-q)\)，偏差哪怕只有每步 0.01，累积也相当可观。而当 \(p=1/2\)（公平游走），均值始终是零。这是否意味着你一直待在原点附近？

恰恰相反。均值为零，但标准差是

\[
\sqrt{\Var(S_n)}=2\sqrt{npq}=\sqrt{n}.
\]

走了一万步后，标准差约 100。你期望的位置是零没错，但典型偏差以 \(\sqrt{n}\) 的尺度增长。均值停留在原点，是一条路径越来越可能远离原点，同时又以几乎相等的概率偏向两侧。``均值为零''不等于``紧贴原点''——它是正偏差和负偏差在平均中互相抵消的结果。

\subsection{大尺度下出现 Gaussian}

由中心极限定理（\(0<p<1\)），

\[
\frac{S_n-n(p-q)}{2\sqrt{npq}}
\xrightarrow{d}\mathcal N(0,1).
\]

当 \(p=0\) 或 \(p=1\)，单步方差为零，路径退化为确定性直线，不能用上述标准化；除此之外，不管你最初用什么真实硬币，足够多步后，标准化的位置分布轮廓逼近同一个钟形曲线。离散的 \(+1/-1\) 步进，在大尺度模糊化后，留下的正是 Gaussian 的对称形状。

\subsection{Binomial 给出精确位置分布}

在逼近之前，前 \(n\) 步的位置分布有精确表达式。若 \(n\) 步中向右的次数为 \(K\)，则向左次数为 \(n-K\)，位置

\[
S_n=K-(n-K)=2K-n.
\]

\(S_n=s\) 只在 \(s\) 和 \(n\) 同奇偶时才可能发生——跨奇数步不可能落在偶数位置，反之亦然。概率为

\[
P(S_n=s)
=\binom n{(n+s)/2}
p^{(n+s)/2}
q^{(n-s)/2}.
\]

这个奇偶限制不是技术细节，它是 Markov 链语境下周期 \(2\) 的最直接体现：从零出发，偶数步只能在偶数位置，奇数步只能在奇数位置。所谓的``周期''，说到底就是对可达位置的奇偶约束。

\subsection{放上两个墙：游走变击中问题}

去掉无界假设，在区间 \([0,N]\) 两端放上吸收壁，游走碰到任一端就停。这就回到了赌徒破产，但视角从``破产概率''换成``边界如何把扩散约束为击中问题''。

公平游走（\(p=1/2\)）从资金 \(i\) 出发，先到 \(N\) 的概率：

\[
\frac iN,
\]

平均吸收时间：

\[
i(N-i).
\]

这两个数在上一单元通过首步差分方程得出，下一篇还将用 Martingale 停时重新得到击中概率。它们一起说明一件事：即便每局游戏公平——每局期望收益为零——有限资金的玩家仍然以概率一最终触碰某个边界。``单步公平''和``长期安全''没有直接关系。游走公平，吸收是必然的，只是去的方向取决于初始位置。

有漂移时（\(p\neq q\)），击中概率不再线性。同一首步方程 \(h_i=ph_{i+1}+qh_{i-1}\) 在 \(p\neq q\) 时的通解为 \(A+B(q/p)^i\)，代入 \(h_0=0\)、\(h_N=1\)：

\[
h_i=\frac{1-(q/p)^i}{1-(q/p)^N}.
\]

取 \(p=0.45\)（每局有 5\% 的劣势），\(N=100\)，\(i=50\)。\((q/p)=0.55/0.45\approx1.22\)，虽然不大，但指数放大后分母和分子都变成几十倍，最终概率远比 \(1/2\) 低。肉眼难以从单步分辨 \(0.45\) 和 \(0.5\)，但时间替你把微小偏差放大到决定命运。

\subsection{维度一高，回家的路就远了}

把游走从一维直线上挪到 \(\Z^d\) 格点上。每步等概率走向一个相邻格点。结论：

\begin{itemize}
\tightlist
\item
  一维和二维简单对称随机游走\textbf{常返}：以概率一，你总会回到起点；
\item
  三维及以上\textbf{暂留}：存在正概率永远不再回来。
\end{itemize}

Polya 这个结论的判别方法恰好是上一单元用过的准则：从期望返回次数看常返性。把每一步的返回概率加起来——一维和二维时，这个级数发散，意味着期望返回次数无限，所以常返；三维及以上级数收敛，期望次数有限，所以暂留。高维格点有越来越多方向可供逃离，回头的概率被几何稀释了。

二维虽然常返，但平均返回时间仍然是无穷。你总会回来，但可能等很久很久。维度的这个质变——从二维到三维，从 ``一定会回来'' 到 ``可能永远不回''——是随机游走中最值得停下来的一个转折点。

\subsection{一步一缩，游走变成 Brownian 运动}

把步长和步时同时缩小。令每一步幅值为 \(\sqrt{\Delta t}\)，每一时间步长为 \(\Delta t\)，单位时间内走 \(1/\Delta t\) 步。公平游走的单步方差为 \((\sqrt{\Delta t})^2=\Delta t\)，单位时间累积方差 \(\Delta t\cdot(1/\Delta t)=1\)，不随缩放消失。适当插值后，极限路径成为 Brownian motion——连续的、几乎处处不可微的随机轨迹。严格的极限命题是 Donsker 不变原理，但缩放直觉已经解释了要害：成千上万微小的独立推动叠加起来，不会产生一条光滑曲线，只会产生一条处处有锯齿的极限。

这个缩放直观地把扩散方程、Gaussian 热核和 Brownian 路径串联在一起。扩散方程描述概率密度的演化，它的基本解是 Gaussian 热核，而 Brownian 路径的转移密度恰好就是热核。游走→扩散→热核→Brownian 运动，四个概念共享同一个缩放内核。

\subsection{模型边界：简单游走不是什么}

简单随机游走的前提相当苛刻，满足它的真实运动不多。如果把条件放松后还套用简单游走的结论，就是误用。可能的偏离包括：

\begin{itemize}
\tightlist
\item
  步长不恒定——每一步的跳跃幅度有自身分布；
\item
  方向有持续性——上一步向上，下一步仍然倾向于向上（动量或趋势）；
\item
  漂移与当前位置有关——资金越少越倾向于冒险，或密度越高越倾向于撤离；
\item
  跳跃带有重尾——偶尔出现极大跳跃，高斯逼近失效；
\item
  环境本身随机——转移概率随空间位置变化且不可预测；
\item
  边界有可能反射而不是吸收——粒子碰到壁会弹回。
\end{itemize}

这些变体每一个都让分析复杂度上升一到两个数量级。简单随机游走不能当作所有轨迹的默认模型。它的价值在于作为一个基准，清楚展示了如何从最少的假设出发——独立、同分布、加减一——推演出局部规则在整体尺度和边界上的全部后果。
