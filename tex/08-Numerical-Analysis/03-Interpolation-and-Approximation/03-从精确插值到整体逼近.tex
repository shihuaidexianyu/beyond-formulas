\section{从精确插值到整体逼近}
\label{sec:08-Numerical-Analysis/03-Interpolation-and-Approximation/03}

你有 50 个带噪声的观测点，想用一个多项式拟合。插值多项式穿过每一个数据点——包括噪声的每一次随机跳动。如果数据是精确的（比如某个已知函数的求值），插值合理。但如果那些偏离代表的是测量误差，逐点通过意味着你正在一丝不苟地复制噪声，把它当成了被估计函数的结构。

你也许会说：那减少节点数，用一个低次多项式插值。节点少了振荡确实减轻，但被丢弃的那些数据点里也包含信号——你扔掉了信息。

这个困境的出路不在插值的内部改进，而在于换一个问题：\textbf{不再要求函数穿过每一个数据点，只要求整体偏差尽量小。}

\subsection{必须先定义``最佳''才有最佳逼近}

逼近问题：选择一个 \(n\) 次多项式 \(p_n\in P_n\)，使

\[
\|f-p_n\|
\]

尽量小。但``尽量小''的含义完全取决于范数 \(\|\cdot\|\) 的选择。没有范数就没有``最佳''。

\begin{itemize}
\tightlist
\item
  \(L^2\) 范数 \(\|f-p_n\|_2=(\int_a^b|f(x)-p_n(x)|^2 w(x)\,dx)^{1/2}\)：关心误差能量在整个区间上的加权平均。大误差被平方放大，但单个点的巨大偏离可能被积分平均掉。
\item
  离散最小二乘 \(\sum_{i=1}^m (f(x_i)-p_n(x_i))^2\)：\(L^2\) 的离散版本，只关心采样点上的残差平方和。当数据量远大于多项式次数时，``通过所有点''做不到也不需要——最小化残差平方和就足够。
\item
  \(L^\infty\)（一致）范数 \(\|f-p_n\|_\infty=\max_{x\in[a,b]}|f(x)-p_n(x)|\)：只关心整个区间上最差的点——最大绝对偏差。适用于对任何一点的误差都有硬性容忍上限的场景。
\item
  加权范数：在 \(L^2\) 或 \(L^\infty\) 中加入权重函数，让逼近在特定区域（如分布尾部、概率密度高的区域）更精确，在别处可以放松。
\end{itemize}

同一个函数、同一个多项式空间，改变范数就改变了最优解。不先声明范数就说``最佳逼近''，问题本身没有定义完整。

\subsection{\texorpdfstring{\(L^2\) 逼近就是正交投影}{L^2 逼近就是正交投影}}

有了内积

\[
\langle f,g\rangle=\int_a^b f(x)g(x)w(x)\,dx,
\]

\(L^2\) 逼近变成一个几何问题：在子空间 \(\operatorname{span}\{\phi_0,\ldots,\phi_n\}\) 中找到离 \(f\) 最近的点。这个最近点恰好是 \(f\) 在该子空间上的正交投影。

设基函数 \(\phi_0,\ldots,\phi_n\) 关于内积 \(\langle\cdot,\cdot\rangle\) 两两正交，逼近多项式为

\[
p_n=\sum_{k=0}^n c_k\phi_k.
\]

正交投影的条件是残差与子空间的每个基函数正交：

\[
\langle f-p_n,\phi_j\rangle=0,\qquad j=0,\ldots,n.
\]

把 \(p_n\) 的展开代入，利用正交性 \(\langle\phi_k,\phi_j\rangle=0\)（\(k\neq j\)），所有交叉项消失，只剩下第 \(j\) 项：

\[
\langle f,\phi_j\rangle-c_j\langle\phi_j,\phi_j\rangle=0
\;\Longrightarrow\;
c_j=\frac{\langle f,\phi_j\rangle}{\langle\phi_j,\phi_j\rangle}.
\]

每个系数只依赖 \(f\) 与对应基函数的内积——正交基把联合求解 \(n+1\) 个系数的线性方程组，拆成了 \(n+1\) 个独立的标量除法。

一个手工实例：在 \([-1,1]\) 上将 \(f(x)=x^2\) 投影到 \(\operatorname{span}\{1,x\}\)（取 \(w\equiv1\)）。两个基函数本身已正交，因为 \(\int_{-1}^1 1\cdot x\,dx=0\)。常数系数：

\[
c_0=\frac{\langle f,1\rangle}{\langle 1,1\rangle}
=\frac{\int_{-1}^1 x^2\,dx}{\int_{-1}^1 1\,dx}
=\frac{2/3}{2}=\frac13.
\]

一次系数 \(c_1=0\)（\(f\) 是偶函数，\(x\) 是奇函数，内积为零）。因此该子空间中 \(x^2\) 的最佳 \(L^2\) 逼近是常数 \(p_1(x)=1/3\)。

它不通过函数的任何一个非零点：在 \(x=0\) 处误差为 \(-1/3\)，在 \(x=1\) 处误差为 \(+2/3\)。但它最小化了整个 \([-1,1]\) 上的平方误差积分——给\(|x|\)大的地方（函数值大，逼近困难）更高的代价，并容忍了零附近的偏差。

\subsection{为什么要专门选正交多项式}

用自然的单项式基 \(1,x,x^2,\ldots\) 做逼近，表面上方便，但在有限区间上它们高度相关——\(x^k\) 和 \(x^{k+1}\) 在 \([0,1]\) 上的形状太相似了。这会使得正规方程的系数矩阵（Hilbert 矩阵或类 Hilbert 矩阵）的条件数随次数指数增长：高次系数对数据的微小扰动极端敏感，数值结果完全不可信。

Legendre、Chebyshev 等正交多项式族解决了这个问题。它们通过 Gram-Schmidt 从单项式基构造而来，天然满足正交性，因此：

\begin{itemize}
\tightlist
\item
  每个系数有独立的投影含义——调整一个系数不影响其他系数的正交性；
\item
  正规方程退化成了对角的——不需要求解密集的病态线性方程组；
\item
  数值条件数可控。
\end{itemize}

对于离散最小二乘——给定 \(m\) 个数据点，用 \(n\) 次多项式拟合（\(m>n\)）——应该用 QR 分解或 SVD 直接处理设计矩阵，而不是先形成正规方程再求解。正规方程将原始矩阵的条件数近似平方，本已边缘的数值问题被放大成灾难。这个线性代数细节会在数值线性代数单元展开；此刻只需记住：当代码报出奇怪的负方差或系数爆炸时，第一个要检查的就是是否绕过了 QR 而直接写了 \(A^{\trans}A\)。

\subsection{一致逼近：最坏点的较量}

\(L^\infty\) 逼近的目标不是平均误差，而是整个区间上最差的那一个点：

\[
\min_{p\in P_n}\max_{x\in[a,b]}|f(x)-p(x)|.
\]

这和 \(L^2\) 有质的差异。\(L^2\) 逼近可以在区间边缘有较大的误差，只要积分后的总能量不大；但一致逼近不允许任何一个点出现不可接受的偏离。

对于闭区间上的连续函数，最佳一致逼近多项式有一个标志性特征：误差函数 \(f(x)-p^*(x)\) 会在至少 \(n+2\) 个点上交替达到等幅的正负极值。这称为 equioscillation（交错）。直观上，如果最大正误差只出现在一两个点而其他地方误差都很小，你还能微调多项式压低这些峰值，同时稍微抬高其余点——只要峰值还比抬上去的地方高，你就可以继续压低峰值。均衡时，正负峰值恰好对称地分布在全区间——调整任何系数都无法再压低最坏点而不在别处制造新的最坏点。

Chebyshev 多项式与这种最坏误差控制紧密相关。在 \([-1,1]\) 上，\(T_n(x)=\cos(n\arccos x)\) 的所有极值点恰好达到 \(\pm1\) 且交替出现——它是``在给定最高次系数下最小化最大绝对值''这一 minimax 问题的解。许多特殊函数的快速数值实现更关心最大相对误差，而不是均方误差——使用者需要保证在全定义域内每一位小数都可信。

\subsection{Weierstrass 说存在，没说怎么找}

Weierstrass 逼近定理是逼近论的奠基性结果：闭区间上的任意连续函数，对任意 \(\varepsilon>0\)，都存在一个多项式 \(p\) 使

\[
\|f-p\|_\infty<\varepsilon.
\]

它宣告多项式空间是稠密的——仅用多项式就能以任意精度逼近任意连续函数。但它故意不回答三个工程核心问题：

\begin{itemize}
\tightlist
\item
  \textbf{需要多高的次数？} 定理只保证存在某个 \(n\)，不说 \(n\) 是多少。函数越光滑（导数存在且连续直到高阶），逼近系数的衰减越快。解析函数常有谱收敛——误差随次数指数下降。而一个只有有限阶可微的函数，即使连续，收敛速度也受限于其光滑阶数。Lipschitz 连续但不可导的函数，多项式逼近的阶最多是 \(O(1/n)\)。
\item
  \textbf{如何稳定地找到多项式？} 在等距节点上做高次插值，Runge 现象会让区间边缘的误差爆炸。均匀节点上的插值多项式未必收敛到原函数——即使在原函数解析时，节点选择不当也会破坏收敛。
\item
  \textbf{有限精度算出来的多项式是什么？} Weierstrass 假设的是精确实数算术。在浮点数下，高次多项式的求值本身就是一个病态运算。
\end{itemize}

还有一个理论边界：\textbf{不连续函数不能在包含跳点的闭区间上被一致逼近到任意小误差。} 因为多项式是一致连续的，一致极限保连续。若 \(f\) 在某点有跳变，任何连续函数在该点的邻域内都无法同时逼近跳变两侧的函数值。排除跳点的小邻域后，或改用 \(L^2\) 范数（跳点处的误差在积分中权重为零），界限就可能不同。

\subsection{插值与逼近之间，选择的是问题而非方法}

插值不是逼近的``粗糙版''，逼近也不是插值的``不精确版''。它们满足的是不同约束。

选择之前可以迅速过一遍这几条：

\begin{itemize}
\tightlist
\item
  数据是精确求值，还是含有随机或系统噪声？
\item
  节点处的残差为零是物理要求（边界条件），还是可以放松？
\item
  你最关心平均行为还是最坏情况？前者导向 \(L^2\) 或离散最小二乘，后者导向一致逼近。
\item
  节点位置你能选择（如实验设计中选采样点），还是已由外部给定？
\item
  后续需要局部更新（加一个数据点只改局部），还是一次性建立全局模型？
\item
  模型用于区间内的插值，还是区间外的外推？外推对逼近的结构选择远比区间内敏感——基函数在数据范围外的行为没有数据约束。
\end{itemize}

一种方法并不比另一种更``高级''。在已知函数无噪且平滑时，Chebyshev 节点上的高次插值往往足够好。在测量含噪且样本量大时，低次最小二乘更安全。选错的原因通常是忘了先问``我到底想最小化什么''。
