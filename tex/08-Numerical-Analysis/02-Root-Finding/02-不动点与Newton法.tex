\section{不动点与 Newton 法}
\label{sec:08-Numerical-Analysis/02-Root-Finding/02}

二分法稳如泰山，但每一步只贡献零点几个十进制位。如果你的函数是光滑的、导数也拿得到，能更快一点吗？

Newton 法的回答是：用当前点的切线去猜根，每一步的正确位数大约翻倍。但这个许诺有一长串前提——离根不够近、导数太小、函数形状太弯时，切线指的方向可能把你送到完全错误的地方。

\subsection{先把求根变成找不动点}

求 \(f(x) = 0\) 的根是一类问题。另一种等价提法是：找到一个 \(x\)，使得 \(x = g(x)\)。这两个提法之间的桥梁是：
\[
f(x) = 0 \quad \Longleftrightarrow \quad x = g(x).
\]
同一个方程 \(f(x)=0\) 可以对应好几种不同的 \(g\)。比如 \(x^2 - a = 0\) 可以重写成：
\[
x = \frac{a}{x}, \qquad x = x^2 + x - a, \qquad x = \frac{1}{2}\left(x + \frac{a}{x}\right).
\]
每一个都满足「\(x\) 是 \(g\) 的不动点当且仅当 \(f(x) = 0\)」。但不同的 \(g\) 放进迭代 \(x_{k+1} = g(x_k)\) 里，有的收敛如飞，有的直接发散，有的在原地踏步。

\subsection{不动点迭代：导数决生死}

把 \(x_{k+1} = g(x_k)\) 写开。设 \(r = g(r)\) 是一个不动点，令误差 \(e_k = x_k - r\)。用微分中值定理：
\[
e_{k+1} = g(x_k) - g(r) = g'(\xi_k) e_k,
\]
其中 \(\xi_k\) 落在 \(x_k\) 与 \(r\) 之间。当迭代进入根附近时，\(\xi_k\) 逼近 \(r\)，上式趋近于
\[
e_{k+1} \approx g'(r) e_k.
\]

这就给出了不动点迭代的局部判据——只需要检查一个数字 \(|g'(r)|\)：
\begin{itemize}
\tightlist
\item \(|g'(r)| < 1\)：误差每步被压缩，迭代局部收敛。越小越快。
\item \(|g'(r)| > 1\)：误差被放大，迭代局部发散，离根越来越远。
\item \(|g'(r)| = 1\)：线性项消失，收敛性取决于二阶及以上。
\end{itemize}

回到刚才的 \(x^2 - a = 0\)，三种写法在正根 \(r = \sqrt{a}\) 处的 \(g'(r)\) 分别是：
\begin{itemize}
\tightlist
\item \(g(x) = a/x\)：\(g'(r) = -1\)，边界情况，高阶项决定行为。
\item \(g(x) = x^2 + x - a\)：\(g'(r) = 2\sqrt{a} + 1 > 1\)，发散。
\item \(g(x) = \frac12(x + a/x)\)：\(g'(r) = 0\)，超线性收敛（下面会看到是二次的）。
\end{itemize}

同一个方程，改写方式决定了算法是飞向答案还是飞向灾难。

\subsection{收缩映射：把局部结论推广到整个区间}

只在根处检查 \(|g'(r)| < 1\) 只能保证初值「足够近」才安全。「足够近」是多近？无法从这个局部信息里得出。

更强的条件是：存在一个闭区间 \(I\)，满足
\begin{enumerate}
\tightlist
\item \(g(I) \subseteq I\)——迭代从不跳出区间；
\item 存在 \(q < 1\) 使得对任意 \(x \in I\)，有 \(|g'(x)| \le q\)。
\end{enumerate}

由微分中值定理，第二个条件给出 \(|g(x) - g(y)| \le q |x - y|\)，也就是 \(g\) 是压缩映射。Banach 不动点定理保证：\(I\) 内存在唯一不动点，且从 \(I\) 内任意初值出发的迭代都收敛于它。

压缩性还顺手送了一个后验误差界。把 \(e_k = x_k - r\) 拆成相邻差的和：
\[
|x_k - r| \le \sum_{j \ge k} |x_{j+1} - x_j|.
\]
每一步 \(|x_{j+1} - x_j| \le q |x_j - x_{j-1}|\)，于是几何级数求和给出
\[
|x_k - r| \le \frac{q}{1 - q} |x_k - x_{k-1}|.
\]
你不需要知道真根，只需要看最近两步的间距，就能得到当前误差的上界。这对实现自动停止条件很有帮助。

\subsection{Newton 法：每一步重新造一个不动点迭代}

Newton 法来自一个直接的想法：在当前点 \(x_k\) 处，用切线近似函数，然后问「这条切线的零点在哪？」

形式化：在 \(x_k\) 附近做一阶 Taylor 展开，
\[
f(x_k + s) \approx f(x_k) + f'(x_k) s.
\]
令线性近似为零，解出步长：
\[
s_k = - \frac{f(x_k)}{f'(x_k)}.
\]
所以
\[
x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}.
\]

几何上看，这是在画 \(f\) 在 \((x_k, f(x_k))\) 处的切线，把切线与横轴的交点作为下一次猜测。代数上看，这就是取了
\[
g(x) = x - \frac{f(x)}{f'(x)}
\]
然后做不动点迭代 \(x_{k+1} = g(x_k)\)。

对 \(g\) 求导：
\[
g'(x) = 1 - \frac{f'(x)^2 - f(x) f''(x)}{f'(x)^2}
= \frac{f(x) f''(x)}{f'(x)^2}.
\]
在简单根 \(r\) 处，\(f(r) = 0\) 且 \(f'(r) \ne 0\)，所以 \(g'(r) = 0\)。这意味着不动点判据 \(e_{k+1} \approx g'(r) e_k\) 中的线性因子消失了——误差不再是一阶缩小的，而是更高阶的。这就是二次收敛的根源。

\subsubsection{平根方例子：Babylonian 算法}

取 \(f(x) = x^2 - a\)，则 \(f'(x) = 2x\)。Newton 更新为：
\[
x_{k+1} = x_k - \frac{x_k^2 - a}{2x_k}
= \frac12 \left( x_k + \frac{a}{x_k} \right).
\]
这就是计算 \(\sqrt{a}\) 的 Babylonian 算法。

这个公式有一种直觉美：如果你的估计偏大了，\(a/x_k\) 会偏小，两者的平均把误差从两边向中间拉。更妙的是，每步有效位数大约翻倍——从一个粗糙的初估出发，三五步之后就能接近机器精度。

\subsection{二次收敛的来龙去脉}

把推导写细一点，看看二次速度从哪掉出来的。

设 \(r\) 是简单根：\(f(r) = 0\)，\(f'(r) \ne 0\)。记 \(e_k = x_k - r\)。在 \(x_k\) 处对 \(f(r)\) 做 Taylor 展开到二阶（带 Lagrange 余项）：
\[
0 = f(r)
= f(x_k) + f'(x_k)(r - x_k)
+ \frac12 f''(\xi_k)(r - x_k)^2
= f(x_k) - f'(x_k) e_k
+ \frac12 f''(\xi_k) e_k^2,
\]
其中 \(\xi_k\) 在 \(x_k\) 和 \(r\) 之间。这给出
\[
f(x_k) = f'(x_k) e_k - \frac12 f''(\xi_k) e_k^2.
\]

代入 Newton 更新 \(e_{k+1} = x_{k+1} - r = e_k - f(x_k)/f'(x_k)\)，得
\[
e_{k+1}
= e_k - \frac{f'(x_k) e_k - \frac12 f''(\xi_k) e_k^2}{f'(x_k)}
= \frac{f''(\xi_k)}{2 f'(x_k)} e_k^2.
\]

当 \(f''\) 连续、\(f'\) 在根附近远离零时，存在常数 \(C\) 使得
\[
|e_{k+1}| \le C |e_k|^2.
\]

这个不等式的含义是：误差足够小之后，每一步的正确位数大约翻倍。不是「每步加一个固定数量」，而是「旧误差的平方」——如果某步误差是 \(10^{-4}\)，下一步大概到 \(C \times 10^{-8}\)，再下一步到 \(C^3 \times 10^{-16}\)。几步之内撞上机器精度。

但也正是这个不等式暴露了 Newton 法的脆弱性：这个平方关系只在误差已经足够小的时候才成立。初值若离根很远，二阶项 \(C e_k^2\) 可能比 \(e_k\) 还大，迭代非但不会接近根，反而可能飞走。这就是为什么说 Newton 法是「局部收敛」：它快，但你要先把它放进快速通道的入口。

\subsection{重根为什么让 Newton 慢下来}

如果 \(f(x) = (x-r)^m h(x)\)，\(h(r) \ne 0\)，且重数 \(m > 1\)，情况就变了。

用不动点判据来推导：\(f'(x)/f(x) = m/(x-r) + h'(x)/h(x)\)。在根附近，
\[
\frac{f(x)}{f'(x)} \approx \frac{x - r}{m}.
\]
于是迭代函数 \(g(x) = x - f(x)/f'(x)\) 在根处的导数为
\[
g'(r) = 1 - \frac{1}{m} = \frac{m-1}{m}.
\]
代回 \(e_{k+1} \approx g'(r) e_k\)，得到
\[
e_{k+1} \approx \frac{m-1}{m} e_k,
\]
线性收敛。对于二重根（\(m=2\)），每步大约只砍一半误差，跟二分法的速度差不多。三重根收敛更快但依然是线性的。

如果重数已知，一个简单修正就能恢复二次收敛：
\[
x_{k+1} = x_k - m \frac{f(x_k)}{f'(x_k)}.
\]
把 \(g(x)\) 重写进去，这时 \(g'(r) = 1 - m \cdot (1/m) = 0\)，二次项重新成为主导。

重根处速度退化不是算法的偶然缺陷。重根本身就是条件病态的——函数的微小扰动可以显著移动甚至分裂根。在这个点上，问题的敏感性已经恶化了，算法速度跟着退化只是这个深层事实的反射。

\subsection{快速方法需要护具}

Newton 法可能在以下情况出问题：

\begin{itemize}
\tightlist
\item \(f'(x_k)\) 非常小：步长 \(-f(x_k)/f'(x_k)\) 变得巨大，下一次猜测跳到千里之外。
\item 初值落在错误的吸引域：根 \(r_1\) 附近有一个盆地把迭代吸向另一个根 \(r_2\)，但你不知道。
\item 函数有奇点或定义域边界：切线指向函数没有定义的地方。
\item 形成循环：在若干点之间来回跳跃，不收敛也不发散。
\item 函数或导数含有噪声：数值微分或噪声数据让切线方向本身成了随机变量。
\item 已达到浮点精度极限：正确数字已经占满有效位，再迭代只是在舍入误差中随机漂移。
\end{itemize}

把这些失败模式摆在一起，结论是：纯 Newton 公式只是迭代的核心引擎，可靠的求根器必须把它装在一个安全框架里。

最常见的混合策略是维护一个异号括区 \([a, b]\)。每次迭代时：
\begin{enumerate}
\tightlist
\item 计算 Newton 步给出的候选点；
\item 如果候选落在区间内，并且接受它能让区间显著缩小，就用它；
\item 否则，退回二分步，取区间中点。
\end{enumerate}
这种策略保留了二分法的「根不丢」保证，又在安全时获得 Newton 法的快速推进。

另一种保护是阻尼（或线搜索）：
\[
x_{k+1} = x_k - \alpha_k \frac{f(x_k)}{f'(x_k)}, \qquad 0 < \alpha_k \le 1,
\]
其中 \(\alpha_k\) 从 1 开始逐步减小，直到接受的条件（比如函数值下降或足够靠近括区中心）被满足。这能防止一步跨太远。

\subsection{多元 Newton：换切线为切平面}

多元情形下，\(f: \R^n \to \R^n\) 的求根在每一步变成解一个线性系统：
\[
J_f(x_k) s_k = -f(x_k), \qquad x_{k+1} = x_k + s_k,
\]
其中 \(J_f(x_k)\) 是 \(f\) 在 \(x_k\) 处的 Jacobian 矩阵。

实现时关键细节：求解这个线性系统，而不是显式构造 \(J_f(x_k)^{-1}\) 再乘。显式求逆不仅运算量大，而且数值稳定性更差——\(J_f\) 如果条件数大，求逆会把小误差放大。

多元 Newton 同样具有局部二次收敛性，同样受到初值要求严格、Jacobian 奇异的困扰。类似的安全措施——信赖域、线搜索、或与更稳定的全局方法结合——在多元情形下更为必要。

\subsection{停止条件不等于正确性证明}

迭代停下来了。你报告了答案。有什么证据表明它接近真根？

常见的「停止信号」各有限制：
\begin{itemize}
\tightlist
\item 步差 \(|x_{k+1} - x_k|\) 小：可能确实靠近根了，但也可能是浮点停滞、阻尼过强，或者迭代函数在附近几乎恒等。一个小步长只能说明迭代不再移动，不能说明不动点是你要的根。
\item 残差 \(|f(x_k)|\) 小：受根的条件性影响。陡峭处的准确点可能有大残差，平缓处的远点可能有小残差。
\item 区间宽度小（二分法）：这个直接控位置，但只适用于有括区的方法。
\end{itemize}

稳妥的做法是组合检查：步长、残差大小、括区宽度（若有）、迭代次数上限、以及非有限值的检测。任何一个条件单独都不足以证明收敛。合在一起，才算收集了足够证据。
