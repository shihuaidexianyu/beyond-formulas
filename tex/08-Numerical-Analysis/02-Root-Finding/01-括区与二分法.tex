\section{括区与二分法}
\label{sec:08-Numerical-Analysis/02-Root-Finding/01}

想象一个场景：你有一个复杂的仿真程序，对于给定的输入输出一个值，你需要找出让输出为零的那个输入。你只能查询函数值，却看不到函数内部结构。没有导数公式，没有解析形式。你该怎么办？

首先需要的是一个保证：「根一定在这个区间里。」

\subsection{异号区间是一张含根证书}

如果 \(f\) 在闭区间 \([a, b]\) 上连续，并且
\[
f(a) f(b) < 0,
\]
那么根据介值定理，\((a, b)\) 内至少存在一个点 \(r\)，满足 \(f(r) = 0\)。

这个命题是二分法的基石。两个端点值符号不同，中间函数图像必须穿过横轴。函数的图像可能很弯曲、可能来回振荡，但只要连续且端点异号，穿轴是不可避免的。

二分法的操作极简单：取中点
\[
m = \frac{a + b}{2},
\]
计算 \(f(m)\)。如果 \(f(m) = 0\)，恭喜，已经命中。否则，\(f(m)\) 必然和 \(f(a)\) 或 \(f(b)\) 之一异号——保留异号的那半区间，丢掉另一半。整个过程中，含根证明从未丢失，区间一直在缩小。

有一个浮点实现细节值得提前铺设：直接计算 \((a + b)/2\) 如果 \(a\) 和 \(b\) 同号且都接近边界，可能溢出。安全写法是 \(a + (b - a)/2\)（当 \(b - a\) 可安全表示时）。更一般地，语言或数值库常提供专门的安全 midpoint 函数。另一个容易忽略的情况：算出的中点已经等于某个端点——这说明在当前精度下区间已经无法再切分了，再算下去是死循环，应该立即停止并报告。

注意二分法与「从一个猜测点出发」的方法有本质区别。它保存的不是一个点，而是一个包含了根的区间。即使函数在某处导数几乎为零、图像几乎平坦，只要连续性和异号保持，根就不会逃走。这是用「保证」换「速度」的选择。

\subsection{误差界来自区间宽度，不来自函数值}

初始区间宽度记作 \(L_0 = b_0 - a_0\)。每次迭代后宽度减半，\(n\) 次后：
\[
L_n = \frac{L_0}{2^n}.
\]
取第 \(n\) 次更新后的区间中点 \(m_n\) 作为近似，根 \(r\) 一定满足：
\[
|m_n - r| \le \frac{L_n}{2} = \frac{L_0}{2^{n+1}}.
\]

这个界在第一次迭代之前就能算出来。要让区间宽度不超过目标容差 \(\tau\)，需要的迭代次数是
\[
n \ge \left\lceil \log_2 \frac{L_0}{\tau} \right\rceil.
\]

每一步只贡献约 1 个二进制定位信息（约 0.3 个十进制位）。跟后面的 Newton 法比起来，这很慢。但它跟你用哪种计算机、哪个编译器、函数长什么形状都没有关系。开始之前，你就知道最多需要几步。这是确定性：不是概率上大概需要多少步，而是保证不超过多少步。

\subsubsection{走一个具体例子：\(x^3 - x - 2 = 0\)}

\(f(1) = 1 - 1 - 2 = -2\)，\(f(2) = 8 - 2 - 2 = 4\)。一负一正，根在 \([1, 2]\) 里。

第一次中点 \(1.5\)：\(f(1.5) = 3.375 - 1.5 - 2 = -0.125\)，与 \(f(2)\) 异号，保留 \([1.5, 2]\)。

第二次中点 \(1.75\)：\(f(1.75) = 5.359375 - 1.75 - 2 = 1.609375\)，正，与 \(f(1.5)\) 异号，保留 \([1.5, 1.75]\)。

十次迭代后，区间宽度是 \(2^{-10} \approx 9.77 \times 10^{-4}\)。你不需要知道真根是多少，就已经拥有一张绝对位置误差证书：真根离当前中点不超过半个区间宽度。这份证书独立于函数值的大小、导数的陡峭程度——它只来自「我一直在保留异号区间」这一不变量。

\subsection{异号是充分条件，不是必要条件}

偶重根两侧函数值符号不变。比如
\[
f(x) = (x-1)^2
\]
在 \(x = 1\) 处碰触横轴后弹回，两侧都非负。不管你怎么取包含 1 的区间，端点都可能同号。二分法对偶重根彻底「失明」：它从符号变化寻找根，这里没有符号变化。

反过来，如果函数不连续，端点异号也不能推出根存在。一个跳跃：
\[
f(x) = \begin{cases}
-1, & x < 0, \\
1, & x \ge 0
\end{cases}
\]
在 \([-1, 1]\) 上 \(f(-1) = -1\)，\(f(1) = 1\)，端点很痛快地异号，但函数从不等于零。连续性是符号变化转化为零点存在的桥梁——没有它，推理链断裂。

区间内也可能藏了多个根。二分法最终会锁定其中一个，但不会告诉你还有几个同伴藏在别处。它不枚举，只收敛。

\subsection{只用 \(|f(x)|\) 小判断收敛的危险}

只看函数值是否接近零来宣布收工，有两类陷阱：

如果根附近函数非常平缓，距离根还比较远的点也能给出很小的函数值。你以为已经逼近了，离终点还差很远。

如果根附近函数非常陡峭，一个位置极其准确的点可能仍有不小的函数值。你把一个很准的点丢掉了，因为函数值没达到你的预期。

一阶估计揭示了函数值和位置误差之间的关系：
\[
|x - r| \approx \frac{|f(x)|}{|f'(r)|}.
\]
\(|f'(r)|\) 很小时，小残差不保证近；\(|f'(r)|\) 很大时，大残差不保证远。函数值到位置误差的换算，需要根处的条件信息。

二分法的区间宽度直接控制位置，不依赖导数。实践中可以同时检查几项条件：

\begin{itemize}
\tightlist
\item 区间宽度是否满足绝对和相对位置容差；
\item 中点残差是否足够小（作为一种辅助确认）；
\item 中点是否已因浮点舍入等于某个端点（达到精度极限的信号）。
\end{itemize}

如果直接用 \(f(a) f(b) < 0\) 判断异号，极大函数值的乘积可能上溢，极小函数值的乘积可能下溢。更稳妥的做法是分别获取符号——用 signbit 函数或直接比较——并预先处理零、NaN 和无穷。

\subsection{二分法适合的不只是「简单方程」}

二分法慢，但它有一个特性是快方法不具备的：它维护一个形式化的「根在此区间」的不变式。这个不变量在你无法验证导数、不能保证函数光滑、或者答案需要拿去当另一个系统的输入时，非常值钱。

它适合的场景远不止课本上的多项式求根：
\begin{itemize}
\tightlist
\item 单调方程的反演：给定值 \(y\)，找 \(x\) 使 \(f(x) = y\)，其中 \(f\) 是昂贵的仿真输出，只有函数值可用。
\item 分位数的定位：CDF 是单调的，CDF 值只有一个查询接口——二分法天然匹配。
\item 事件时间的确定：随着时间推进，某个量从正值变负值——你只需要知道它在哪个时刻过零，精度需求不高但保证不能漏。
\end{itemize}

它还是快方法的安全网。先用二分做一个可靠的括区，确保根不丢；然后在区间内尝试 Newton 步或插值步，接受的条件是该候选点落在区间内且让区间显著缩小；一旦候选被拒绝，退回二分步。这种混合策略把「保证」和「速度」结合在一起。
