方程 \(f(x)=0\) 一旦超出二次三次的范围，通常就没有求根公式可用。剩下的办法只有一条：反复查询函数，一步步把根围住。本章的共同困难是，你手里的``查询''能力各不相同——有时只能拿到函数值的正负号，有时能拿到函数值本身，有时连导数也能算出来。信息的多少决定了能买到多快的收敛，也决定了失手时会摔多重。

拿 \(f(x)=x^3-2x-5\) 做尺子。它的唯一实根在 \(2\) 与 \(3\) 之间。二分法每步把区间对折，约十步换三位十进制精度，全程不问 \(f\) 长什么样。Newton 法从 \(x_0=2\) 出发，一步到 \(2.1\)，两步到 \(2.0946\)，二分法要跑十五步的精度它两步就拿到——前提是初值已经足够近。

\emph{纵轴越高越快，横轴越靠右要求越多。三种方法沿一条向上的对角线排开，看起来是花钱买速度；但图上还有第二个维度没画出来——失手的代价。左端那一点带着一张含根证书，右端那一点什么也不带。}

所以三种方法真正的分野不在速度表上，而在各自维护的证据里。二分法始终保存``根仍在这个区间内''这一事实，代价是每步只用符号；Newton 法相信当前切线在附近足够像原函数，一旦这个信任错付就没有兜底；割线法用两个旧函数值猜斜率，成本最低，安全性和 Newton 法一样脆。方法快不快，要连它放弃了什么安全网一起看。

\subsection{本章篇目}

\begin{itemize}
\tightlist
\item \hyperref[sec:08-Numerical-Analysis/02-Root-Finding/01]{``括区与二分法''}——一次变号就是一张含根证书，误差界在第一次调用之前就能算出；

\end{itemize}
