\section{割线法、收敛阶与混合策略}
\label{sec:08-Numerical-Analysis/02-Root-Finding/03}

你有一个黑盒函数，每次调用都要跑几分钟仿真或花一笔钱。你想求它的根。Newton 法每步需要导数，但你没有——要么函数不给导数，要么实现导数和你重写整个仿真差不多。二分法不需要导数，可它每步只缩小区间一半，太慢。

有没有一种方法，不需要导数，却比二分快得多？

\subsection{用已有的两个函数值冒充导数}

上一节的 Newton 步是 \(x_{k+1}=x_k-f(x_k)/f'(x_k)\)。没有 \(f'(x_k)\) 的时候，最朴素的补救是：用最近两次函数值算一个割线斜率，假装它是导数。即用

\[
\frac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}}
\]

替换 \(f'(x_k)\)。代入 Newton 步，得到

\[
x_{k+1}
=x_k-f(x_k)
\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})}.
\]

这就是割线法（secant method）。几何上看，它对 \((x_{k-1},f(x_{k-1}))\) 和 \((x_k,f(x_k))\) 两点做线性插值，再取这条插值直线与 \(x\) 轴的交点作为下一步猜测——和 Newton 法完全相同的思路，只是切线换成了割线。

它的成本结构是个漂亮的作弊：每步只需要一次新的函数计算，因为上一步的 \(f(x_{k-1})\) 就是这一步的 \(f(x_k)\)，可以缓存复用。每个函数计算都服务了两步迭代——当前步的分子和下一步的分母。与用有限差分近似 Newton 法相比，割线法用同样的两次函数值贡献了两步的斜率信息，而有限差分 Newton 每步就要消耗两次函数值来近似一个导数。

但便宜有便宜的代价。你现在应该马上追问：如果 \(f(x_k)\) 和 \(f(x_{k-1})\) 非常接近，分母会出什么事，步长会出什么事。

\subsection{它比线性快，却没有 Newton 那么快：黄金比例收敛}

在足够光滑函数的简单根附近，割线法的误差满足渐近关系

\[
e_{k+1}\approx C e_ke_{k-1},
\]

其中 \(e_k=x_k-r\) 是第 \(k\) 步到真根 \(r\) 的误差。这个关系可以从插值余项严格推出：把割线法看作两点线性插值后，用插值误差公式提取出乘积结构。我们先承认它，集中看它的后果。

这条递推式的意思很清楚：当前的误差约等于上两步误差之积（乘一个常数）。这比线性收敛的 \(e_{k+1}\approx \lambda e_k\) 强——误差会乘上一步的误差而不是固定的常数——但又比 Newton 的 \(e_{k+1}\approx C e_k^2\) 弱——只用到两步误差的乘积，而非一步误差的平方。

现在做一个小小的渐近假设：假设在收敛后期，误差量级满足 \(|e_k|\sim |e_{k-1}|^p\)，即每步误差是上一步误差的 \(p\) 次幂量级。把这个假设代进递推式：

\[
|e_{k-1}|^{p^2} \sim |e_{k+1}|
\approx |C|\cdot|e_k|\cdot|e_{k-1}|
\sim |e_{k-1}|^{p+1}.
\]

指数必须相等，所以

\[
p^2=p+1.
\]

这个方程的来历不需要死记——它就是"每一步的阶乘上自己等于相邻两步误差乘积的阶"这句话的代数版。正根是黄金比例：

\[
p=\varphi=\frac{1+\sqrt5}{2}\approx1.618.
\]

割线法是超线性收敛（\(p>1\)），但不到二次。用比 Newton 少一半的单步信息成本，换来稍低但仍在超线性范围内的渐近阶。

这里有一个许多教材不写的关键事实：如果你比较的是"每个函数计算的效率"，割线法可能和 Newton 法打个平手。Newton 的二次收敛需要每步同时计算函数和导数，折合每个函数计算的效率大约是 \(\sqrt{2}\approx1.414\)（两步函数计算让误差平方）；割线法每一步只算一次函数，效率因子就是 \(1.618\)。当然这种比较前提是函数和导数评估成本相当——如果导数由自动微分几乎免费获得，这个比较就完全向 Newton 倾斜。

\subsection{收敛阶怎样统一比较：Q-阶}

需要一个统一框架来比较各种方法。若序列 \(x_k\to r\)，且存在 \(p\ge1\) 与 \(0<\lambda<\infty\) 使

\[
\lim_{k\to\infty}
\frac{|e_{k+1}|}{|e_k|^p}=\lambda,
\]

称序列具有 Q-阶 \(p\)。当 \(p=1\) 时还要求 \(\lambda<1\) 才称线性收敛；\(p>1\) 称超线性，\(p=2\) 称二次。

典型方法的阶：

\begin{itemize}
\tightlist
\item
  二分法——区间误差界每步乘 \(1/2\)，线性收敛（\(p=1,\lambda=1/2\)）。
\item
  收缩不动点迭代——线性收敛，\(\lambda\) 就是不动点处的导数值。
\item
  简单根附近的割线法——约 \(1.618\) 阶，超线性但非二次。
\item
  简单根附近的 Newton 法——二次（\(p=2\)）。
\end{itemize}

但 Q-阶只描述渐近行为——所谓"渐近"，就是你已经足够接近根了。它完全不告诉你走到那个区域需要多少步，也不比较各步的代价。早期的全局几何、中期的超线性过渡、末期的舍入平台，每段各有自己的主导因素。收敛阶是工具箱里的一个工具，不是方法的最终成绩单。

\subsection{经验阶为什么容易被误判}

有了 Q-阶的定义，自然会想知道"我这个具体问题跑到第几阶了"。如果真根已知，可以观察

\[
\frac{|e_{k+1}|}{|e_k|^p}
\]

是否趋近常数。真根未知时，常用相邻迭代差 \(x_{k+1}-x_k\) 替代误差 \(e_k\)，由三或四个连续点估计 \(p\)。

但这类估算在三个区域完全不可靠：

第一，早期迭代。此时离根还远，全局几何——函数的大尺度弯曲、多个根的存在、平台的欺瞒——主导了迭代路径。拟合出来的"阶"描述的是全局风景，不是根的局部结构。

第二，末期迭代。一旦进入舍入平台，误差停止下降或开始随机波动。此时 \(x_k\) 和 \(x_{k+1}\) 只是两个相邻浮点数，比值可能是 \(1,0.5,2\) 等毫无几何意义的数。

第三，没有 Q-阶的序列。振荡型方法、多步方法、达到有限精度的终止、随机化方法，不一定有简单 Q-阶。硬套定义会得到看似精确但完全误导的数字。

经验阶唯一可靠的用法是"确认你确定已经进入渐近区之前的猜测"，而不是用来决定收敛是否已经发生。

\subsection{割线点不是括区点，混合策略收场}

割线法最大的安全问题比收敛阶更直白：它不保证下一步落在含根区间内。即使初始两个端点异号（\(f(a)f(b)<0\)），普通割线法的后续迭代点可能飞到千里之外。如果函数有噪声、有近乎平坦的区域、或者附近有另一个根，斜率估计会被严重扭曲。

工程上的成熟做法是混合策略：

\begin{enumerate}
\tightlist
\item
  始终维护一个异号的括区 \([a,b]\)，保证 \(f(a)f(b)<0\)——这是从二分法继承的安全网。
\item
  尝试割线步（或更高阶的逆二次插值步）来快速逼近。
\item
  检查候选点：如果它落在括区之外，或者进展太小（像在原地踏步），或者会导致分母危险地接近零，就丢掉它，改用安全的二分步。
\item
  用新点更新括区，重复上述过程。
\end{enumerate}

Brent 方法（以及它的变体 Brent--Dekker）是这种思想的标杆实现。它的哲学很朴素：让快速插值承担大部分推进工作，同时保留二分法的最坏情况屏障。绝大多数步由割线或逆二次插值完成——它们快；偶尔的一步二分法保证你不会发散——它可靠。这段逻辑概括起来就是：聪明的算法知道什么时候不该信任一个漂亮的公式。

\subsection{选择方法时真正比较什么}

割线法的收敛阶分析给了我们一种定量的语言，但选方法从来不是单看一个阶数。下面这些问题是优先级更高的现实考量：

\begin{itemize}
\tightlist
\item
  能否可靠地找到异号括区？如果能，混合方法就有了安全底牌；如果不能，就得选择自带全局化策略的方法（如阻尼 Newton 或信赖域法）。
\item
  函数是否连续、光滑、含噪声？含噪函数上的割线斜率可能被噪声粒子完全劫持。
\item
  导数能否准确且低成本地获得？自动微分改变了这个问题的答案——当导数几乎免费，Newton 法或拟 Newton 法的优势大幅扩大。
\item
  需要确定的误差证书，还是只需要一个快速的近似值？
\item
  是单次求根，还是同一个模型要解很多次？后者值得花成本做预处理或构造更好的初始猜测。
\item
  函数、导数评估和通信成本分别是多少？如果函数是远程 API 调用，减少调用次数高于一切。
\item
  函数是否可解析延拓到复数域？若是，complex-step 导数避开了实数相消，可能改变最优策略。
\end{itemize}

如果导数可由自动微分低成本获得，Newton 法可能最合适；如果函数是昂贵黑盒仿真，割线或逆插值更有吸引力；如果求根失败的代价很高（例如嵌入在另一个优化循环内部），括区混合方法是默认的安全选择。

每种方法的收敛阶告诉你的只是"如果一切顺利，它有多快"。选择方法的大部分智力工作在于判断"在这个具体问题上，一切顺利的概率有多大，不顺利时我能承受什么代价"。
