\section{解析延拓与 Fourier 衰减}
\label{sec:08-Numerical-Analysis/09-Complex-Analysis-and-Residues/01}

\hyperref[sec:08-Numerical-Analysis/08-Fourier-and-Spectral-Methods/01]{``从 Fourier 级数到连续变换''}中有一个观察：光滑函数的 Fourier 系数以幂律衰减，而解析函数的系数几何衰减。两者之间不是量的渐变——是质的突变。光滑到 \(C^k\)，系数 \(\sim 1/k^{k+1}\)；光滑到 \(C^\infty\)，系数比任何多项式都快但仍可能慢于指数；一到解析，直接跳到 \(e^{-c|k|}\)。``解析''到底多了什么？

\subsection{三个函数的系数衰减，摆在面前}

取三个以 \(2\pi\) 为周期的函数，各算 Fourier 系数的大 \(k\) 行为：

\begin{itemize}
\tightlist
\item
  \(f_1(x) = |x|\)（在 \(x = 0\) 处不可微）：
  \[
  \widehat{f}_1(k) \sim \frac{C}{k^2}.
  \]
  多项式衰减，因为函数在原点有一个折角。
\item
  \(f_2 \in C^\infty\) 但不解析（\(e^{-1/x^2}\) 在原点处理后的周期化版本，所有导数在零点为零，但函数在该点附近不恒为零）：
  \[
  \widehat{f}_2(k) \text{ 衰减快于任何 } k^{-m}, \text{ 但慢于任何 } e^{-c|k|}.
  \]
  不是多项式，也不是指数——在两者之间。指数衰减要求系数按几何级数缩小，这里做不到。
\item
  \(f_3(x) = \dfrac{1}{\rho - \cos x},\ \rho > 1\)：
  \[
  \widehat{f}_3(k) \sim C_\rho \, e^{-|k| \operatorname{arcosh} \rho}.
  \]
  纯几何衰减。\(\rho\) 越接近 1，衰减越慢；\(\rho\) 越大，衰减越快。
\end{itemize}

三组数据摆在面前，问题很自然：同样是无穷可微，为什么 \(f_2\) 进不到指数衰减？限制不在实轴的光滑性上。

\subsection{往实轴下面看一眼}

复可微在一点 \(z_0\) 存在，要求极限

\[
f'(z_0) = \lim_{h \to 0} \frac{f(z_0 + h) - f(z_0)}{h}
\]

与 \(h\) 沿复平面哪个方向趋于零无关。实可微只要求左右沿实轴一致——两个方向。复可微要求前后左右无数个方向全部一致。这一步收紧到几乎违反直觉。

区域内处处复可微的函数是解析的（全纯的）。解析函数自动 \(C^\infty\)，而且它的 Taylor 级数在收敛圆盘内收敛到函数本身——不是只做出一个级数形式，而是级数真正等于函数。\(e^{-1/x^2}\) 这种``所有导数为零却不恒为零''的反例在复平面上不可能存在：如果在原点复可微，函数的幂级数就是全零，那它在一个有聚点的集合（实轴上的一个区间）上为零，恒等定理迫使它恒为零。矛盾。

所以 \(e^{-1/x^2}\) 虽然在实轴无穷可微，但它不是复解析的——无法在不碰到奇点的条件下延拓到包含实轴区间在内的复平面区域。

\subsection{延拓能走多远，由最近奇点决定}

恒等定理的另一面：若两个解析函数在一个有聚点的集合上相等，它们在整个共同解析域上相等。因此，一个在实轴上给定的函数，它的解析延拓是唯一的——只要能延拓出去。

以 \(f(x) = 1/(1 + x^2)\) 为例。在实轴上它光滑且有幂级数。延拓到复平面：\(f(z) = 1/(1 + z^2)\)，在 \(z = \pm i\) 有极点。所以这个函数在条带 \(|\operatorname{Im} z| < 1\) 内解析，在高度 \(\pm 1\) 撞到奇点。条带宽度是 \(1\)，由最近奇点的距离决定。

再看 \(f_3(x) = 1/(\rho - \cos x)\)。奇点满足 \(\cos z = \rho\)，即

\[
\frac{e^{iz} + e^{-iz}}{2} = \rho
\quad\Rightarrow\quad
e^{iz} = \rho \pm \sqrt{\rho^2 - 1}.
\]

取对数得 \(z = \pm i \operatorname{arcosh} \rho\)（加上 \(2\pi\) 的整数平移）。最近奇点到实轴的距离是 \(\operatorname{arcosh} \rho\)。条带宽度就是这个数。

现在可以看出规律了：\(f_1(x) = |x|\) 在原点不可微，复平面上的奇点已经落到实轴上——条带宽度为零。\(f_2\)（\(C^\infty\) 不解析）的奇点可能以某种方式``堆积''在实轴附近但不恰好在实轴上，或者实轴本身就是自然边界——无论如何，不存在正宽度的解析条带。只有没有奇点的条带才能保证指数衰减。

\subsection{从条带宽度到系数衰减：一条积分路径的移动}

这个环节是证明的核心，也是直觉的关键。

周期 \(2\pi\) 函数的 Fourier 系数

\[
\widehat{f}(k) = \frac{1}{2\pi} \int_0^{2\pi} f(x) \, e^{-ikx} \, dx.
\]

实轴上积分是原始的写法。但 \(f\) 已经延拓到了复平面。对于 \(k > 0\)，把积分路径从实轴向下平移到 \(\operatorname{Im} z = -b\)（其中 \(0 < b < a\)，\(a\) 是条带半宽度）。Cauchy 积分定理说，在无奇点的条带内，封闭路径上的积分为零，两条平行线段上的积分相等——端部的竖直线段在趋于无穷时贡献消失（需要 \(f\) 在条带内有界）。

新路径上，\(z = x - ib\)，于是

\[
e^{-ikz} = e^{-ik(x - ib)} = e^{-ikx} \, e^{-kb}.
\]

\(e^{-kb}\) 出来了。积分的绝对值被这个因子乘上 \(f\) 在路径上的上界：

\[
|\widehat{f}(k)| \le \frac{1}{2\pi} \int_0^{2\pi} |f(x - ib)| \, e^{-kb} \, dx
\le \bigl( \sup_{|\operatorname{Im} z| \le b} |f(z)| \bigr) \, e^{-b|k|}.
\]

对于 \(k < 0\)，路径向上移，得到因子 \(e^{-b|k|}\)。合起来就是

\[
|\widehat{f}(k)| \le C_b \, e^{-b|k|}.
\]

这就是``光滑性决定衰减率''从模糊变成精确的全过程。不是泛泛的``越光滑越快''，而是：保证的指数衰减率由最近奇点到实轴的距离决定。

\subsection{回到三个例子验证}

\begin{itemize}
\tightlist
\item
  \(f_1(x) = |x|\)：最近奇点在实轴上，\(a = 0\)，任何正 \(b\) 都超出条带，不适用上述定理。系数 \(1/k^2\) 是有限光滑性的幂律，不是指数。
\item
  \(f_2\)（\(C^\infty\) 不解析）：没有正宽度的无奇点条带，定理不适用。衰减可以超多项式但不指数。
\item
  \(f_3(x) = 1/(\rho - \cos x)\)：\(a = \operatorname{arcosh} \rho > 0\)。对任意 \(b < \operatorname{arcosh} \rho\)，指数衰减 \(e^{-b|k|}\) 有保证。\(\rho \to 1^+\) 时，条带宽度 \(\operatorname{arcosh} \rho \to 0^+\)，指数衰减退化为越来越慢的几何级数，极限情况接上代数衰减——三种衰减模式在 \(\rho\) 连续变化中平滑过渡。
\end{itemize}

整函数（全平面无奇点）可以有任意宽度的条带，但这只保证衰减超指数。具体多快还取决于函数离开实轴后的增长速度——Paley--Wiener 理论正是把整函数的增长阶和 Fourier 变换的支集形状精确对应起来。

\subsection{与谱方法和采样定理的连线}

\hyperref[sec:08-Numerical-Analysis/08-Fourier-and-Spectral-Methods/01]{``从 Fourier 级数到连续变换''}中``解析函数可把积分路径移入复平面，得到几何衰减''是对以上推导的预告；``谱方法用光滑性换高精度''中``解析函数常表现为几何收敛''是数值应用。本节的贡献是把``为什么''补全：指数衰减率由复平面上奇点到实轴的距离给定，这是函数的内在性质，不是算法技巧。

采样定理也在这条几何线上。在适当平方可积条件下，严格带限信号可按 Paley--Wiener 理论延拓为指数型整函数。但``带限''并不给予时域超指数衰减——理想的 brick-wall 低通对应的是 sinc 函数，尾部只按 \(1/|t|\) 代数衰减。带宽控制了采样率的下限（频谱副本不重叠），却不管时域的衰减速度——两者之间隔着复平面上的奇点分布。
