\section{紧致性把无限局部信息压成有限控制}
\label{sec:12-Real-Analysis-Support/03-Topology-Basics/02}

你要给一个迭代过程定一个安全步长。在参数空间的每一点 \(\theta\) 附近，梯度都是 Lipschitz 的，于是每点都配得上一个自己的安全半径 \(\delta_\theta>0\)。局部结论一个不缺，你却拿不出想要的东西——你要的是一个对整个区域都够用的正数 \(\delta\)，而无限多个正数取下确界完全可以是 0。

这个困难的形状会反复出现：手上是无限多条局部承诺，需要的是一条全局承诺。每点连续想升级成一致连续，每点有界想升级成整体有界，每点附近有下降方向想升级成整体最优解存在，卡住的地方都在这一步。紧致性正是为跨过这一步准备的条件。

\subsection{有限子覆盖是一种能力，不是一项装饰}

\begin{definition}
集合 \(K\) 称为\textbf{紧的}，如果对任意一族开集 \(\set{U_\alpha}_{\alpha\in A}\)，只要
\[
K\subseteq\bigcup_{\alpha\in A}U_\alpha,
\]
就存在有限多个指标 \(\alpha_1,\dots,\alpha_N\) 使 \(K\subseteq U_{\alpha_1}\cup\cdots\cup U_{\alpha_N}\)。
\end{definition}

初读这条定义容易把它当成对集合形状的一句描述，读完就放过去。它的分量在于给了你一个动作：任何人拿来一族开覆盖——哪怕这族开集由 \(K\) 中每一点各贡献一个、数量与 \(K\) 一样多——你都可以从中挑出有限个，扔掉其余全部，覆盖依然完整。

有限意味着可以取最小值、取最大值、逐个累加。无限多个正数的下确界可能为零，有限个正数的最小值一定为正；无限个有界量的上确界可能发散，有限个的最大值一定有限。开头那个安全步长的困局，只要定义域紧致就自动解开：每点的 \(\delta_\theta\) 张出一族开球，覆盖整个区域，紧致性从中挑出有限个，这有限个半径的最小值就是那条全局承诺。

\subsection{开区间交不出这份能力}

把上图的 \([0,1]\) 换成 \((0,1)\)，能力就消失了。给每个点 \(x\) 配一个专属邻域 \(\left(\frac x2,\frac{x+1}2\right)\)，这一族确实盖住了 \((0,1)\)。可是从中任取有限个，它们左端点的最小值是某个正数 \(a>0\)，于是 \((0,a]\) 这一段没人管。要堵住靠近 0 的所有缝隙，需要无限多个成员，一个都省不掉。

同一个缺陷换成序列语言也看得见：\(x_n=1/n\) 全在 \((0,1)\) 里，它的每个收敛子列都奔向 0，而 0 不属于 \((0,1)\)。函数 \(f(x)=1/x\) 在 \((0,1)\) 上处处连续，但取 \(x_n=1/n\)、\(y_n=1/(2n)\)，两点越靠越近而函数值差趋于无穷——每点的 \(\delta_x\) 确实存在，靠近 0 时却被压向零，下确界为零。三种描述指的是同一件事：集合漏掉了自己内部序列想去的地方。

\begin{proposition}
度量空间中的集合 \(K\) 紧，当且仅当 \(K\) 中每个序列都有收敛子列且极限落在 \(K\) 内（称为序列紧致）。
\end{proposition}

\begin{theorem}[Heine--Borel]
在 \(\R^n\) 中，\(K\) 紧当且仅当 \(K\) 闭且有界。
\end{theorem}

Heine--Borel 是有限维欧氏空间的一项福利，读的时候要把它和定义分开存放。上一节讲过闭性依赖环境空间，有界性依赖度量，两者都不是紧致的本义；一旦离开 \(\R^n\)，闭且有界不再够用。无限维 Banach 空间的闭单位球就是标准反例：它含有无限多个彼此距离固定的方向，任何有限个小球都盖不满。这一点在下一节讨论全有界时会算得更细。

\subsection{最优解的存在性靠的是这份能力}

连续映射把紧集映成紧集，而 \(\R\) 中的紧集闭且有界，于是像集的上下确界既有限又被自己收着。

\begin{theorem}[极值定理]
紧集 \(K\) 上的连续实值函数取得最大值与最小值，即存在 \(x_{\max},x_{\min}\in K\) 使 \(f(x_{\max})=\max_K f\)、\(f(x_{\min})=\min_K f\)。
\end{theorem}

条件对账：有界性保证确界是有限数，闭性保证确界作为极限点被收进集合，连续性保证像集仍然紧。少任何一条结论就垮。\(f(x)=x\) 在 \((0,1)\) 上的下确界是 0 却取不到，缺的是闭性；\(f(x)=x\) 在 \([0,\infty)\) 上没有最大值，缺的是有界性。微积分里的最值定理正是这条定理在实数轴上的特例，\hyperref[sec:02-Calculus/02-Limits-and-Continuity/04]{``连续性与整体保证''}把账算在``闭有界区间''头上，现在可以把``闭有界''换成``紧致''，结论一字不改地搬进任意度量空间。

优化里那句``连续目标加紧可行域，最优解一定存在''说的就是这件事。写下 \(\min_{\theta\in\Theta}L(\theta)\) 之前，如果 \(\Theta\) 是开集或无界集，这个 \(\min\) 可能根本没有对象，符号是空的。把约束写成 \(\norm{\theta}\le B\) 而不是 \(\norm{\theta}<B\)，看着是个形式上的小改动，却决定了存在性论证能不能起步。

\subsection{一致连续暴露了紧致性的工作方式}

\begin{theorem}[Heine--Cantor]
紧集上的连续函数一致连续。
\end{theorem}

一致连续要求的是同一个 \(\delta\)：对任意 \(\varepsilon>0\) 存在 \(\delta>0\)，使 \(d_X(x,y)<\delta\) 蕴含 \(d_Y(f(x),f(y))<\varepsilon\) 对 \(K\) 中所有 \(x,y\) 同时成立。普通连续性只发给每个点一份 \(\delta_x\)，各点的份额可以任意小。

证明骨架三行。每点连续给出 \(\delta_x\)，用半径 \(\delta_x/2\) 的开球盖住 \(K\)；紧致性挑出有限个球，中心为 \(x_1,\dots,x_N\)；令 \(\delta=\min_i\delta_{x_i}/2\)，这是有限个正数的最小值，因而为正。任取 \(d(x,y)<\delta\)，\(x\) 必落在某个 \(B_{\delta_{x_i}/2}(x_i)\) 内，三角不等式把 \(y\) 也送进 \(B_{\delta_{x_i}}(x_i)\)，两者的函数值各自离 \(f(x_i)\) 不超过 \(\varepsilon/2\)。条件对账：连续性提供局部半径，紧致性把无限族缩成有限族，取最小值这一步只在有限时合法，三角不等式负责把两个点绑在同一个球里。

回到 \(f(x)=1/x\) 在 \((0,1)\) 上的失败，缺口正在中间那步：无限族缩不成有限族，取不了最小值。把定义域收紧成 \([a,1]\)、\(a>0\)，紧致性恢复，一致连续随之恢复。开头那个安全步长的问题，答案也在这里——参数区域闭且有界时，全局 \(\delta\) 存在；区域敞着口，它可能不存在。

同一台机器还能推出别的东西。若 \(K\) 紧、\(F\) 闭且二者不交，则 \(\inf\set{d(x,y)\given x\in K,\,y\in F}>0\)：距离函数 \(x\mapsto d(x,F)\) 满足 \(|d(x,F)-d(x',F)|\le d(x,x')\)，因而连续，在 \(K\) 上由极值定理取到最小值；最小值若为零，该点属于 \(F\) 的闭包也就属于 \(F\)，与不交矛盾。两个不相交的闭集之间未必有正间隙，加上一边紧致才有。

\subsection{换一种拓扑，同一台机器还能再用一次}

紧致性回答的问题始终是：能不能从无限的局部信息里提取出有限的控制。在 \(\R^n\) 中验证它只需检查闭且有界，进了函数空间、测度空间或分布空间就得回到定义或序列条件老实检查。\((0,1)\) 和 \([0,1]\) 只差两个点，能力上却是有和无的区别，这种差别不靠肉眼看形状能分辨。

有意思的是这台机器可以换零件继续用。无限维空间的闭单位球在范数拓扑下不紧，换成弱\(^{*}\)拓扑之后它就紧了，这是 Banach--Alaoglu 定理，也是无限维优化与变分法仍能从有界序列中抽出收敛子列的依据。``覆盖''的含义变了，``从无限中挑出有限''这个动作没变。至于极限被抽出来之后是否还留在原来的空间里，那是完备性要管的事，下一节接着说。
