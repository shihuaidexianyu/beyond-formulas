\section{距离怎样产生开集与闭集}
\label{sec:12-Real-Analysis-Support/03-Topology-Basics/01}

你想说两组模型参数``差不多''，也想说一列近似分布``逼近''了目标分布。这两句话借的都是微积分里的词，可微积分里的这些词全靠 \(|x-y|\) 撑着，而参数向量和概率分布都不是实数轴上的点。摆在面前的只有两条路：每换一类对象就把收敛与连续重新发明一遍，或者把 \(|x-y|\) 在证明中真正用到的那点性质抽出来，让整套推理一次性搬家。

后一条路要让出的东西出奇地少。回头翻任何一个 \(\varepsilon\)--\(\delta\) 论证，绝对值只被用到三件事上：距离为零当且仅当两点重合；交换两点顺序距离不变；绕经第三点不会更近。把这三条立为公理，剩下的推理一个字都不用改。

\subsection{三条公理就能接管全部 \(\varepsilon\)--\(\delta\) 推理}

度量空间 \((X,d)\) 由一个集合 \(X\) 和一个函数 \(d:X\times X\to[0,\infty)\) 组成，要求 \(d(x,y)=0\) 当且仅当 \(x=y\)；\(d(x,y)=d(y,x)\)；以及三角不等式 \(d(x,z)\le d(x,y)+d(y,z)\)。非负性其实是推论：把三角不等式用在 \(x,y,x\) 上得 \(2d(x,y)\ge d(x,x)=0\)。

这三条没有一条提到坐标、基底或维数。它们只规定集合上任意两点之间怎么算远近，不过问集合里装的是数、向量、函数还是分布。于是``\(x_n\to x\)''可以统一写成 \(d(x_n,x)\to0\)，``\(f\) 在 \(x\) 处连续''可以统一写成小的 \(d_X\) 距离推出小的 \(d_Y\) 距离。语言搬家完成了，接下来要问的是：搬过去之后，哪些几何直觉还留得住。

\subsection{同一个集合换一种距离，``接近''的含义就换了}

\(\R^n\) 上常用的距离至少有三种：\(d_p(x,y)=\norm{x-y}_p\)，\(p=1,2,\infty\)。曼哈顿距离累加坐标差的绝对值，欧氏距离量直线段长度，最大值距离只盯偏离最大的那个坐标。在平面上它们的单位球分别是菱形、圆和正方形。形状差得很远，判定收敛的结果却完全一致——有限维上任意两个范数等价，存在常数 \(c,C>0\) 使 \(c\norm{v}_p\le\norm{v}_q\le C\norm{v}_p\) 对所有 \(v\) 成立，于是一个范数下的小球总夹在另一个范数的两个球之间。

等价不等于可以互换着用。等价常数会随维数增长，在几百维的参数空间里，\(L_1\) 与 \(L_\infty\) 之间的换算系数大到让``误差小于 \(0.01\)''这句话在两种度量下表达完全不同的现实要求。收敛性是渐近概念，工程阈值不是。

离散度量走的是另一个极端：相同取 0，不同取 1。此时每个单点集自成一个球，收敛序列必须最终恒等——没有比 1 更小的正距离可用，``逐渐靠近''这件事被彻底禁止了。这个例子的用处在于提醒：度量公理并不保证你熟悉的那些图像还在。

函数空间里最常用的是 sup 距离 \(d_\infty(f,g)=\sup_x|f(x)-g(x)|\)，它对应的收敛正是一致收敛，量词顺序的差别在 \hyperref[sec:12-Real-Analysis-Support/02-Convergence/02]{``点态与一致收敛只差一个量词顺序''}中已经拆开过。与它对照，\(L^1\) 或 \(L^2\) 距离允许两个函数在一小段上差很多，只要那一段够窄。比较两条传感器响应曲线时，\(L^2\) 距离小仍可能掩盖一个很窄温区内的明显偏差；若那个温区恰好是过温保护的触发点，这个被积分稀释掉的偏差就是不可接受的。选哪种度量没有对错之分，你选的是``哪种差异算显著''。

\subsection{开集是每一点都还留有活动余地的集合}

以 \(x\) 为心、半径 \(r>0\) 的开球是 \(B_r(x)=\set{y\in X:d(x,y)<r}\)，注意严格小于，外壳不算在内。集合 \(U\subseteq X\) 叫开集，条件是它的每一点 \(x\) 都配得上某个半径 \(r_x>0\) 使 \(B_{r_x}(x)\subseteq U\)。

关键在于半径可以随点变小。站在 \(U\) 深处，你能朝任意方向大步走而不出界；站在贴近边缘的位置，允许的步长被压得很小，但只要它还是正数，你就仍有余地。这份``余地''才是开集提供的东西，也正是 \(\varepsilon\)--\(\delta\) 论证每一步都在消耗的资源。

\emph{左边每一点都带着一圈完全属于集合的私人空间，右边的边界点被集合自己抓住。}

任意多个开集的并仍是开集，有限个开集的交也是。无限交则会塌陷：每个 \((-1/n,1/n)\) 都开，但 \(\bigcap_{n\ge1}(-1/n,1/n)=\set{0}\)，而单点在 \(\R\) 中不开，因为包含 0 的任何球里都有非零点。允许无限交的话，图中那圈私人空间的半径会被逼到零，开集的全部好处随之消失。

\subsection{闭集是极限点跑不掉的集合}

集合 \(F\) 叫闭集，如果补集 \(X\setminus F\) 开。这个定义写起来干净，用起来却不直观；度量空间里它等价于一条可以直接验算的序列判据：只要 \((x_n)\subseteq F\) 且 \(x_n\to x\in X\)，就有 \(x\in F\)。上图右侧画的正是这件事——序列一路向边界挤，而边界点自己也在集合里，逃逸失败。

\([0,1]\) 闭：项都落在区间内的收敛数列，极限跑不到区间外。\((0,1]\) 不闭：\(1/n\) 是它的成员，极限 0 却不是。开与闭并非互斥的标签，空集和全空间既开又闭，离散空间里每个子集都既开又闭，而 \(\Q\) 在 \(\R\) 中两样都不是——含有理数的开区间总夹着无理数，所以 \(\Q\) 不开；无理数又能被有理数列逼近，所以 \(\Q\) 也不闭。

闭性还随环境空间变化。\((0,1)\) 作为 \(\R\) 的子集不闭，可一旦把全集换成 \(X=(0,1)\)，它就是整个空间，既开又闭。判定闭与不闭之前，先说清楚``哪些极限点算数''。这个依赖性在下一节讨论紧致性时会再次出现，届时它决定了一个集合能不能撑住存在性论证。

\subsection{内部、闭包与边界把一个集合拆成三层}

有了开球，就能从任意集合 \(A\) 生成三个新集。内部 \(A^\circ\) 是含于 \(A\) 的最大开集，也就是那些拥有整球邻域的点。闭包 \(\overline A\) 是含 \(A\) 的最小闭集，等于 \(A\) 加上它全体极限点。边界 \(\partial A=\overline A\setminus A^\circ\) 收集剩下的点，它们的每个邻域都同时碰到 \(A\) 和 \(A\) 的补集，站在上面朝任何方向迈一步都可能出界。

拿 \(A=(0,1)\) 验算：内部是它自己，闭包是 \([0,1]\)（\(1/n\) 把 0 拽进来，\(1-1/n\) 把 1 拽进来），边界是 \(\set{0,1}\)。换成 \(A=\Q\cap[0,1]\)，闭包仍是 \([0,1]\)，内部却空了——没有哪个有理数拥有全由有理数组成的开球。同样的闭包，内部一个空一个不空，这个反差把``稠密''和``占地''两件事分开了。

三个概念后面各有去处。内部区分严格可行与贴着边界可行，在约束优化的规格条件里出现；闭包是测度论正则性条件的常客；边界撑起 Green 公式与流形上的积分。

\subsection{连续性有三个入口，最抽象的那个走得最远}

映射 \(f:(X,d_X)\to(Y,d_Y)\) 在 \(x\) 处连续，最直接的写法照抄 \(\varepsilon\)--\(\delta\)：
\[
\forall\varepsilon>0,\ \exists\delta>0,\quad d_X(x,y)<\delta\Longrightarrow d_Y(f(x),f(y))<\varepsilon.
\]
整句话只用到两个度量，坐标从未登场。

度量空间中还有两种等价说法。序列说法要求 \(x_n\to x\) 时 \(f(x_n)\to f(x)\)，它最贴近``极限与函数可交换''的老直觉，做具体验证时最省事。原像说法要求 \(Y\) 中每个开集的原像 \(f^{-1}(U)\) 在 \(X\) 中开，它的威力在复合时显形：\((g\circ f)^{-1}(U)=f^{-1}(g^{-1}(U))\)，两次取原像，两次保持开性，复合的连续性一行写完，不需要任何 \(\varepsilon\) 与 \(\delta\) 的接力。

三种说法刻画的是同一件事，但适用场合分得很开：\(\varepsilon\)--\(\delta\) 适合做定量估计，序列说法适合验算，原像说法适合抽象论证——它甚至不需要度量，只需要知道哪些集合是开的。等到进入一般拓扑空间，最后这个入口会直接升格为连续性的定义。

到此为止，收敛与连续已经在任意度量空间里重新可用了。可用不等于好用：这些概念都是逐点的，每一点各有自己的 \(r_x\) 或 \(\delta_x\)，而多数有价值的结论要的是对全集统一成立的一个常数。把无限多个局部承诺压成一个全局承诺，需要额外的条件，那正是下一节的主题。
