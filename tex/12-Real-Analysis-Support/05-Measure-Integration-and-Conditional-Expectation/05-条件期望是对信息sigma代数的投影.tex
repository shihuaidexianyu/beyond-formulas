\section{条件期望是对信息 \(\sigma\)-代数的投影}
\label{sec:12-Real-Analysis-Support/05-Measure-Integration-and-Conditional-Expectation/05}

概率论入门时你学过一个很直观的公式：给定离散随机变量 \(Y\)，条件期望是

\[
\E[X\mid Y=y] = \frac{\E[X\ind_{\set{Y=y}}]}{P(Y=y)}.
\]

分母是 \(Y=y\) 的概率，分子是 \(X\) 在这个事件上的期望贡献。每个 \(y\) 给一个数，合起来就是随机变量 \(\E[X\mid Y]\) 在事件 \(\set{Y=y}\) 上的取值。这个公式既好算又好理解。

现在把 \(Y\) 换成连续变量。你想照着写：

\[
\frac{\E[X\ind_{\set{Y=y}}]}{P(Y=y)}.
\]

问题来了——对于连续 \(Y\)，任何单点 \(y\) 都有 \(P(Y=y)=0\)。分子也是 0，分母也是 0。\(0/0\)，没有定义。

\subsection{\(0/0\) 危机与逃避方向}

一个自然的反应是绕过去：用条件密度。如果 \((X,Y)\) 有联合密度 \(f_{X,Y}\) 且 \(Y\) 有边缘密度 \(f_Y\)，那就定义

\[
\E[X\mid Y=y] = \int x\,\frac{f_{X,Y}(x,y)}{f_Y(y)}\,dx.
\]

这个路子能工作，条件密度 \(f_Y(y)>0\) 的点上一切合规。但它把你的定义锁在了"必须有密度"的框架里——遇到没有密度的分布怎么办？遇到更一般的抽象空间怎么办？更重要的是，它没有告诉你 \(\E[X\mid Y]\) 作为一个随机变量的本质是什么——它只是给了你一个计算公式，然后说"这就是条件期望"。

真正的困难不是计算，而是理解。你想知道的不是一个怎么算的公式，而是："给定信息 \(Y\)，我对 \(X\) 的最佳猜测到底是什么？"当 \(Y\) 是离散的时候，这个问题的答案是"每个 \(y\) 上的局部平均"。当 \(Y\) 连续的时候，局部平均怎么定义？局部要在多小的邻域上做？邻域缩到 0 的过程会不会依赖于缩法？

\subsection{换个方向：不问"点"，问"区域"}

离散情形的真正要素不是分母 \(P(Y=y)\)，而是"每个可区分的事件上做平均"这件事。你之所以能算出 \(\E[X\mid Y=y]\)，是因为你能识别出事件 \(\set{Y=y}\)，并且在这个事件上对 \(X\) 取平均。连续情形的障碍是每个点都是零概率事件，无法单独识别——但以正概率出现的事件仍然是可以识别的。

这就引出了一个新的方向：不要条件于单个点，而是条件于一组可识别的事件。用测度论的语言，就是条件于一个 \(\sigma\)-代数。

设整体信息空间是 \((\Omega,\mathcal F,P)\)。你拥有的信息由 \(\mathcal F\) 的一个子 \(\sigma\)-代数 \(\mathcal G\) 表示。\(\mathcal G\) 中的集合就是"以你现有信息可以识别的那些事件"。比如，如果你只知道 \(Y\) 的值，那你能识别的事件就是所有形如 \(\set{Y\in B}\)（\(B\) 可测）的集合，记这个信息族为 \(\sigma(Y)\)。

条件期望 \(\E[X\mid\mathcal G]\) 是一个随机变量，要求满足两条：

\begin{enumerate}
\tightlist
\item
  \(\E[X\mid\mathcal G]\) 是 \(\mathcal G\)-可测的——它只使用 \(\mathcal G\) 中已有的信息，不偷看未知信息；
\item
  对每个 \(A\in\mathcal G\)，都有
  \[
  \int_A \E[X\mid\mathcal G]\,dP = \int_A X\,dP.
  \]
\end{enumerate}

第一条限制答案能"看见"什么。第二条要求答案在每个可由现有信息识别的区域上保持 \(X\) 的平均质量。只匹配全空间上的均值远远不够——那样的话常数 \(\E[X]\) 就能满足，但它没有用到 \(\mathcal G\) 中的任何信息。必须对每个 \(A\in\mathcal G\) 都匹配，才算在每个可识别的子区域上都正确。

这个定义的精妙之处在于它从不除以零——它用积分等式替代了除法律，而积分对于零测集天然免疫。零测集上的积分总是 0，因此定义自动忽略了那些"无法识别"的细枝末节。

条件概率的定义也随之浮出水面：

\[
P(B\mid\mathcal G)
=\E[\ind_B\mid\mathcal G].
\]

注意：它是一个随现有信息变化的随机变量，不是一个固定数字。如果你只知道 \(Y\) 的值，那 \(P(B\mid Y)\) 是 \(Y\) 的函数——\(Y\) 取不同值，概率评估也跟着变。

\subsection{Radon--Nikodym 定理保证存在性}

定义写出来了，但这样的随机变量是否一定存在？对非负 \(X\)，在 \(\mathcal G\) 上定义测度

\[
\nu(A)=\int_A X\,dP,
\qquad A\in\mathcal G.
\]

因为 \(X\ge0\)，\(\nu\) 确实是个测度。如果 \(P(A)=0\)，则 \(\nu(A)=0\)——即 \(\nu\) 关于 \(P|_{\mathcal G}\) 绝对连续（\(\nu\ll P|_{\mathcal G}\)）。Radon--Nikodym 定理说，此时存在一个 \(\mathcal G\)-可测函数 \(Z\)，使

\[
\nu(A)=\int_A Z\,dP,
\qquad A\in\mathcal G.
\]

这个 \(Z\) 正满足条件期望的两条要求。一般可积 \(X\) 再通过正部负部拆分构造。

这个构造过程有一层深意：条件期望不是你先猜一个条件密度函数再积分得到的，而是作为测度相对于已有信息的导数而存在。它把条件期望从"计算工具"的地位提升到了"测度论中的基本对象"——不依赖于密度、不依赖于离散性、不依赖于任何具体参数化方式。

若 \(Z_1,Z_2\) 都满足定义，则它们只在几乎处处意义下相等。零概率集合上的取值无法被任何积分条件识别，因此条件期望是一个等价类，而不是每个样本点上唯一指定的函数。你可以在零测集上任意修改条件期望的值，不会影响任何积分等式。

\subsection{退回到有限分割：验证定义没有跑偏}

看看这个定义在熟悉的场景下会给出什么。若 \(\mathcal G\) 由有限分割 \(B_1,\ldots,B_m\) 生成，且每个块的概率 \(P(B_j)>0\)。\(\mathcal G\)-可测意味着在每块上为常数，因此

\[
\E[X\mid\mathcal G]
=\sum_{j=1}^m c_j \ind_{B_j}.
\]

代入积分条件：对 \(A=B_k\)，

\[
\int_{B_k} c_k\,dP = \int_{B_k} X\,dP
\Rightarrow
c_k P(B_k) = \E[X\ind_{B_k}]
\Rightarrow
c_k = \frac{\E[X\ind_{B_k}]}{P(B_k)}.
\]

正是离散情形下的分层平均公式。答案在每个无法进一步区分的块上为常数，常数正是块内平均。若某块概率为零，该块上的 \(c_j\) 可以任意取值——反正任何积分都不会用到这个块——再次印证了条件期望的"几乎处处"本质。

对随机变量 \(Y\)，记

\[
\E[X\mid Y]
\eqdef\E[X\mid\sigma(Y)].
\]

因为答案对 \(\sigma(Y)\) 可测，在常见的可测空间中，存在一个可测函数 \(g\) 使得 \(\E[X\mid Y]=g(Y)\)。符号 \(\E[X\mid Y=y]=g(y)\) 只是选择了这个函数一个版本，但 \(g\) 只在 \(P_Y\)-几乎处处意义下确定。若某个 \(y\) 的 \(P_Y\) 概率为零，条件期望的定义不规定该点的取值——你可以选任意值，不影响等价类。

\subsection{常用性质都能从两条定义读出}

条件期望的大多数性质只需要满足可测性和积分等式，不需要任何额外假设。只要相应变量可积：

\begin{itemize}
\item
  \textbf{线性：}
  \(\E[aX+bY\mid\mathcal G]
  =a\E[X\mid\mathcal G]+b\E[Y\mid\mathcal G]\)；
\item
  \textbf{保持次序：}若 \(X\le Y\) 几乎处处，则
  \(\E[X\mid\mathcal G]\le\E[Y\mid\mathcal G]\) 几乎处处；
\item
  \textbf{已知量可以提出：}若 \(H\) 有界且对 \(\mathcal G\) 可测，则
  \[
  \E[HX\mid\mathcal G]=H\E[X\mid\mathcal G];
  \]
\item
  \textbf{独立信息不改变平均：}若 \(X\) 与 \(\mathcal G\) 独立，则
  \(\E[X\mid\mathcal G]=\E[X]\)；
\item
  \textbf{塔式性质：}若 \(\mathcal G\subseteq\mathcal H\)，则
  \[
  \E[\E[X\mid\mathcal H]\mid\mathcal G]
  =\E[X\mid\mathcal G].
  \]
\end{itemize}

"已知量可以提出"里的可测性不能省略。如果 \(H\) 包含 \(\mathcal G\) 看不见的随机性，它就不是条件下的常数——你不能把未知量从条件期望里提出来。塔式性质也要求信息族嵌套，对两个互不包含的 \(\sigma\)-代数，连续条件化一般不能随意交换顺序。

若 \(\varphi\) 为凸函数，且 \(X\) 与 \(\varphi(X)\) 可积，还满足条件 Jensen 不等式：

\[
\varphi\bigl(\E[X\mid\mathcal G]\bigr)
\le
\E[\varphi(X)\mid\mathcal G].
\]

取 \(\varphi(x)=x^2\)：条件期望的平方不超过平方的条件期望。换句话说，用部分信息做预测会抹平波动——预测值比原始变量更"平滑"，方差不会凭空变大。这正是"条件平均消除不可解释波动"的数学表达。

\subsection{\(L^2\) 中就是正交投影}

如果 \(X\in L^2\)，视角可以直接切换为几何。所有平方可积且 \(\mathcal G\)-可测的随机变量组成 \(L^2\) 的一个闭子空间。条件期望正是 \(X\) 到这个子空间的正交投影：

\[
\E\left[
\bigl(X-\E[X\mid\mathcal G]\bigr)H
\right]=0
\]

对每个平方可积的 \(\mathcal G\)-可测 \(H\) 成立。这个正交条件推出方差分解：

\[
\E[(X-H)^2]
=
\E[(X-\E[X\mid\mathcal G])^2]
+
\E[(\E[X\mid\mathcal G]-H)^2],
\]

对任何 \(\mathcal G\)-可测的 \(H\) 成立。当 \(H=\E[X\mid\mathcal G]\) 时，第二项为零——条件期望是所有 \(\mathcal G\)-可测预测中均方误差最小的那个。

这个几何视角把概率论中"利用信息做最佳预测"的直觉变成了精确的数学陈述，并且和最小二乘投影放在同一框架下。它只在 \(L^2\) 中成立——需要二阶矩；条件期望本身只要求 \(X\in L^1\)，在那个更广的空间里正交性不适用，但"最佳预测"的直觉仍然成立。

\subsection{从鞅到 Bellman：信息更新的通用语言}

条件期望的 \(\sigma\)-代数语言让随机过程的"信息累积"有了统一的表述。给定 filtration \((\mathcal F_t)\)，若

\[
M_t=\E[X\mid\mathcal F_t],
\]

则塔式性质立刻给出鞅关系：\(\E[M_{t+1}\mid\mathcal F_t]=M_t\)。随着信息增加，预测不断更新，但对过去重新做平均后，预测回到旧值——信息越来越多，但不会系统性地往上或往下偏。

在强化学习中，Bellman 方程中的

\[
\E[V(S_{t+1})\mid S_t,A_t]
\]

也是对由当前状态和动作生成的 \(\sigma\)-代数做条件期望。Markov 假设声称这些信息已经足以预测下一步的分布——过去的状态不再提供额外信息。如果状态表示遗漏了历史中的关键变量，等式形式虽写得出来，但模型含义已经错了。

这个区隔很重要：测度定义确保条件期望作为数学对象存在，但它不能替代"信息是否充分"的建模判断。你可以对任何 \(\sigma\)-代数写条件期望，但如果你的 \(\sigma\)-代数没有编码真正相关的信息，计算出来的预测在数学上合法，在实际中无用。
