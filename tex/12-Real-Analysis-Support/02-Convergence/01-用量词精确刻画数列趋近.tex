\section{用量词精确刻画数列趋近}
\label{sec:12-Real-Analysis-Support/02-Convergence/01}

``\(n\) 很大的时候 \(x_n\) 就接近 \(L\) 了''——这句话在直觉上没问题，拿来当证据就漏得厉害。看 \(x_n=1+\frac1n\)：它每一步都比上一步更靠近 0，说它``越来越接近 0''没有事实错误，可它的极限是 1。再看 \(x_n=(-1)^n/n\)：它反复穿过 0，每次靠近之后又拐走，凭什么说它趋于 0？日常语言分不清``朝某个方向移动''和``最终停在某处''，也分不清``路过''和``留下''。

\(\varepsilon\)--\(N\) 定义把这层含糊换成一份可检验的承诺，这与微积分里 \hyperref[sec:02-Calculus/02-Limits-and-Continuity/02]{``把趋近写成严格承诺''} 处理函数极限的做法是同一套机制，只是把连续变量换成了序号。

\emph{带子先由 \(\varepsilon\) 定宽，起点 \(N\) 随后被逼出来；带子收窄，起点就往右挪。}

\subsection{定义是一场提问与应答，顺序不能倒}

\begin{definition}
数列 \((x_n)\) 收敛到 \(L\)，记作 \(x_n\to L\)，如果
\[
\forall\varepsilon>0,\ \exists N\in\N,\ \forall n\ge N,\ \abs{x_n-L}<\varepsilon.
\]
\end{definition}

把这串量词读成一次交互会更清楚：对方先出题，随便要多小的误差容限 \(\varepsilon\)；你应答，报出一个序号 \(N\)；从那一项往后，所有项都必须待在以 \(L\) 为中心、\(\varepsilon\) 为半径的带子里。图中两条带子对应两次提问，\(\varepsilon\) 收窄一半，你给出的 \(N\) 就得往后挪——这完全合法，因为 \(\varepsilon\) 出现在 \(\exists N\) 之前，\(N\) 允许依赖它。

顺序一旦倒过来，说的就是另一件事。先固定 \(N\)、再要求对所有 \(\varepsilon\) 都成立，意味着从第 \(N\) 项起序列必须恒等于 \(L\)，绝大多数收敛数列做不到。量词的次序不是书写习惯，它直接决定命题的强弱，这一点在下一节会以更尖锐的形式重现。

还有一个容易滑过的细节：\(N\) 一旦选定，管的是它之后的\emph{全部}项。不存在``第 100 项在带子里、第 101 项跳出去、第 102 项又回来''这种情况——进带之后不许再出去。这正是``路过''与``留下''的分水岭。

用它复查开头两例。对 \((-1)^n/n\) 与 \(L=0\)：给定 \(\varepsilon\)，取任何 \(N>1/\varepsilon\)，则 \(n\ge N\) 时 \(\abs{x_n}=1/n\le 1/N<\varepsilon\)，正负交替不碍事，因为定义只管距离。对 \(1+\frac1n\) 与 \(L=0\)：取 \(\varepsilon=0.5\)，任何 \(n\) 都有 \(x_n>1\)，距离至少是 1，永远进不了带子，承诺当场违约。``越来越接近''于是被判定为与收敛无关的表述。

\subsection{标准证法是先估误差再反解 \(N\)}

以 \(\frac{3n+1}{n+2}\to3\) 为例。先把误差算成一个只含 \(n\) 的表达式，

\[
\begin{aligned}
\abs{\frac{3n+1}{n+2}-3}
&= \abs{\frac{(3n+1)-3(n+2)}{n+2}}\\
&= \frac{5}{n+2},
\end{aligned}
\]

再解 \(\frac{5}{n+2}<\varepsilon\)，得 \(n>\frac5\varepsilon-2\)。于是取任何 \(N>\max\set{0,\frac5\varepsilon-2}\) 即可（塞进那个 0 只是防止 \(\varepsilon\) 很大时算出负数）。

要领在于方向：\textbf{从误差出发反解 \(N\)，而不是先猜一个 \(N\) 再去验证}。猜法只在最简单的例子上碰巧奏效。工程上做误差分析时是同一个动作——先把误差写成迭代步数的显式上界，再问要达到给定精度需要跑多少步。\(\varepsilon\)--\(N\) 证明和复杂度估计其实是同一件事的两种记法。

\subsection{唯一性与有界性都从同一个带子里读出来}

极限唯一：若 \(x_n\to L\) 且 \(x_n\to M\) 而 \(L\ne M\)，取 \(\varepsilon=\abs{L-M}/3\)，两个定义各给一个序号，取其大者之后两条不等式同时成立，三角不等式给出

\[
\abs{L-M} \le \abs{L-x_n}+\abs{x_n-M} < \frac23\abs{L-M},
\]

矛盾。这里选 \(1/3\) 只为代数干净，任何小于 \(1/2\) 的比例都能逼出矛盾；条件对账只用到两件事——两个极限相距为正，以及同一项不能同时挤进两条不相交的带子。

收敛必有界：取 \(\varepsilon=1\)，则 \(n\ge N\) 时 \(x_n\in(L-1,L+1)\)，尾部被框住；前面只剩有限多项，取绝对值最大者合并即可。反向不成立，\((-1)^n\) 有界却不收敛。不过有界仍然值钱：Bolzano--Weierstrass 说每个有界实数列都含有收敛子列。它的证明先从任意序列里提取单调子列（把``之后各项都不超过它''的项叫作峰，峰有无穷多个就得到递减子列，只有有限个就从最后一个峰之后一路往上取，得到递增子列），再对这个有界单调子列调用上一章的结论。提取子列的技巧在任何全序集上都成立，落地那一步靠的仍是完备性。

子列还提供了一件反向工具：收敛数列的每个子列收敛到同一个极限，所以找到两个极限不同的子列就足以否定收敛。\((-1)^n\) 的奇偶子列分别锁死在 \(-1\) 和 \(1\)，判决立刻下来。当然，找到一个收敛子列什么也说明不了，序列完全可以在若干个聚点之间长期漂移。

\subsection{运算法则背后是误差的分账}

若 \(x_n\to x\)、\(y_n\to y\)，则 \(x_n+y_n\to x+y\)、\(x_ny_n\to xy\)，且当 \(y\ne0\) 时 \(x_n/y_n\to x/y\)。这些不该背成``极限符号可以随便搬进搬出''，它们各自对应一次误差的分账。加法最直白：把 \(\varepsilon\) 劈成两半，两个数列各领一半，三角不等式合账。乘法多一道手续，

\[
\abs{x_ny_n-xy} \le \abs{x_n}\,\abs{y_n-y} + \abs{y}\,\abs{x_n-x},
\]

其中 \(\abs{x_n}\) 有界这件事刚刚证过，于是两项都被各自的误差控制住。除法最挑剔，得先用 \(\abs{y_n-y}<\abs{y}/2\) 把分母从零附近隔开，才能保证放大倍数不失控——数值计算里除以接近零的量会灾难性放大误差，根源就在这一步。

夹逼定理则只需一行量词。若 \(a_n\le x_n\le b_n\) 且两边同趋于 \(L\)，给定 \(\varepsilon\) 取 \(N\) 使 \(n\ge N\) 时 \(L-\varepsilon<a_n\) 与 \(b_n<L+\varepsilon\) 同时成立，那么

\[
L-\varepsilon < a_n \le x_n \le b_n < L+\varepsilon.
\]

要害是上下两边必须夹向同一个极限，只知道两边有界远远不够。

到这里，\(N\) 依赖 \(\varepsilon\) 已经被视为理所当然。可如果数列的每一项本身是一个函数，收敛要在定义域的每个点上分别检验，\(N\) 就多了一个依赖对象——它还可以随点而变。下一节说明，允不允许这种依赖，决定了极限能不能继承连续性。
