一个优化脚本跑了三小时，最后一行打印：目标值 \(0.0417\)，迭代已收敛。把这个结果写进报告之前，有三件事其实还没人担保。这个``收敛''是按哪一把尺子量的——平均误差、均方误差，还是最坏那一点的误差？序列是真的收敛到了某个函数，还是仅仅彼此越靠越近？就算极限存在，它还是不是一个你能接着用的对象，会不会已经跳出了你研究的那一族函数？

三个问号对应三样必须先装好的结构：距离、完备、以及——如果你还想知道最优解长什么样、怎么一步算出来——角度。

\subsection{把函数当成点，要依次装上四样东西}

前面几个单元把函数当作被求导、被积分、被逼近的对象。本单元换一个眼光：每个函数本身是一个点，一整族函数是一个空间，于是可以问两点之间多远、一串点是否收敛、极限落在哪里。这一步把分析从``研究函数''升级成``研究函数组成的空间''，而这次升级要求先按顺序补齐四样东西。

第一样是距离。\(f\) 和 \(g\) 之间的差异是一整条曲线，把它压成一个标量的方式不止一种，\(L^p\) 范数给出一族尺子。选哪个 \(p\)，等于声明你怕哪种错误——第一篇会看到这与选损失函数是同一件事。

第二样是完备。存在性论证几乎只有一种套路：造一列越来越好的候选，然后取极限。这一步要求 Cauchy 列的极限不许逃出空间，否则辛苦造出来的最优解可能根本不在你的函数类里。第二篇的 Riesz--Fischer 定理把这张支票兑现，\hyperref[sec:12-Real-Analysis-Support/03-Topology-Basics/03]{``完备性让逼近留在空间内''}是它在一般度量空间里的版本。

第三样是角度。有了距离只能问``多远''，问不了``往哪个方向''。所有 \(L^p\) 里只有 \(p=2\) 的范数由内积诱导，于是只有那里有正交、有 Pythagoras 定理、有唯一的最近点。第三篇会把这个``只有''算成一个等式，看它如何把 \(p\) 钉死在 \(2\)。

第四样是投影。角度一到位，``在某个子空间里找离 \(f\) 最近的点''就有了唯一解和一条可检验的判据。第四篇把这件事推到底：线性回归与条件期望是同一个投影动作落在两个大小不同的子空间上，统计里那些看似互不相干的``最优''，共用的是同一个定理。

四样东西在一行算式里就能碰头。在 \(L^2([0,1])\) 上用常数逼近 \(f(x)=x\)，最优常数是 \(c=\int_0^1x\,dx=\tfrac12\)，误差 \(\norm{f-c}_2^2=\tfrac1{12}\)。这个 \(c\) 既是积分，也是 \(f\) 向常数子空间的正交投影，还是随机变量 \(f\) 的期望——三种说法指的是同一个几何动作。整个单元要做的，就是说清这个巧合为什么不是巧合。

\subsection{本单元篇目}

以下按概念依赖排列。若从具体困惑进入，也可以先打开最贴近当前问题的一篇，再沿篇内链接回补。

\begin{enumerate}
\tightlist
\item
  \hyperref[sec:12-Real-Analysis-Support/07-Lp-Spaces-and-Function-Geometry/01]{``\(L^p\) 范数把积分变成距离''}：不同 \(p\) 各强调误差的哪一面，Minkowski 与 Hölder 提供哪些基本控制，为什么元素必须是等价类；
\item
  \hyperref[sec:12-Real-Analysis-Support/07-Lp-Spaces-and-Function-Geometry/02]{``完备性让 \(L^p\) 成为 Banach 空间''}：一个逼近序列怎样走出自己的家，Riesz--Fischer 又怎样把洞补齐；
\item
  \hyperref[sec:12-Real-Analysis-Support/07-Lp-Spaces-and-Function-Geometry/03]{``\(L^2\) 的几何让投影与正交可用''}：平行四边形恒等式为什么只放行 \(p=2\)，投影定理各步吃掉哪些条件，Fourier 展开与 RKHS 从哪里长出来；
\item
  \hyperref[sec:12-Real-Analysis-Support/07-Lp-Spaces-and-Function-Geometry/04]{``条件期望与线性回归是两种投影''}：最佳线性预测与最佳均方预测各自投向何处，模型容量的几何含义是什么，残差正交为何不能当成拟合好坏的证据。
\end{enumerate}

读法上按``距离——完备——角度——投影''推进，四篇是一条直线，中途跳过任何一篇，后面那篇的条件对账都会有一处对不上。若你此刻的困惑是具体的——为什么换个损失函数模型就变了，为什么``最优解存在''这句话需要证明，为什么残差图看起来干净模型却很差——也可以直接翻到对应的那一篇，再沿链接回补前面的结构。\hyperref[sec:12-Real-Analysis-Support/03-Topology-Basics/01]{``距离怎样产生开集与闭集''}是这条线的上游，它在一般度量空间里说过的话，本单元逐句落到函数上。
