\section{流形是局部像欧氏空间的集合}
\label{sec:12-Real-Analysis-Support/08-Manifold-Basics/01}

手机地图上，你周围三百米的街区是可信的：转角的夹角、两条路的相对位置，都和你抬头看到的一致。把镜头一路拉远到整个地球，可信就没了——墨卡托投影里的格陵兰和非洲差不多大，实际上它只有非洲的十四分之一。换一种投影，面积对了，角度又歪了。没有哪种投影能让整个地球在一张平面图上处处忠实。

这不是制图技术不够好。球面和平面不同胚，不存在把整个球面双向连续地铺到平面上的一一映射，遑论保住几何关系。可是地图册照样能用：每页管一小块，翻页处重叠的部分彼此对得上，读者靠对照重叠区把两页拼起来。

\textbf{流形的定义就是把``局部可用坐标、整体未必''这件事原样写下来。} 坐标卡是局部的，转换函数负责在重叠处对齐，此外不多要求任何东西。

\subsection{一张坐标卡只承诺一小块}

设 \(M\) 是一个拓扑空间。这里先不要求它是任何欧氏空间的子集，只要求它有开集和连续这些词可用。一个 \(d\) 维坐标卡是一对 \((U,\varphi)\)，其中 \(U\subseteq M\) 是开集，而

\[
\varphi:U\to\varphi(U)\subseteq\R^{d}
\]

把 \(U\) 同胚地映到 \(\R^{d}\) 的某个开集上。

同胚这个词值得翻成操作语言。它意味着坐标读数和点本身可以互相还原：给定点你能算出坐标，给定坐标你能找回那个点。它还意味着靠得近的点坐标也靠得近，不会有两个相邻的点在地图上突然跳开，反过来也一样。一张卡就是地图册里的一页——给你一块区域，外加一套读数。

关键在于这个承诺有多小。卡只对 \(U\) 说话。\(U\) 之外发生什么，这张卡一个字也不提。

\subsection{一张卡盖不住，所以要一整本图册}

一组卡若把 \(M\) 全部覆盖住，就称为图册。覆盖的意思是每个点至少落在一张卡里，允许落在很多张卡里。当两张卡 \((U,\varphi)\) 与 \((V,\psi)\) 都罩住同一块地方时，\(U\cap V\) 里的每个点手上握着两套坐标，转移映射

\[
\psi\circ\varphi^{-1}:\varphi(U\cap V)\to\psi(U\cap V)
\]

负责把一套换算成另一套。若图册中任意两张重叠卡的转移映射都光滑，这个图册就把 \(M\) 变成一个 \(d\) 维光滑流形。

为什么一张卡常常不够？拿二维球面 \(S^{2}=\set{x\in\R^{3}:\norm{x}=1}\) 来看。它是紧的，而任何单张卡的像是 \(\R^{2}\) 的开集；紧集不同胚于 \(\R^{2}\) 的开集，因为同胚保持紧性，而 \(\R^{2}\) 的非空开集从来不紧。一张卡就此出局，这是拓扑封死的，不是技巧不够。

两张卡则绰绰有余。从北极 \((0,0,1)\) 做球极投影：对北极以外的 \(p\in S^{2}\)，连接北极与 \(p\) 的直线交赤道平面于一点，把这个交点的二维坐标发给 \(p\)。这张卡覆盖球面去掉北极。从南极再做一张，覆盖球面去掉南极。两卡在球面去掉两极的部分重叠，赤道附近的一大片区域同时属于两页。重叠处的转移映射化简后是 \(\R^{2}\setminus\set{0}\) 上的反演 \(y\mapsto y/\norm{y}^{2}\)，它光滑。于是 \(S^{2}\) 是二维光滑流形。

回头看开头那张图，地球仪与地图册的对应完全精确：每张地图是一张卡，地图册是图册，翻页处的比例换算就是转移映射。失真不来自制图师的手艺，来自 \(S^{2}\) 的整体形状——而流形的定义干脆接受这一点，只要求逐页可用、翻页处对得上。

\subsection{光滑性被放在转移映射上，这是个有意的选择}

定义里有一处安排容易滑过去：光滑要求加在转移映射身上，没有加在 \(\varphi\) 身上。原因是 \(\varphi\) 的光滑性根本无从谈起。\(M\) 只是个拓扑空间，上面没有微分结构，问``\(\varphi\) 是否可微''等于问一个没有定义的问题。转移映射不一样，它两头都在 \(\R^{d}\) 的开集里，是标准的多元微积分对象，可微与否有教科书答案。

这个安排的后果是，流形的微分结构完全由那些翻页操作携带。同一个拓扑空间配上不同的图册，可能得到不同的光滑结构——虽然在本书涉及的所有例子里，这种病态不会出现。

维数也由此变得良定义。同一点附近的任意两张卡，转移映射在 \(\R^{d}\) 与 \(\R^{d'}\) 的开集之间光滑可逆，反函数定理逼着 \(d=d'\)。你不能一张卡把某块区域读成二维、另一张读成三维，中间没有光滑可逆的桥。

\subsection{看看什么不是流形，边界才清楚}

圆锥面 \(z=\norm{(x,y)}\) 是个提醒人小心的例子。它其实满足拓扑流形的定义——把它垂直投影到 \(xy\) 平面就是一个同胚，一张卡盖住全部，顶点也不例外。但它不是 \(\R^{3}\) 的光滑子流形：顶点处 \(z\) 对 \(x,y\) 不可微，那里没有切平面，任何一张让它成为光滑子流形的卡都不存在。流形与光滑流形是两道门槛，圆锥面跨过了第一道，卡在第二道。

两条相交直线的失败更容易看清。交点附近的邻域像个十字，而一维流形的局部模型是一段开区间。十字挖掉交点后裂成四个连通分支，开区间挖掉一点只裂成两个。连通分支数是同胚不变量，两者不同胚，交点处没有合法的坐标卡。

半开区间 \([0,1)\) 卡在另一处。端点 \(0\) 的小邻域同胚于 \([0,\varepsilon)\)，而 \(\R\) 的开集的同胚像在 \(\R\) 中仍是开的，\([0,\varepsilon)\) 不开。它是带边流形，属于稍宽的定义，本书说``流形''时默认不含边。

三个例子指向同一件事：判断是不是流形，问的永远是每一点附近能否找到合法的卡。整体形状——闭不闭合、打不打结、有几个洞——不参与这个判断，那些是拓扑另外要操心的事。

\subsection{嵌在 \(\R^{n}\) 里的流形有更省事的判据}

本书遇到的流形几乎都不是抽象拓扑空间，而是老实待在某个 \(\R^{n}\) 里。这类对象叫子流形：若 \(M\subseteq\R^{n}\)，且在 \(M\) 的每一点附近存在 \(\R^{n}\) 的一个局部坐标变换，使 \(M\) 在新坐标下恰好是``前 \(d\) 个坐标自由、后 \(n-d\) 个坐标恒为零''的那张平片，则 \(M\) 是 \(d\) 维子流形。

实际用得最多的是正则值定理。

\begin{theorem}[正则值定理]
设 \(F:\R^{n}\to\R^{k}\) 光滑，\(c\in\R^{k}\)。若在 \(F^{-1}(c)\) 的每一点处 \(F\) 的 Jacobi 矩阵秩都等于 \(k\)，则 \(F^{-1}(c)\) 是 \(\R^{n}\) 的 \(n-k\) 维子流形。
\end{theorem}

证明骨架只有两步。Jacobi 满秩意味着可以挑出 \(k\) 列构成可逆子块；隐函数定理据此把这 \(k\) 个变量解成其余 \(n-k\) 个变量的光滑函数，方程组在局部变成一张图像；把``自变量''当作坐标，就得到需要的那张平片。条件对账：光滑性保证隐函数定理可用，满秩保证可逆子块存在，而``在解集的每一点上''这个量词不能省——只要有一点掉秩，那里就可能长出尖点。

球面是最省事的实例。取 \(F(x)=\norm{x}^{2}\)、\(c=1\)，则 \(\nabla F(x)=2x\)，在球面上处处非零（球面不含原点），Jacobi 秩为一，于是 \(S^{n-1}\) 是 \(n-1\) 维子流形。整个论证只用到梯度不为零，没碰积分也没碰概率。

\subsection{坐标无关成了这门学问的纪律}

有了图册，一件事变得不可回避：流形上任何一句话，如果它的真假随着换一张卡而改变，那它说的就不是流形的性质，而是那张卡的性质。点 \(p\) 的坐标是 \((0.3,-1.2)\) 还是 \((5,7)\)，取决于你翻到哪一页；两点之间的坐标差是多少，同样如此。这些量不属于 \(M\)。

于是这门学问给自己立了条纪律：只承认那些在所有坐标卡下给出一致答案的对象，或者虽然分量随卡变化、但变化方式由转移映射的 Jacobi 完全决定的对象。前者是标量，后者是向量、张量、微分形式。判定一个量合不合法的标准动作，就是让它过一遍转移映射，看它变成什么样。

这条纪律看起来是负担，实际是省力的。它把``选坐标''这一步从结论里剥离出去，使得球面上的一个几何事实不必对南半球和北半球各证一遍。后面各节——切空间、黎曼度量、光滑映射的微分——每一个概念都会先交代它在换卡时如何变化，再谈别的。下一节\hyperref[sec:12-Real-Analysis-Support/08-Manifold-Basics/02]{``切空间把方向还给弯曲空间''}就从最基本的一个问题开始：在没有全局加法的地方，``方向''该怎么定义。
