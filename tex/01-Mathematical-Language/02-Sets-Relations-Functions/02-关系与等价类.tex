\section{关系与等价类}
\label{sec:01-Mathematical-Language/02-Sets-Relations-Functions/02}

主数据团队上线了一条去重规则：两条记录的姓名相似度超过 \(0.85\) 且手机号后四位相同，就判为同一位客户。跑完全量数据，最大的那个客户簇里有两百多条记录，肉眼一翻，里面至少混着七八个不相干的人。

把阈值提到 \(0.9\)，簇只是小了一点，性质没变。问题不在阈值上。``相似''这个关系从一开始就不具备做分类所需要的性质，而缺的那一条，恰恰是三条里最不显眼的一条。

\subsection{关系就是被挑出来的那些配对}

先把词落到地上。给定集合 \(A\) 与 \(B\)，笛卡尔积 \(A\times B\) 摆出了所有可能的配对；从 \(A\) 到 \(B\) 的二元关系 \(R\) 就是这些配对中的一个子集。\((a,b)\in R\) 也写作 \(aRb\)。

三个学生、三门课，一共九种``谁选了哪门''的可能，实际选课表挑中其中五种。数据库里那张两列的表、纸上画的箭头图、代码里那个返回真假的判断函数，装的是同一堆有序对，只是换了张脸。整数上的整除关系是 \(\Z\times\Z\) 的子集，\((3,6)\) 在里面而 \((6,3)\) 不在；实数上的小于关系是 \(\R\times\R\) 的子集。

当关系的两头是同一个集合，也就是 \(R\subseteq A\times A\) 时，才谈得上下面三条性质。

\begin{definition}
设 \(R\subseteq A\times A\)。若每个 \(a\in A\) 都满足 \(aRa\)，称 \(R\) 自反；若 \(aRb\) 总能推出 \(bRa\)，称 \(R\) 对称；若 \(aRb\) 与 \(bRc\) 同时成立时总有 \(aRc\)，称 \(R\) 传递。三条同时成立的关系叫等价关系，通常记作 \(\sim\)。
\end{definition}

三条彼此独立，成立一条不承诺另外两条。``认识''大体对称，却很不传递：你认识小华，小华认识她表哥，这不代表你认识那位表哥。``小于''传递得很，但既不自反（\(2<2\) 为假）也不对称。``等于''三条全占。所以拿到一个新关系时，不要凭语感猜它的性质，逐条去验；尤其注意传递性需要三个元素才能检验，随手举一对例子什么也验不出来。

\subsection{等价关系是一台故意忽略差异的装置}

等价关系不说两个对象完全相同，只说按当前锁定的标准可以归为一类。办身份证就是这个逻辑：公安系统不管你的发型和昨天吃了什么，只锁定姓名、出生日期、证件号这几个字段，字段吻合就判为同一个人。无数种差异被一次性放弃，换来一个可以稳定执行的判定。

最常用的例子是模 \(m\) 同余。固定正整数 \(m\)，在整数上定义

\[
a\sim b
\quad\Longleftrightarrow\quad
m\mid(a-b),
\]

即 \(a-b\) 是 \(m\) 的倍数，也就是两者除以 \(m\) 的余数相同。三条性质都靠整除的加法结构一步过关：\(a-a=0\) 被任何 \(m\) 整除；\(a-b\) 是倍数则 \(b-a\) 也是；\(a-b\) 与 \(b-c\) 都是倍数，相加得到 \(a-c\) 也是。

对任意 \(a\)，它的等价类是所有与它等价的元素凑成的集合：

\[
[a]=\{x\in A:x\sim a\}.
\]

取 \(m=3\)，整数被切成三块：\([0]=\{\ldots,-3,0,3,6,\ldots\}\)、\([1]=\{\ldots,-2,1,4,7,\ldots\}\)、\([2]=\{\ldots,-1,2,5,8,\ldots\}\)。留意 \([1]\) 与 \([4]\) 不是两个相交的类，它们就是同一个类，因为 \(1\sim 4\)。类是一个整体，换个代表元来称呼它，它还是它。

\subsection{等价类要么相等，要么不交}

这是等价关系全部威力的所在，而且证明只用到对称与传递各一次。

假设 \([a]\) 与 \([b]\) 有一个公共元素 \(x\)，即 \(x\sim a\) 且 \(x\sim b\)。由对称性得 \(a\sim x\)，再与 \(x\sim b\) 传递，得 \(a\sim b\)。于是任取 \(y\in[a]\)，从 \(y\sim a\) 与 \(a\sim b\) 传递出 \(y\sim b\)，即 \([a]\subseteq[b]\)；把 \(a\) 与 \(b\) 的角色对调再走一遍，得到反向包含。两个类完全重合。

条件对账：对称性保证``沾上边''这件事没有方向，传递性负责把公共元素的关系推广到整个类，自反性则保证每个元素至少落在自己的类里、不会有元素无家可归。缺任何一条，下面这张图就不成立。

这样一组互不相交、并起来正好是全集的非空子集，叫做 \(A\) 的一个划分。反方向同样成立：先把集合随意切块，再宣布同块的元素等价，得到的就是一个等价关系。等价关系与划分是同一件事的两种说法，这个对应会在商群、商空间、聚类结果的表示里反复出现。

\subsection{商集：把类提升为新的对象}

所有等价类凑成的集合叫商集，记作 \(A/{\sim}\)。它的元素不再是个体，而是整块整块的类。

有理数就是这样造出来的。从整数对 \((p,q)\)（\(q\neq 0\)）出发，规定

\[
(p,q)\sim(r,s) \quad\Longleftrightarrow\quad ps=qr,
\]

于是 \((1,2)\)、\((2,4)\)、\((-3,-6)\) 落进同一个类，商集就是 \(\Q\)。这里为什么用乘法 \(ps=qr\) 而不用 \(p/q=r/s\)？因为除法预设了``比值''这个对象已经存在，而我们正要把它造出来。等价关系允许你先宣布``这些写法代表同一个东西''，再把那个东西定义为它们所在的类。

工程上做的是同一件事，只是换了名字。实体解析的产出就是一个划分，而``规范形式''不过是给每个类选一个代表元：从一个客户簇里挑出主记录，从若干种日期写法里选定 ISO 格式，从同义词表里指定标准词。选代表元这一步之所以合法，靠的正是类与类不交——否则同一条记录会被两个主记录同时认领。

\subsection{传递性是埋伏最多的那一条}

回到开头。在实数上定义 \(xRy\) 当且仅当 \(\abs{x-y}\le 1\)。自反没问题，对称是绝对值天生的。传递呢？

于是 \(0R0.8\)、\(0.8R1.6\) 都成立，\(0R1.6\) 却不成立，传递性当场碎掉。接近不等于等价：一串短跳板能架到任意远的地方去。

开头那条去重规则栽的就是这个跟头。记录 A 像 B、B 像 C、C 像 D，链子一节节接下去，A 与 D 之间可能已经毫无相似之处，却被并进了同一个簇。相似度阈值管住的是相邻两跳，管不住链条的总长度。要得到可用的身份分组，得引入稳定标识（证件号、账号）、给合并加上不可跨越的硬约束，或者干脆接受桥接并对簇的直径设上限。相似关系不会因为你调高阈值就自己长出传递性。

同类的词还有``接近''``相关''``有共同好友''。看到它们就该警觉：三条性质，拿具体数值，一条一条验。

\subsection{闭包只补形式，不补语义}

如果一个关系差了某条性质，又不想删掉已经确认的有序对，就只能往里加。在所有包含 \(R\) 且具备该性质的关系中，若存在最小的一个（按集合包含比较），就称它为 \(R\) 关于该性质的闭包——除了为达标不得不加的，一个多余的都不放进去。

以传递闭包为例。集合 \(\{a,b,c\}\) 上的 \(R=\{(a,b),(b,c)\}\) 显然不传递，补上 \((a,c)\) 即得 \(R^{+}=\{(a,b),(b,c),(a,c)\}\)。一般地，只要存在一条链 \(x=x_{0}Rx_{1}R\cdots Rx_{n}=y\)，就令 \(xR^{+}y\)，因此

\[
R^{+}=\bigcup_{n\ge 1}R^{n},
\]

其中 \(R^{n}\) 是走恰好 \(n\) 步能连上的有序对。把元素看成点、有序对看成有向边，原关系记录的是直接相邻，传递闭包记录的是可达——这正是 \hyperref[ch:029]{``图论：局部邻接怎样形成全局网络''}里反复出现的对象。再把所有 \((x,x)\) 补进去，就是自反传递闭包 \(R^{*}\)。自反闭包、对称闭包同理，但必须说清补的是哪一条，``取闭包''本身不是一个确定的操作。

危险在于闭包只在形式上达标。把``距离不超过 1''取传递闭包，\(0\) 一路能连到任何实数，得到的关系确实传递，也确实和日常说的``接近''再无关系。相似度去重若直接用传递闭包分组，得到的就是相似图的连通分量——数学上无懈可击，业务上把整个客户库并成了几个巨簇。补齐性质和保住含义是两件事，闭包只负责前一件。

对称性把对象横着摊平成类，代价是彻底放弃类内的次序。如果反过来，要求关系``不许双向''，得到的就是一种纵向的层次结构。下一节把对称性换成反对称性，看看这条岔路通向哪里。
