\section{数据处理不等式与充分表示}
\label{sec:07-Information-Theory/02-Joint-Information/04}

你手机里有一张 4000 万像素的原图。你把它压成 200 万像素的缩略图，发给朋友。朋友能从缩略图里恢复出你脸上毛孔的细节吗？不能——那些像素已经不在了。但朋友能不能判断这张照片是在室内还是室外拍的？大概率可以。

处理数据总会丢掉一些东西，但不一定丢掉你关心的东西。数据处理不等式把前半句变成定理，而后半句指向一个更微妙的事实：有时候，丢掉的东西恰好全是噪声。

\subsection{先碰一个具体场景：量化丢了多少}

把上面的直觉装进一个可算的例子。设 \(X\) 是一个取四个值 \(\{a,b,c,d\}\) 的均匀信源，每个概率 \(1/4\)。所以

\[
H(X) = 2 \text{ bit}.
\]

现在让 \(X\) 通过一个含噪声的观测 \(Y\)：一个二元对称信道，输出 \(Y\) 只取两个值 \(\{0,1\}\)，转移规则是

\[
P(Y=0\mid X\in\{a,b\}) = 1-\varepsilon,\qquad
P(Y=1\mid X\in\{c,d\}) = 1-\varepsilon.
\]

也就是说 \(Y\) 告诉你 \(X\) 属于前一半还是后一半，但偶尔报错。可以算出

\[
I(X;Y) = 1 - h_2(\varepsilon) \text{ bit}.
\]

当 \(\varepsilon = 0\)（无噪声），\(Y\) 完美区分前后两半，互信息是 1 bit。当 \(\varepsilon = 0.5\)（纯噪声），\(Y\) 与 \(X\) 独立，互信息为零。

现在对 \(Y\) 再做一次处理：把它量化为 \(Z = Y\)（恒等，不额外丢信息）或 \(Z = 0\)（常数，信息全丢）。如果再过一个有噪信道，互信息继续下降。规律是：只要处理链是 Markov 的——\(Z\) 只看 \(Y\) 生成，不偷看 \(X\)——关于 \(X\) 的信息只会减少或不变，不会增加。

\subsection{不等式本身与两条链式法则}

设信息经过流水线

\[
X \to Y \to Z,
\]

即 \(Z\) 仅由 \(Y\) 进一步处理而来，给定 \(Y\) 后不再直接依赖 \(X\)。数据处理不等式（Data Processing Inequality, DPI）断言：

\[
I(X;Z) \le I(X;Y).
\]

证明只用链式法则的两个方向。先把 \((Y,Z)\) 绑在一起：

\[
I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y).
\]

Markov 条件恰好给出 \(I(X;Z\mid Y)=0\)（上一节的内容），所以

\[
I(X;Y,Z) = I(X;Y).
\]

再从另一头拆：

\[
I(X;Y,Z) = I(X;Z) + I(X;Y\mid Z) \ge I(X;Z).
\]

两步合起来：

\[
I(X;Y) = I(X;Y,Z) \ge I(X;Z).
\]

证明不需要任何分布假设，不需要有限字母表，只依赖 Markov 结构和互信息的非负性。整个过程严格，但每一步都在说同一件事：\(Z\) 含有的关于 \(X\) 的信息，不可能超过它的上游原料 \(Y\)。

\subsection{丢失量到底是什么}

证明里第二条链式法则还透露了信息的去向。整理不等式两侧的差：

\[
I(X;Y) - I(X;Z) = I(X;Y \mid Z).
\]

所以丢失的那部分信息，是知道了 \(Z\) 之后，\(Y\) 仍然保留但 \(Z\) 没能传达的关于 \(X\) 的信息。它不是凭空蒸发了——它还在 \(Y\) 里，只是被 \(Z\) 丢弃了。

等号成立的充要条件因此浮现：

\[
I(X;Y \mid Z) = 0,
\]

即 \(X \to Z \to Y\) 也满足 Markov 条件。换句话说，\(Z\) 保留了 \(Y\) 中关于 \(X\) 的全部信息，处理无损失。这里的``反向 Markov''仍是条件独立陈述，不是把因果箭头倒转。

\subsection{确定函数压缩：最常见也最直观}

实际中最常见的处理是确定函数：

\[
Z = g(Y).
\]

此时 \(X \to Y \to Z\) 自动成立（\(Z\) 只看 \(Y\)），DPI 变成

\[
I(X; g(Y)) \le I(X; Y).
\]

取特征、量化、压缩、神经网络层前馈——都属于确定函数处理。若 \(g\) 可逆，\(g^{-1}\) 存在，则从 \(Z\) 可以恢复 \(Y\)，信息不丢：\(I(X; g(Y)) = I(X; Y)\)。若 \(g\) 多对一，通常丢信息，但有可能恰好丢掉的部分与 \(X\) 无关。

这里隐着一个工程上的关键判断：压缩一定丢信息，但不一定丢与当前任务有关的信息。接下来把这个直觉变成定义。

\subsection{充分表示：当压缩恰好不伤任务}

设想 \(Y\) 是一段高维原始数据，\(X\) 是我们关心的目标（分类标签、未来值、待估参数）。我们想找一个低维表示 \(T(Y)\)，使得

\[
I(X; T(Y)) = I(X; Y),
\]

即压缩不丢关于 \(X\) 的信息。从丢失量公式看，这等价于

\[
I(X; Y \mid T(Y)) = 0,
\]

也就是

\[
X \perp Y \mid T(Y).
\]

满足这个条件的 \(T(Y)\) 称为关于 \(X\) 的充分表示（sufficient representation）。在经典统计里，把 \(X\) 换成未知参数 \(\theta\)，把 \(Y\) 视为样本，得到的就是充分统计量——样本中关于参数的全部信息被压缩进一个低维函数。

回到机器学习语境：如果你能把一张 \(224\times 224\) 的图压缩成 128 维向量，而向量里保留了关于``猫还是狗''的全部信息，那你就拿到了一个对分类任务充分的表示。它可能比原图小了三个数量级，但不伤害当前任务的判别能力。

``压缩必定损害下游性能''因此是一个过于粗糙的陈述。压缩不能创造信息，却可以筛选信息——留下与任务相关的，甩掉与任务无关的。在有限样本和有限模型容量下，舍弃噪声甚至有正则化收益。

\subsection{现实中去噪后预测反而更好——这不违反 DPI}

设 \(Z = g(Y)\) 是一个去噪或特征提取步骤。DPI 说 \(I(X; Z) \le I(X; Y)\) 在总体分布上成立。但在用有限模型和有限数据训练时，基于 \(Z\) 的测试准确率可能高于基于原始 \(Y\)。

这看起来像矛盾，但信息不等式和泛化性能不在同一个层面：
\begin{itemize}
\tightlist
\item
  DPI 说的是最优统计信息的上限：给定无限容量和无限数据，原始 \(Y\) 能提供的信息不比 \(Z\) 少；
\item
  实际模型的容量、优化器、正则化和样本量都是有限的。原始 \(Y\) 含有更多信息，但模型可能无力从中提取；\(Z\) 虽然信息更少，但结构更简单，模型更容易学会。
\end{itemize}

因此 DPI 不担保``用原始数据永远更好''。它担保的是``不存在从 \(Z\) 里变出 \(X\) 的新信息这种魔法''。实际算法能否接近那个信息上界，是另一个问题。

\subsection{多层网络中的信息单调性与测量陷阱}

对确定前馈网络

\[
X \to H_1 \to H_2 \to \cdots \to H_L,
\]

DPI 逐层施加：

\[
I(X; H_{k+1}) \le I(X; H_k).
\]

所以在合适定义下，网络层数增加不增加关于输入的互信息。

但连续确定映射下的互信息有几个陷阱：
\begin{itemize}
\tightlist
\item
  若映射连续且可逆，互信息理论上不变——但实际上对有限精度表示，量化效应会使数值严重偏离；
\item
  若不加噪声，连续空间的互信息可能为无穷或对微小扰动极度敏感；
\item
  用有限样本估计高维互信息本身就极不稳定。
\end{itemize}

因此直接套用 DPI 解释深度网络的``信息瓶颈''现象时，必须区分理论互信息和有限样本估计值。理论上的单调递减，估计值可能因噪声、量化和估计偏差而呈现相反趋势。

\subsection{不能倒推因果}

最后一条边界容易被忽略。假设你观察到

\[
I(X; Z) < I(X; Y),
\]

就断言``数据经过了 \(Y \to Z\) 的因果处理''——这是不成立的。互信息的大小关系只是相关性的强弱比较；DPI 需要先有 Markov 结构假设才能推出大小关系。反过来用大小关系推断结构，逻辑不通。

更一般地，任何信息不等式都是给定结构后对信息量的约束；结构本身必须来自领域知识或实验干预，不能仅靠算互信息来反向推导。

数据处理不等式给的是一个简洁有力的上界，但它本身不替你做结构选择。下一章，我们离开联合信息的链式结构，转而追问两个分布之间到底``差多少''——从编码的额外代价开始，引出 KL 散度。
