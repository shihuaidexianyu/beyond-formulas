\section{信道模型与一次传输的信息量}
\label{sec:07-Information-Theory/05-Channel-Coding/01}

你对着一个不稳定的麦克风说话。你说``0''，对方听到``0''的概率是 90\%，听到``1''的概率是 10\%。你说``1''也类似——各有 10\% 翻转。信道每秒传送 1000 个比特。问题是：你往这个信道里灌了每秒 1000 比特，接收方真正拿到了多少信息？

1000 比特？显然不对——里面有些比特被噪声吞了。900 比特？也不对——接收方不知道哪个比特被污染了。正确答案是 1000 乘以某个小于 1 的因子，这个因子取决于噪声的严重程度。而算出这个因子的第一步，是把信道、输入策略和传输结果这三个概念拆开。

\subsection{一个信道不等于一张联合分布}

发送者选择输入 \(X\)，环境根据它随机产生输出 \(Y\)。离散信道由条件概率

\[
W(y\mid x)=P(Y=y\mid X=x)
\]

描述。这个矩阵 \(W\) 回答``输入已经是 \(x\) 时，输出怎样随机变化''——信道是环境的物理属性，对发送者来说给定了就不可改变。但它没有规定发送者多久使用一次各个输入。

你还需要选择输入分布 \(p_X(x)\)——你准备以多大频率发送 0，以多大频率发送 1。有了信道 \(W\) 和输入策略 \(p_X\)，联合分布才完整出现：

\[
p_{XY}(x,y)=p_X(x)W(y\mid x),
\]

输出边缘也随之固定：

\[
p_Y(y)=\sum_xp_X(x)W(y\mid x).
\]

因此同一张信道转移矩阵，在不同输入分布下可以传递不同数量的信息。如果你永远只发 0——\(p_X(0)=1\)——无论信道多么干净，接收方只能确定你发了 0，没有信息量可言。如果你以各半概率随机发 0 和 1，同样的信道上就能承载信息。把信道 \(W\)、输入策略 \(p_X\) 和二者诱导的联合分布混成一个对象，是后面理解容量时最常见的障碍。信道是死的；输入策略是你手里的自由度；联合分布是这三者合在一起的结果。

\subsection{互信息衡量输出消除了多少输入不确定性}

一个自然的想法：直接看输出熵 \(H(Y)\)。输出端熵大，说明输出变化丰富，也许传输的信息多？

马上撞上反例。假如信道和输入完全无关——无论你发什么，输出端都以均等概率吐出 0 和 1。\(H(Y)=1\) 比特，熵很大。但输出端的 0/1 序列和你的输入没任何关系，接收方读取输出猜不出你发了什么——你实际传递的信息量为零。输出熵高不等于通信能力强。

那看输入熵 \(H(X)\)？另一个反例：信道完美无噪声，但你只用一种输入（\(H(X)=0\)）。物理上信道可以传递信息，但你没有往里面装任何消息。

两个极端说明：有用的信息既不是``输入端发了多少不确定性''也不是``输出端出现了多少变化''，而是``看到输出后，对输入的剩余不确定性减少了多少''。这恰好是互信息的定义。对固定的 \(p_X\) 与 \(W\)，一次信道使用传递的信息量为

\[
I(X;Y)=H(X)-H(X\mid Y).
\]

没看到 \(Y\) 之前，你对输入的不确定性是 \(H(X)\)；看到 \(Y\) 之后，剩下的平均不确定性是 \(H(X\mid Y)\)；减少的那一部分就是要传递的信息。

互信息还有两个等价的写法，各有各的解读角度：

\[
I(X;Y)=H(Y)-H(Y\mid X),
\]

这个形式说：互信息等于输出端的总变化 \(H(Y)\)，减去``给定输入后仍残留的噪声变化'' \(H(Y\mid X)\)。把噪声扣掉，剩下的才是输入可控的信号部分。

第三个形式展开到联合分布：

\[
I(X;Y)
=\sum_{x,y}p_X(x)W(y\mid x)
\log\frac{W(y\mid x)}{p_Y(y)}.
\]

把这个和式拆开看：对于每一对 \((x,y)\)，如果条件概率 \(W(y\mid x)\) 比边缘概率 \(p_Y(y)\) 大很多——即给定 \(x\) 时输出 \(y\) 的概率远高于平均——那么这一对 \((x,y)\) 对互信息的贡献为正。看到 \(y\) 让你更有把握说``输入可能是 \(x\)''。如果条件概率低于边缘，贡献为负——看到 \(y\) 让你觉得``不太可能是 \(x\)''。整个互信息是这些贡献按真实联合概率加权的总和。

第三种写法可以直接改写为 KL 散度的形式：

\[
I(X;Y)=\sum_xp_X(x)\KL\bigl(W(\cdot\mid x)\|p_Y\bigr).
\]

读法：输入 \(x\) 能传递信息，是因为给定 \(x\) 后的输出分布 \(W(\cdot\mid x)\) 和总体输出分布 \(p_Y\) 不太一样。如果所有输入都诱导出相同的输出分布（即 \(W(\cdot\mid x)\) 不随 \(x\) 改变），输出完全不能区分输入，互信息为零。不同输入诱导的输出分布之间隔得越远，互信息越大。``输出变化大''本身不够——你要的是不同输入推出不同输出。

\subsection{两个极端先校准直觉}

把两个极端情况走一遍，直觉就落地了。

若信道无噪声，\(Y=X\)。给定 \(X\) 后 \(Y\) 毫无悬念，\(H(Y\mid X)=0\)，因此

\[
I(X;Y)=H(X).
\]

输出完整保留了输入的不确定性——信道给你传了多少，互信息就等于多少。但注意：如果发送者永远只用同一个输入，\(H(X)=0\)，即使物理信道完美，互信息也为零。信道的能力是一回事，你有没有往里装消息是另一回事。

另一极端：输出与输入完全无关——任何 \(x\) 都对应同一个条件分布 \(W(y\mid x)=q(y)\)。此时 \(X,Y\) 独立，\(H(X\mid Y)=H(X)\)，于是

\[
I(X;Y)=H(X)-H(X\mid Y)=H(X)-H(X)=0.
\]

输出可能仍然十分随机——\(H(Y)\) 可以很大——但这种随机全是噪声，不能告诉接收者你发了什么。高输出熵本身不等于高通信能力；必须扣除``给定输入后仍残留''的那部分噪声熵 \(H(Y\mid X)\)。

\subsection{二元擦除信道：先看一个透明例子}

二元擦除信道（BEC）的结构简单到可以手算互信息。以概率 \(1-\varepsilon\) 原样输出输入比特，以概率 \(\varepsilon\) 输出特殊符号 \(?\)：

\[
Y=\begin{cases}
X,&\text{概率 }1-\varepsilon,\\
?,&\text{概率 }\varepsilon.
\end{cases}
\]

擦除与输入值无关——无论是 0 还是 1，被擦除的概率都是 \(\varepsilon\)。这个信道的优点在于：接收方永远知道哪些比特是可靠的。看到 \(0\) 或 \(1\)，输入完全确定——没有被污染的可能。看到 \(?\)，知道这一位丢了，后验分布退回到先验分布——你对输入一无所知，因为擦除不提供任何有关输入的信息。

由这种结构，条件熵可以算出来。看到确定比特（概率 \(1-\varepsilon\)）时条件熵为零；看到 \(?\)（概率 \(\varepsilon\)）时条件熵等于先验熵 \(H(X)\)。因此

\[
H(X\mid Y)=\varepsilon H(X),
\]

从而

\[
I(X;Y)=H(X)-\varepsilon H(X)=(1-\varepsilon)H(X).
\]

代入具体数字：公平输入（\(H(X)=1\) 比特），\(\varepsilon=0.2\)（20\% 的比特被擦除），每次使用平均传递 \(0.8\) 比特。如果输入极度偏斜——比如 99\% 发 0，只有 1\% 发 1，\(H(X)\approx 0.08\) 比特——即使 \(\varepsilon\) 不变，互信息也跌到约 0.064 比特。信道物理属性没变，但输入本身携带的消息太少，互信息跟着缩水。

这个例子已经暗示了容量的定义：给定信道后，你不仅要问``当前使用方式下传递了多少信息''，还要问``最好的使用方式下能传递多少''——你应该选择最有利的输入分布。

\subsection{无记忆指信道，不指消息}

离散无记忆信道（DMC）满足

\[
P(y^n\mid x^n)=\prod_{i=1}^nW(y_i\mid x_i).
\]

这个式子的关键限定在等式右边是按 \(i\) 分解的——第 \(i\) 次的输出 \(y_i\) 在给定第 \(i\) 次输入 \(x_i\) 后，与所有其他位置无关。它说的是信道的记忆属性，不是输入序列的结构。

它并不要求编码后的输入符号 \(X_1,\ldots,X_n\) 相互独立。事实上，纠错码的码字符号通常高度相关——信息比特经过编码器后，相邻符号之间产生了结构性依赖，这些依赖正是纠错能力的来源（一个比特出错，其他比特可以用来推断它原来的值）。信道无记忆意味着噪声在不同时刻独立作用，不意味着你在不同时刻发送的符号之间不能有约束。

真实系统中的突发错误、随时间变化的状态、反馈、干扰和同步失配，都可能打破信道无记忆的假设。在一次雷暴中，连续数百毫秒的接收信号可能全部被破坏——这不是独立噪声，是突发擦除。转移矩阵是分析的起点，不是所有信道的完整描述。

\subsection{信道串联不会凭空增加证据}

若输出 \(Y\) 又经过一个后处理信道产生 \(Z\)——比如接收器对接收信号做量化、压缩或降噪处理——整个链路形成 Markov 链

\[
X\to Y\to Z.
\]

\(Z\) 只通过 \(Y\) 依赖 \(X\)：给定 \(Y\) 后，\(Z\) 与 \(X\) 条件独立。数据处理不等式给出

\[
I(X;Z)\le I(X;Y).
\]

对 \(Y\) 做任何后处理都不能增加关于 \(X\) 的信息。量化、压缩或再加噪可以保留一部分输入信息，但不能创造原输出中没有的证据。接收方无论用多聪明的算法处理接收到的信号，都不能超出物理信道传输过来的信息上限。

这条不等式的深层含义是：一切编码增益必须在发送之前安排。你不能收到一个含噪信号之后，靠后处理从噪声中变出新的信息——后处理只能整理已有信息，不能凭空增产。这也解释了为什么信道编码定理要把编码放在发送端：只有提前在输入符号之间构建可区分结构，接收端才有机会恢复被噪声打乱的消息。

\subsection{先别急着把互信息叫容量}

\(I(X;Y)\) 依赖当前输入分布 \(p_X\)。你以各半概率发 0 和 1 算出一个互信息值，只代表这种特定使用方式下的通信效率。只有在所有允许的输入分布中取最大值，才得到信道容量：

\[
C=\max_{p_X}I(X;Y).
\]

容量是信道的固有属性——给定转移矩阵 \(W\) 后，它不依赖任何特定的输入策略。互信息是某种使用方式下的表现；容量是对信道最佳使用方式的优化值。这两个量的关系类似于``某个驾驶员的单圈成绩''和``这台车在这条赛道上的理论最快圈速''——后者的存在不依赖于前者的具体表现。

本节中的互信息计算——BEC 的 \((1-\varepsilon)H(X)\)——还依赖你选了什么样的 \(p_X\)。下一节用二元对称信道把这一区别完整算出来：先用均匀输入求互信息，再验证均匀输入恰好达到最大值，得出容量表达式。

二元对称信道（BSC）的翻转概率是 \(p\)，均匀输入下 \(I(X;Y)=1-H(p)\)。这个结果直接回答了开篇的疑问：往 BSC 里灌 1000 bit/s，如果翻转率是 10\%，实际的信息传输率是 \(1-H(0.1)\approx 0.531\) 比特/次，即约 531 bit/s。剩下来的那 469 bit/s 填的是噪声——接收方看到了，但无法从中提取发送方的消息。
