\section{信道容量与有噪编码定理}
\label{sec:07-Information-Theory/05-Channel-Coding/03}

\subsection{一个具体的问题}

手上有一个离散无记忆信道 \(W(y \mid x)\)。每次使用：送入符号 \(x\)，以条件概率 \(W(y \mid x)\) 收到 \(y\)。可以按某种编码方案把消息映射成长度为 \(n\) 的码字序列发送，接收端依据收到的序列猜测原始消息。

当块长 \(n \to \infty\) 时，每个信道使用能可靠传送的最大比特数是多少？不是什么工程折中，是渐近意义上不可逾越的理论墙。

\subsection{先在 BSC 上比划一下}

取最简单的有噪信道：二元对称信道（BSC），交叉概率 \(p\)。发送 0 或 1，以概率 \(p\) 翻转，\(1-p\) 不变。

直接一位一位发：错误概率 \(p\)。比如 \(p = 0.01\)，每发一百位约错一位。

重复码：每比特重复三次，多数表决译码。错误概率降到约 \(3p^2 \approx 3 \times 10^{-4}\)。但码率从 1 降到 \(1/3\)。重复五次，错误率降到约 \(10^{-5}\)，码率降到 \(1/5\)。

这是用码率换可靠性。问题是：在块长可以任意长、允许对消息整体做任意编码的前提下，可靠性和码率的 trade-off 的渐近极限在哪？重复码的效率极低——有没有编码方案能在码率接近某个正数的同时让错误概率趋于零？那个正数是多少？

\subsection{单次互信息凭什么管长块的事}

对离散无记忆信道，容量的定义出奇地短：

\[
C = \max_{p_X} I(X; Y).
\]

这仅仅是：选一个单字母输入分布 \(p_X\)，算一次输入和输出之间的互信息，取最大值。没有任何关于块长、编码方案或错误概率的字眼。

Shannon 定理赋予这个单字母量操作意义：它等于长块可靠通信的最高渐近速率。把简单的单次概率优化值变成渐近可达速率的精确界限——信息论中最深刻的一次跨越就在这条等号上。

\subsection{块码的形式化}

先固定讨论对象。一个 \((n, M)\) 块码包括：

\begin{itemize}
\tightlist
\item
  编码器：消息 \(m \in \{1, \ldots, M\}\) 映射为长度 \(n\) 的信道输入序列 \(x^n(m)\)；
\item
  译码器：根据接收序列 \(y^n\) 猜测消息 \(\hat{m}\)；
\item
  速率：
  \[
  R = \frac{1}{n} \log_2 M \quad \text{bit/use};
  \]
\item
  平均错误概率 \(P_e^{\text{avg}} = P(\hat{M} \ne M)\)，消息通常假定均匀分布；最大错误概率 \(P_e^{\max} = \max_m P(\hat{M} \ne m \mid M = m)\)。
\end{itemize}

可靠性不是某个特定 \(n = 1000\) 时错误率低于某个阈值，而是存在一列 \(n \to \infty\) 的码序列，使错误概率趋于零。

\subsection{长块为什么能工作：典型序列的直觉}

单次使用信道，输入和输出的关系有随机性。长块使用 \(n\) 次后，大数定律介入。渐近等分性质（AEP）告诉了我们几件事：

\begin{itemize}
\tightlist
\item
  典型输入序列约有 \(2^{n H(X)}\) 个。
\item
  对典型输入 \(x^n\)，与之联合典型的输出约有 \(2^{n H(Y \mid X)}\) 个。
\item
  典型联合对 \((x^n, y^n)\) 约有 \(2^{n H(X, Y)}\) 对。
\end{itemize}

发送端从约 \(2^{nR}\) 个码字中选一个发出。接收端需要从 \(2^{nR}\) 个候选中找出哪一个才是真正发送的。

如果把码字看成随机散在空间里的点，每个码字能产生的典型输出大约有 \(2^{n H(Y \mid X)}\) 个。全部可能输出的集合大小约为 \(2^{n H(Y)}\)。平均而言，每个码字的``输出球''覆盖了总输出空间的 \(2^{n H(Y \mid X)} / 2^{n H(Y)} = 2^{-n I(X; Y)}\) 比例。

只要码字数 \(2^{nR}\) 不超过 \(2^{n I(X; Y)}\) 左右，这些``输出球''平均就不会严重重叠。不重叠意味着接收端几乎总能唯一识别发送码字。

\subsection{可达性：随机码字的严格论证}

固定输入分布 \(p_X\)。随机生成约 \(2^{nR}\) 个长度 \(n\) 的码字，每个坐标独立按 \(p_X\) 抽取。

译码器采用联合典型译码：寻找码本中唯一一个与收到序列 \(y^n\) 构成联合典型的码字。两种错误事件：

\begin{enumerate}
\tightlist
\item
  真正发送的码字与输出不联合典型。AEP 保证这个概率趋于零。
\item
  某个未发送的码字碰巧也与输出联合典型——一个冒充者。
\end{enumerate}

第二种是瓶颈。随机且与发送无关的码字，与给定输出偶然联合典型的概率在指数阶约为 \(2^{-n I(X; Y)}\)。码本中有约 \(2^{nR}\) 个如此这般的竞争者，联合界给出总误匹配概率：

\[
2^{nR} \cdot 2^{-n I(X; Y)} = 2^{-n (I(X; Y) - R)}.
\]

当 \(R < I(X; Y)\) 时，这个量按指数趋于零。再选最大化互信息的输入分布，即得：凡 \(R < C\)，存在一列码使得错误概率趋于零。

要注意：这是存在性证明。随机码本的平均表现好到足以保证其中一定存在某个具体码本达到同等或更优的性能。它不表示你随手生成的一个短码本就能用——只是说``好码本存在于那''。

\subsection{不可能性：为什么超不过 C}

反向假设消息 \(M\) 在 \(2^{nR}\) 个值上均匀分布，且能以很小的平均错误概率从 \(Y^n\) 恢复。Fano 不等式连接错误概率和条件熵：

\[
H(M \mid Y^n) \le h_2(P_e) + P_e \log_2(M - 1).
\]

右端第一项 \(\le 1\)；第二项中 \(\log_2(M - 1) < nR\)。因此

\[
H(M \mid Y^n) \le 1 + P_e \, nR.
\]

当 \(P_e \to 0\) 时，这一项相对 \(n\) 是 \(o(n)\)。这意味着接收到的输出几乎保留了消息的全部熵：

\[
\begin{aligned}
nR = H(M) &= I(M; Y^n) + H(M \mid Y^n) \\
&\le I(X^n; Y^n) + o(n).
\end{aligned}
\]

用到了 Markov 链 \(M \to X^n \to Y^n\) 和数据处理不等式。

展开 \(I(X^n; Y^n)\)。信道无记忆性给出 \(H(Y^n \mid X^n) = \sum_i H(Y_i \mid X_i)\)，熵的次可加性给出 \(H(Y^n) \le \sum_i H(Y_i)\)。所以

\[
\begin{aligned}
I(X^n; Y^n) &= H(Y^n) - \sum_{i=1}^n H(Y_i \mid X_i) \\
&\le \sum_{i=1}^n \bigl[ H(Y_i) - H(Y_i \mid X_i) \bigr] \\
&= \sum_{i=1}^n I(X_i; Y_i) \le nC.
\end{aligned}
\]

最后一步：每个 \((X_i, Y_i)\) 都是同一信道的单次使用，其互信息不超过容量 \(C\)。

除以 \(n\)，取极限：可靠速率不可超过 \(C\)。

\subsection{容量是渐近阈值，不是短码性能表}

有噪编码定理建立的是渐近分界线：\(R < C\) 可靠可达，\(R > C\) 不可达。标准有限 DMC 还有强逆定理：\(R > C\) 时最优码的错误概率趋于 1，不仅是不能趋于零。

但以下问题不在定理的覆盖范围内：

\begin{itemize}
\tightlist
\item
  块长 \(n = 1000\) 时最低错误率是多少；
\item
  临界速率 \(R = C\) 上能不能以某种方式通信；
\item
  编码和译码的计算复杂度；
\item
  延迟、峰值功率、误码地板和实现精度的影响；
\item
  零错误通信能到多高速率。
\end{itemize}

现代编码理论和有限块长信息论研究的正是这些缺口。接近容量通常需要更长的块、更多的计算或更精细的软信息译码。Shannon 定理保证了极限的存在性，不替工程师构造有限资源下的最优方案。

\subsection{输入约束进入容量定义}

不同输入消耗的代价可能不同。给定代价函数 \(c(x)\) 和平均预算 \(\Gamma\)，容量是有约束的：

\[
C(\Gamma) = \max_{p_X : \E[c(X)] \le \Gamma} I(X; Y).
\]

离散对称信道常由均匀输入达到容量，一般信道未必。互信息关于 \(p_X\) 是凹函数（\(p_Y\) 和 \(H(Y \mid X)\) 都关于 \(p_X\) 线性，而熵是凹函数），优化在有限字母表下可用 Blahut--Arimoto 算法求解。

\subsection{信源与信道怎么接到一起}

若要求无损恢复，一个离散无记忆信源每样本含 \(H(S)\) bit，每个信源样本可使用信道 \(\kappa\) 次。分离思想：

\[
H(S) < \kappa C.
\]

在标准无记忆和长块条件下，可以先把信源压缩到接近熵限，再把压缩比特用容量逼近码可靠发送。允许平均失真 \(D\) 时，对应比较改为

\[
R(D) < \kappa C.
\]

经典单用户条件下，信源编码和信道编码可分别设计而不损失渐近最优性。

分离定理有条件：短时延、多用户网络、联合语义目标或模型不匹配时，联合设计可能更优。不要把单用户渐近定理扩张成所有通信问题的无条件原则。
