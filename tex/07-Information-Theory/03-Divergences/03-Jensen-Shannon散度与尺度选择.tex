\section{Jensen--Shannon 散度与尺度选择}
\label{sec:07-Information-Theory/03-Divergences/03}

两个新闻语料库摆在面前，你想知道它们的用词分布差多少。麻烦马上出现：某个只在一国境内运营的公司名，在第一个库里出现了几千次，在第二个库里一次都没有。

上一节说过，只要参照分布在某处判零而被比较的分布不判零，KL 就是无穷。这里两个方向各有各的独有词，所以两边都发散。更别提``两个语料库有多不同''这个问题本身没有方向——谁做参照都说不出理由。

先试试最省事的补法：把两个方向平均，\(\tfrac12\KL(P\|Q)+\tfrac12\KL(Q\|P)\)。对称是对称了，可发散没治好，只是从单边爆炸变成了两边一起爆炸。病根在于让 \(P\) 和 \(Q\) 互相充当参照，而它们的支撑本来就不重合。

\subsection{先造一个双方都覆盖得住的参照}

Jensen--Shannon 散度的做法很直接：不让两个分布互相对照，另立一个共同参照。取等权混合

\[
M = \tfrac12 (P + Q),
\]

由 \(M\ge P/2\) 与 \(M\ge Q/2\) 立刻得到密度比 \(dP/dM\le 2\) 与 \(dQ/dM\le 2\)，于是两个 KL 项都不超过 \(\log 2\)。无论 \(P\) 与 \(Q\) 的支撑差多远，跟 \(M\) 比较都不会发散。这个论证不依赖逐点概率，连续分布同样成立。

\begin{definition}
\(\operatorname{JS}(P, Q) = \tfrac12 \KL(P \| M) + \tfrac12 \KL(Q \| M)\)，其中 \(M=\tfrac12(P+Q)\)。
\end{definition}

三条性质随定义送出：交换 \(P,Q\) 不改变 \(M\)，所以对称；两个 KL 项都非负，所以非负；以 2 为对数底时上界是 1 比特。左端零点在 \(P=Q\) 处取得，右端在两者支撑完全不交时达到。

上界为什么恰好是 1 比特，有个不必背的解释。引入一个公平的来源标签 \(Z\in\set{0,1}\)，\(Z=0\) 时从 \(P\) 抽样，\(Z=1\) 时从 \(Q\) 抽样。忽略来源的话，\(X\) 的边缘分布正是 \(M\)。把互信息展开，公共因子 \(P(z)\) 在对数里消去，剩下的恰好是定义式：

\[
I(Z; X)=\sum_z P(z)\,\KL(P_{X\given Z=z}\|P_X)=\operatorname{JS}(P,Q).
\]

所以 JS 就是``看到一个样本之后，你对它来自哪一边多知道了多少''。而来源标签本身只有 \(H(Z)=1\) 比特的不确定性，互信息不可能超过它。支撑完全不交时，看一眼样本就能断定来源，1 比特被吃干净；\(P=Q\) 时样本毫无帮助，读数是零。上界不是凑出来的，是标签只带一比特这件事的直接后果。

来源先验不必公平。令 \(P(Z=0)=\pi\)，加权版本 \(\operatorname{JS}_\pi\) 仍等于 \(I(Z;X)\)，上界换成二元熵 \(h_2(\pi)\)。\(\pi=0.9\) 时上界只有约 \(0.469\) 比特——样本大概率来自主导那一边，观察对判断来源的帮助本来就小。所以报告 JS 数值时，权重和对数底都得交代，否则同一对分布可以给出好几个不同的数。

\subsection{支撑不重叠时，尺子该换了}

JS 治好了发散，但没治好另一个毛病。两个支撑不交的分布，不管挨得近还是隔得远，JS 一律顶到上界。把 \(\KL\) 的无穷换成 JS 的常数，梯度依然是零，优化器依然不知道往哪边挪。

用一个最小例子把这件事看清楚。设 \(P\) 是集中在 \(0\) 的点质量，\(Q_\theta\) 是集中在 \(\theta\) 的点质量。只要 \(\theta\ne 0\)，两者支撑不交。

这张图解释了生成对抗网络早期训练的一个典型故障。高维数据集通常落在一个低维流形上，生成器输出的分布也落在另一个低维流形上，两者交集的测度多半是零。判别器越训越准，生成器收到的梯度反而越来越接近零——不是学不动，是目标函数在这个位置上根本没有坡度。改用 Wasserstein 距离作目标的动机就在这里：它对支撑不重叠是有反应的，哪怕两块流形还没碰上，也知道该往哪个方向挪。换来这一点要处理约束（Lipschitz 条件不好维持），并且重新设计判别器的训练方式。

总变差距离 \(\TV(P,Q)=\sup_A\abs{P(A)-Q(A)}\) 是另一把常用的尺子，它是真正的度量，取值在 \([0,1]\)，含义是``两个分布最多能在多大程度上被一次观测区分''。它跟 JS 一样在支撑不交时饱和到最大值，所以上面那个问题它也解决不了。JS 与 TV、Hellinger、KL 一起属于 \(f\)-散度族；Wasserstein 不在这个族里，因为它用到了样本空间本身的几何——搬运质量要走多远，前面几种尺子根本不问这个问题。

顺带更正一个常见说法：JS 虽然对称有界，但一般不满足三角不等式，严格讲仍是散度不是度量。真正是度量的是 \(\sqrt{\operatorname{JS}}\)，这是一条已证的结论，这里只引用。

\subsection{挑尺子之前先说清要量什么}

不存在对所有任务都最优的散度。选择通常由三个问题定下来：有没有明确的真实分布和近似分布，支撑会不会不重合，以及你关心的差异是哪一种。

有明确参照方向时，KL 的方向本身就是信息的一部分——比较概率预测与真实生成机制，\(\KL(P\|Q)\) 直接是对数损失超出下限的那一截，也就是本单元第一节那张柱状图里的红色部分。比较两个地位对等的数据集词分布，JS 的方向无关性更自然，而且它有限、有界，跨任务之间的数值还能横向比较。图像分布只发生了轻微平移这类问题，KL 和 JS 会同时饱和，Wasserstein 才读得出几何上的邻近。

\subsection{定义清楚，不等于算得出来}

上面所有公式都假设 \(P\) 和 \(Q\) 已知。现实里你手上只有有限样本，而从样本到散度这一步能出的岔子比公式本身多。

最典型的是零：大量词或取值在样本里根本没出现，代入公式就是零概率，KL 立刻发散。随手加平滑（Laplace、Good--Turing 之类）能让数跑出来，但你估计的已经是被平滑改造过的那对分布之间的散度，不是原来那个量。高维连续数据更麻烦，密度估计自身的误差常常大过散度的差异本身，算出来的小数点后两位没有意义。

所以报告经验散度时，分布是怎么得到的、未观察类别怎么处理、用了哪个方向和对数底、数值带多大的抽样波动，这四件事都得写出来。少写一件，读者就无法判断你比较的到底是分布还是估计方法。这条边界在数理统计部分还会再遇到：有些看起来``算出来''的散度值，其实是估计流程留下的影子。

到这里，衡量``两个分布差多少''的工具已经齐了。回头看会发现，整套东西的地基是同一句话——用错分布编码要多付比特。这句话至今只是一个直觉上很有说服力的说法，还没有人证明真的存在一种编码，能把平均码长压到熵那么低。下一章\hyperref[ch:057]{``无损信源编码：熵为什么是压缩极限''}把这个缺口补上。
