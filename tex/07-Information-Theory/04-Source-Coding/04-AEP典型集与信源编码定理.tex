\section{AEP、典型集与信源编码定理}
\label{sec:07-Information-Theory/04-Source-Coding/04}

\subsection{困境：一个熵不到 0.1 bit 的信源，逐符号却至少要花 1 bit}

Bernoulli\((0.99)\) 信源：以 0.99 的概率输出 0，以 0.01 的概率输出 1。上一节算出单符号熵

\[
H(X)=-(0.99\log_2 0.99+0.01\log_2 0.01)\approx 0.081\text{ bit}.
\]

按 Kraft 不等式的逻辑，最优逐符号前缀码的平均长度可以逼近这个熵，但不能低于它。然而任何二元前缀码要给两个符号各分配一个码字——最短的码字长度就是 1 bit。所以最优逐符号码的平均长度卡在 1 bit，离理论下界差了整整一个数量级。

这不是设计得不够聪明，是逐符号的粒度太粗了。一个符号只能取两个值，码字长度必须是整数，0.081 bit 的信息量根本没法用整数个 bit 来表达。

\subsection{试试长块：把 \(n\) 个符号绑在一起编}

把目光从单个符号抬到长度为 \(n\) 的块。现在``字母表''有 \(2^n\) 个元素——似乎更糟了，序列数量的增长是指数级的。给每个序列单独分配码字显然不行。

但等一下。\(2^n\) 个序列的出现概率天差地别。全零序列的概率是 \(0.99^n\)，全一序列的概率是 \(0.01^n\)。对于 \(n=100\)，前者约 0.366，后者约 \(10^{-200}\)——比宇宙中的原子数还小无数个数量级。绝大多数序列你一辈子也碰不上。

这就提示了一个思路：不要给所有序列平等对待。找到那些``实际会出现''的序列——它们承载了几乎全部概率——只给这些序列分配短索引。不出现的序列可以随便处理，因为反正见不到。

\subsection{碰壁后的转折：块自信息就是样本均值}

先不急着想编码方案，算算看：一个长度 \(n\) 的块 \(X^n=(X_1,\ldots,X_n)\)，概率是

\[
p(X^n)=\prod_{i=1}^n p(X_i).
\]

取负对数再除以 \(n\)，得到每符号的平均自信息：

\[
-\frac1n\log p(X^n)=\frac1n\sum_{i=1}^n\bigl[-\log p(X_i)\bigr].
\]

右边的每一项 \(-\log p(X_i)\) 是一个随机变量——它的期望正是 \(H(X)\)，方差有限（只要熵有限）。当 \(X_i\) 独立同分布时，右边就是一个 i.i.d. 序列的样本均值。

大数定律上场。当 \(n\) 足够大，样本均值以概率 1 收敛到期望：

\[
-\frac1n\log p(X^n)\longrightarrow H(X)\quad\text{几乎必然}.
\]

这个收敛不是大概、不是平均——是几乎必然。它说的是：随便抽一个长序列，把它的概率取负对数再除以长度，你几乎一定能得到一个接近 \(H(X)\) 的数字。

改写一下：对绝大多数序列，

\[
p(x^n)\approx 2^{-nH(X)}.
\]

这就是渐近等分性质（Asymptotic Equipartition Property, AEP）。``渐近''因为你要求 \(n\) 大；``等分''不是说所有序列概率相等，而是说实际会出现的那些序列，在一阶指数尺度上概率都差不多——都是 \(2^{-nH}\) 这个数量级。不同序列之间的概率差异当然存在，但差异是次指数级的，被指数尺度抹平了。

\subsection{精确刻画：典型集把极限定理变成可数的对象}

把大数定律的``接近''用 \(\varepsilon\) 量化。给定 \(\varepsilon>0\)，定义弱典型集

\[
A_\varepsilon^{(n)}=\Bigl\{x^n:\Bigl|-\frac1n\log p(x^n)-H(X)\Bigr|<\varepsilon\Bigr\}.
\]

AEP 等价于

\[
P\bigl(X^n\in A_\varepsilon^{(n)}\bigr)\to 1\quad(n\to\infty).
\]

也就是说，长度 \(n\) 的随机序列落在典型集里的概率趋近于 1。外面的那些``非典型''序列，单个看也许有概率不小的，但加在一起总概率趋于零。

典型集里每个序列的概率被夹在两个指数之间：

\[
2^{-n(H+\varepsilon)}<p(x^n)<2^{-n(H-\varepsilon)}.
\]

现在用这两个不等式卡出典型集的大小。总概率不超过 1，所以典型序列数至多约为 \(2^{n(H+\varepsilon)}\)（不然每个至少 \(2^{-n(H+\varepsilon)}\)，加起来就超了）。同时典型集承载接近 1 的概率，而每个元素概率至多 \(2^{-n(H-\varepsilon)}\)，所以数量至少约为 \(2^{n(H-\varepsilon)}\)。让 \(\varepsilon\to0\)，在一阶指数率上：

\[
|A_\varepsilon^{(n)}|\doteq 2^{nH(X)}.
\]

符号 \(\doteq\) 表示两边的一阶指数增长率相同——取对数除以 \(n\) 后极限相等。有限 \(n\) 时不严格相等，有 \(2^{\pm n\varepsilon}\) 的因子浮动。

\subsection{典型不等于``最可能''}

一个容易踩的坑：把典型集当成``概率最大的那些序列的集合''。对偏置硬币，全部为 0 的序列通常是单个最可能的序列，但它往往不典型——因为它的经验频率（100\% 的 0）离真实比例（99\% 的 0）有一段距离，自信息会偏离 \(H(X)\)。典型集关心的是一个整体：每个成员未必排在概率榜最前面，但整个集合作为一个整体，承载了几乎全部的概率质量。

公平硬币是边界情形。每个长度 \(n\) 的序列概率都是 \(2^{-n}\)，熵是 1 bit，所以所有序列都是弱典型的。没有非典型的``低概率区域''可以丢弃——公平硬币序列不可压缩。AEP 没有给公平硬币提供任何压缩杠杆，这正是对的：最大熵信源本来就没有冗余。

\subsection{可达性：高于熵的速率足够，而且构造很简单}

回到 Bernoulli\((0.99)\)。取 \(n=1000\)。典型集的大小大约 \(2^{nH}\approx 2^{81}\)。给每个典型序列分配一个不同的二进制索引，需要大约 81 bit——摊到每个符号头上，约 0.081 bit。再加上一个小巧的``逃生通道''：用一个特殊码字统一处理所有非典型序列（它们加起来概率微乎其微，解码时碰到这个码字就报错）。整体方案：

\begin{itemize}
\tightlist
\item
  码率略高于 \(H(X)\)——比如 \(H+\varepsilon\)；
\item
  错误概率随 \(n\) 增大而趋于零（非典型部分的概率消失）；
\item
  每个符号的平均比特数逼近 \(H(X)\)，把逐符号方案那个令人沮丧的 1 bit 远远甩在后面。
\end{itemize}

把这段论证写成定理的方向：对任意速率 \(R>H(X)\)，只要块长 \(n\) 足够大，就存在每符号不超过约 \(R\) bit、错误概率任意小的固定长度近无损码。

从算术编码的角度能得到一种更具操作感的理解。典型序列的概率约为 \(2^{-nH}\)，在 \([0,1)\) 区间里占据的宽度也约为 \(2^{-nH}\)。用二进制展开定位这个子区间，恰好需要约 \(nH\) bit。典型集编码和算术编码在指数阶上一致的，不同的只是常系数和有限 \(n\) 的实现细节。

\subsection{不可能性：低于熵的速率装不下典型世界}

反过来，假如硬要用码率 \(R<H(X)\) 编码。长度 \(nR\) 的二进制索引最多区分 \(2^{nR}\) 个序列。但典型世界里有大约 \(2^{nH}\) 个序列，它们概率相近（都在 \(2^{-n(H\pm\varepsilon)}\) 量级）。就算你精心挑选最有利的 \(2^{nR}\) 个典型序列来编码，它们能覆盖的概率至多大致是

\[
2^{nR}\cdot 2^{-n(H-\varepsilon)}=2^{-n(H-R-\varepsilon)}.
\]

取 \(\varepsilon\) 小于 \(H-R\)（可以做，因为 \(H-R>0\)），这个指数趋于零。非典型部分本来概率也趋于零。两个加起来，总成功概率趋于零。低于熵的固定码率不可能实现渐近无误恢复。

这就是离散无记忆信源的 Shannon 信源编码定理：\(H(X)\) 是近无损压缩的临界速率——高于它可达，低于它不可达。

这一定理不是宣称每个有限文件都能恰好压到 \(nH(X)\) bit，也不是说任意数据都可压缩。它在一个明确的渐近设定下成立：信源模型已知、块长趋于无穷、允许错误概率趋于零。真实压缩器还要面对三个额外成本：信源模型未知需要学习、模型描述本身占 bit、以及有限样本的离散性带来的舍入损失。

\subsection{零错误、近无损与有损：不要混在一起}

信源编码场景不止一种。把边界分清楚：

\begin{itemize}
\tightlist
\item
  逐符号前缀码：零错误，平均长度满足 \(H\le L<H+1\)——1 bit 的粒度损失来自单符号的整数约束；
\item
  长块变长码：保持唯一可译，把每符号平均冗余压到零——块越长，整数取整的浪费摊得越薄；
\item
  固定长度近无损码（典型集构造）：允许非典型块产生小概率错误，换取编码器和解码器的结构简单；
\item
  通用压缩：信源模型要从数据中学习，额外支付模型描述和有限样本成本。
\end{itemize}

\subsection{当信源不再无记忆}

上面的全部论证都假设了 i.i.d.。若信源有依赖——比如 Markov 链或更一般的平稳过程——不能把边缘熵 \(H(X_1)\) 直接当作压缩极限。正确的量是熵率

\[
\bar H=\lim_{n\to\infty}\frac1n H(X_1,\ldots,X_n),
\]

并在适当的平稳、遍历条件下，由 Shannon--McMillan--Breiman 定理给出对应的 AEP：

\[
-\frac1n\log p(X_1,\ldots,X_n)\to \bar H\quad\text{几乎必然}.
\]

典型集的大小变为约 \(2^{n\bar H}\)，编码定理用 \(\bar H\) 替换 \(H(X)\) 后一字不改地通过。

若信源非平稳或非遍历，单一典型集的图景可能需要换成多个典型集的混合，甚至典型集本身都失去意义。AEP 是 i.i.d. 假设送给你的礼物——在更野的信源面前，你得自己去找概率集中的地方。
