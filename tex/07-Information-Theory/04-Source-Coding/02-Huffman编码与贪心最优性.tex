\section{Huffman 编码与贪心最优性}
\label{sec:07-Information-Theory/04-Source-Coding/02}

你现在有一组符号和每个符号的出现概率。你想给每个符号分配一个二元码字，让平均码长尽量短。

Kraft 不等式告诉过你：一组码长序列 \((\ell_1, \ldots, \ell_m)\) 能实现为前缀码，当且仅当 \(\sum_i 2^{-\ell_i} \le 1\)。Kraft 回答的是``哪些长度组合在物理上可能''，它没有回答的是：给定概率分布，哪个可能的长度组合使平均码长最小。

直觉上方向很明确：高概率的符号码字短，低概率的符号码字长。但如果你按 \(-\log_2 p(x)\) 四舍五入后直接排，两个符号可能会抢同一个前缀位置，树结构强行要求全局和解。你没法独立地给每个符号挑一个长度——整个前缀树是一整棵，改一处叶子会牵动整个分支结构。

Huffman 算法的力量，在于它把这样一个全局树优化问题，精准地化成了一个一个的局部合并决策。而且这个化法是精确的——不是经验法则，是定理保证的最优性。本节沿着它的推导过程展开，重点放在那个``为什么贪心是对的''的证明上，因为这个证法本身就是一种可迁移的组合优化技术。

\subsection{从树的底部反推最优结构}

先盯住一棵最优的二元前缀树。如果有一个内部节点只有一个孩子，你可以把那棵子树整体上移一层——这个动作只会缩短某些码字，不会拉长任何码字。所以最优树一定是满树：每个内部节点恰好有两个孩子。

满树的一个直接推论：最深一层的叶子必定成对出现——最深叶的同胞不可能是内部节点，否则那个内部节点下面还会长出更深的叶子。因此最深处的两个叶必然共享一个父节点。

接下来问一个最关键的问题：这两个最深叶应该分配给哪两个符号？

假设它们还不是概率最小的两个符号。令 \(p_a \le p_b\) 是两个最小概率，而最深层的两个位置被概率为 \(p_x\) 和 \(p_y\) 的符号占据，且 \(p_x > p_a\) 或 \(p_y > p_b\)。把 \(p_a\) 与更深位置上较大概率的符号交换。记较深位置的长度为 \(\ell_{\text{deep}}\)，较浅位置的长度为 \(\ell_{\text{shallow}}\)，交换前后平均码长的变化为

\[
(p_a - p_{\text{large}})(\ell_{\text{deep}} - \ell_{\text{shallow}}) \le 0,
\]

因为 \(p_a \le p_{\text{large}}\) 且 \(\ell_{\text{deep}} \ge \ell_{\text{shallow}}\)。所以交换不会增加平均码长。因此，总存在一棵最优树，使概率最小的两个符号栖于最深层且为同胞。

这个论证叫交换论证。它没有构造一棵新树，而是从一棵假定的最优树出发，证明你可以把符号在树上重新安排，在不损害最优性的前提下让最小概率的两个符号占据我们想要的位置。这种``存在某棵最优树满足某性质''的证明策略，是组合优化中的常用武器——Kruskal 的最小生成树和许多调度问题的最优性证明都使用了同一套路。

\subsection{合并这一步，缩约成一个更小的同类问题}

一旦你确认两个最小概率 \(p_1, p_2\) 可以被安排在最优树的最深层作为同胞，你就可以把它们暂时捏成一个``复合符号''。这个复合符号的概率是 \(p_1 + p_2\)。原来的问题——为 \(m\) 个符号建最优前缀树——缩成了为 \(m-1\) 个符号建最优前缀树。

这两棵树之间的代价关系是干净线性的。设在缩约树中，复合符号的码长为 \(r\)。拆开后，两个子符号的码长都是 \(r + 1\)。因此

\[
\text{原树代价} = \text{缩约树代价} + (p_1 + p_2).
\]

那个多出来的 \((p_1 + p_2)\) bit 恰好是合并操作带来的额外开销——每合并一次，两个符号各多走一层。

这给出了递归算法：

\begin{enumerate}
\tightlist
\item
  从当前概率集合中取出最小的两个；
\item
  合并为一个权重为二者之和的新节点；
\item
  把新节点放回集合，重复直到只剩一个节点（根）；
\item
  从根向下，沿左右分支标记 0 和 1，读出每个叶子的码字。
\end{enumerate}

\subsection{走一个完整的手算例子}

四个符号，概率分别为

\[
p(A) = 0.4,\quad p(B) = 0.3,\quad p(C) = 0.2,\quad p(D) = 0.1.
\]

第一步：\(D(0.1)\) 与 \(C(0.2)\) 合并，得复合节点权重 \(0.3\)。现在集合中有 \(0.3, 0.3, 0.4\)。

第二步：两个 \(0.3\) 合并，得 \(0.6\)。集合变为 \(0.6, 0.4\)。

第三步：\(0.4\) 与 \(0.6\) 合并，得根节点 \(1.0\)。

从根向下标注边：一种可能的标注给出

\[
A \mapsto 0,\quad B \mapsto 10,\quad C \mapsto 110,\quad D \mapsto 111.
\]

平均码长：

\[
L = 0.4 \cdot 1 + 0.3 \cdot 2 + 0.2 \cdot 3 + 0.1 \cdot 3 = 1.9 \text{ bit}.
\]

这个分布的熵：

\[
H(X) = -0.4\log_2 0.4 - 0.3\log_2 0.3 - 0.2\log_2 0.2 - 0.1\log_2 0.1 \approx 1.846 \text{ bit}.
\]

差约 \(0.054\) bit。注意到合并中途出现了两个权重相同的 \(0.3\)——并列时取哪个合并会产生不同的树拓扑，从而产生不同的码字组合（比如 \(A \mapsto 1, B \mapsto 00, C \mapsto 010, D \mapsto 011\)），但平均码长可能完全相同。Huffman 算法保证的是最优值，不保证最优解的码字唯一性。

\subsection{贪心为什么不是靠运气赌对的}

很多贪心策略在直觉上很合理，结果却是次优的。Huffman 需要一个严格的证明，而它的证明结构本身就有独立的教学价值。整个论证分两块，我们显式地展开它们。

\textbf{第一部分：交换论证（贪心选择性质）}

设 \(T\) 是任意一棵最优二元前缀树。设概率最低的两个符号为 \(a\) 和 \(b\)，概率分别为 \(p_a\) 和 \(p_b\)。设 \(T\) 中最深层（码长最大）的两个同胞叶分别为符号 \(x\) 和 \(y\)，码长记为 \(\ell_{\max}\)。

若 \(\{a, b\} \neq \{x, y\}\)，交换叶上的符号标签。具体地：把 \(a\) 换到 \(x\) 的位置、\(x\) 换到 \(a\) 的位置；对 \(b\) 和 \(y\) 做同样操作。交换后，\(a\) 和 \(b\) 的码长分别变为 \(\ell_{\max}\)，而 \(x\) 和 \(y\) 的码长分别变为原来的 \(\ell(a)\) 和 \(\ell(b)\)。

交换前后平均码长的变化为

\[
\begin{aligned}
\Delta L &= [p_a \ell_{\max} + p_b \ell_{\max} + p_x \ell(a) + p_y \ell(b)] - [p_a \ell(a) + p_b \ell(b) + p_x \ell_{\max} + p_y \ell_{\max}]\\
&= (p_a - p_x)(\ell_{\max} - \ell(a)) + (p_b - p_y)(\ell_{\max} - \ell(b)).
\end{aligned}
\]

因为 \(p_a \le p_x\)、\(p_b \le p_y\) 且 \(\ell_{\max} \ge \ell(a), \ell(b)\)，每一项都非正，所以 \(\Delta L \le 0\)。更换后平均码长不增加，新树仍是最优的，且最小概率的两个符号占据了最深层同胞位置。

\textbf{第二部分：最优子结构}

设合并 \(a\) 和 \(b\) 后产生的缩约问题的最优树为 \(T'\)，其平均码长为 \(L'\)。在 \(T'\) 中将复合符号节点拆成 \(a\) 和 \(b\) 两个子节点，得到原问题的一棵树 \(T\)。按前面推导的代价关系，

\[
L = L' + (p_a + p_b).
\]

如果原问题存在比 \(T\) 更优的树 \(T^*\)，且其平均码长为 \(L^* < L\)。由交换论证，\(T^*\) 可以调整为使 \(a\) 和 \(b\) 为最深同胞的最优树，合并这两个叶得到的缩约树平均码长为 \(L^* - (p_a + p_b) < L'\)，与 \(T'\) 是缩约问题的最优树矛盾。因此 \(T\) 是原问题的最优树。

\textbf{归纳}：对 \(m\) 个符号的集合，反复合并最小概率的两个符号。每次合并把规模缩减一，且保持最优子结构。基例 \(m = 2\) 时只有一种可能的满二元树——两个叶子各分配一个单 bit 码字，平均码长为 1 bit——显然最优。由归纳，Huffman 算法产生全局最优前缀码。

\subsection{熵界：Huffman 离理论下界还有多远}

任何唯一可译码的平均长度不低于熵：\(H(X) \le L\)。Huffman 作为前缀码中最优者，自然也满足这个下界。对于上界，Shannon 码的存在性保证可以做到 \(L < H(X) + 1\)；Huffman 不比 Shannon 差，因此

\[
H(X) \le L_{\mathrm{H}} < H(X) + 1.
\]

如果概率碰巧是 dyadic 的——每个概率都是 \(2^{-k}\) 的形式，例如

\[
(1/2,\; 1/4,\; 1/8,\; 1/8),
\]

理想长度 \((1, 2, 3, 3)\) 恰好都是整数，Huffman 能精确打到熵界：\(L = H(X) = 1.75\) bit。非 dyadic 概率则无法逐符号恰好达到熵——因为码长必须是整数，而 \(-\log_2 p(x)\) 通常不是整数。这是整数码长这个离散约束加在连续最优解上的舍入代价，不是 Huffman 算法的缺陷。

\subsection{即使最优，也可能看起来很浪费}

考虑 Bernoulli\((0.99)\) 信源。两个符号 A 和 B，\(p(A) = 0.99\)，\(p(B) = 0.01\)。二元前缀树上单符号编码只有两种可能：给 A 分配 0、B 分配 1，或者反过来。平均码长怎么都是 1 bit。但熵只有

\[
H = -0.99\log_2 0.99 - 0.01\log_2 0.01 \approx 0.081 \text{ bit}.
\]

整整浪费了十倍以上。Huffman 在自己的问题类别中已经做到最优了；差距来自编码类别的限制——逐符号编码强迫每次至少消耗一整 bit，即使这个符号几乎不携带不确定性。

打破这个限制的方向有两个。把多个符号组成一块（block coding）：100 个符号合成一个超级符号，常见序列共享整数码长，舍入误差被摊销到 100 个符号上——单符号平均码长可以逼近熵。或者干脆放弃为每一个块分配整数码长，改成对整个消息序列分配一个区间，让分数 bit 在长序列中平滑累积——算术编码走的就是这条路。下一节会接续展开算术编码的区间细分方法。

\subsection{\(D\) 元 Huffman：字母表更大的情形}

如果编码字母表有 \(D\) 个符号（例如三进制编码 \(D = 3\)），最优满 \(D\) 元树的叶子数必须满足

\[
m = (D - 1) k + 1
\]

对某个整数 \(k\)。这是因为每个内部节点恰好有 \(D\) 个孩子，每创建一个内部节点，叶子数增加 \(D - 1\)。根节点单独提供一个叶子，之后每新增一个内部节点净增 \(D - 1\) 片叶。

当原始符号数不满足此关系时，需要补充概率为零的虚拟符号，让总数达到最近的满足条件的数。算法流程和二元情形相同，只是每步合并最小的 \(D\) 个权重。虚拟符号不传输，但在树结构计算中占位。

\subsection{理论与真实压缩器的鸿沟}

即使算法层面最优，一个真实的压缩器还需要回答几个工程问题，它们都落在平均码长公式之外：

\begin{itemize}
\tightlist
\item
  \textbf{概率表传输}：解码器不知道概率分布时，码表本身也要编码传过去。小文件里，码表可能比被压缩内容还大。Canonical Huffman 码通过标准化码字生成规则——相同长度的码字按字母序升序赋值——只需传输每个符号的码长序列而非整棵树，大幅压缩了码表开销。
\item
  \textbf{经验分布不等于未来数据}：Huffman 针对编码时用的分布是最优的。如果未来数据的真实分布不同，平均码长就不是最优的了。自适应方案在编码过程中实时更新概率估计，代价是一旦出错编码和解码两端的模型就不再同步——一个 bit 的偏差可能导致后续全部比特不可恢复。
\item
  \textbf{并列权重的打破规则}：概率相同时，不同选择会产生不同的树，但只要编码和解码两端使用同一条规则（比如``权重相同时按字母序''），唯一可译性不受影响。
\item
  \textbf{单符号字母表}：只有一个符号要编码的场景——码字长度是否允许为零？信息论上，空码字字长为零，平均码长也为零。实现上，解码器需要知道``有东西发出来了还是没有''，需要带外信息。
\end{itemize}

这些边界不是对 Huffman 算法的否定，而是对所有理论最优结果的一种提醒：最优性是在一个精确声明的数学模型内部成立的。走出这个模型一步——哪怕只是一步——保证就消失。知道那条线的位置，你和理论之间的关系才是健康的。
