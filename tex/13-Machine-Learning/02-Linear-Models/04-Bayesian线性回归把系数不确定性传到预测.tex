\section{Bayesian 线性回归把系数不确定性传到预测}
\label{sec:13-Machine-Learning/02-Linear-Models/04}

你有一个线性模型 \(y = x^{\trans}\beta + \varepsilon\)，最小二乘给出了 \(\widehat\beta = (X^{\trans}X)^{-1}X^{\trans}y\)。一个新客户的 \(x_*\) 来了，你把 \(\widehat\beta\) 往里一代，得到点预测 \(x_*^{\trans}\widehat\beta\)，然后画上 ±2 标准误的置信区间。评审的人问：``这个区间是什么意思？''你迟疑了一下——这个区间是关于 \(\widehat\beta\) 在重复抽样下的分布，不是关于这一个客户的这一个 \(y_*\) 会在哪个范围。

\textbf{困境是}：系数本身不确定，但点估计掩盖了这份不确定；经典的重复抽样区间回答的又是估计程序的长期性质，不是当前这一笔预测的可信区间。我们需要一种方法，把系数的后验分布完整保留下来，并在预测时把这份不确定积分进去，让预测区间直接表达我们对这个 \(x_*\) 的 \(y_*\) 的相信程度。

\subsection{先搁下 \(\sigma^2\) 未知的现实，从最简单的 Gaussian 共轭开始}

先假定噪声方差已知，避免同时处理两层不确定性。模型为：

\[
y\mid\beta \sim \mathcal N(X\beta,\sigma^2I),
\qquad
\beta \sim \mathcal N(m_0,S_0),
\]

其中 \(S_0\) 正定，设计矩阵 \(X\) 视为给定。prior 均值 \(m_0\) 是你看到数据前对系数最合理的猜测，\(S_0\) 表达你对这个猜测的信心——对角元素大表示你不太确定该系数在哪儿。

截距如果包含在 \(\beta\) 中，要注意：截距项的 prior scale 通常应该比其他系数宽松，否则你相当于在收缩截距——这在数学上合法，但在背景知识上，截距通常是位置参数，没有理由把它也拉向零。

\subsection{Posterior 来自两个二次型相加}

log posterior 的计算，忽略与 \(\beta\) 无关的常数：

\[
\log p(\beta\mid y,X)
=
-\frac1{2\sigma^2}
\norm{y-X\beta}_2^2
-\frac12
\norm{\beta-m_0}_{S_0^{-1}}^2
+C,
\]

其中 \(\norm{u}_{M}^2=u^{\trans}Mu\)。第一项是数据的似然贡献——残差平方和，第二项是 prior 贡献——当前候选 \(\beta\) 偏离 prior 均值有多远。

两个二次型都是关于 \(\beta\) 的凸函数。展开并收集同类项：定义 posterior precision

\[
\Lambda_n = S_0^{-1} + \sigma^{-2}X^{\trans}X
\]

以及 information vector

\[
h_n = S_0^{-1}m_0 + \sigma^{-2}X^{\trans}y.
\]

完成平方后，posterior 同样是高斯：

\[
S_n = \Lambda_n^{-1},\qquad
m_n = S_nh_n,
\qquad
\beta\mid y,X \sim \mathcal N(m_n,S_n).
\]

这个结构的含义是：prior precision 和 data precision 直接相加。数据只在 \(X^{\trans}X\) 有信息的方向上增加精度；样本没有足够变异的方向上，posterior 仍然靠 prior 撑着。Prior 不是``可以忽略的初始条件''，而是决定那些数据沉默的方向上 posterior 会收缩到哪里的锚。

\subsection{MAP 链接到 Ridge，但 Ridge 只是冰山的尖}

posterior mode 等价于最小化

\[
\frac1{2\sigma^2}\norm{y-X\beta}_2^2
+\frac12\norm{\beta-m_0}_{S_0^{-1}}^2.
\]

若取 \(m_0=0\)、\(S_0=\tau^2I\)，乘以 \(2\sigma^2\) 后得到

\[
\norm{y-X\beta}_2^2 + \lambda\norm{\beta}_2^2,
\qquad \lambda=\frac{\sigma^2}{\tau^2}.
\]

所以 isotropic zero-mean Gaussian prior 的 MAP 恰好就是 Ridge 的解。这里有两个细节容易被忽略：

一是``零均值 isotropic prior 的 MAP = Ridge''这个等式只在 prior 参数化特定的情况下成立。如果你给不同系数不同的 prior 方差，或给截距不加惩罚，MAP 就不再等同于标准的 Ridge。

二是 MAP 只是一个点。完整 Bayesian 分析保留了 \(S_n\)——协方差矩阵刻画了系数之间的联合不确定性：哪些系数组合被数据精确定位了，哪些组合几乎不能分辨。接下来在预测时，我们要把这份协方差矩阵真的用上。

\subsection{Proper prior 让秩亏设计也能给出唯一后验}

当 \(p>n\) 或特征线性相关时，\(X^{\trans}X\) 秩亏，最小二乘有无穷多解。但加上一个 proper Gaussian prior 后，prior precision \(S_0^{-1}\) 填补了缺秩方向，使 posterior precision \(\Lambda_n\) 可逆。此时可以得到唯一的 posterior mean 和预测分布。

但有一条必须恪守的纪律：数值解存在，不代表数据已经识别了所有系数。某些方向上 posterior 的收缩几乎全部来自 prior 的贡献，数据并未提供额外的辨认信息。在这些方向上，后验事实上就是先验——你只是在用 prior 做插值，而不是在学习。正确解读 posterior 需要分清 prior 在哪些方向上是``活跃的''。

\subsection{Posterior predictive：把系数积分掉}

对新特征向量 \(x_*\)，模型规定

\[
Y_* = x_*^{\trans}\beta + \varepsilon_*,
\qquad \varepsilon_* \sim \mathcal N(0,\sigma^2).
\]

plug-in 预测只用 \(x_*^{\trans}m_n\) 加上噪声 \(\sigma^2\)，但这也只捕捉了噪声，没捕捉系数的不确定。完整的 posterior predictive 是把 \(\beta\) 对 posterior 积分：

\[
Y_*\mid x_*,X,y
\sim
\mathcal N\left(
x_*^{\trans}m_n,\;
\sigma^2 + x_*^{\trans}S_n x_*
\right).
\]

预测方差的分解有明确的语义：

\[
\underbrace{\sigma^2}_{\text{观测噪声}}
+
\underbrace{x_*^{\trans}S_n x_*}_{\text{参数不确定性}}.
\]

第一项是这个世界的固有噪声——即使你完全知道 \(\beta\)，新样本也是随机的。第二项是你的知识缺口——你不确定 \(\beta\) 到底在哪，而 \(x_*\) 的方向恰好放大或缩小了这份不确定。

随着同分布数据的增加，第二项通常会缩小（posterior 越来越集中），但第一项不会消失。你可以用更多样本降低你对系数的无知，却无法用更多样本消除测量本身的可变性。

对一组新设计矩阵 \(X_*\)，联合预测为

\[
y_*\mid X_*,X,y
\sim
\mathcal N\left(
X_*m_n,\;
\sigma^2I + X_* S_n X_*^{\trans}
\right).
\]

不同新预测之间因为共享同一个后验抽出的 \(\beta\) 而产生相关。如果你逐点报告区间，会丢失一个关键结构：多个预测可能因为系数的不确定而一起偏高或偏低，逐点边际区间看不到这种协同移动。

\subsection{不确定性的几何：不只看距离，更要看方向}

\(x_*^{\trans}S_n x_*\) 这个二次型揭示了一个重要的几何事实：不确定性的扩大不只取决于 \(x_*\) 离训练数据中心的欧氏距离，更取决于 \(x_*\) 指向哪些特征方向。

若 \(x_*\) 主要沿训练数据充分覆盖的方向延伸，\(S_n\) 在那个方向上收缩得很小，预测不确定性不大。但若 \(x_*\) 含有训练设计几乎没激活的方向——例如一个此前从未出现的交互项——该项可以很大。``离训练数据远''是在 \(S_n\) 诱导的 Mahalanobis 度量下衡量的，不是原始坐标的几何距离。

这一观察对特征处理的启示是：prior scale 必须与特征尺度一起被记录。特征标准化后，isotropic prior 确实对所有方向施加了相同的收缩；但如果特征未标准化，用同一个 \(\tau\) 对不同物理单位的变量施加的是完全不同的实际收缩力。改变单位不应该悄悄改变科学推断，因此 prior 的设计必须跟随特征变换一起版本管理。

多项式外推时还有另一重危险：posterior 区间可能会变宽以示警告，但这个区间仍然建立在``线性均值形式正确''的前提之上。如果真实关系有弯曲，再宽的区间也未必覆盖真实值。Bayesian 不确定性是给定模型之后的\textbf{条件不确定性}，不自动包含模型选择错误带来的那层无知。

\subsection{未知噪声方差：从正态走到 Student-t}

现实中 \(\sigma^2\) 几乎肯定未知。如果用一个与 \(\sigma^2\) 匹配的 normal--inverse-gamma prior——也就是给 \(\sigma^2\) 一个 inverse-gamma 分布，并在给定 \(\sigma^2\) 时 \(\beta\) 仍是正态——那么你可以同时更新系数与噪声方差。积分掉两者后，posterior predictive 变成 multivariate Student-t：尾部更厚，反映的是``我们连噪声水平都不确定''这个额外的不确定性来源。

与把 \(\sigma^2\) 固定为某个点估计（比如残差 MSE）相比，Student-t 分布用更重的尾部告诉你：有限样本下，你对极端预测的防备还不够。如果只给 \(\sigma^2\) 一个极弱的 improper prior，需要检查联合 posterior 是否 proper——样本数不足或设计秩亏时，积分可能发散。无信息先验也不是按下删除键就能消除假设。

\subsection{数值实现：永远不显式求逆}

公式写 \(S_n = \Lambda_n^{-1}\) 是为了沟通概念。计算时，解线性系统

\[
\Lambda_n m_n = h_n
\]

得到 posterior mean，用 Cholesky 分解 \(\Lambda_n\) 来采样或计算 log determinant。当特征数 \(p\) 远大于样本数 \(n\)，可以用 Woodbury identity 把主要运算转换到 \(n\times n\) 空间：

\[
(\sigma^{-2}X^{\trans}X + S_0^{-1})^{-1}
= S_0 - S_0 X^{\trans}(\sigma^2 I + X S_0 X^{\trans})^{-1} X S_0.
\]

选 primal 还是 dual 形式，应由维度和条件数共同决定。

画完公式还不够。从 posterior 的窄宽判断模型质量就像只看误差条长短不问条是否盖住了真相。应该做 posterior predictive checks：生成数据和真实数据的残差分布一致吗？尾部合理吗？改变 prior scale 后结论是否剧烈翻转？在独立数据上核对预测区间的 coverage——如果区间系统性地漏掉某一类样本，增加 MCMC 迭代数或换更高精度的浮点运算都不能修复错误的 likelihood 假设。

Bayesian 线性回归把前面三条线合成一条：最小二乘提供线性几何，Ridge 提供向零的收缩，Gaussian 共轭提供了完整的后验分布——而这份后验不只是用来画 error bar 的装饰，它直接决定了预测时你对新样本的认知程度。
