\section{从二分类到 Softmax 分类}
\label{sec:13-Machine-Learning/02-Linear-Models/03}

\subsection{预测值跑到 1.5，问题不在截断}

订阅业务要预测客户下个季度会不会续费，标签 \(y\) 取 0 和 1，特征是年龄、使用时长、投诉次数。手边最顺手的工具是线性回归，跑完系数方向都对：投诉多的分低，用得久的分高。翻预测值时出现一批小于 0 的数和一批大于 1.5 的数。

把输出硬夹回 \([0,1]\) 能让报表好看，麻烦并没有走。夹住的那批样本，模型仍然认为它们比``必然续费''还要更必然，这个信息在损失里没有任何代价。而且残差的散布在两端天然不对称——\(y\) 只能取 0 和 1，靠近 0 的地方残差只能往上偏，靠近 1 的地方只能往下偏，上一节赖以成立的同方差假设从一开始就不成立。

得从头回答两件事：这份数据是怎么生成的，以及什么样的损失与这个生成过程一致。

\subsection{线性结构该放在对数几率上}

设 \(Y\in\set{0,1}\)，\(p(x)=P(Y=1\given x)\)。概率被关在 \((0,1)\) 里，\(x^{\trans}\beta\) 却跑遍实轴，两者不能直接相等。中间需要一次换算。

先看几率 \(p/(1-p)\)：\(p\) 从 0 走到 1，几率从 0 走到 \(+\infty\)，还是只占半条轴。再取对数，\(\log\bigl(p/(1-p)\bigr)\) 就铺满了整条实轴。把线性结构安在这里：
\[
\log\frac{p(x)}{1-p(x)}=x^{\trans}\beta
\qquad\Longleftrightarrow\qquad
p(x)=\sigma(x^{\trans}\beta)=\frac{1}{1+\exp(-x^{\trans}\beta)} .
\]

系数的读法随之被钉死：\(\beta_j\) 是对数几率的变化量，不是概率的变化量。投诉次数的系数是 \(-0.5\)，说的是每多一次投诉，续费的几率乘以 \(\exp(-0.5)\approx 0.61\)，与这位客户原本的续费概率是 0.5 还是 0.95 无关。乘在几率上的倍数是常数，落到概率上的差值不是。

\subsection{损失是 Bernoulli 似然的负对数，不是随手挑的}

生成假设已经写死为 \(Y\given x\sim\Bernoulli(p(x))\)，损失就没有挑选余地。\(n\) 个独立样本的似然取负对数，得到
\[
L(\beta)=-\sum_{i=1}^{n}\bigl[y_i\log p_i+(1-y_i)\log(1-p_i)\bigr],
\qquad p_i=\sigma(x_i^{\trans}\beta).
\]
这就是二元交叉熵。为什么平方损失配 Gaussian、对数损失配 Bernoulli，背后是同一条对应关系，见\hyperref[sec:13-Machine-Learning/01-Learning-Problems-and-Evaluation/03]{``目标函数与噪声模型的对应：从生成机制到优化目标''}。

它的导数形状很干净：
\[
\nabla L(\beta)=X^{\trans}(p-y),\qquad
\nabla^2L(\beta)=X^{\trans}WX,\quad W=\diag\bigl(p_i(1-p_i)\bigr).
\]
梯度长得和线性回归一模一样，只是拟合值换成了概率。Hessian 半正定的骨架是一行：任取 \(v\)，\(v^{\trans}X^{\trans}WXv=\sum_i w_i(x_i^{\trans}v)^2\ge 0\)，因为 \(w_i=p_i(1-p_i)>0\)。条件对账：这里用到的只是 \(w_i\ge 0\)，与 \(X\) 的秩无关，所以凸性总成立；要严格凸还需 \(X\) 列满秩，否则沿零空间方向目标是平的。

凸性买到的是``没有非全局的局部极小''，它没买到``最优点存在''。下一小节就是这个缺口。

\subsection{可分数据让最大似然跑向无穷}

设想训练集能被一张超平面完全分开，正类全在一侧、负类全在另一侧，训练准确率 \(100\%\)。直觉上这是最省事的一种数据。对 logistic 回归而言它是最麻烦的一种。

取那个分离方向 \(\beta^{\star}\)，把参数放大成 \(t\beta^{\star}\)。每个样本的间隔 \(y_ix_i^{\trans}\beta^{\star}\) 都严格为正，乘上 \(t\) 之后 \(p_i\) 单调趋近正确标签，负对数似然沿着 \(t\to\infty\) 单调下降到 0，永不取到。有限的最大似然估计不存在。求解器给出的结果只反映它在什么时候被迭代次数或收敛容差叫停，\(\norm{\widehat\beta}\) 会随着容差收紧一路涨上去，报出来的标准误也跟着失去意义。

分类边界完美，概率估计反而无法确定——这是本节最值得记住的一处反直觉。分离在 \(p\) 接近或超过 \(n\) 时几乎必然发生，高维数据里它不是罕见情况。

补一项 Ridge 惩罚就够了。目标变成 \(L(\beta)+\tfrac{\lambda}{2}\norm{\beta}_2^2\)，第二项在 \(\norm{\beta}\to\infty\) 时以二次速度增长，而 \(L\) 有下界 0，于是整个目标强制矫顽，水平集有界，最小点存在且唯一（\(\lambda>0\) 使目标严格凸）。惩罚力在参数增大时把它拉回来，与似然想把它推出去的力在某处平衡。这一次正则化不是在防过拟合，是在把一个原本没有定义的估计问题补成有定义的；上一节那两笔账里，这属于数值那一笔的极端版本。相应的优化性质见\hyperref[sec:09-Convex-Optimization/07-Applications/01]{``光滑经验风险与 \(L_2\) 正则化''}，把``最大间隔''单独拿出来当目标则通向\hyperref[sec:09-Convex-Optimization/07-Applications/03]{``最大间隔与支持向量机''}。

求解上，Hessian \(X^{\trans}WX\) 的结构让 Newton 法退化成迭代重加权最小二乘：每一步解一个以 \(W\) 为权的加权最小二乘问题（见\hyperref[sec:09-Convex-Optimization/06-Optimization-Algorithms/02]{``Newton 法用曲率校正方向''}）。当某些 \(p_i\) 逼近 0 或 1 时 \(w_i\to 0\)，加权矩阵接近奇异，这在数值上正是分离逼近的信号。

数值实现还有一处必须小心。先算出 \(p_i\) 再取 \(\log p_i\)，\(p_i\) 下溢成 0 时直接得到 \(-\infty\)。稳定写法是绕过概率、直接算 \(\log(1+\exp z)=\max(z,0)+\log\bigl(1+\exp(-\abs{z})\bigr)\)，两个分支的指数自变量都非正。同类技巧见\hyperref[sec:08-Numerical-Analysis/07-Numerical-Methods-for-ML/01]{``在对数域中稳定计算概率''}。

\subsection{多类要的是相对分数}

类别数 \(K>2\) 时，给每一类各挂一个 sigmoid 会得到 \(K\) 个互不相干的概率，加起来不等于 1，也没有用上``只能选一个''这条约束。改成给每类一个分数 \(z_k=w_k^{\trans}x\)，再一起归一化：
\[
p_k=\frac{\exp z_k}{\sum_{j=1}^{K}\exp z_j},
\qquad
\log p_k=z_k-\log\sum_{j=1}^{K}\exp z_j .
\]
对 one-hot 标签，单样本交叉熵 \(\ell=-\sum_k y_k\log p_k\)，梯度仍然是 \(\nabla_z\ell=p-y\)。第一项奖励正确类的分数，第二项的对数配分函数求导恰好还给 softmax 概率，两者相减就是那个差。二分类是 \(K=2\) 的特例。

softmax 只看分数之差。所有 \(z_k\) 同加常数 \(c\)，分子分母各乘 \(e^{c}\)，概率不变。参数空间因此多出一个平移方向，沿它移动不改变任何预测——这是一种可识别性缺失，与上一节共线的情形同源，处理办法也类似：固定一个参考类的 logit 为零，或者靠正则化挑出代表解。同一个不变性反过来给了数值上的便利，取 \(m=\max_k z_k\)，
\[
\log\sum_k\exp z_k=m+\log\sum_k\exp(z_k-m),
\]
指数的自变量全部非正。logits 是 \((1000,1001,999)\) 时直接求幂会溢出，减去最大值后变成 \((-1,0,-2)\)，概率一模一样。这一步在实现里没有省略的余地。

要不要用 softmax，判据是类别之间是否互斥，与类别多少无关。一张照片可以同时是室内、有人物、夜景，这些标签不该在同一个分母上竞争，各自一个独立的 sigmoid 才对应正确的生成假设。模型的输出结构应当照抄任务的结构。

\subsection{概率输出和决策是两件事}

模型说 \(P(Y=1\given x)=0.3\)，不等于该判成 0。漏判一个流失客户的代价若是误判的九倍，期望代价在 \(p\) 低到 0.1 时就该触发挽留动作。阈值由行动代价、处理容量和基准率共同决定，0.5 只是 sigmoid 的几何中点，在决策上没有任何特权。

评估也要分层，四类指标回答的不是同一个问题。对数损失衡量整套概率的质量，既罚判错也罚过度自信。校准问的是被预测为 0.7 的那批样本里是不是真有七成为正。ROC 与 PR 曲线描述的是排序能力，与阈值取在哪里无关。准确率只评价某一个阈值下的硬决策，类别严重不平衡时全判多数类也能刷得很高。把其中一个当成另一个的代理，是分类项目里最常见的误报来源（更细的区分见\hyperref[sec:13-Machine-Learning/01-Learning-Problems-and-Evaluation/02]{``损失、风险、目标与指标不是同一个量''}）。

有一处陷阱值得单独点出。训练时为了平衡数据而过采样正类，等于人为改动了先验，排序能力可能不受影响，输出的概率却已经偏离部署环境的真实水平，必须按采样比例做回调才能当概率用。基准率随时间漂移时，历史验证集上算出的校准曲线也不再代表当下。

下一节把不确定性从点估计推进一步。这里的系数只有一个数值和一个标准误，而当先验被显式写出来时，参数的整个后验分布都能被算出来，并且能一路传到预测上。
