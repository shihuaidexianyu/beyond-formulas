\section{训练误差为何总是乐观}
\label{sec:13-Machine-Learning/10-Learning-Theory/01}

几乎每个上手训练过模型的人都亲眼见过这条曲线：训练误差一路降到趋近于零，验证误差却在中途掉头向上，然后居高不下。过拟合常被当作``调参没调好''的工程问题——加正则化、早停、少几层网络、多几万样本——似乎总有办法压下去。但这些手段之所以需要存在，根源是数学的：训练误差对真风险系统性地乐观。

本节把这份乐观拆成可以逐项计算的组成部分。一条关键的分界线贯穿始终：固定假设的评估是干净的，而看过数据后再选出的假设，评估已经被同一批数据的随机性污染了。这不是样本量的问题——再多样本，只要选择和评估共享数据，乐观就会渗入。

\subsection{两个风险，名字相似，指的不是同一个东西}

设样本对 \((X, Y)\) 服从 \(\mathcal{X} \times \mathcal{Y}\) 上的分布 \(P\)，训练集

\[
S = \bigl((X_1, Y_1), \dots, (X_n, Y_n)\bigr)
\]

是 \(n\) 个独立同分布的观测。一个假设 \(h: \mathcal{X} \to \mathcal{Y}\) 配合损失 \(\ell(h(X), Y)\)。部署时你真正关心的是真风险：

\[
R(h) = \E\bigl[\ell(h(X), Y)\bigr],
\]

期望是对一个来自同一分布但从未见过的新样本取的。你能算的只有经验风险——训练集上的平均损失：

\[
\widehat R(h) = \frac{1}{n} \sum_{i=1}^{n} \ell(h(X_i), Y_i).
\]

在 0-1 损失 \(\ell = \ind\{h(X) \ne Y\}\) 下，\(R(h) = P(h(X) \ne Y)\) 是真实的错误概率，\(\widehat R(h)\) 是训练集上的错误比例。本节以 0-1 损失为例；结论的形式对任意取值有界的损失普遍成立。

泛化误差（generalization gap）指的是差值 \(R(h) - \widehat R(h)\)。学习的最终目标是让 \(R\) 小；\(\widehat R\) 只是 \(R\) 的一个代理。代理可以很小而目标依然很大——两者之间的距离就是本单元要研究和控制的对象。

\subsection{固定假设：一个干净的参照点}

先考虑最简单的情形：假设 \(h\) 在你看到任何训练数据之前就已经选定。比如你翻开一本教科书，抄了一个固定的分类规则。这时 \(\ell(h(X_i), Y_i)\) 是 \(n\) 个独立同分布的随机变量，取值在 \([0,1]\)，每个的期望恰好是 \(R(h)\)。于是 \(\widehat R(h)\) 是 \(R(h)\) 的无偏估计——多次重复这个``抽取 n 个样本、计算训练误差''的实验，平均结果就是真风险。

\hyperref[sec:05-Probability/07-Transforms-and-Bounds/04]{``Chernoff 方法与 Hoeffding 集中界''}中的 Hoeffding 不等式直接给出了这些独立有界随机变量的均值偏离其期望的概率上限：

\[
P\bigl(|\widehat R(h) - R(h)| \ge \varepsilon\bigr)
\le 2e^{-2n\varepsilon^2},
\]

等价地，以至少 \(1 - \delta\) 的概率：

\[
|\widehat R(h) - R(h)|
\le \sqrt{\frac{\log(2/\delta)}{2n}}.
\]

把具体数字代进去感受一下这个界的力度。取 \(n = 10^4\)，\(\delta = 0.05\)，界宽大约是 \(0.014\)。也就是说：你有一个固定的分类器，你在一万个独立样本上测试它，测试错误率和真实错误率的差距以至少 95\% 的概率不超过大约 1.4 个百分点。分布无关、有限样本、指数级收紧。这就是为什么``拿一个留出的测试集评估模型''是可信的——所有可信性的数学根基就是这几行。

这个证明有两个不可让渡的前提。第一，\(h\) 不能以任何方式依赖这批评估样本。第二，评估样本与将来部署时遇到的样本必须来自同一个分布。前者是本节的剩余主题；后者意味着一旦分布发生漂移，\(R(h)\) 的定义本身就被替换了，任何数学界都无从谈起。

\subsection{看过数据再选假设：同一批数据被用了两次}

实际训练流程几乎从来不是``先选假设，再看数据''。经验风险最小化（ERM）返回的是：

\[
\widehat h \in \argmin_{h \in \mathcal{H}} \widehat R(h).
\]

你最后报告的数字是 \(\widehat R(\widehat h)\)——在训练集上表现最好的那个假设的训练误差。它和上一节的 \(\widehat R(h)\) 只差一个帽子，统计性质却已经彻底不同。

区别在哪里？同一批数据先被用来从 \(\mathcal{H}\) 中挑选 \(\widehat h\)，又被用来评估 \(\widehat h\)。Hoeffding 不等式最核心的前提——``假设与评估样本独立''——被训练流程自己破坏了。第 \(i\) 个样本 \((X_i, Y_i)\) 同时扮演了两个角色：它参与决定了哪个假设胜出，又参与了对胜出假设的打分。这两次使用共享了同一份随机波动。

偏差的方向是可以确定的。对任意固定的 \(h \in \mathcal{H}\)，ERM 的输出 \(\widehat h\) 必然不比 \(h\) 差——毕竟 \(\widehat h\) 就是被挑出来在训练集上表现最好的那个：

\[
\widehat R(\widehat h) \le \widehat R(h) \quad \text{对每个 } h \in \mathcal{H}.
\]

两边取期望，利用固定 \(h\) 时 \(\widehat R(h)\) 的无偏性：

\[
\E\bigl[\widehat R(\widehat h)\bigr]
\le \E\bigl[\widehat R(h)\bigr] = R(h).
\]

这个不等式对 \(\mathcal{H}\) 中的每一个 \(h\) 都成立，自然也对最优的那个 \(h^* \in \argmin_{h \in \mathcal{H}} R(h)\) 成立：

\[
\E\bigl[\widehat R(\widehat h)\bigr]
\le R(h^*).
\]

而 \(R(\widehat h) \ge R(h^*)\) 恒成立——\(\widehat h\) 的真风险不可能低于类内最优真风险。于是得到一组不等式链：

\[
\E\bigl[\widehat R(\widehat h)\bigr]
\le R(h^*)
\le \E\bigl[R(\widehat h)\bigr].
\]

训练误差的期望不超过类内最优真风险，而 \(\widehat h\) 的真风险的期望不低于类内最优真风险。因此 \(\widehat R(\widehat h)\) 系统性地小于 \(R(\widehat h)\) 的期望——它不能作为 \(R(\widehat h)\) 的无偏估计。这份向下偏差的方向不是偶然的，也不是特定数据集的巧合：ERM 必然挑选在训练集上表现最好的假设，而``训练集上表现最好''本身就部分来自那批特定样本的友好噪声。

选择空间 \(\mathcal{H}\) 越大，能挑出的``幸运者''就越幸运，这份向下偏差就越大。这不是模型复杂度的错——即使 \(\mathcal{H}\) 里全是垃圾假设，只要足够多，其中总会有一个偶然在这批样本上显得很好。

\subsection{一个可以用硬币重现的选择效应}

抛开所有机器学习的术语，选择偏差的核心可以用硬币干净地演示。

准备 \(m\) 枚均匀硬币，每一枚代表一个候选假设。每枚硬币抛 \(n\) 次，正面比例记录为该``假设''的``训练表现''。从 \(m\) 枚中选出正面比例最低的那一枚，报告它的比例。单枚硬币的比例以半径 \(\sqrt{\log(2/\delta)/(2n)}\) 集中在 \(1/2\) 附近——这是 Hoeffding 对固定硬币的保证。

但 \(m\) 枚中最极端的一枚，其期望偏离约 \(\sqrt{\log m/(2n)}\)。注意因子从 \(\log(1/\delta)\) 变成了 \(\log m\)——换了被惩罚的对象。代入 \(m = 10^6\)，\(n = 100\)：被选中的硬币正面比例大约 \(0.5 - 0.26 \approx 0.24\)。一枚完全均匀的硬币，仅仅因为它是从一百万个候选里挑出来的最优者，就呈现出了强烈的偏币外观。

硬币没有毛病。候选数量制造了选择空间，选择空间消耗了随机性预算。同一现象在统计推断中早已有过精确的表述：\hyperref[sec:11-Mathematical-Statistics/05-Hypothesis-Testing/04]{``多重比较改变错误的计量单位''}——做一百次独立的显著性检验几乎必然出现假阳性，正如从一百万个候选模型中几乎必然出现虚高的训练表现。两条故事线是同一笔账：每多一次``看过数据再做决定''，随机性的同一份预算就被多花了一次。

工程实践将同一逻辑翻译成一条铁律：测试集只能用一次。调超参数、选特征、选模型结构——所有这些``看过数据做决定''的操作都要经过验证集或重抽样（\hyperref[sec:11-Mathematical-Statistics/06-Resampling-and-Model-Selection/03]{``交叉验证评估的是完整训练流程''}）。每当你让评估数据参与了一次决定，那批数据就部分地变成了训练数据——它不再能提供无偏的评估，\(\widehat R(\widehat h)\) 式的乐观随之渗入。

\subsection{Hoeffding 的链条从哪里断裂}

回到 Hoeffding 不等式的证明，第一步是``\(\ell(h(X_i), Y_i)\) 独立同分布，均值为 \(R(h)\)''。当 \(h = \widehat h\) 由样本决定时，第 \(i\) 个样本同时出现在``选出 \(\widehat h\)''和``评估 \(\widehat h\)''两个角色中，各项不再独立于 \(\widehat h\)，条件均值也不再是 \(R(\widehat h)\)——链条在第一环就断了。后面的 Markov、Chernoff、指数衰减——全部建立在这第一环之上，第一环一断，整条推理链失效。

修复只有两条路径，各对应一种拆分``选择''和``评估''的方式。

第一条路：物理拆分。把数据分成两份，一份专门用于选择假设（训练集或验证集），另一份专门用于评估选出的假设（测试集）。评估时，选出的假设对于测试集而言是固定的——Hoeffding 的前提恢复了。这是留出法和交叉验证的逻辑，代价是选择阶段可用的样本变少了。

第二条路：逻辑绑定。继续使用同一批数据做选择，但把 Hoeffding 式的界加强为同时对 \(\mathcal{H}\) 中所有 \(h\) 成立，即要求

\[
\sup_{h \in \mathcal{H}} |\widehat R(h) - R(h)|
\]

以高概率小。这样一来，无论 ERM 从中选中了谁，选中者的泛化误差都已受控。这条路线叫一致收敛（uniform convergence），所需的样本量取决于 \(\mathcal{H}\) 的``复杂度''（VC 维、Rademacher 复杂度等），而不是被选中假设的复杂度。这是下一节的主题。

两条路的选择取决于你手上有什么。测试集充足且分布稳定时，物理拆分的界紧、假设弱、实现简单。测试集稀缺或需要多次模型选择时，一致收敛的界给出了理论上的安全边际，但界常数通常较松，工程中更常见的做法仍是重抽样验证。

从这里开始，泛化理论的所有后续发展——Margin 界、PAC-Bayes、稳定性与泛化的联系、双重下降——都是对这条基本故事线的精细化和扩展。但故事的核心不会变：训练误差乐观的根源首先不是``模型太复杂''，而是``同一批数据被用来选择又被用来评估''。第一个事实是选择效应，第二个才是过参数化。把顺序颠倒了，就会在错误的环节寻找解药。
