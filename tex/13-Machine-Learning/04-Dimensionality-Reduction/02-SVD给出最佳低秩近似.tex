\section{SVD 给出最佳低秩近似}
\label{sec:13-Machine-Learning/04-Dimensionality-Reduction/02}

上一节的 PCA 从样本方差出发——找到数据散得最开的方向。SVD 面对的是一个不同的问题：给你一个矩阵 \(A\)，它不是数据表，也不是协方差阵，而是一个线性映射。你能否用一个秩更低的矩阵保存它最重要的``作用''？这是数据压缩问题，也是理解线性映射的结构问题。

\subsection{一个矩阵，它到底在干什么}

考虑一个具体的 \(A\in\R^{m\times n}\)。把它乘到一个输入向量 \(x\) 上：\(y = Ax\)。\(A\) 做的事情可以拆成三步：先把 \(x\) 旋转到一组正交的方向上，然后沿每个方向伸缩（有的方向可能被压到零），最后把结果再旋转到输出空间。这就是 SVD：

\[
A = U\Sigma V^{\trans}
= \sum_{j=1}^{r} \sigma_j u_j v_j^{\trans},
\]

其中 \(r = \rank(A)\)，\(\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r > 0\) 是奇异值，\(u_j, v_j\) 分别是 \(U, V\) 的列向量。每一对 \((u_j, v_j)\) 定义了一个``作用通道''：\(v_j\) 是输入侧的方向，\(u_j\) 是输出侧的方向，\(\sigma_j\) 是这条通道的放大倍数。

越大的奇异值意味着矩阵沿那个方向施加的作用越强。换句话说，如果 \(\sigma_1 \gg \sigma_2\)，那么对绝大多数输入向量，\(A\) 的行为几乎就是先把输入投影到 \(v_1\) 方向，放大 \(\sigma_1\) 倍，再映射到 \(u_1\) 方向。其他方向的作用相比之下微弱得多。

\subsection{截断：扔掉弱方向会损失多少}

既然弱方向的作用可以忽略，直接扔掉它们。只保留前 \(k\) 项：

\[
A_k = \sum_{j=1}^{k} \sigma_j u_j v_j^{\trans}.
\]

\(A_k\) 的秩不超过 \(k\)。问题是：在所有秩不超过 \(k\) 的矩阵中，\(A_k\) 是最好的近似吗？``最好''又要如何度量？

Eckart--Young--Mirsky 定理给了干净的回答。在谱范数（\(\|\cdot\|_2\)）和 Frobenius 范数（\(\|\cdot\|_F\)）下，截断 SVD 同时达到最小误差：

\[
\min_{\rank(B)\le k} \|A - B\|_2 = \sigma_{k+1},
\]

\[
\min_{\rank(B)\le k} \|A - B\|_F
= \Bigl(\sum_{j>k} \sigma_j^2\Bigr)^{1/2}.
\]

两个范数对应的最优近似恰好是同一个矩阵 \(A_k\)。这个事实不是显然的——两种范数量度的东西不同，最优解却重合了。

为什么截断是最优的？秩不超过 \(k\) 的矩阵最多完整保存 \(k\) 个独立的作用方向。因此必然有至少一个强度不低于 \(\sigma_{k+1}\) 的方向被遗漏。截断 SVD 的策略是：既然只能保留 \(k\) 个方向，就保留最强的 \(k\) 个。这个策略恰好用尽了秩预算，达到了不可突破的下界。

\subsection{用图像试一下：哪些信息先回来}

把一张灰度图像看作矩阵 \(A\)，对其做 SVD 后只用前 \(k\) 个外积重建。\(k=1\) 时，重建结果是整张图沿着一个方向的均匀渐变——只有最主导的明暗趋势。\(k=5\) 时，背景的大块明暗和大尺度边缘开始浮现。\(k=20\) 时，主要形状和纹理结构已清晰可辨。\(k=100\) 时，肉眼几乎看不出与原图的差别。

奇异值衰减的速度决定了压缩的效率。如果前几十个奇异值就捕获了绝大部分 Frobenius 范数，图像是``低秩友好''的；如果奇异值缓慢衰减，意味着图像有大量近乎独立的结构方向，压缩效果就会大打折扣。

但这里埋着一个容易误踩的陷阱：尾部不等于噪声。一张胸部 X 光片中，小结节可能只占据整张图像不到千分之一的像素，对应的奇异值在大尺度背景下微不足道。如果仅凭能量占比决定截断位置，那个结节就随尾部一起被丢弃了。对诊断任务而言，它是信号里的全部信息。Frobenius 范数保证的是``平方误差总和最小''，不保证``每个局部都准确''。

\subsection{谱隙决定子空间的稳定程度}

上一节在 scree plot 上寻找的那个``拐点''，在 SVD 中对应的是奇异值之间的间隙。如果 \(\sigma_k\) 与 \(\sigma_{k+1}\) 之间差距很大，前 \(k\) 个奇异向量张成的子空间对小的数据扰动相对稳定——稍有噪声，子空间不会大幅旋转。如果 \(\sigma_k \approx \sigma_{k+1}\)，那么轻微扰动就足以让这两个方向对应的奇异向量发生明显旋转。

重复的奇异值对应的单个奇异向量本来就不唯一——任何一组正交基张成的同一个子空间都是合法的分解。因此，当奇异值接近时，不要试图解释单个奇异向量的方向；它们张成的子空间才是具有稳定含义的对象。这是 SVD 解释中一条被频繁忽视但后果严重的纪律。

\subsection{不要绕道平方条件数}

理论上，\(A^{\trans}A\) 的特征分解可以给出 \(A\) 的右奇异向量（\(V\) 的列）和奇异值的平方。但这条``绕道''在数值上是危险的。显式形成 \(A^{\trans}A\) 把条件数平方了——如果 \(A\) 的条件数是 \(10^6\)，\(A^{\trans}A\) 的条件数就变成 \(10^{12}\)，双精度浮点的有效位数会被吞掉将近一半。小奇异值对应的方向尤其容易在平方过程中丢失精度。

成熟的 SVD 实现（LAPACK 的 DGESVD/GESDD 等）通过双对角化等策略直接操作 \(A\)，避免了显式形成 Gram 矩阵。除非你有特殊理由和充分的数值背景，始终使用现成的 SVD 实现，不要手工通过特征分解绕道。

\subsection{矩阵太大时：随机化 SVD 的权衡}

当矩阵很大而你只需要前少量奇异成分时，Lanczos 迭代、子空间迭代或随机化 SVD 是实际选择。随机化方法的核心想法简洁而有效：用一个较窄的随机矩阵 \(\Omega\) 右乘 \(A\)，得到 \(Y = A\Omega\)。\(Y\) 的列空间以高概率捕获了 \(A\) 的主要列空间。在 \(Y\) 的正交基上把 \(A\) 投影成一个小矩阵，再对这个小矩阵做精确 SVD，计算成本大幅下降。

速度快了，代价是结果带有近似误差和随机误差——不同的随机种子可能给出略有不同的奇异值和奇异向量。因此使用随机化方法时应：

\begin{itemize}
\tightlist
\item
  设置适当的 oversampling 参数（随机矩阵的列数比需要的 \(k\) 多 5 到 10 列）和必要的幂迭代次数，以压制尾部奇异值的影响；
\item
  检查 \(\|A - A_k\|\) 或随机残差估计，确认近似误差在可接受范围内；
\item
  改变随机种子观察子空间稳定性——如果前 \(k\) 个奇异向量随种子大幅变化，说明奇异值间隙太小，那块子空间本身就不稳定；
\item
  区分两类误差：算法的近似误差（随机化带来的，可控的）和模型的截断误差（舍弃 \(k\) 以后奇异值带来的，选择性的）。两者的来源和补救方式完全不同。
\end{itemize}

截断 SVD 的数学保证是确切的——在给定秩约束下，它就是最优。但``最优''的含义永远被范数的选择所限定。当你需要在 Frobenius 范数之外定义``好''——比如某个下游任务的准确率、某个关键特征的可见性、或者逼近的稀疏性——最优解可能转移到完全不同的矩阵上。数学工具给出了最优性的精确含义；选择哪个范数来定义``好''，是你作为建模者的判断。
