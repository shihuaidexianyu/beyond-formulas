\section{矩阵补全从缺失条目到低秩正则}
\label{sec:13-Machine-Learning/04-Dimensionality-Reduction/03}

你手上有一张用户-物品评分表。少数格子里有数字，大多空着。老板要你预测空着的那些评分。直觉告诉你：用户的口味类型有限，物品的属性类别也有限——所有用户都能用几十个潜在偏好向量概括，所有物品都能用同样的几十个属性向量描述。整张表应该近似低秩。只要能找到这个低秩结构，空白自然就补上了。

这个直觉对了一大半。但有一小半会让人摔得很疼。

先看一个最小的反例。只观察了 \(2\times2\) 矩阵的对角线：左上=1，右下=4。有多少个秩一矩阵能匹配这两个数字？

\[
\begin{pmatrix}1&2\\2&4\end{pmatrix}
\quad\text{和}\quad
\begin{pmatrix}1&1\\4&4\end{pmatrix}
\]

都是秩一，对角线一模一样，右上和左下完全不同。第一个矩阵的右上=2，第二个的右上=1。数据只告诉了你对角线上的条目，没有告诉你不在这条线上该是多少。低秩约束缩小了候选空间，却远没有压缩到唯一。

再看一个更极端的：某个用户一条评分都没有。无论其他行多完整、无论用了多精巧的低秩算法，都无法仅凭矩阵自身判断他喜欢什么。他的整行可以是任何值——只要跟其他行拼出一个低秩矩阵就行。缺失条目的位置和低秩结构的配合方式，直接决定了你能恢复什么、不能恢复什么。信息不在那个空行里，算法不能从不存在的信息中恢复出答案。

\subsection{从秩最小化到核范数}

理想形式很干净。令真实矩阵为 \(M\)，\(\Omega\) 是观测位置集合，\(P_\Omega\) 保留这些位置的条目、其余置零。我们想找跟观测一致的最低秩矩阵：

\[
\min_X\rank(X)
\quad\text{s.t.}\quad
P_\Omega(X)=P_\Omega(M).
\]

干净归干净。rank 是离散的、非凸的，直接优化通常属于 NP-hard。向量里用 L1 替代 L0 来促进稀疏；矩阵里用核范数替代秩来促进低秩：

\[
\|X\|_*=\sum_j\sigma_j(X),
\]

核范数是奇异值的 L1 范数。跟 Lasso 令回归系数倾向于零一样，这里鼓励奇异值变零——多一个零奇异值，秩就降一。替换后得到凸问题：

\[
\min_X\|X\|_*
\quad\text{s.t.}\quad
P_\Omega(X)=P_\Omega(M).
\]

实际数据总有噪声。记 \(Y\) 为观测到的带噪条目（仅在 \(\Omega\) 上有值），更常写为：

\[
\min_X
\frac12\|P_\Omega(X-Y)\|_F^2+\lambda\|X\|_*.
\]

这个形式跟 Lasso 的结构完全平行：第一项忠诚于观测，第二项把奇异值往零压。解它的关键一步是对奇异值作软阈值：先对矩阵 SVD，把每个 \(\sigma_j\) 替换为 \((\sigma_j-\tau)_+\)（\(\tau\) 是阈值，\((\cdot)_+\) 示取正部），再把三个因子乘回去。迭代软阈值算法就是在交替做"往梯度下降方向走半步"和"过一遍奇异值软阈值"。

另一条计算路线把矩阵显式写成 \(X=UV^{\trans}\)，用低秩因子直接建模：

\[
\frac12\|P_\Omega(UV^{\trans}-Y)\|_F^2
+\frac{\lambda}{2}
\left(\|U\|_F^2+\|V\|_F^2\right).
\]

因子化更适合大规模场景——不需要存整个 \(n\times m\) 矩阵，只存两个瘦因子。代价是目标对 \(U,V\) 不再凸、需要预先选择潜在秩，并且因子本身不唯一：对任意可逆矩阵 \(R\)，\(UR\) 与 \(VR^{-\top}\) 产生同一个乘积。优化找到的 \(U,V\) 只是乘积的一种表示，不具备独立的解释意义——你无法指着 \(U\) 的某一列说"这就是用户的消费能力"，因为旋转一下 \(U\) 和 \(V\) 后，那列的含义就变了。

\subsection{可恢复性需要结构与观测共同配合}

有了凸松弛不等于万事大吉。精确恢复定理同时要求几个条件：矩阵确实足够低秩；奇异向量不过度集中在少数坐标上，即具备 incoherence；观测足够多且在行列中分布较均匀；噪声受控。

为什么 coherence 这么关键？考虑一个秩一矩阵，它唯一的非零条目在左上角，其余全零。除非你恰好观察了那个左上角，低秩假设不能告诉你这个条目存在——你看到的全零数据跟全零矩阵完全一致，秩为零的解已经完美匹配观测。低秩描述矩阵有多少全局自由度；incoherence 保证信息没有藏在极少数条目里，必须分散到足够多的行列中。信息越集中，就越需要密集的采样才能捕获。

推荐数据的麻烦还不止 incoherence。更根本的问题是：缺失通常不是随机的。用户更可能给自己很喜欢或很不喜欢的内容打分；平台会优先展示算法认为用户会感兴趣的东西。"没评分"可能意味着"不感兴趣"或"没被展示"，而不是"随机漏了"。未观测本身携带信号。矩阵补全可以在某种缺失机制下预测未观测条目，但它不能仅凭低秩假设，把"选择性展示下的评分"翻译成"随机展示下的真实偏好"。

\subsection{验证方式必须模拟真正缺失的方式}

最常见的陷阱：把已观测评分随机拆成训练集和测试集。这样同一个用户和同一个物品在两边大量出现，测试只测量了"熟悉用户对熟悉物品"的插值能力。但部署时真正关心的是新用户、新物品或未来时间段——这种随机拆分测出的数字毫无意义，甚至严重误导。

应该按用户留出、按物品留出或按时间切分。冷启动用户一条训练评分都没有，只能依赖从其他用户学到的物品属性来推断；新物品需要依赖用户属性来推断。两种场景测试的是完全不同的泛化能力。

一次不欺骗自己的矩阵补全分析至少包括这些步骤：

\begin{enumerate}
\tightlist
\item
  先画观测 mask，检查整行、整列缺失和曝光偏差；
\item
  与全局均值、用户偏置和物品偏置等简单基线比较——如果复杂模型打不过"用户平均分+物品平均偏移"，说明低秩结构没学到有用的东西；
\item
  在符合部署情境的验证集上调节秩或 \(\lambda\) 并评估；
\item
  分层报告活跃用户、冷启动用户、热门物品和长尾物品各自的误差，而不是只报一个总体数字；
\item
  用合成低秩矩阵检验实现能否在已知条件下恢复，并改变 mask 观察对采样模式的敏感性。
\end{enumerate}

最诚实的结论有时是：某一行真的没有任何信息，当前矩阵无法识别它——需要侧信息（用户画像、物品特征）或主动收集数据。继续增加优化轮数、换更大的模型、调更细的 \(\lambda\)，不会从空行里变出信息来。

\subsubsection{反例构造}

给定一个 \(3\times3\) 矩阵，只观察了第一行。动手构造两个不同的秩一补全，让它们在观测位置完全一致、未观测位置却差异很大。然后逐步往各行各列增加分散的观测，观察哪些自由度被排除了、补全何时变得唯一。最后分别用随机按条目切分和按用户留出计算验证误差——前者回答"已知用户的已知偏好我能不能插值"，后者回答"新用户我能不能猜"。两个数字常差得很远，但它们回答的是不同的问题。
