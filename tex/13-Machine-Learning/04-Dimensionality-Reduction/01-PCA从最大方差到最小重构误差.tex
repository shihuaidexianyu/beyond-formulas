\section{PCA 从最大方差到最小重构误差}
\label{sec:13-Machine-Learning/04-Dimensionality-Reduction/01}

你在一家化工厂的数据中控室里。一条产线上装了 42 个传感器：温度、压力、流量、振动……每秒钟各采一个数。你想把这些时序画在屏幕上让人看懂——但 42 条线叠在一起，除了高峰时段几条一起往上窜，什么结构都读不出来。

你的第一想法是：挑几个代表性的传感器。哪个传感器波动大就留哪个。但仔细一想：振动传感器可能数值上动静很大，却主要是高频噪声；它和产品质量的相关性未必比得上一个读数沉稳的温度计。

\textbf{困境是}：``重要''必须被量化。对于无监督的数据探索，最自然的定义是——保留那些能让数据点之间互相分开的方向，也就是数据最分散的方向。但方差大的方向可能是结构，也可能是噪声；可能是你关心的维度，也可能只是一个强度单位造成的数量级碾压。

PCA 给出的答案有两面：从正面说，选择能承载最大样本方差的正交方向；从反面说，选择让正交投影重构误差最小的低维子空间。这两个目标在数学上等价，但分别捕捉了直觉的不同侧面。

\subsection{中心化不是一个可有可无的预处理步骤}

把 \(n\) 个样本按行排列成 \(X\in\R^{n\times p}\)，每一行一个样本，每一列一个变量。第一步永远是去均值：

\[
X_c = X - \mathbf 1\bar x^{\trans},
\]

其中 \(\mathbf 1\) 是全 1 列向量，\(\bar x\) 由各列的样本均值组成。

如果不做这一步，原点到数据中心的距离也会被计入``方差''。结果第一主成分可能只是指向均值所在的方向——它描述的是``数据整体在哪''，而不是``样本之间怎样变化''。PCA 的目标是分析围绕均值的结构，不中心化等于把中心放在别处。

接下来的尺度问题没有一刀切的答案。协方差 PCA 直接使用中心化后的原始数值：

\[
\frac1{n-1}X_c^{\trans}X_c.
\]

如果身高以米记，收入以元记，身高数值在 1.6-1.9 之间，收入数值可上万。协方差矩阵几乎完全被收入的方差统治，第一主成分不过是``收入方向''。标准化到单位方差——等价于对相关矩阵做 PCA——给了每个变量相近的发言权，但也同时放大了那些本来方差就很小的噪声变量。

没有通用的正确做法。变量单位相同且方差量级具有科学意义时，标准化的代价是稀释了真实的信号结构；变量量纲各异时，不标准化的代价是让大数压倒小数。尺度是一个建模决定，不是一个默认参数。

\subsection{从最大方差到特征向量：一个优化问题的诞生}

沿单位方向 \(v\) 的投影得分是 \(X_c v\)，其未归一化的样本方差为

\[
\|X_c v\|_2^2 = v^{\trans} X_c^{\trans} X_c v.
\]

第一主方向因此是下面的优化问题的解：

\[
\max_{\|v\|_2=1} v^{\trans} X_c^{\trans} X_c v.
\]

这是一个 Rayleigh 商问题：最优 \(v_1\) 是 \(X_c^{\trans}X_c\) 最大特征值对应的特征向量。后续方向在与前面所有方向正交的约束下依次最大化剩余方差——这正是实对称矩阵的谱分解性质。

更直接的做法是 SVD：

\[
X_c = U\Sigma V^{\trans},
\]

那么 \(V\) 的列就是主方向（loadings），\(X_c V = U\Sigma\) 是样本在新坐标下的得分（scores），第 \(j\) 个方向解释的方差为 \(\sigma_j^2/(n-1)\)。

为了建立直观，设想两个完全同步的中心化变量，它们的协方差与

\[
\begin{pmatrix}
1 & 1\\
1 & 1
\end{pmatrix}
\]

成比例。方向 \((1,1)^{\trans}/\sqrt2\) 承载了全部变化，方向 \((1,-1)^{\trans}/\sqrt2\) 上完全没有变化——两个维度的原始坐标实际上只对应一个自由度。如果第二个变量在同步之外多了少量独立噪声，第二奇异值不再为零，但仍远小于第一项。这个简例解释的是：奇异值的衰减速度告诉你数据到底活在哪个维度的子空间里。

\subsection{两个目标的等价：最大方差就是最小重构误差}

保留前 \(k\) 个方向组成 \(V_k\)，样本的低维表示为

\[
Z = X_c V_k.
\]

从该表示重构回原空间得到

\[
\widehat X_c = Z V_k^{\trans} = X_c V_k V_k^{\trans}.
\]

\(V_k V_k^{\trans}\) 是到主成分子空间的正交投影矩阵。总平方长度可以正交分解：

\[
\|X_c\|_F^2 = \|X_c V_k V_k^{\trans}\|_F^2 + \|X_c - X_c V_k V_k^{\trans}\|_F^2.
\]

总量固定，因此最大化保留方差和最小化平方重构误差完全等价。保留前 \(k\) 个奇异方向时，重构误差精确等于被丢弃的奇异值平方和：

\[
\sum_{j>k} \sigma_j^2.
\]

下一节的 Eckart--Young--Mirsky 定理将指出：在 Frobenius 范数意义下，没有秩不超过 \(k\) 的任何矩阵能比这个截断做得更好。PCA 是最优低秩逼近——在平方误差的意义上。

但这句话同时也画出了 PCA 的边界：它最优的是线性子空间下的平方重构。方差小的方向可能恰好决定疾病类别；方差大的方向可能只是光照变化或批次效应。无监督的方差最优不保证有监督的分类最优。

\subsection{从公式回到建模流程：PCA 不能在全数据上做}

如果 PCA 要参与预测 pipeline，均值、标准差和主方向都只能从训练折估计，然后原样应用到验证和测试数据。在全数据上先跑 PCA 再划分交叉验证折，验证样本的信息会污染主方向的估计，产生信息泄漏——你会在验证集上得到过于乐观的分数，因为主方向已经看过了这些样本的结构。

成分的数量 \(k\) 也不能被``累积解释方差达到 95\%''一条规则机械决定。需要同时审视：

\begin{itemize}
\tightlist
\item
  \textbf{scree plot}：奇异值序列是否有明显的阶梯式下降，天然形成一道谱隙；
\item
  \textbf{重构需求}：保留的成分能否满足压缩率或去噪质量的业务要求；
\item
  \textbf{下游性能}：分类或回归的验证指标是否在某个 \(k\) 之后停止改善；
\item
  \textbf{稳定性}：主子空间在不同的子抽样中是否保持基本一致，还是随着样本变动方向本身就在旋转；
\item
  \textbf{可解释性}：保留下来的 loading 向量能否结合变量的物理或业务语义理解。
\end{itemize}

单个 loading 向量的符号没有固有意义——\(v\) 和 \(-v\) 代表的是同一条轴。重复或非常接近的奇异值会使该子空间内的具体基随数据扰动旋转（下一节讨论谱隙时会回到这个问题），此时应该解释整个子空间，而不是执着于某一列 loading 的具体数值和方向。

离群点对主方向有不成比例的牵引力——因为平方距离会放大极端值的影响。非线性流形——比如数据实际分布在一个球面或一个瑞士卷上——也不可能被任何低维平面展开。PCA 的计算结果可以绝对正确，而问题完全在于：它优化的目标已经不符合你的任务需求。

\subsubsection{一个两类二维数据的构造}

为了把``方差最大不等于分类最优''这个点说透，可以自己构造一个例子：两类二维数据，共同变化的方向方差很大，区分两类的方向方差很小。第一主成分几乎与共同变化的方向重合；如果只保留这一个主成分做分类，两类的投影会严重重叠，效果远不如使用原始两维。

这个构造直接证明了：无监督重构的最优方向，不一定是监督预测的有用方向。PCA 保留大方差方向，有没有类别信息是另一回事。

同一组数据还能暴露一个预处理陷阱。如果你用全部数据做中心化再划分交叉验证折，均值里已混入了验证折的信息，验证分数会被轻微污染。在每一折内部重新中心化——也就是所有预处理完全嵌入交叉验证的循环内——才能得到不受污染的干净估计。
