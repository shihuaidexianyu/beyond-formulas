\section{交叉熵训练其实在最小化 KL 差异}
\label{sec:13-Machine-Learning/11-Information-Theoretic-Learning/01}

你训练一个语言模型，验证集上的平均损失从 4.61 掉到 3.09 之后就不再动了。换更大的骨干网络，多喂两倍的语料，把学习率退火重来一遍，只有第三位小数有反应。周会上有人说这是欠拟合，容量不够；也有人说这份数据已经榨干了，再投人力是浪费。两种诊断指向完全相反的下一步，而日志上那个 3.09 本身不会告诉你该信谁。

要分辨，先得把这个数字拆开，看它由哪几段拼成。

\subsection{损失里有一段与参数无关}

固定输入 \(x\)，把标签的真实条件分布记作 \(p(\cdot\given x)\)，模型输出的分布记作 \(q_\theta(\cdot\given x)\)。交叉熵

\[
H(p,q_\theta)=-\sum_y p(y\given x)\log q_\theta(y\given x)
\]

有一个操作含义：按 \(q_\theta\) 设计码本（概率高的标签配短码），却拿它去编码实际服从 \(p\) 的标签，平均每个标签要花掉多少比特。这个含义怎么来的、为什么码长与对数概率对得上，见 \hyperref[sec:07-Information-Theory/03-Divergences/01]{``错误模型的代价：从交叉熵到 KL 散度''}；本节只借结论，不重复推导。

在求和号里加一项减一项 \(p\log p\)，交叉熵就裂成两段：

\[
\begin{aligned}
H(p,q_\theta)
&=-\sum_y p(y\given x)\log p(y\given x)
 -\sum_y p(y\given x)\log\frac{q_\theta(y\given x)}{p(y\given x)}\\
&=H(p)+\KL(p\|q_\theta).
\end{aligned}
\]

这一步只用了对数的可加性，条件是 \(q_\theta\) 在 \(p\) 的支撑上处处为正；否则第二项取到 \(+\infty\)，等式在扩展实数意义下仍然成立，但已经不含信息。要紧的是第一项。\(H(p)\) 只由数据生成机制决定，与 \(\theta\) 无关，对参数求梯度时它整项消失。第二项非负且仅在 \(q_\theta=p\) 时归零，依据是 Gibbs 不等式；KL 的不对称性与方向选择见 \hyperref[sec:07-Information-Theory/03-Divergences/02]{``Gibbs 不等式与 KL 的方向性''}。

把两条并起来：训练过程把 \(\KL(p\|q_\theta)\) 往下压，交叉熵就往 \(H(p)\) 靠，而不会往零靠。一个把条件分布学得分毫不差的模型，它的损失等于数据自身的不确定性。

\emph{损失曲线趋向的水平渐近线是数据自身的熵，训练只在渐近线之上的那一段里工作。}

回到开头的 3.09。若这个任务上 \(H(p)\approx 3.0\) nat，模型已经走到离地板 0.09 nat 的位置，可争取的空间不到 \(3\%\)，再大的骨干也只能在这 0.09 里腾挪。若 \(H(p)\approx 1.5\) nat，则有一半的损失是模型自己造成的，扩容和调参都还有回报。同一个 3.09，两种结论，差别全在那条虚线画在哪。

\subsection{困惑度换了单位，地板跟着换过去}

语言建模常报困惑度而不是损失：

\[
\mathrm{PPL}=\exp\Big(-\frac1n\sum_{i=1}^n\log q_\theta(y_i\given x_i)\Big).
\]

指数是严格单调的，所以困惑度与交叉熵给出同样的模型排序，谁也不比谁多含信息。它换来的是可读性：\(\mathrm{PPL}=21.9\) 可以读成``模型平均把下一个词收窄到大约 22 个等可能的候选''。对 \(K\) 类均匀预测，损失为 \(\log K\)，困惑度恰是 \(K\)，这给了一条随手可用的基线——训练损失若高过 \(\log K\)，模型还不如掷骰子。

地板也跟着做同一个指数变换。\(H(p)\approx 3.0\) nat 对应的困惑度地板是 \(e^{3.0}\approx 20.1\)。于是 21.9 与 20.1 之间只剩 \(9\%\) 的相对空间，而从 4.61 一路降到 3.09 的过程在困惑度上是从 100 降到 21.9。指数会把接近地板的那一小段损失差放大成看起来还很可观的困惑度差，也会把远离地板时的巨大差距压缩得不显眼。看惯了哪个尺度，就要留意另一个尺度上的错觉。

对数的底同样只是单位。以 2 为底得到比特，以 \(e\) 为底得到 nat，全部损失乘同一个常数，\(\argmin\) 不变。但学习率、梯度裁剪阈值、早停容忍度这些经验数值是跟着尺度调出来的，换底之后要重新校准。

\subsection{一次只见一个标签，这个等式仍然成立}

训练数据不会递给你一个完整的 \(p(\cdot\given x_i)\)，只递给你一个具体的 \(y_i\)。把 one-hot 向量当作 target 分布，交叉熵就退化成

\[
-\sum_{k=1}^K\ind\{y_i=k\}\log q_\theta(k\given x_i)
=-\log q_\theta(y_i\given x_i),
\]

在全体样本上取平均，得到

\[
\mathcal L(\theta)=-\frac1n\sum_{i=1}^n\log q_\theta(y_i\given x_i).
\]

同一个表达式有三重身份：它是 categorical 模型的负对数似然，是期望交叉熵 \(\E_x[H(p,q_\theta)]\) 用经验分布替换 \(p\) 之后的估计，也是你写在训练脚本里的那个 \texttt{cross\_entropy}。最大似然与最小化 KL 在这里合流，不是巧合——把 \(p\) 换成经验分布之后，\(\argmin_\theta \KL(\hat p\|q_\theta)\) 与 \(\argmax_\theta\) 似然是同一个优化问题。

这里有一处层次容易混。单个 one-hot 向量的熵是零，于是很容易以为训练损失的下界是零。但上一小节那条虚线画的是 \(H(Y\given X)\)——总体条件分布的熵在输入上的平均，不是某个样本 target 的熵。同一张图片交给三个标注者可能拿回三个标签，这份分歧客观存在；训练集里只记录了其中一个，分歧被折叠进了采样噪声，却没有消失。经验分布让下界看起来是零，实际能达到的仍是 \(H(Y\given X)\)。

\subsection{地板高，未必是模型的错}

\(H(Y\given X)\) 里的条件是给定特征。这个量不是任务的常数，而是相对于你手上这组 \(X\) 的条件熵——换一组特征，地板会跟着动。这一点比公式本身更常被误读：人们习惯说``这个任务的贝叶斯错误率是多少''，仿佛它写在任务的出生证明上。

把条件熵翻译成错误率的硬下界，靠的是 Fano 不等式，推导与松紧程度的讨论见 \hyperref[sec:07-Information-Theory/06-Information-and-Learning/04]{``分类、神经网络与信息论边界''}。理论上的用法很干净：估出 \(H(Y\given X)\)，代进不等式，得到任何算法都够不着的错误率。实践上这条路基本走不通，高维特征下条件熵的估计误差常常大过你想测的效应。

所以判定地板高低要换几条更实在的路子。最直接的是重标注一批样本，让若干位标注者独立作业，统计他们两两之间的不一致率——人和人之间都定不下来的那部分，模型也定不下来，这个比例是地板的一个经验下界。其次是画学习曲线：把训练集按 \(1/8,1/4,1/2,1\) 的比例切分，各训一遍，看验证损失随样本量的走势。若曲线迅速压平且训练损失贴着同一水平线，多半是信息见底了；若训练损失远低于验证损失且仍在分开，问题在容量与正则那一侧。第三是在冻结的特征上跑一个 kNN 或线性探针，若一个简单探针就能逼近你精心训练的模型，说明表示里的可用信息已经被取尽，瓶颈不在拟合能力。

最省事的一条是换特征。接进一个新的数据源，若地板明显下沉，那原来的地板就是特征选择造成的，不是任务固有的。若接了三个数据源地板纹丝不动，再堆模型的期望回报就该调低了。

\subsection{换掉 target，最优解跟着换}

上面所有讨论都假定 target 是真实条件分布的无偏样本。训练里有几种常见做法悄悄改掉了这个前提。

Label smoothing 把 one-hot 换成 \((1-\alpha)\) 倍的 one-hot 加上 \(\alpha\) 倍的均匀分布。最小化改版交叉熵的最优 \(q_\theta\) 等于平滑后的 target，不再等于真实条件分布。这是有意引入的偏差，用校准度换泛化与训练稳定性；顺带地，损失的地板也被抬高到了平滑 target 的熵，你不能再拿原来那条虚线去判断还有多少空间。类别加权改变的是不同标签的相对风险，它回答的问题从``模型是否接近真实条件分布''变成了``模型在加权风险下是否最优''，在类别极不平衡时很实用，但报出来的损失数值与未加权情形不可比。知识蒸馏用教师的软输出当 target，衡量的是学生与教师的距离，而教师本身可能已经偏离了数据分布。

这些变体都还写得成交叉熵的形状，都还能用同一套数值技巧，但它们的最优解指向不同的分布。如果下游关心的是自然人群中的校准度，就得在未加权、未平滑、未重采样的验证集上重新检查，训练损失的数字不能直接搬过去当证据。

\subsection{log-sum-exp 保住目标，裁剪偷偷改目标}

softmax 从 logits \(z\) 出发给出 \(q_k=e^{z_k}/\sum_j e^{z_j}\)。先算 softmax 再取对数，在极端 logits 上会栽跟头：某个 \(z_k\) 很大时 \(e^{z_k}\) 溢出，很小时下溢成零，再取对数就是 \(-\infty\) 或 NaN。正确的写法把两步合并：

\[
\log q_\theta(y=k\given x)=z_k-\logsumexp(z),
\qquad
\logsumexp(z)=m+\log\sum_j e^{z_j-m},\quad m=\max_j z_j.
\]

减去最大值再取指数，最大的那一项变成 \(e^0=1\)，其余都在 \((0,1]\) 内，溢出没有了机会。这个改写在实数上是恒等式，目标函数的每一位都没有变，变的只是运算顺序。

概率裁剪是另一回事。把 \(q_k\) 抬到 \(\max(q_k,\varepsilon)\)，或者给对数的输入加一个 \(\varepsilon\) 偏移，得到的已经不是原来那个交叉熵，它的极小值点也随之偏移。多数时候偏移小到看不出来，但当模型确实需要在某些样本上输出接近零的概率时，裁剪会在梯度上留下一道人造的平台。如果下游计算非要严格正的概率不可，裁剪可以用，只是要清楚这是在修改优化目标，不是在``稳住''它。

至此，交叉熵训练的目标、地板与几种常见改装都摆清楚了。还剩一个没交代的问题：\(q_\theta\) 为什么偏偏取 softmax 这个形状？把指数放在线性打分外面，看上去像是为了归一化随手选的。下一节会给出另一条来路——它是在若干矩约束之下、不额外添加假设时唯一能得到的形式。
