\section{图结构把联合分布拆成局部因子}
\label{sec:13-Machine-Learning/07-Graphical-and-Sequential-Models/01}

你在急诊分诊台上做一个辅助判断系统，输入是十个二值症状：发热、咳嗽、胸痛、呼吸困难、恶心……每位病人就是这十个位置上的一串 0/1。系统要回答的问题很朴素——已经知道其中五个症状的取值，剩下五个的概率是多少。可要回答这种问题，手里得有联合分布，而十个二值变量的完整联合表有 \(2^{10}-1=1023\) 个自由参数。到三十个症状就是十亿量级，再多的病历也填不满。问题于是变成：能不能不写下整张表，仍然回答关于任意子集的条件概率。

\subsection{链式法则拆开了表，却一个参数也没省下}

先看最直接的做法。用链式法则把联合分布写成十个因子的乘积：

\[
p(x_1,\dots,x_{10})
=p(x_1)\,p(x_2\given x_1)\,p(x_3\given x_1,x_2)\cdots
p(x_{10}\given x_1,\dots,x_9).
\]

表面上十个因子比一千多个数轻松，实际不然。最后一个因子 \(p(x_{10}\given x_1,\dots,x_9)\) 本身就是一张以 \(2^{9}=512\) 种前置组合为行的条件概率表。把所有因子的参数加起来，恰好还是 \(1023\)：链式法则是恒等式，恒等式不会凭空减少自由度。

估计这些数字的困难同样没有减轻。某个前置组合在几万份病历里可能一次都没出现，对应那一行的条件概率就无从谈起。数据稀疏与组合爆炸是同一件事的两面。

要把参数量降下来，必须往模型里放入恒等式之外的东西——一个可能出错的断言。

\subsection{有向图声明的是哪些依赖不存在}

图模型放进去的断言是这样一句话：给定父节点之后，某个变量与其余非后代变量再无关系。在有向无环图（DAG）中记 \(X_i\) 的父节点集合为 \(\operatorname{pa}(i)\)，联合分布被写成

\[
p(x_1,\ldots,x_d)
=\prod_{i=1}^{d}
p\bigl(x_i\given x_{\operatorname{pa}(i)}\bigr).
\]

与链式法则的差别只在一处：那里 \(X_i\) 条件于排序中所有更早的变量，这里只条件于父节点。被省掉的那些变量，图替你声明了

\[
X_i\perp X_{\text{非后代}\setminus\operatorname{pa}(i)}
\given X_{\operatorname{pa}(i)}.
\]

参数量随之改变。若每个节点至多三个父节点，每张条件概率表只有 \(2^{3}=8\) 行，\(d\) 个节点合计 \(8d\) 个参数——指数变成了线性。一般地，父节点数上界为 \(k\) 时参数量是 \(O(d\,2^{k})\)，一张稀疏图把 \(2^{d}-1\) 压到多项式级。

省下来的东西不白省。这些条件独立不是从数据推出的结论，而是写进模型的前提。前提写错了，程序照跑不误：似然仍然能优化，后验仍然能算到小数点后四位，只是那个数字系统性地偏了。缺一条边也不等于两个变量永远不相关——它们在给定别的变量时可能相关，也可能独立；边的有无只有放在整套条件独立声明里才有含义。

\subsection{三种三节点结构决定信息通不通}

要判断某条边的缺失究竟蕴含什么，只需吃透三种三节点格局。设 \(X,Z,Y\) 三个变量，画法分别是链 \(X\to Z\to Y\)、叉 \(X\leftarrow Z\to Y\)、碰撞 \(X\to Z\leftarrow Y\)。

\emph{同样三个节点，箭头方向决定了观察 \(Z\) 是切断通道还是打开通道。}

链的读法是知识经过 \(Z\) 转手：\(X\) 变动会推动 \(Z\) 的分布偏移，\(Z\) 再推动 \(Y\)。一旦 \(Z\) 的取值被钉死，\(X\) 再怎么变也越不过它，通道断了。叉的读法是共同原因：不观察 \(Z\) 时 \(X\) 与 \(Y\) 因共享 \(Z\) 的波动而相关，给定 \(Z\) 后各自只剩独立噪声。流行病学里``控制混杂变量''的图形依据就在这一列。

碰撞这一列与前两列反向，也最容易在实践中出岔子。\(X\) 与 \(Y\) 各自独立地影响 \(Z\)；不观察 \(Z\) 时两条因果各走各的，通道原本就是断的；一旦给定 \(Z\)（或它的任一后代），通道反而打开。举个具体的：\(X\) 是``患者有心脏病''，\(Y\) 是``患者摔断了腿''，\(Z\) 是``患者进了急诊室''。在一般人群里两者近乎独立，但只统计急诊室内的病人——这就是给定了 \(Z\)——心脏病与骨折会呈现负相关：既然知道他是摔断腿进来的，他因心梗进来的概率就被压低了。分层之后冒出来的关联，可能来自共同效应的筛选，而不是任何一方导致了另一方。选择偏倚的图形根源正在图中最右一列。

把这三条局部规则推广到任意大小的 DAG，就得到 d-分离。

\begin{definition}
给定条件集合 \(C\)，考察 \(X\) 与 \(Y\) 之间的一条无向路径。若路径上存在某个非碰撞节点落在 \(C\) 中，或存在某个碰撞节点使得它自己及其全部后代都不在 \(C\) 中，则该路径被阻断。所有路径都被阻断时称 \(X\) 与 \(Y\) 被 \(C\) d-分离，此时任何按该图分解的分布都满足 \(X\perp Y\given C\)。
\end{definition}

这条判据只用图的拓扑，不看任何具体数值。它给出的是充分方向：d-分离蕴含条件独立；反过来，某组特定的参数取值也可能造出图上读不出的额外独立，那属于巧合而非结构。条件独立本身的代数性质——收缩、分解、弱联合——在\hyperref[sec:05-Probability/02-Conditional-Probability/04]{``条件独立与信息结构''}里已有交代，这里做的是把那些规则换成可以用眼睛沿路径走一遍的形式。

\subsection{无向图换掉方向，也换掉了归一化的代价}

有向图适合表达生成顺序：先有病因，后有症状。但图像分割里相邻像素的标签之间没有先后可言，你只希望邻居倾向于取同一类别。这类对称的相互作用用无向图写更自然。

无向图不用条件概率，用势函数。设最大团集合为 \(\mathcal C\)，

\[
p(x)=\frac{1}{Z}\prod_{C\in\mathcal C}\psi_C(x_C),
\qquad
Z=\sum_{x}\prod_{C\in\mathcal C}\psi_C(x_C),
\]

其中 \(\psi_C\ge 0\) 只给团内配置打相对分数，不必归一。它对应的条件独立读法比 d-分离干净：给定一个节点的全部邻居后，它与图中其余节点条件独立；判断任意两组变量是否独立，只看条件集合是否切断了所有无向路径，没有碰撞节点那种反向开启的例外。

麻烦挪到了别处。势函数是局部的，配分函数 \(Z\) 却要对全空间求和。调整一个小团的参数，所有配置的概率都得重新归一，因为它们必须继续加成一。写出对数似然的梯度就能看见：

\[
\nabla_\theta\log Z(\theta)=\E_{p_\theta}\!\left[T(X)\right],
\]

右端是模型分布下的期望。有向图的参数学习可以按节点拆开分别做，无向图的每一步都被 \(Z\) 绑在一起。\hyperref[sec:13-Machine-Learning/08-Sampling-and-Inference/06]{``配分函数把能量变成全局概率''}会专门处理这个量，MCMC 与变分方法则是绕开它的两条主路。

\subsection{两类图能表达的独立性集合互不覆盖}

既然两种图都在编码条件独立，一个自然的期待是它们可以互译。事实是不能，两个方向都有反例。

有向能说而无向说不出的，正是碰撞结构。上图最右一列断言了 \(X\perp Y\) 与 \(X\not\perp Y\given Z\) 这一组合。任取一张三节点无向图来匹配：若保留 \(X\)--\(Y\) 边，则 \(X\) 与 \(Y\) 在任何条件集合下都不被分离，\(X\perp Y\) 落空；若删去这条边，则条件集合 \(\set{Z}\) 切断了唯一剩下的路径，无向图会断言 \(X\perp Y\given Z\)，与要求相反。两种选择都不对，说明没有无向图能精确表达碰撞结构的独立性集合。

反方向的例子取四个变量 \(A,B,C,D\) 排成一个方环，无向边为 \(A\)--\(B\)、\(B\)--\(C\)、\(C\)--\(D\)、\(D\)--\(A\)。它断言的独立恰好两条：\(A\perp C\given\set{B,D}\) 与 \(B\perp D\given\set{A,C}\)，此外没有任何边缘独立。设想有一张 DAG 与之等价。它的骨架必须仍是这个方环，否则可分离的变量对就对不上。可是给一个环的边定向且保持无环，环上必然出现一个入度为二的节点——不妨设为 \(A\)，于是有 \(B\to A\leftarrow D\)，而 \(B\) 与 \(D\) 在方环中不相邻。这个碰撞结构在给定 \(A\) 时被打开，该 DAG 于是断言 \(B\not\perp D\given\set{A,C}\)，与第二条要求冲突。换个节点当汇点也一样，环上总有这么一个位置。

条件对账：上面两处只用了骨架一致与无环两个前提，没有动用任何数值参数。结论因此是结构性的——两族图模型各有自己表达不了的独立性模式，选哪一种是建模决策，不是记号偏好。也存在两边都表达不了的分布，那时通常要退到因子图这类更细的表示。

\subsection{精确推断的代价由树宽决定，而不是由节点数决定}

分解式写完，日常要做的事是给定证据 \(x_E\) 求查询变量的后验：

\[
p(x_Q\given x_E)\propto\sum_{x_H}\prod_a \psi_a(x_a),
\]

对隐藏变量 \(x_H\) 求和。变量消元法逐个处理待消变量：挑出含它的全部因子相乘，再把它加掉，得到一个新因子。新因子的定义域是这些因子涉及的其余变量之并——消元顺序不同，中间因子的大小可以差好几个数量级。

刻画这件事的量是树宽。把某个消元顺序过程中出现的最大中间因子所含变量数减一，称为该顺序的宽度；所有顺序中的最小宽度就是图的树宽 \(w\)。每个变量取 \(K\) 个值时，精确推断的代价大致是 \(O(d\,K^{\,w+1})\)。链与树的树宽为一，计算量随长度线性增长；\(n\times n\) 的网格树宽为 \(n\)，计算量随边长指数增长，稍大一点连中间表都存不下。

这解释了实践里的两条路。要么把模型限制在链、树或低树宽的结构上，让精确推断可行——隐 Markov 模型的前向--后向、树上的和积消息传递、Kalman 滤波的预测-更新，都是同一套局部消元在特殊结构上的实例，本单元后面几节会分别展开。要么承认精确推断算不动，退到\hyperref[ch:116]{``采样与近似推断：当目标量写得出却算不出''}里的采样与变分方法，用可控的偏差换可行的计算。

值得留意的是，同一张图上画着两件事：哪些独立让你少估参数，哪些依赖让你多付计算。稀疏不只是统计上的节省，也是算法上的通行证。

\subsection{图通常是假设，不是从数据里学出来的结论}

最后一层需要挑明。前面所有推理都以``图已经给定''为前提，而实践中这张图往往来自领域知识和习惯画法，不是数据的产物。

想从数据里学结构，困难有三重。有限样本下接近独立与恰好独立难以区分，似然面在许多候选结构之间几乎持平，选出来的``最优图''可能只是这次抽样多赢了一点。即使样本无限，答案也不唯一：不同 DAG 可以蕴含完全相同的条件独立集合，构成一个 Markov 等价类——\(X\to Z\to Y\)、\(X\leftarrow Z\to Y\) 与 \(X\leftarrow Z\leftarrow Y\) 在纯观察数据面前无法区分，只有碰撞结构留下了可辨认的印记。再者，未观察的共同原因会在两个本无直接联系的变量之间留下残余相关，逼算法补上一条并不存在的边。搜索空间本身也随节点数超指数增长，得靠评分准则与结构限制才走得完。

由此可知，箭头首先记录的是概率分解的方向，不是干预的方向。说``\(X\) 出现在 \(Y\) 的条件概率表的自变量里''是安全的；说``改变 \(X\) 会沿箭头改变 \(Y\)''则需要另外的前提——结构方程、无隐藏混杂、faithfulness，或者干脆做实验。这些前提怎样表述、哪些因果量能从观察分布中识别出来，留给\hyperref[ch:120]{``因果推断：预测世界不等于改变世界''}。

一张图画得清爽，只说明作者对结构有明确判断，不说明判断为真。用图模型报告结论时，值得把四层条件分开写：图声明了哪些条件独立，参数取了什么形式，推断是精确还是近似，数据量能否把这些结构与随机波动分开。下一节把这四层放进最容易检查的情形——变量全是 Gauss 的时候，条件独立会直接写在精度矩阵的零元素上。
