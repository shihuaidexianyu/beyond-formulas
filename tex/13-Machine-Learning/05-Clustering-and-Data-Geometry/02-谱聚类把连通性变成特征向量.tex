\section{谱聚类把连通性变成特征向量}
\label{sec:13-Machine-Learning/05-Clustering-and-Data-Geometry/02}

K-means 直接比较样本坐标：每个簇找一个中心，谁离中心近就归谁。这对团状簇很管用，但碰上弯曲的几何形状就失效了。两个嵌套的同心圆环——K-means 找出的中心会掉在两个环之间的空白地带，把本属于同一环的点切成两半。问题出在衡量相似度的方式上：K-means 问的是``你们离得近不近''，而圆环上的点是沿着环面连通的——该问的是``你们之间有没有路''。

谱聚类换了一个测量工具。先把样本变成相似图：局部相近的点之间连一条边，权重反映相似程度。随后寻找剪断尽可能少、尽可能弱的边的图分区。问题从``坐标中心在哪里''变成了``连通结构怎么被切断''。

\subsection{相似矩阵定义了一种新几何}

构造对称非负的权重矩阵

\[
W_{ij}=W_{ji}\ge 0,
\]

比如在 \(k\)-近邻图上用 Gaussian 权重

\[
W_{ij}
=\exp\left(
-\frac{\norm{x_i-x_j}^2}{2\sigma^2}
\right).
\]

只给近邻以内的点对赋非零权重，远处的点权重为零——边不连接就没有直接的影响力。度矩阵汇总每个节点连出去的总权重：

\[
D=\diag(d_1,\ldots,d_n),
\qquad
d_i=\sum_j W_{ij}.
\]

非归一化图 Laplacian 定义为

\[
L=D-W.
\]

后面所有的谱分析都以这个 \(W\) 为前提。邻居数 \(k\) 太小时，可能把本来连着的一簇切成好几块——图里出现了原本数据中不存在的断裂。\(k\) 太大时，可能在两个不同的簇之间架起捷径——图把不该连的东西连上了。\(\sigma\) 太小则只保留极局部的边，很多点变孤立；太大则所有权重趋近于相等，图丧失区分度。谱方法没有消灭尺度选择这件事，它只是把尺度选择从``中心怎么算''挪到了``图怎么建''。

\subsection{Laplacian 二次型衡量相邻点是否被拆散}

对任意一个向量 \(f\in\R^n\)（每个节点被赋一个实数值），

\[
f^{\trans}Lf
=\frac12\sum_{i,j}W_{ij}(f_i-f_j)^2.
\]

这个式子的含义可以直接读出来：如果一条权重很大的边两端被赋了差异很大的值，\((f_i-f_j)^2\) 大，\(W_{ij}\) 也大，乘积就大——代价高。反过来，如果强连接的节点对取值相近，代价小。特别地，把 \(f\) 取成全一向量 \(\mathbf 1\)，所有 \(f_i-f_j=0\)，二次型为零：\(L\mathbf 1=0\)。

图有 \(c\) 个互不连通的连通分量时，零特征值的重数恰好是 \(c\)——每个分量对应一个在其上恒为 1 而其余分量为 0 的指示向量。理想情况下簇之间完全无边，连通分量直接给出聚类。现实图里却没有这么干净——跨簇之间总有少量弱边。于是你的目标变成：寻找与零特征空间方向接近的低特征值方向，它们沿弱边变化缓慢，沿强边不会剧烈跳动。

\subsection{离散切割通过连续松弛变成特征问题}

对二分图，用取值在 \(\{\pm 1\}\) 的离散向量表示两侧，最小割的代价可以写成某种 \(f^{\trans}Lf\) 的形式。但直接优化离散分配是组合问题——状态数是节点数的指数级别。

退一步。放松 \(f\) 为实向量，加上 \(f\perp\mathbf 1\)（去掉平凡常数解）和 \(\norm f=1\)（固定尺度），问题变成 Rayleigh 商的最小化：

\[
\min_{f\perp\mathbf 1,\ \norm f=1}
f^{\trans}Lf.
\]

解是第二小的特征值对应的特征向量，叫 Fiedler vector。按它的符号或沿一个阈值切开，就得到近似的图分区。多簇情形：取 \(k\) 个最小特征向量，把每个节点嵌入 \(k\) 维谱坐标——也就是说，节点 \(i\) 的新表示是这几个特征向量在第 \(i\) 个分量上拼出的行向量。再在这组新坐标上跑 K-means，得到最终簇划分。

最后一步跑 K-means 值得多看一眼。谱聚类先靠图谱改变了表示——让原来弯曲的连通结构在新坐标中沿着连通方向展开——然后才调用 K-means 完成分类。它并没有抛弃 K-means，而是先帮 K-means 换了一个更容易分开的空间。

\subsection{归一化：不能只靠切边总数判断好坏}

普通的 cut 只算被切断的边权重之和，不关心切出来的两块各自多大。于是算法可能通过孤立一个低度的单节点拿到极小的 cut 代价——这在聚类任务里毫无意义。

Normalized cut 和 ratio cut 为分区的规模和总体度数定了价：切出来的每个区块越大、越密集，允许你切的边才能越多。对应到 Laplacian 上，有归一化形式

\[
L_{\mathrm{sym}}
=I-D^{-1/2}WD^{-1/2}
\]

和随机游走形式

\[
L_{\mathrm{rw}}=I-D^{-1}W.
\]

不同归一化背后是不同的平衡准则。在度数差异很大的图上——比如一个密集核心连着一堆稀疏外围节点——两种归一化可能给出不同的分区结果。不能因为名字里都有``谱聚类''三个字就直接互换特征向量公式，要先搞清楚你默认的平衡准则是什么。

\subsection{谱图漂亮不等于结构被证明}

谱嵌入沿着相似图上的连通方向展开数据，所以二维可视化中出现清晰的分块团并不意外——这恰恰是被构造的。如果换一组建图参数团块消失，说明结论主要来自参数选择而非数据本身的稳定结构。如果样本密度不均匀，固定邻居数可能在高密度区切太碎，固定带宽可能让低密度区完全断开。

计算上，存稠密的 \(W\) 需要 \(O(n^2)\) 空间，完整特征分解更贵。稀疏近邻图和迭代特征求解器（比如 Lanczos 方法）可以扩展规模，但稀疏近似又使近邻搜索的误差进入图结构。数值近似、图构造误差和统计不确定性需要分别检查——不能拿好看的嵌入图一次性回答这三个问题。

谱聚类的第一性假设很明确：簇内部通过高权重路径连通，簇之间连接弱。这和``簇围绕一个中心''是完全不同的几何假设。当数据的真实结构符合这种连通性时，Laplacian 特征向量能揭示 K-means 看不到的几何。当不符合时，算法只是在你人为构造的另一张图上精确求解，解出来的东西和原始数据之间的关系需要另外论证。
