\section{经典线性回归把系数估计接到抽样分布}
\label{sec:11-Mathematical-Statistics/08-Regression-and-ANOVA/01}

\subsection{拟合完的那条线还欠一个误差条}

你手上是一个月的机房运维记录：每天空调运行时长 \(x_i\)，当天总用电量 \(y_i\)。最小二乘跑完，斜率 \(\widehat\beta_1 = 1.24\)，残差图看上去没什么花样。汇报时你说，每多开一小时空调，大约多耗 1.2 度电。

会上有人追了两句。第一句：换成下个月那三十天，这个 1.24 会不会滑到 0.9？第二句：这条线能拿来算电费责任吗，多出来的那 1.2 度电确实是空调烧掉的？

第一句问的是波动幅度，第二句问的是这个系数在测量什么。最小二乘对两句都没有作答。它完成的是一次投影：在设计矩阵张成的子空间里，找离 \(y\) 最近的那个点。投影是确定性的几何操作，换一批数据它会漂多远，几何本身没有意见。

所以这一节要把回归拆成两笔账记。第一笔账只用线性代数，交付点估计；第二笔账添一层关于误差如何生成的概率假设，才换来标准误、置信区间和 \(p\) 值。两笔账用的凭据不同，垮掉的方式也不同，混在一起记是后面大部分误读的源头。

\subsection{点估计只要几何，误差条要概率}

把回归写成矩阵形式
\[
y = X\beta + \varepsilon,\qquad X \in \R^{n\times p},
\]
其中 \(X\) 的每一列是一个特征，第一列通常是全 1 的截距列。当 \(\rank(X) = p\) 时，最小二乘的解是一行代数：
\[
\widehat\beta = (X^{\trans}X)^{-1}X^{\trans}y,\qquad
\widehat y = X\widehat\beta,\qquad
e = y - \widehat y .
\]
正规方程 \(X^{\trans}e = 0\) 直接说明残差与 \(X\) 的每一列正交，\(\widehat y\) 是 \(y\) 在列空间 \(\operatorname{Col}(X)\) 上的正交投影。这一段推理里没有出现任何随机变量，它和\hyperref[sec:03-Linear-Algebra/03-Orthogonality/03]{``最小二乘：为无解方程寻找最佳近似''}讲的是同一件事。

第一笔账到此结束。要往下走，得先声明数据是怎么来的。经典假设把误差写成
\[
\varepsilon \given X \sim \mathcal{N}(0,\ \sigma^2 I_n),
\]
一句话里压了四件独立的事：给定 \(X\) 时误差均值为零、各次观测互不相关、方差全都等于同一个 \(\sigma^2\)、以及分布形状是正态。等会儿的条件对账要一件一件拆开看。

接下来的推导只有三步骨架。把 \(y = X\beta + \varepsilon\) 代进估计式，抵消掉 \((X^{\trans}X)^{-1}X^{\trans}X\)，得到
\[
\widehat\beta = \beta + (X^{\trans}X)^{-1}X^{\trans}\varepsilon ,
\]
估计值等于真值加一个由噪声驱动的偏移。第二步取期望与方差，记 \(A = (X^{\trans}X)^{-1}X^{\trans}\)，则 \(\E[\widehat\beta \given X] = \beta\)，而
\[
\Var(\widehat\beta \given X) = A\,(\sigma^2 I_n)\,A^{\trans} = \sigma^2 (X^{\trans}X)^{-1}.
\]
第三步用正态分布在线性变换下封闭这一条，把矩升级成完整分布：
\[
\widehat\beta \given X \sim \mathcal{N}\!\left(\beta,\ \sigma^2 (X^{\trans}X)^{-1}\right).
\]

噪声尺度 \(\sigma^2\) 未知，用残差补上。最小二乘花掉了 \(p\) 个方向去贴合数据，残差落在一个 \(n-p\) 维子空间里，于是
\[
s^2 = \frac{\operatorname{RSS}}{n-p},\qquad \operatorname{RSS} = \norm{y - X\widehat\beta}_2^2
\]
是 \(\sigma^2\) 的无偏估计。记 \(v_j = [(X^{\trans}X)^{-1}]_{jj}\)，第 \(j\) 个系数的标准误就是
\[
\SE(\widehat\beta_j) = s\sqrt{v_j},
\]
在 \(H_0:\ \beta_j = \beta_{j,0}\) 与全部经典假设下，
\[
T = \frac{\widehat\beta_j - \beta_{j,0}}{s\sqrt{v_j}} \sim t_{\,n-p},
\]
置信区间随之为 \(\widehat\beta_j \pm t_{n-p,\,1-\alpha/2}\, s\sqrt{v_j}\)。这里的 \(95\%\) 说的是程序的长期覆盖率，而不是这一次区间盖住真值的概率，这个区别在\hyperref[sec:11-Mathematical-Statistics/04-Interval-Estimation/01]{``置信度属于程序，而非这次参数''}里已经辨过。

\subsection{设计矩阵决定标准误的宽窄}

协方差矩阵 \(\sigma^2(X^{\trans}X)^{-1}\) 是两个因子的乘积，各自可以单独解读。\(\sigma^2\) 是数据的内在噪声，你改不了它，只能承认它。\((X^{\trans}X)^{-1}\) 是设计的几何：特征取值散得开、方向彼此分得清，这个矩阵的对角元就小。

共线性正是从这里发作的。假设两列几乎平行，\(X^{\trans}X\) 接近奇异，逆矩阵对应的对角元被顶到很大，于是即便 \(\sigma^2\) 很小，两个系数各自的抽样分布也被拉得极宽。回到上面那张图的右半边：共线不改变曲线的中心，它把整条钟形曲线横向摊平。样本量再翻倍也补不回来，因为病根在设计而不在噪声。

值得留意的是，共线只毒害单个系数的解读，不毒害拟合值。两列几乎平行时，它们的和方向仍然被稳稳估计出来，\(\widehat y\) 与预测区间照常可用。所以看到``方差膨胀因子很高''，正确的反应是停止逐个解读这几个系数，而不是宣告模型作废。

\subsection{每个假设各自防住一种失效}

推导用掉的四件事，值得一件一件对账。对账的问题统一是：这条塌了，塌的是哪一笔账。

零条件均值 \(\E[\varepsilon \given X] = 0\) 保的是第一笔账。它一垮，\(\widehat\beta\) 就朝着一个错误的目标收敛，样本量增大只会让你更精确地估出一个错的数。遗漏了同时影响 \(x\) 和 \(y\) 的变量属于这一类，它无法靠残差图看出来，只能靠领域知识和设计。

同方差保的是第二笔账。误差方差随 \(x\) 变化时，\(\widehat\beta\) 依然无偏，塌掉的只是 \(\sigma^2(X^{\trans}X)^{-1}\) 这个宽度公式：报出来的区间可能系统性偏窄或偏宽，名义 \(95\%\) 的实际覆盖率对不上。残差对拟合值作图是它的观察窗口，喇叭形张开就是信号；补救手段是三明治型稳健协方差估计，它换掉方差公式而保留原来的点估计。

误差不相关同样只保第二笔账，但它出事时后果更重。同一台机组连续三十天的记录、同一个门店的多条订单、时间序列里相邻两天的天气，误差都成簇地同向偏移。有效样本量远小于 \(n\)，标准误会被严重低估，\(p\) 值随之虚高显著。诊断靠残差按组或按时间排列后看是否成块同号，也可以看残差的自相关图；补救靠按机组或按门店聚类的稳健标准误，或者直接上混合效应模型。

正态性只在小样本里出场。它是 \(t\) 与 \(F\) 精确分布的来源；样本量一大，中心极限定理接手，\(T\) 统计量趋于正态，误差分布的形状就不那么要紧了。麻烦发生在样本小而误差厚尾的角落，此时 \(t\) 检验的尾部概率会明显失准，置换检验或 bootstrap 是更稳妥的替代，见\hyperref[sec:11-Mathematical-Statistics/06-Resampling-and-Model-Selection/01]{``Bootstrap 近似估计量的抽样波动''}。

把这四条并排看，一个格局浮出来：第一笔账只需要一条假设，第二笔账要另外三条。点估计比推断结实得多，报数容易，报误差条难。

\subsection{\(R^2\) 与嵌套 \(F\) 各自回答一个很窄的问题}

模型含截距时，投影几何给出干净的分解
\[
\underbrace{\sum_i (y_i - \bar y)^2}_{\operatorname{TSS}}
= \underbrace{\sum_i (\widehat y_i - \bar y)^2}_{\operatorname{ESS}}
+ \underbrace{\sum_i (y_i - \widehat y_i)^2}_{\operatorname{RSS}},
\qquad
R^2 = 1 - \frac{\operatorname{RSS}}{\operatorname{TSS}} .
\]
\(R^2\) 报告的是：在这批样本、这个尺度、这组特征下，响应的变异有多大比例落进了回归平面。它对样本外表现、对假设是否成立、对因果解读，都不表态。往模型里塞任何一列，哪怕是随机生成的噪声，训练 \(R^2\) 也只升不降——列多了，可投影的子空间只会变大，残差范数不可能被撑回去。调整 \(R^2\) 给新增列记了一笔罚金，但它仍是样本内指标；样本外能力得交给交叉验证，见\hyperref[sec:11-Mathematical-Statistics/06-Resampling-and-Model-Selection/03]{``交叉验证评估的是完整训练流程''}。

嵌套模型的比较问的是另一个问题。约束模型有 \(p_0\) 个参数，完整模型有 \(p_1 > p_0\) 个，后者的列空间包住前者，所以 \(\operatorname{RSS}_1 \le \operatorname{RSS}_0\) 是几何必然，下降本身不构成证据。\(F\) 统计量把下降量摊到每个新增参数上，再用完整模型的噪声水平去度量：
\[
F = \frac{(\operatorname{RSS}_0 - \operatorname{RSS}_1)/(p_1 - p_0)}{\operatorname{RSS}_1/(n - p_1)} .
\]
在新增方向系数全为零的零假设与全部经典假设下，\(F \sim F_{p_1-p_0,\,n-p_1}\)。只有当每单位自由度换来的下降明显超过背景噪声，拒绝才成立。单个系数的 \(t\) 检验是这个框架的特例，此时 \(F = T^2\)，两者给出同一个 \(p\) 值。

\subsection{观测数据里的系数不承诺干预后的结果}

回到会上的第二句追问。\(\widehat\beta_1\) 度量的是：在样本里，其他纳入模型的变量取值相同的那些天之间，空调多开一小时伴随的用电量差异。它是一个条件相关量。要把它读成``把空调多开一小时会导致多耗 1.2 度电''，需要额外的一步：没有被遗漏的共同原因。气温同时抬高空调时长和其他制冷设备的负载，这样一个变量若没进模型，\(\E[\varepsilon\given X]=0\) 就已经不成立，系数吸收了不属于它的那部分。

更隐蔽的失误是往模型里塞错变量。控制一个位于因果链条中间的变量会挡掉部分效应，控制一个同时被 \(x\) 和 \(y\) 影响的碰撞点则会凭空造出关联。哪些变量该进、哪些该留在外面，取决于假定的因果结构而非拟合优度，\hyperref[sec:13-Machine-Learning/12-Causal-Inference/03]{``混杂、碰撞点与后门调整''}给出了判据。

还有一处系统性偏差常被忽略：模型往往是看过数据之后挑出来的。若你试了三十种变量组合，选了 \(R^2\) 最高的那个，再照常报告它的 \(p\) 值和区间，这些数字的分布计算里并没有包含挑选这一步。上面推出的 \(t\) 与 \(F\) 分布假定模型在见到数据之前就已固定。同一批数据先选模型再做推断，纸面上的分位数就不再适用，误差条比它印出来的窄。

于是回归推断评价的是整套建模流程的质量，而不是最后一次矩阵运算的数值。下一节把同一套投影记账法搬到另一个场景：几组数据的均值是否有差别。那里的平方和分解看起来像一门独立的技术，拆开却是这一节的回归换了一身记号。
