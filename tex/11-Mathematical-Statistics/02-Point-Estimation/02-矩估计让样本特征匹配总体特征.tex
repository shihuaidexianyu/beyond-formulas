\section{矩估计让样本特征匹配总体特征}
\label{sec:11-Mathematical-Statistics/02-Point-Estimation/02}

你有一个参数模型 \(P_\theta\)。\(\theta\) 未知。但你知道 \(\theta\) 和总体的某些特征之间有关系。Bernoulli 的 \(\theta\) 就是总体均值；正态的 \(\mu\) 也是总体均值，\(\sigma^2\) 是总体方差；Gamma 分布的参数与均值和方差构成一个方程组。如果能从数据中估计出这些总体特征，再反推出 \(\theta\)，路就打通了。

总体特征不好直接算——你手里没有整个总体，只有 \(n\) 个样本。但样本特征好算：样本均值是几行代码，样本方差也是，更高阶的样本矩无非是数据幂次的平均值。一个直接的想法跳出来：让样本特征等于总体特征，解出参数。

这就是矩估计的核心思路。

\subsection{从匹配均值开始的构造}

设参数 \(\theta \in \mathbb{R}^k\)——有 \(k\) 个未知数。总体理论矩定义为：
\[
m_j(\theta) = \E_\theta[X^j],\qquad j = 1,\ldots,k.
\]
样本矩直接对数据取平均：
\[
\hat m_j = \frac{1}{n}\sum_{i=1}^n X_i^j.
\]
矩估计 \(\hat\theta\) 是以下方程组的解：
\[
m_j(\hat\theta) = \hat m_j,\qquad j=1,\ldots,k.
\]
方程数等于参数数，通常恰好确定一个解。

最简单的入口——Bernoulli(\(\theta\))：
\[
\E[X] = \theta,
\]
因此：
\[
\hat\theta = \bar X.
\]
只匹配一阶矩，因为只有一个参数。结果和直觉完全一致：用样本合格率估计总体合格率。

\subsection{Bernoulli 与均匀分布}

对 \(X_i \sim \operatorname{Uniform}(0,\theta)\)：
\[
\E[X] = \frac{\theta}{2},
\]
矩估计给出：
\[
\hat\theta_{\mathrm{MM}} = 2\bar X.
\]
看起来没问题。但仔细想：如果抽到 5 个数据点 \(0.3, 0.8, 1.9, 0.7, 8.2\)，样本均值是 \(2.38\)，所以 \(\hat\theta_{\mathrm{MM}} = 4.76\)。但样本最大值是 \(8.2\)。

你的估计说 \(\theta \approx 4.76\)，数据来自 Uniform\((0, 4.76)\)。可你明明观测到了 \(8.2\)——这在模型下概率为零。矩估计用均值方程求解，完全不知道 Uniform 还有一个硬约束：所有观测值必须 \(\le \theta\)。

这个信息浪费不是小问题。分布的支持集——参数空间的硬边界——是一个很强的结构，而矩估计只通过汇总统计量（平均值）间接触及参数，绕开了分布的形状约束。同一模型的最大似然估计是 \(\max_i X_i\)（下一节推导），由支持集约束直接确定，永远不可能产生``数据在模型下不可能出现''的参数。

两条路径在 Bernoulli 上汇合（矩估计 = MLE = \(\bar X\)），在 Uniform 上分道扬镳——这正是不同构造原理的差异在具体模型中显现的时刻。

\subsection{正态均值与方差的矩估计}

对 \(X \sim N(\mu,\sigma^2)\)：
\[
\E[X] = \mu,\qquad \E[X^2] = \mu^2 + \sigma^2.
\]
匹配前两阶原点矩，得到方程组：
\[
\hat\mu = \bar X,
\]
\[
\hat\mu^2 + \hat\sigma^2 = \frac{1}{n}\sum_i X_i^2.
\]
代入 \(\hat\mu = \bar X\) 解出：
\[
\hat\sigma^2 = \frac{1}{n}\sum_i X_i^2 - \bar X^2
            = \frac{1}{n}\sum_i (X_i - \bar X)^2.
\]
方差估计的分母是 \(n\)，不是 \(n-1\)。这和上一节讨论的 MLE 结果一致。

这个估计在有限样本中有向下偏差（偏差量级 \(-\sigma^2/n\)），原因在上一节已经计算过：\(\sum_i (X_i-\bar X)^2\) 的期望是 \((n-1)\sigma^2\)，除 \(n\) 后期望为 \(\frac{n-1}{n}\sigma^2\)。要得到无偏估计，需用 \(n-1\)。但矩估计不管偏差——它只管``让二阶样本矩等于二阶总体矩''这一条方程被满足。构造方法和评价标准是分开的：矩估计负责``怎么构造''，MSE（或偏差、方差）负责``好不好''。

\subsection{为什么矩估计常常一致}

矩估计有一个干净的渐近论证。如果：
\begin{itemize}
\tightlist
\item 样本矩由大数定律收敛到理论矩：\(\hat m_j \overset{P}{\to} m_j(\theta)\)；
\item 从矩到参数的逆映射 \(m^{-1}\) 在真 \(\theta\) 处连续；
\item 参数可识别——不同的 \(\theta\) 产生不同的矩向量；
\end{itemize}
那么由连续映射定理：
\[
\hat\theta_{\mathrm{MM}} \overset{P}{\to} \theta.
\]
论证很简洁：样本矩趋近理论矩，逆映射连续就把这种趋近传递给了参数估计。

但每个条件都有它可能失败的场景。矩不存在——Cauchy 分布没有均值，矩估计的第一步就踏空了。逆映射不唯一——方程组可能有多组解，哪一组是``真的''并不由矩方程本身决定。逆映射在真值附近不连续——样本矩的小扰动可能导致参数估计的大跳变。重尾分布的样本高阶矩由少数极端值主导，收敛极慢——名义上一致，实际上 \(n = 10000\) 都不够稳定。

\subsection{矩方程多于参数时怎么办}

参数只有 \(k\) 个，但你可能想用多于 \(k\) 个矩条件——每个矩条件都携带一些信息，多用几条似乎应该更好。但 \(k\) 个方程刚好定解；多于 \(k\) 个，没有任何参数能同时精确满足所有方程。

广义矩估计（GMM）解决这个矛盾：
\[
\hat\theta = \argmin_\theta\; \hat g(\theta)^{\trans} W \hat g(\theta),
\]
其中 \(\hat g(\theta)\) 汇总了所有样本矩条件与零的差距向量（或样本矩与理论矩的差距），\(W \succeq 0\) 是权重矩阵。不同矩条件的尺度和相关性不同，权重的选择影响效率——最优权重与矩条件的协方差结构有关，需要估计。

多余的矩条件还可以做 overidentification 检验：如果模型正确，加权矩差距应该不大；如果太大，模型可能在某个维度上和数据冲突。但这个检验本身也依赖模型正确性——它告诉你``在这个模型内有什么不对劲''，不一定能指出``真实世界哪里不对''。

\subsection{何时矩估计有吸引力}

矩估计不是 MLE 的``粗糙前置步骤''。它在若干场景中有独立价值：
\begin{itemize}
\tightlist
\item 理论矩和参数的关系简单、显式可解——不需要迭代优化，写完公式就出结果；
\item 似然函数难写或计算昂贵——复杂依赖结构、隐式模型、模拟模型等；
\item 你只愿意依赖有限个矩条件，不想对整个分布做完整参数假设——半参数思路的入口；
\item 需要快速初值喂给 MLE 或其他迭代算法——矩估计花几毫秒给出一个合理出发点；
\item 模型本身就自然以矩条件的形式表达——经济学中的 Euler 方程、物理中的守恒律、流行病学中的再生数方程。
\end{itemize}
代价也是明确的：丢弃了似然中的其他分布信息，效率可能低于 MLE；不自动尊重参数空间的硬约束；高阶矩对尾部极度敏感，几个极端值可以完全绑架样本矩。矩估计是一种建模选择——你选择相信哪些总体特征足以捕获参数的全部信息。
