\section{MAP 把先验与似然合在一个点上}
\label{sec:11-Mathematical-Statistics/02-Point-Estimation/04}

你拿到一枚硬币。抛了 \(n=10\) 次，\(S=7\) 次正面。

极大似然估计直截了当：\(\hat\theta_{\mathrm{MLE}}=7/10=0.7\)。这就是数据告诉你的数字，没有多余的话。

但抛硬币之前，你朋友说了一句：``这枚是赌场标准币，大概公平。''这句话不是数据，却也不是废话---如果你的模型里完全没有它的位置，你就浪费了一条可能有用的信息。反过来说，如果你盲目相信这句先验判断而忽视自己亲手抛出的 7/10，同样不合理。

问题来了：怎么把先验信念和观测数据，合进同一个框架里，产出一个合理的参数估计？

\subsection{把参数也当成随机变量}

频率学派把 \(\theta\) 看成一个固定但未知的数。Bayesian 框架换了一个起点：参数本身也服从一个概率分布。在你看到任何数据之前，你对 \(\theta\) 的判断被编码成一个先验分布：

\[
\Theta\sim\pi(\theta).
\]

拿到数据 \(x\) 之后，Bayes 公式把这股先验信息和似然自然地乘在一起：

\[
\pi(\theta\mid x)
\propto
L(\theta;x)\,\pi(\theta).
\]

这个后验分布 \(\pi(\theta\mid x)\) 已经是一个完整的答案：它告诉你，看完数据之后，你对 \(\theta\) 的每一个可能取值分别相信多少。但很多时候你只需要一个数---一个点估计。从后验分布里提取一个单点，最直接的想法是取它的``最高点''：

\[
\hat\theta_{\mathrm{MAP}}
\in
\argmax_\theta
\pi(\theta\mid x).
\]

这就是最大后验估计（MAP）。取个 \(\log\)，等价于最大化

\[
\log L(\theta;x)+\log\pi(\theta).
\]

两项各司其职：第一项是数据对你喊的话，第二项是先验把你往回拉的力量。MLE 只听数据；MAP 同时听数据和先验。

不过先别急着套公式。让我们拿一个具体的例子里走一遍，你会看到好几处``等等，这不对''的瞬间。

\subsection{Beta--Bernoulli：公式里藏着一个减一}

Bernoulli 试验，\(X_i\in\{0,1\}\)，\(S=\sum_iX_i\)。选一个趁手的先验：Beta 分布。

\[
\theta\sim\operatorname{Beta}(\alpha,\beta),\qquad
\pi(\theta)\propto\theta^{\alpha-1}(1-\theta)^{\beta-1},\quad\theta\in(0,1).
\]

乘上似然 \(\theta^S(1-\theta)^{n-S}\)，后验还是 Beta 家族：

\[
\theta\mid x
\sim
\operatorname{Beta}(\alpha+S,\;\beta+n-S).
\]

后验的对数密度（丢掉不依赖 \(\theta\) 的常数）为

\[
(\alpha+S-1)\log\theta+(\beta+n-S-1)\log(1-\theta).
\]

当 \(\alpha+S-1>0\) 且 \(\beta+n-S-1>0\) 时，密度在 \((0,1)\) 内部有唯一极大值。求导令零：

\[
\frac{\alpha+S-1}{\theta}-\frac{\beta+n-S-1}{1-\theta}=0,
\]

解出

\[
\hat\theta_{\mathrm{MAP}} = \frac{S+\alpha-1}
{n+\alpha+\beta-2}.
\]

看到这个式子，停下来想一想。后验均值是

\[
\E[\theta\mid x] = \frac{S+\alpha}{n+\alpha+\beta},
\]

分子分母都比 MAP 各自多 1。两者不是同一个数。

为什么不一样？因为 MAP 取的是后验密度的众数；后验均值取的是平方损失下最优的那个点（对 \(a\) 最小化 \(\E[(\theta-a)^2\mid x]\)，求导令零就是后验均值）。如果你关心绝对误差，最优摘要变成后验中位数。这些摘要各有各的损失函数，没有谁先天就比谁``更 Bayesian''。MAP 只是其中之一。

取 \(\alpha=\beta=1\)（均匀先验），后验均值是 \((S+1)/(n+2)\)---正是 Laplace 继承规则，也在第一节出现过。而 MAP 在均匀先验下退化回 MLE 的 \(S/n\)，因为均匀密度的 \(\log\pi(\theta)\) 是常数，对最大化没有贡献。

但等一下。如果 \(\alpha<1\) 呢？

Beta\((0.5,0.5)\) 的密度在两端趋于无穷，像一个被掰弯的马鞍。乘上似然后，后验密度可能在边界 0 或 1 处达到最大---这时候 \((0,1)\) 内部的驻点根本不是全局最大值，套用上面那个内部公式会得到一个毫无意义的答案。更糟的是，如果 \(\alpha+S-1\le 0\)，内部公式甚至给出负数或未定义。

判断 MAP 时，你需要检查边界：后验密度在 0 和 1 处的值（或极限）是否超过了内部驻点。这不是公式的 bug，而是问题的几何在告诉你：先验强烈偏好极端值，数据不够多时，最可信的参数确实就在边界上。

\subsection{先验怎样变成正则项}

把 MAP 的目标函数换一个写法：

\[
-\log\pi(\theta\mid x)
=
-\log L(\theta;x)-\log\pi(\theta)+\text{常数}.
\]

右边第一项是负对数似然---拟合数据的目标；第二项是负对数先验---惩罚偏离先验信念的参数。MAP 就是在惩罚和拟合之间找平衡。

线性回归里这个对应关系格外干净。假设

\[
y=Xw+\varepsilon,\qquad\varepsilon\sim N(0,\sigma^2 I),
\]

先验取 \(w\sim N(0,\tau^2 I)\)。则

\[
-\log\pi(w) = \frac{1}{2\tau^2}\norm{w}_2^2+\text{常数},
\]

而负对数似然贡献的是 \(\frac{1}{2\sigma^2}\norm{y-Xw}_2^2\)。MAP 目标为

\[
\frac{1}{2\sigma^2}\norm{y-Xw}_2^2+\frac{1}{2\tau^2}\norm{w}_2^2,
\]

乘上常数 \(2\sigma^2\) 后等价于

\[
\norm{y-Xw}_2^2+\frac{\sigma^2}{\tau^2}\norm{w}_2^2.
\]

这正是 Ridge 回归，惩罚参数 \(\lambda=\sigma^2/\tau^2\)。先验越集中（\(\tau^2\) 小），\(\lambda\) 越大，系数被拉向零越狠。

若把 Gaussian 先验换成独立 Laplace 先验：

\[
\pi(w)\propto\prod_j e^{-|w_j|/b},
\qquad
-\log\pi(w)=\frac{1}{b}\sum_j|w_j|+\text{常数},
\]

MAP 等价于 Lasso。L1 惩罚把系数往零拉，而且有把一个方向直接压到零的能力。

这个对应关系很有用：它给正则化提供了一个概率来源---你选的惩罚项，对应着你对参数先验分布的某种信念。反过来，它也明确了正则强度 \(\lambda\) 与噪声尺度 \(\sigma^2\)、先验尺度 \(\tau^2\) 之间的定量关系。

但也别把这条对应推得太远。同一个目标函数可以有多重解释：频率学派说``我加惩罚是为了控制复杂度''，Bayesian 学派说``惩罚来自先验''，优化的人说``加个二次项有助于数值稳定''。三种视角指向同一个算式，但关于不确定性的后续陈述完全不同。把 Ridge 的目标当成``参数确实服从 Gaussian 先验''和当成``一种正则化技巧''，区间的构造和解释会截然不同。

\subsection{MAP 不随参数刻度而保持}

设估计对象是 \(\theta\)，你算出 \(\hat\theta_{\mathrm{MAP}}\)。现在如果有人问：\(\eta=g(\theta)=1/\theta\) 的 MAP 是多少？你直觉上可能认为 \(\hat\eta_{\mathrm{MAP}}=1/\hat\theta_{\mathrm{MAP}}\)，但这在多数情况下是错的。

原因是密度变换带着 Jacobian。后验在 \(\eta\) 空间的密度为

\[
\pi_\eta(\eta\mid x) = \pi_\theta(\theta\mid x)
\left|\frac{d\theta}{d\eta}\right|,
\]

这里 \(\theta=g^{-1}(\eta)\)。求 \(\pi_\eta\) 的最大值，与求 \(\pi_\theta\) 的最大值，一般不对应同一个点，因为右边多了一个乘性因子 \(|d\theta/d\eta|\)。

MLE 没有这个问题：似然 \(L(\theta;x)\) 是一个函数值，最大化后做一一变换，最大值的位置跟着参数一起变换。这是因为 MLE 只比较同一个分布在不同参数下的似然，不涉及密度在不同参数刻度下的``单位面积''权重。MAP 的额外麻烦完全来自先验密度---或者更准确地说，来自测度选择。

这引出一个不太舒服的结论：MAP 不是坐标自由的。你选择用 \(\theta\)、\(\log\theta\) 还是 logit 来表示参数，会得到不同的点估计。所以``后验众数''不是一个纯粹几何的 Bayesian 摘要---它依赖你用什么尺子量参数空间。

但这不代表 MAP 无用。它计算简单、与正则化对应清晰、在高维问题中经常是唯一可计算的后验摘要。认识到它的坐标依赖性，意味着在解释 MAP 时你需要把``我用了什么参数化和什么基准测度''放在心里，并在关键结论上检查后验均值和完整后验区间是否给出同样的方向。

\subsection{先验从哪里来，以及用了几次}

一个更棘手的问题：先验里的超参数 \(\alpha,\beta\)（或 \(\tau^2\)）本身是从哪来的？

如果你凭领域知识设定了它们，这没问题。但如果你先用同一批数据选了一个``合适''的 \(\alpha,\beta\)---比如让先验均值匹配样本均值---然后再把这个先验当作独立的外部信息去做后验推断，你实际上把同一批数据用了两次：一次选超参数，一次算后验。得到的后验会比诚实使用数据的区间更窄，不确定性被低估。

经验 Bayes 有严格的方法来处理这种情况（把超参数的估计不确定性一起纳入），但随手做的``先看一眼数据选个先验再跑 MAP''不是经验 Bayes，只是双重使用数据。

在大样本、固定维度和正则条件下，似然项通常压倒温和的先验，MAP 接近 MLE，先验怎么选影响不大。在小样本、高维度或参数接近不可识别时，先验可以主导结论。这时候敏感性分析不是可选项：你把合理先验换一个，结论是否跟着翻？如果换一个温和先验结论就完全改变，那你还不能把 MAP 当成可靠的发现。

最后一点：后验分布本身才是 Bayesian 框架的完整输出。MAP 只是从中提取的一个摘要。真正稳健的推断，通常需要报告后验区间、后验概率，或在明确损失函数下求解完整的决策问题。MAP 是一个趁手的工具，但不该是工具箱里唯一的那个。
