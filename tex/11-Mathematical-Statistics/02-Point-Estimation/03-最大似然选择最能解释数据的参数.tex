\section{最大似然选择最能解释数据的参数}
\label{sec:11-Mathematical-Statistics/02-Point-Estimation/03}

代码评审里有人提了个 issue。拟合脚本给一批位移传感器读数拟合正态分布，日志打印 \texttt{loglik = 1246.5}。评审意见写着：概率不超过 \(1\)，对数不可能是正数，这里有 bug。

没有 bug。读数以毫米为单位，量程窄，拟合出的 \(\hat\sigma=0.02\)。正态密度在峰值处是 \(1/(\hat\sigma\sqrt{2\pi})\approx 19.9\)，远大于 \(1\)。\(500\) 个观测各贡献大约 \(\log 19.9-0.5\approx 2.5\)，加起来正是一千二百多。把单位换成米，\(\hat\sigma\) 变成 \(2\times 10^{-5}\)，同一份数据的对数似然跳到四千七——数据没变，模型没变，只是刻度尺换了。

这两件事——似然值可以大于 \(1\)，似然值本身随参数化改变——都不是意外，它们直接来自似然的定义。这一节讲清楚这个定义，以及为什么由它出发的估计方法成了从 logistic 回归到语言模型预训练的共同底座。

\subsection{似然是参数的函数，不是参数上的分布}

固定一组观测 \(x=(x_1,\dots,x_n)\)，模型族 \(\set{p_\theta}\) 里的每个 \(\theta\) 都给这组数据分配一个概率（离散情形）或一个密度值（连续情形）。把这个值看成 \(\theta\) 的函数，就是似然：

\[
L(\theta;x)=p_\theta(x).
\]

符号和联合密度一模一样，读法完全相反。写 \(p_\theta(x)\) 时，\(\theta\) 固定、\(x\) 在变，它对 \(x\) 积分等于 \(1\)。写 \(L(\theta;x)\) 时，\(x\) 固定、\(\theta\) 在变，它对 \(\theta\) 积分等于什么，没有人规定——通常不是 \(1\)，而且在 \(\theta\) 无界的参数空间上可能根本发散。

于是开头那个 issue 的两个疑点各自落地。连续模型下 \(L\) 是密度而非概率，密度只受``对 \(x\) 积分为一''的约束，任何一点上的取值都可以任意大，见\hyperref[sec:05-Probability/03-Random-Variables/03]{``连续分布、密度与分位数''}。至于换单位就变值，因为密度带量纲，量纲一换数值当然变——但两个 \(\theta\) 的似然之比是无量纲的，换单位不变。这暗示了正确的用法：似然的绝对值没有意义，比值才有。\(L(\theta_1;x)/L(\theta_2;x)=10\) 说的是，在这组数据上 \(\theta_1\) 的解释力是 \(\theta_2\) 的十倍。整个假设检验的一大支柱建立在这个比值上，见\hyperref[sec:11-Mathematical-Statistics/05-Hypothesis-Testing/03]{``似然比比较两个模型对数据的解释力''}。

最大似然估计就是让这个函数取到峰的参数：

\[
\hat\theta_{\mathrm{MLE}}\in\argmax_{\theta\in\Theta}L(\theta;x).
\]

\subsection{对数把连乘变连加，顺带救了浮点数}

\(\iid\) 样本的似然是 \(n\) 项连乘，\(L(\theta;x)=\prod_i p_\theta(x_i)\)。这个形式在纸上没问题，在机器上是灾难。语言模型给单个 token 的概率量级常在 \(10^{-4}\)，一段一千 token 的文本，联合概率大约 \(10^{-4000}\)，而双精度浮点的最小非零值在 \(10^{-308}\) 附近。乘到第八十个 token 就已经是零，后面九百多项乘的都是零。

取对数，因为 \(\log\) 严格单调，峰的位置一个不动：

\[
\ell(\theta;x)=\sum_{i=1}^n\log p_\theta(x_i).
\]

连乘变连加，量级从 \(10^{-4000}\) 变成 \(-9200\) 左右，浮点数轻松装下。求导也跟着变简单：连乘的导数要用 \(n\) 项乘积法则，连加的导数就是 \(n\) 个导数相加。整个训练流程从头到尾待在对数域里，softmax、交叉熵、logsumexp 都是这条原则的具体实现，通用的改写手法见\hyperref[sec:08-Numerical-Analysis/07-Numerical-Methods-for-ML/01]{``在对数域中稳定计算概率''}。

\subsection{两个能一路解到底的例子}

\(X_i\sim\Bernoulli(\theta)\)，记 \(S=\sum_i X_i\)。对数似然与它的导数是

\[
\begin{aligned}
\ell(\theta)&=S\log\theta+(n-S)\log(1-\theta),\\
\ell'(\theta)&=\frac{S}{\theta}-\frac{n-S}{1-\theta},
\end{aligned}
\]

令 \(\ell'=0\) 解出 \(\hat\theta=S/n=\bar X\)。条件对账：这个推导要求 \(\theta\in(0,1)\) 开区间，且 \(0<S<n\)。全部成功或全部失败时导数在开区间内不过零，峰落在边界上，得直接比较 \(\theta=0\) 与 \(\theta=1\) 两个端点的似然。这不是边角料——线上做 A/B 时某个分层零转化是常事，无约束优化器在那里会一路推向边界然后报奇怪的错。

上一节的矩估计在 Bernoulli 上给出同一个 \(\bar X\)，两条路线在这里重合。换成正态就分开了。\(N(\mu,\sigma^2)\) 的对数似然

\[
\ell(\mu,\sigma^2)=-\frac{n}{2}\log(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum_i(x_i-\mu)^2
\]

对 \(\mu\) 求偏导得 \(\hat\mu=\bar x\)，与 \(\sigma^2\) 无关；把 \(\sigma^2\) 当作一个整体参数求偏导并令零，得

\[
\hat\sigma^2_{\mathrm{MLE}}=\frac1n\sum_i(x_i-\bar x)^2 .
\]

分母是 \(n\)。这个 \(n\) 常被当成笔误改掉，它不是。最大似然的目标是让手上这份数据在模型下最不意外，无偏性根本不在这个目标函数里。由恒等式 \(\sum_i(X_i-\bar X)^2=\sum_i(X_i-\mu)^2-n(\bar X-\mu)^2\) 取期望得 \((n-1)\sigma^2\)，所以 \(\E[\hat\sigma^2_{\mathrm{MLE}}]=\frac{n-1}{n}\sigma^2\)，系统性低估，偏差是 \(-\sigma^2/n\)。\(n=10\) 时平均低估一成；拿这个方差去定报警阈值，阈值会偏窄，误报率比设计值高。换成 \(n-1\) 做分母能修掉偏差，但那个估计不再是似然的峰。两条评价原则给出两个答案，选哪个取决于这个数字接下来要拿去做什么。

\subsection{训练目标本来就是负对数似然}

把模型改成条件形式 \(p_\theta(y\given x)\)，最大似然写成最小化：

\[
\hat\theta=\argmin_\theta\ -\frac1n\sum_{i=1}^n\log p_\theta(y_i\given x_i).
\]

这就是经验风险最小化，损失恰好取成负对数似然。常见的训练目标基本都是这个式子的特例。分类模型里 \(p_\theta(\cdot\given x_i)\) 是 softmax 输出，\(-\log p_\theta(y_i\given x_i)\) 正是真实标签的独热分布与预测分布之间的交叉熵，两者不是``很像''，是同一个表达式，见\hyperref[sec:07-Information-Theory/03-Divergences/01]{``错误模型的代价：从交叉熵到 KL 散度''}。回归模型假设 \(y_i=f_\theta(x_i)+\varepsilon_i\)、\(\varepsilon_i\sim N(0,\sigma^2)\)，负对数似然去掉常数就是平方损失除以 \(2\sigma^2\)；把噪声换成 Laplace，出来的是绝对误差损失。损失函数与噪声模型的这层对应关系，见\hyperref[sec:13-Machine-Learning/01-Learning-Problems-and-Evaluation/03]{``目标函数与噪声模型的对应：从生成机制到优化目标''}。

这个视角有实际用处：选损失函数就是在声明噪声的分布。谁都知道平方损失怕离群点，从似然角度看原因是明摆着的——高斯尾巴衰减太快，一个远点在它眼里概率低到必须靠挪动整条曲线来解释。想要稳健，就换一个厚尾的噪声模型，Huber 损失差不多就是这么来的。

MLE 还有一条性质在工程上很省事：参数变换下不变。若 \(\eta=g(\theta)\) 是一一映射，则 \(\hat\eta_{\mathrm{MLE}}=g(\hat\theta_{\mathrm{MLE}})\)。换参数化只是给同一族分布换标签，似然的排序不会变，所以不必为 \(\log\sigma\) 和 \(\sigma\) 各优化一次。下一节的 MAP 没有这条性质，原因也在下一节交代。

\subsection{渐近最优是一张大样本的期票}

回到那张图。峰的宽度按 \(1/\sqrt{n}\) 收缩，这个速率是有定理撑着的。在一组正则条件下——真参数落在参数空间内部、密度对参数光滑、模型可识别、Fisher 信息有限且非奇异——MLE 一致，且

\[
\sqrt n\,(\hat\theta_n-\theta_0)\overset{d}{\longrightarrow}N\bigl(0,\,I(\theta_0)^{-1}\bigr).
\]

\(I(\theta_0)\) 是 Fisher 信息，等于对数似然曲率的期望，也就是那条曲线在峰附近有多陡。曲率大意味着稍微挪动参数似然就掉得厉害，数据把参数钉得紧；曲率平意味着一大片参数值对数据的解释力差不多，估计自然晃。这条链路的严格版本在\hyperref[sec:11-Mathematical-Statistics/03-Sufficient-Statistics-and-Information/02]{``Score 与 Fisher 信息衡量局部可辨认性''}里展开。渐近方差 \(I(\theta_0)^{-1}/n\) 恰好达到 Cramér--Rao 下界，所以 MLE 渐近有效，见\hyperref[sec:11-Mathematical-Statistics/03-Sufficient-Statistics-and-Information/03]{``Cramér--Rao 界给无偏估计设下限''}。

一致、渐近正态、渐近有效，三条听起来无懈可击，但它们都带一个前缀。正态方差那个 \(-\sigma^2/n\) 的偏差就在这里：渐近上它趋于零，\(n=10\) 时它是一成。承诺在 \(n\to\infty\) 处兑现，报表交付在 \(n=10\) 处。

前提失效的场合也不少见。真参数落在边界上时（方差分量为零、混合权重为零），Taylor 展开的前提就没了，抽样分布不再是正态。混合模型和隐 Markov 模型的分量标签可以互换，参数不可识别，信息矩阵奇异。高维回归里参数维度随 \(n\) 一起长，经典渐近框架整个不适用。模型错设时 MLE 仍会收敛，但收敛到 KL 散度意义下最接近真实分布的那个伪真参数，此时 \(I^{-1}\) 给出的方差是错的，需要三明治估计做修正。把``大样本下 MLE 渐近正态''当口号背，等于把这一串前提一起丢掉。

\subsection{峰可能不存在，也可能不止一个}

最大似然是个优化问题，优化问题的通病它一样不少。

Gaussian 混合模型有一个著名的病态：让某个分量的方差趋于零、均值对准某个样本点，那一点的密度可以任意大，似然发散到无穷。这个模型的 MLE 不存在。优化器一路往下跑不停，日志上看是损失持续下降，看着像训练顺利。这类症状和\hyperref[sec:09-Convex-Optimization/07-Applications/01]{``光滑经验风险与 \(L_2\) 正则化''}里线性可分时 logistic 回归参数范数发散是同一种毛病——凸性或光滑性保证不了最优解存在，需要额外的约束或惩罚把解拉回有限处。

非凸和多峰则是复杂模型的常态。算法停在一个驻点，只说明梯度小了，不说明这是全局峰。多组初值、profile likelihood、把似然面沿着关心的那几个方向切一刀画出来，都是必要的功课。报告里区分开``算法没找到''和``峰根本不存在''，比报告一个终止时的参数值有用得多。

至此估计量完全由数据决定：似然峰在哪儿，答案就在哪儿。可实际工作中，动手之前往往已经知道点什么——退货率不会是 \(0\%\)，回归系数不会大到 \(300\)，某个分组的转化率大概率贴近全站均值。本单元开头那个把估计往全站均值拉一半的做法，是把这类信息硬塞进估计量；下一节给它一个正式的位置：把先验乘进似然，再取峰。
