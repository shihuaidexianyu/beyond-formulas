\section{参数未知，而统计量随机}
\label{sec:11-Mathematical-Statistics/01-Statistical-Models/02}

上一节我们建立了一个模型：\(X_1,\ldots,X_n\) 来自某个 \(P_\theta\)。但 \(\theta\) 是多少？你不知道。你只能看到数据，只能从数据里算出一个数，希望这个数离 \(\theta\) 不太远。

手算 \(92/100 = 0.92\)，这个动作花了两秒。问题在于：如果你明天再抽 100 件，可能得到 88 件合格，后天可能是 95 件。0.92 变成了 0.88 又变成 0.95。每次算出来的都不一样。生产线没有变化——同一批工艺、同一种原材料——变化的不是现实，是你的样本。

那你凭什么相信今天的 0.92？

这是统计推断的核心困境：参数是固定的但我们看不到，能看到的东西又在波动。解决方案不是消除波动——波动是抽样的自然产物——而是理解波动、量化波动、利用波动来评价推断规则。

在经典频率学派表述中，参数 \(\theta\) 是固定但未知的数。它不会因为换了一次样本就改变数值。会改变的是你从样本中算出的任何量——这些量叫统计量。

统计量是样本的函数：
\[
T = T(X_1,\ldots,X_n),
\]
且定义中不能出现任何未知参数。样本均值 \(\bar X = \frac{1}{n}\sum_i X_i\) 是统计量：你知道 \(n\)，知道每个 \(X_i\) 的观测值，就能直接算出。表达式 \(\bar X - \theta\) 不是统计量——你没法算，因为 \(\theta\) 未知。\(\bar X / \sigma\)（\(\sigma\) 未知时）也不是。这一点看似简单，但在检验和区间构造中反复出现：一个量能不能从数据中直接计算，决定了它能扮演什么角色。

但``统计量''是一个很宽泛的概念。样本均值是统计量，样本最大值也是统计量，第一个观测 \(X_1\) 也是统计量——任何不依赖未知参数的数据函数都算。显然不是每个统计量都有用。把 \(X_1\) 当成 \(\theta\) 的估计，技术上合法，结果上糟糕。

\subsection{估计量是带有任务的统计量}

当一个统计量被用来估计某个参数或参数的函数时，称为估计量。通常记作：
\[
\hat\theta = T(X_1,\ldots,X_n).
\]
观测到具体数据 \(x_1,\ldots,x_n\) 后，它取到一个数值：
\[
\hat\theta_{\mathrm{obs}} = T(x_1,\ldots,x_n),
\]
这个数叫估计值。

同一个公式，观测前是随机变量，观测后是数值。偏差、方差、覆盖率讨论的是估计量在重复抽样中的分布——``用这个方法，长期来看会怎样''。而``这个估计值有一个方差''是语法错误：\(92/100\) 是固定数，没有方差。有方差的是计算它的那个规则，在重复抽样中的表现。

\subsection{Bernoulli 样本中的三层对象}

把上一节的 92/100 放回模型：
\[
X_i\overset{\mathrm{iid}}{\sim}\operatorname{Bernoulli}(\theta).
\]
这里有三层不同的对象：

\begin{itemize}
\tightlist
\item 参数 \(\theta\)——生产线真实的合格概率。固定，未知。你永远不会直接看到它。
\item 统计量 \(S = \sum_i X_i\)——合格件数。随机，因为样本随机。在重复抽样中，\(S\) 可能是 88、92 或 97，服从 Binomial(\(n,\theta\))。
\item 估计量 \(\hat\theta = \bar X = S/n\)——合格率。也是随机，因为它由随机统计量计算而来。用它来估计 \(\theta\)。
\item 估计值——这次实际看到 \(S=92,\ n=100\)，所以 \(\hat\theta_{\mathrm{obs}} = 0.92\)。一个数，不再随机。
\end{itemize}

每次重复抽样时，\(S\) 在变，\(\hat\theta\) 在变，但 \(\theta\) 保持同一个固定值。统计推断研究的就是：在重复抽样中，\(\hat\theta\) 围绕 \(\theta\) 的波动有多大，系统性偏多少，平均误差多少。这些问题的答案构成了我们评价估计方法的语言——偏差、方差、MSE、覆盖率，全都建立在这个三层区分之上。

Bayesian 方法走另一条路：给参数 \(\theta\) 指定先验分布，让参数也成为一个随机变量。两种框架的概率陈述针对不同的对象——频率学派讨论估计量在重复抽样中的分布性质，Bayesian 讨论参数在给定数据后的条件分布。不能把``固定未知参数''和``后验随机变量''的概率陈述混写在一个句子里。

\subsection{参数可以是向量、函数或预测目标}

参数不限于一个数。它可以是：
\begin{itemize}
\tightlist
\item 正态模型中的 \((\mu,\sigma^2)\)——位置和尺度两个数；
\item 回归系数向量 \(\beta\)；
\item 协方差矩阵 \(\Sigma\)；
\item 生存函数或密度函数本身——``无限维''参数；
\item 两组均值差、风险比等参数函数 \(g(\theta)\)——不直接估计 \(\theta\)，而是估计它的一个变换。
\end{itemize}

大多数分析只关心其中某一个分量。其余未知量称为干扰参数。估计正态均值时，方差 \(\sigma^2\) 也是未知的——你不想报告方差，但方差会进入均值估计的标准误。忽略干扰参数的不确定性，你会低估最终结论的变异性。

有时候，任务根本不是``恢复真实参数''，而是预测新观测。预测明天产品的合格概率和估计生产线的长期合格率是两个不同的问题，评价标准也不该相同。前者的损失函数是预测误差，后者是估计误差。在同一个模型内，最优估计量不一定是最优预测。

\subsection{数据压缩会保留什么}

每个统计量都把一个完整的 \(n\) 维样本压缩成几个数字。样本均值把顺序、极端值、离散程度全部扔掉，只保留平均位置。直方图保留更多，但不如原始数据精确。

压缩是好是坏，取决于丢掉的东西里有没有关于参数的信息。对于 Bernoulli iid 模型，\(S = \sum_i X_i\) 包含了关于 \(\theta\) 的全部似然信息：知道成功出现在哪些位置，对推断 \(\theta\) 没有任何额外帮助。这就是充分统计量的直觉——\(S\) 已经``足够''了，原始数据中其余的结构纯属噪声，不影响我们对参数的判断。后面会严格定义这句话。

反过来，如果只保留样本均值，你就没法估计方差——离散程度的信息全丢了，它不在均值里。统计量的选择必须服务于推断任务。你要估计什么，就应该保留什么信息。

\subsection{``无未知参数''也有语境}

统计量的公式不能使用未知参数，但可以使用已知设计量、固定样本量、已知方差或给定的超参数。比如已知 \(\sigma\) 时，
\[
\frac{\bar X - \mu_0}{\sigma/\sqrt{n}}
\]
在检验原假设 \(H_0:\mu=\mu_0\) 时可以计算——\(\mu_0\) 是原假设指定的值，不是未知真值。

但如果你先用数据估计了一个超参数——比如用样本方差代替 \(\sigma^2\)，或者用交叉验证选 \(\lambda\)——然后把它当成固定已知量做后续推断，你就忽略了第一步估计引入的额外不确定性。数据驱动阈值、模型选择后的推断、经验 Bayes——这些做法在第二步的条件化中都可能低估变异性。你已经用数据做了一次选择，再假装没做过，置信区间就会过窄。
