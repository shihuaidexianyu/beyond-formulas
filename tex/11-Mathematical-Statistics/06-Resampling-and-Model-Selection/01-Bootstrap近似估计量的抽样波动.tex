\section{Bootstrap 近似估计量的抽样波动}
\label{sec:11-Mathematical-Statistics/06-Resampling-and-Model-Selection/01}

你手头有 \(n\) 个 iid 观测

\[
x_1,\ldots,x_n\sim F,
\]

算出了一个估计量

\[
\hat\theta=T(x_1,\ldots,x_n).
\]

现在你需要报告这个估计的标准误。均值有 \(s/\sqrt{n}\)，线性回归系数有公式，但你的 \(T\) 是一个复杂的非线性统计量——比如中位数、分位数、相关系数、或者某个你自己拼出来的指标。标准误的解析表达式不存在，手工推导可能要花几页纸，还容易出错。

数据只有一批，但你想知道如果重新采样，\(\hat\theta\) 会在多大范围内波动。这就是 bootstrap 要解决的问题。

\subsection{困局：真实分布 \(F\) 未知}

抽样的逻辑是：从 \(F\) 独立抽取样本，算出 \(\hat\theta\)；重复很多次，看 \(\hat\theta\) 的抽样分布。问题是 \(F\) 未知——你只知道它生成了你手里的这批数据，但不知道它的具体形状。没有 \(F\)，就没法从它抽样，也就没法模拟抽样分布。

一种思路是假设一个参数模型 \(F_\theta\)，用数据估计 \(\hat\theta\)，再从 \(F_{\hat\theta}\) 抽样。这就是参数 bootstrap。如果模型设定正确，它可能很高效。但如果模型错了——比如你假设正态，真实分布却是重尾的——你会精确地重现错误模型的波动模式，而不是真实数据的波动模式。

另一种思路更直白：既然 \(F\) 未知，那就用你有的东西来替代它。你能看到的最接近 \(F\) 的东西是什么？就是你手里的这批数据本身。

\subsection{直觉：把数据当成总体}

这个想法就是非参数 bootstrap 的核心。用经验分布函数

\[
\hat F_n = \frac1n\sum_{i=1}^n\delta_{x_i}
\]

替代未知的 \(F\)。这里的 \(\delta_{x}\) 是集中在点 \(x\) 上的点质量分布——也就是说，\(\hat F_n\) 把总概率 \(1\) 平均分配给 \(n\) 个观测值，每个分得 \(1/n\)。

然后做什么？从 \(\hat F_n\) 独立抽取大小仍为 \(n\) 的样本：

\[
x_1^\star,\ldots,x_n^\star \sim \hat F_n\quad\text{iid}.
\]

这个操作等价于从原始数据中做 \(n\) 次有放回抽取。每个 bootstrap 样本中，某些原始数据点可能出现多次，某些可能完全不出现。对这个 bootstrap 样本计算统计量

\[
\hat\theta^\star = T(x_1^\star,\ldots,x_n^\star),
\]

重复 \(B\) 次，得到 \(\hat\theta^{\star1},\ldots,\hat\theta^{\star B}\)。这些 bootstrap 统计量的条件分布（条件于已观测数据）用来近似 \(\hat\theta\) 的真实抽样分布。

整个逻辑链只有两步：（1）用经验分布替代真实分布；（2）用模拟替代解析推导。每一步都是一种近似，但合在一起通常效果不错。

\subsection{为什么必须有放回且样本量不变}

这两个条件不是任意的，背后各有理由。

有放回是经验分布 iid 抽样的直接推论。\(\hat F_n\) 把每个观测值赋予概率 \(1/n\)，从中独立抽取，自然允许同一个点被重复抽到，也允许某些点被遗漏。如果无放回抽取 \(n\) 个点，每次只会得到原数据的一个排列——对那些对顺序不敏感的统计量（均值、中位数等），bootstrap 样本的统计量完全相同，完全模拟不了抽样波动。你本来想看"数据变了估计会怎么变化"，如果每次"新"数据只是原数据的排列，你什么都看不到。

保持样本量 \(n\) 是为了让估计问题的尺度不变。真正的估计问题是"从 \(F\) 抽取 \(n\) 个样本算 \(\hat\theta\)"，bootstrap 模仿的是同一个操作——只是把 \(F\) 换成了 \(\hat F_n\)。如果改变样本量，标准误会跟着变化，你测出来的波动就不再对应原始问题。注意有一种变体叫 \(m\)-out-of-\(n\) bootstrap，它故意用不等于 \(n\) 的样本量，目的是处理某些非正则情形（比如参数在边界上），那是有意为之的修正，不能和普通 bootstrap 混用。

\subsection{标准误与偏差估计}

有了 \(B\) 个 bootstrap 统计量，标准误就是它们的样本标准差：

\[
\widehat{\SE}_{\mathrm{boot}} = \sqrt{
\frac{1}{B-1}
\sum_{b=1}^B
\left(
\hat\theta^{\star b}
-\bar{\hat\theta^\star}
\right)^2
},
\qquad
\bar{\hat\theta^\star}= \frac1B\sum_{b=1}^B\hat\theta^{\star b}.
\]

偏差也可以估计：

\[
\widehat{\Bias}_{\mathrm{boot}} = \bar{\hat\theta^\star}-\hat\theta.
\]

这里的均值和标准差都条件于已观测数据。Bootstrap 假设经验分布 \(\hat F_n\) 已经足够接近真实分布 \(F\)，使从 \(\hat F_n\) 重抽样能够复现从 \(F\) 抽样的主要波动模式。

拿样本均值检验一下这个想法。条件于数据，\(x_i^\star\) 从 \(\hat F_n\) iid 抽取，因此

\[
\Var^\star(\bar x^\star)
= \frac1n \cdot \frac1n\sum_{i=1}^n(x_i-\bar x)^2
= \frac{n-1}{n}\cdot\frac{s^2}{n}.
\]

Bootstrap 自动给出了 \(s^2/n\) 的 \(\frac{n-1}{n}\) 倍——只差一个有限样本修正因子，在 \(n\) 很大时几乎就是标准答案。对样本均值这种有解析公式的简单统计量，bootstrap 没有带来新发现；但把它验证你能用的那些工具换到复杂的非线性统计量上，同样几步标准操作就能得到标准误，省掉了繁重的推导。

\subsection{几种区间并不等价}

得到标准误只是第一步，你通常还需要置信区间。下面四种区间构造不同，覆盖性质也不同。

最简单的 normal interval 假设 \(\hat\theta\) 近似正态：

\[
\hat\theta
\pm
z_{1-\alpha/2}
\widehat{\SE}_{\mathrm{boot}}.
\]

它共享了正态区间的所有优点和风险：对称、简单，但遇到偏斜分布时覆盖不对。

Percentile interval 直接取 bootstrap 统计量的经验分位数：

\[
\left[
q^\star_{\alpha/2},
q^\star_{1-\alpha/2}
\right].
\]

它不假设对称或正态，允许区间自动适应偏斜。背后的直觉是：bootstrap 统计量分布的形状反映了估计量的真实抽样分布形状。如果 \(\hat\theta\) 的抽样分布向右偏，bootstrap 分位数区间也会向右偏。

Basic interval 用另一种直觉构造。它把 bootstrap 误差 \(\hat\theta^\star-\hat\theta\) 的分布当作 \(\hat\theta-\theta\) 分布的镜像。既然 \(q^\star_{1-\alpha/2}-\hat\theta\) 是 bootstrap 误差的上界，参数 \(\theta\) 的下界就应该取

\[
\hat\theta-(q^\star_{1-\alpha/2}-\hat\theta)=2\hat\theta-q^\star_{1-\alpha/2},
\]

于是得到

\[
\left[
2\hat\theta-q^\star_{1-\alpha/2},
2\hat\theta-q^\star_{\alpha/2}
\right].
\]

这层镜像假设是直觉构造，合理性依赖于"误差分布对称地反映在参数两侧"这个近似成立，不是恒等式。

BCa interval 进一步修正偏差（bias）和加速度（acceleration，标准误随参数真值变化的速率），常有更高阶的覆盖性质。但实现需要的额外计算和假设也更多。

不能因为"用了 bootstrap"就宣称区间覆盖正确。不同区间对偏斜、参数变换和边界的表现不一样，选择哪种区间需要结合具体问题做判断，或用模拟研究来确认。

\subsection{Bootstrap 会在哪里失败}

经验分布只能从已有数据中重抽，不能生成样本范围之外的新值。考虑一个尖锐的例子：\(x_1,\ldots,x_n\sim\mathrm{Uniform}(0,\theta)\)，估计量是样本最大值 \(\hat\theta = \max_i x_i\)。所有 bootstrap 样本的最大值都不可能超过已观测到的最大值，因此 bootstrap 分布完全没有捕捉到真实抽样中未来最大值可能更大的右侧波动。这是非光滑边界统计量的典型失败。

其他困难场景包括：

\begin{itemize}
\tightlist
\item
  样本极小，经验分布过于离散，每个 bootstrap 样本几乎就是原始数据的若干份拷贝，提供不了足够的变异；
\item
  重尾分布导致均值或方差不稳定，bootstrap 本身也需要这些矩的存在才能表现良好；
\item
  参数位于边界（比如方差估计为零），bootstrap 分布退化为边界附近的退化分布；
\item
  统计量在真实分布处不光滑——比如最大值、最小值、分位数附近——经验分布的离散性会放大不光滑的影响；
\item
  先做了模型选择（选变量、选模型形式），再对选出的模型做普通 bootstrap——选择步骤在重抽样循环之外，bootstrap 不知道选择过程本身的波动；
\item
  时间序列、空间数据或聚类数据却逐行 iid 重抽，破坏了数据内部的依赖结构。
\end{itemize}

对依赖数据，有 block bootstrap（把数据切成块，以块为单位有放回重抽）、cluster bootstrap（以聚类为单位重抽）等变体。它们保留的依赖单位必须与数据生成机制一致——对时间序列用逐行重抽，相当于假设独立，把序列信息的价值全部浪费了。

参数 bootstrap 走了另一条路：先拟合一个参数模型 \(F_{\hat\theta}\)，再从该模型生成数据。如果参数模型大致正确，这种做法的方差可能更小；但如果模型错了，bootstrap 会精确地重现那个错误模型的特征，而不是真实数据生成过程的特征。两种 bootstrap 的选择，是在"非参数稳健但可能粗糙"与"参数平滑但可能偏倚"之间做权衡。

\subsection{\(B\) 只控制 Monte Carlo 误差}

初学者容易把 \(B\) 当成万能旋钮——觉得多跑几次 bootstrap，问题就会变好。实际上需要区分三层误差：

\begin{itemize}
\tightlist
\item
  原数据的抽样误差：你只有 \(n\) 个观测，样本本身可能不具代表性。再多的 bootstrap 重复也无法弥补原样本太小或抽样有偏；
\item
  用经验分布近似真实分布的误差：\(\hat F_n\) 本身只是 \(F\) 的一个近似。样本量 \(n\) 决定了这个近似有多好，\(B\) 与此无关；
\item
  有限 \(B\) 带来的 Monte Carlo 误差：bootstrap 只跑了 \(B\) 次，不是无穷次。\(B\) 越大，Monte Carlo 噪声越小，但不会让前两层误差消失。
\end{itemize}

实践中，标准误估计通常 \(B = 200\) 左右就足够稳定；置信区间如果需要比较精确的分位数，通常推荐 \(B = 1000\) 或更多。报告时应写清楚随机种子、\(B\) 的值、重抽单位（逐行还是分块）和区间类型，结果才能复核。只写一个"bootstrap 区间"，等于没说。
