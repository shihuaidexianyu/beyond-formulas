\section{置换检验依赖可交换性}
\label{sec:11-Mathematical-Statistics/06-Resampling-and-Model-Selection/02}

新的召回策略灰度给一半用户，跑了两周，实验组人均消费比对照组高 \(3.2\) 元，每组 \(600\) 人。问题跟上一节不同：这次要的不是误差范围，而是一个判决——这 \(3.2\) 元能不能用``分组恰好分成这样''解释掉。

顺手的做法是两样本 \(t\) 检验。但这个指标的形状很难看：九成用户两周内一分钱没花，剩下一成里又有几个人贡献了大半流水。零堆积加上极长的右尾，样本均值的正态近似收敛得很慢，\(n=600\) 未必够；何况偶尔冒出来的大额订单会同时把均值和 pooled 方差顶上去，\(t\) 统计量的分母跟着分子一起动。查表得到的那个 \(p\) 值，可信度取决于一条你没法验证的近似。

换一个入口。如果新策略毫无作用，每个用户这两周花多少钱是他自己的事，跟他被分到哪一组无关。那么``实验组''和``对照组''这两个标签，不过是随机分配器贴上去的：数值固定，标签随机。既然如此，你可以自己再贴一次——把 \(1200\) 个用户的组标签打乱重贴，重算一次组间差；重复几万次，就得到了``策略无效时，这个差会长成什么样''的分布。观测到的 \(3.2\) 元落在这个分布的哪一带，就是你要的判决。

\subsection{零分布是数出来的，不是查出来的}

把统计量记作

\[
T=\bar Y_{\text{treat}}-\bar Y_{\text{ctrl}},
\]

原始标签给出 \(T_{\mathrm{obs}}\)。设 \(\pi\) 遍历所有把 \(1200\) 个用户切成两个 \(600\) 人组的方式，双侧 \(p\) 值就是

\[
p=\frac{\#\set{\pi:\abs{T^\pi}\ge\abs{T_{\mathrm{obs}}}}}{\#\set{\text{全部 }\pi}}.
\]

这个式子里没有任何分布假设，只有计数。代价是 \(\binom{1200}{600}\) 这个数大到没法枚举，于是改成随机抽 \(B\) 个排列做 Monte Carlo 近似，

\[
\hat p=\frac{1+\#\set{b:\abs{T^{\pi_b}}\ge\abs{T_{\mathrm{obs}}}}}{B+1}.
\]

分子分母各加一，是把原始那次分配也算作一个排列——它本来就在排列集合里。少了这一项，当 \(B\) 次重排都没超过 \(T_{\mathrm{obs}}\) 时输出会是 \(p=0\)，而跑了一万次没见到并不能支持``概率为零''这种断言。加一之后 \(p\) 的下限是 \(1/(B+1)\)，正好对应你实际付出的模拟精度。

\subsection{打乱的合法性来自可交换性}

图右边那两条曲线是同一份数据算出来的，差别只在打乱的单位。灰度按公司发放时，同一家公司的用户共享一个标签，他们的消费也因为同处一个行业、一套采购流程而彼此相关。逐行打乱把这些用户拆开分到两组，抵消掉了组内的共同波动，于是零分布收窄——真实的机制根本掷不出这么整齐的分配。正确的做法是以公司为单位整体置换：随机化怎么发生，排列就怎么生成。

这条对应关系可以逐个设计地写下来。分层随机化的实验里，置换限制在每一层内部进行，跨层交换等于假装层间差异不存在。配对设计（同一个 prompt 由两个模型版本各答一次、同一批用户前后各测一次）里可交换的不是个体而是配对内部的两个位置，做法是对每一对独立地以 \(1/2\) 概率翻转符号，参照分布有 \(2^n\) 个点，把甲的读数贴到乙头上则是无中生有。时间序列里相邻时刻本来就相关，任意打乱等价于宣称序列独立，得到的零分布同样太窄；此时要么按块置换（切成长度为 \(\ell\) 的块，以块为单位重排，\(\ell\) 需覆盖自相关的衰减尺度），要么先建模去掉依赖再对残差置换。不等概率抽样或按流量分层的实验里，均匀随机地重排也是错的，排列必须按照实际投放方案的概率分布生成。

推荐与搜索场景里这些结构几乎总是同时出现：同一个用户贡献多条曝光，同一个物品出现在很多用户的列表里，同一天的流量共享一次运营活动。任何一维上的分组没被尊重，\(p\) 值就会偏小，而偏小的方向恰好是让你更愿意上线的方向。一个便宜的自检是拿 A/A 数据跑一遍：把没有任何差异的两段流量按你打算用的置换方案检验若干次，\(p\) 值应当大致均匀分布，显著的比例应当接近名义水平。若 \(5\%\) 的阈值实际拒绝了 \(20\%\)，问题一定出在置换单位上。

所以``非参数''不等于``无假设''。参数检验押的是分布形状，置换检验押的是一种对称性；一条假设换成了另一条，只是后者常常可以由实验设计本身来保证，而不必从数据里祈求。

\subsection{Sharp null 与平均效应不是同一个原假设}

还有一层更细的错位。置换检验的精确性建立在 sharp null 上：每一个用户的处理效应都恰好为零，张三分到哪一组，他这两周的消费数字都一模一样。只有这样，每个人的取值才是一个与标签无关的常数，你才能为任意一种标签分配填出对应的数据集。

``平均处理效应为零''是一个弱得多的命题。它允许新策略让一部分人多花、另一部分人少花，加总起来抵消。此时张三的数值随标签变化，重贴标签得到的数据集不再与原数据同分布，置换分布也就不再精确校准。异质性越强、两组方差差得越多，偏离越明显。常见的补救是把统计量学生化，即用组间差除以它自己的标准误再做置换，这样在效应异质或方差不等时仍能保住渐近水平；未学生化的均值差在方差不等的两组上会失准。

两样本标签置换严格检验的命题是``两组的分布完全一致''，而不是``两组的均值一致''。分布形状不同却均值相同时它照样会拒绝，这在报告里必须说清楚，否则读的人会把``分布有差异''读成``策略提升了消费''。潜在结果、平均处理效应与识别条件的系统讨论见\hyperref[ch:120]{``因果推断：预测世界不等于改变世界''}。

\subsection{统计量选定的那一刻功效就定了}

置换检验对第一类错误的控制来自计数，几乎无懈可击。它不附赠功效。功效取决于你选的 \(T\) 是否对你真正关心的那种差异敏感。

均值差擅长发现整体平移。假如新策略并不让每个人多花一点，而是把少数高价值用户的消费翻了一倍、其余人毫无变化，那么这点效应在均值差里会被大量不动的观测稀释，尤其在重尾数据上，几个大额订单的位置本来就在两组之间乱跳。此时秩和统计量对单调偏移更稳，分布距离型的统计量（energy distance、maximum mean discrepancy）能捕捉形状差异，按分位数分别比较则能定位效应落在哪一段。选哪一个，取决于你事先相信效应长什么样。

关键在于``事先''。看了数据之后试遍均值差、中位数差、秩和，再挑 \(p\) 值最小的那个报告，置换程序就必须把这个挑选动作也重排进去，否则报出的 \(p\) 值系统性偏小。这不是置换特有的毛病，任何检验框架下都一样，见\hyperref[sec:11-Mathematical-Statistics/05-Hypothesis-Testing/04]{``多重比较改变错误的计量单位''}。

\subsection{它和 bootstrap 回答的是不同的问题}

两种方法都在摆弄同一份数据，逻辑却是分开的。上一节的 bootstrap 有放回地重抽观测，模仿``再采一批数据''，输出的是估计量的波动尺度，用于标准误和置信区间。置换只重排标签、不动观测值，模仿``随机化机制再掷一次''，输出的是原假设下的参照分布，用于检验。前者要求经验分布接近真实分布，后者要求原假设下标签可交换。

把重抽样那行代码换成置换、或者反过来，得到的数不能承担对方的解释。实践中两者常常配套出现：置换给出是否有差异的判决，bootstrap 给出差异有多大的区间，而后者才是决定要不要上线的那个数。

\subsection{从判决回到流程}

置换检验把``分布形状''换成了``随机化结构''，前提也随之从数据的性质变成了实验的组织方式。这一节的落点是：置换的单位必须与随机化的单位一致，而这件事在实验设计的时候就已经定下来了，事后无法靠更聪明的统计量补救。

下一节把同样的追问搬到另一处：交叉验证里被切开的那份数据，同样要求划分单位与依赖结构对得上；而那里还多出一个更常见的事故——如果标准化、特征选择、超参搜索发生在划分之前，切分线就已经被穿透了。
