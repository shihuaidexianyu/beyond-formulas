\section{三类典型方程行为迥异}
\label{sec:15-Differential-Equations-and-Dynamical-Systems/03-PDE-Introduction/02}

热方程 \(\partial_t u = \kappa\partial_{xx}u\)，波动方程 \(\partial_{tt}u = c^2\partial_{xx}u\)，Laplace 方程 \(\partial_{xx}u+\partial_{yy}u=0\)。三个方程的空间项几乎长一个样——都有二阶空间导数——只是时间项不同：一阶、二阶、没有时间。这一点差别，把它们的解推向了三种完全不同的物理命运。与其先记公式再按图索骥，不如反过来：从时间导数的阶数预判行为，再用解的结构做验证。

\subsection{热方程：高频先死，正则性瞬间变好}

把一根铁棒的一端烧到 100 度，另一端保持 0 度。\(t=0\) 时温度分布是一段 100、一段 0，分界处几乎是阶梯。几秒后去看：分界模糊了，尖锐的跳变已经消失，温度曲线变得光滑。再过几分钟，整根棒子趋向一个温和的线性过渡。

这不是物理想象的附会，是方程 \(\partial_t u = \kappa\partial_{xx}u\) 的数学结构带来的必然结果。在周期边界下试一个正弦分量 \(u(t,x)=T(t)\sin(kx)\)：

\[
T'(t)\sin(kx) = -\kappa k^2 T(t)\sin(kx),
\qquad
T(t) = e^{-\kappa k^2 t}T(0).
\]

波数 \(k\) 越大，衰减率 \(\kappa k^2\) 越大——而且是平方级放大。\(k=1\) 衰减率 \(\kappa\)。\(k=10\) 衰减率 \(100\kappa\)。\(k=100\) 衰减率 \(10000\kappa\)。高频毛刺在极短的时间内被压到肉眼看不见。\hyperref[sec:08-Numerical-Analysis/08-Fourier-and-Spectral-Methods/01]{``从 Fourier 级数到连续变换''} 中，光滑性对应高频系数衰减是一条被动规律——函数光滑，系数自然掉得快。热方程是一条主动规律——它不管你初始数据光不光滑，它强制制造高频衰减，使得解在任意 \(t>0\) 的时刻都变成 \(C^\infty\)。哪怕初值只是分段连续，一瞬间后解就无限可微。方程本身就是一个平滑滤波器。

\textbf{最大值原理}提供了第二条结构保证。杆上任何时刻的最高温度只可能出现在 \(t=0\) 的初始分布或两端边界，不可能在内部某处凭空冒出一个比四周都热的点。无热源时，最热的地方只会变凉，不会自发升温。这条原理不是直观陈述——它是热方程的严格定理，给解提供先验上界，也是唯一性和稳定性证明的多用途工具。

冰水混合是浓缩版的现场演示：刚放入冰块时，冰水交界处温度梯度极大（高频分量丰富）。两分钟后交界处最先变得模糊——高频被速度最快地衰减。五分钟后整杯水的温度分布已相当平滑。最终趋于均匀——只剩 \(k=0\) 的常数模式。

\subsection{波动方程：有限速度，原样搬运}

拨一下吉他弦。指尖捏出的三角形初始形状——带一个尖角——分成两半，各沿琴弦跑向两端，在端点反弹，回来，再反弹。整个过程中尖角始终是尖的。没有变圆，没有变模糊，没有变矮。

一维波动方程 \(\partial_{tt}u = c^2\partial_{xx}u\) 的通解（d'Alembert 公式）精确描述了这一行为：

\[
u(t,x) = F(x-ct) + G(x+ct),
\]

一个向右跑的形状 \(F\) 和一个向左跑的形状 \(G\)，速度恒为 \(c\)。直接代入验证：\(\partial_{tt}u = c^2(F''+G'')\)，\(\partial_{xx}u = F''+G''\)，等式成立。初始形状的任何特征——包括尖角、间断、不光滑——都被原封不动地以速度 \(c\) 向两侧搬运。

与热方程形成两条尖锐的对照：

\begin{itemize}
\tightlist
\item
  \textbf{有限传播速度}：\(x=0\) 处的扰动需要 \(t=L/c\) 才能抵达距离 \(L\) 以外的位置。信息沿特征线 \(x\pm ct=\text{const}\) 传播，特征线以外的区域尚未被通知``有事情发生了''。热方程则相反——任何形式的解都显示初始扰动在 \(t>0\) 的瞬时对全空间有非零影响（尽管是指数级微小），``传播速度''无上限。
\item
  \textbf{正则性不增不减}：初始形状有尖角，解永远带着那个尖角。波动方程不制造光滑性，也不摧毁光滑性。你的解有多光滑，在上游（初始条件）已经完全决定。热方程是光滑性的生产者；波动方程是光滑性的搬运工。
\end{itemize}

池塘里丢石头是多维版本的同一行为：波纹以有限速度向外扩散，波前清晰锐利，波前之外的区域还是平的——信息沿波前传递，尚未到达的地方仍停留在初始的静止状态。

\subsection{Laplace 方程：无时间，无内部自由}

Laplace 方程 \(\Delta u = 0\) 没有时间变量。它描述种种稳态平衡：电势平衡、稳态热传导、不可压缩无旋流。两条结构性质完整打包了``平衡''的含义。

\textbf{均值性质}：调和函数在任一点的值，等于以该点为中心的任意球面（或球体）上的平均值。一维时最朴素：\(\partial_{xx}u=0\) 的解是直线，线段中点的值就是两端取平均。高维情况下，如果一个稳态温度场内某点比它周围的平均值更高，热量就会从高处向低处流动——不再是稳态。因此调和函数在内部任何位置都不能取严格的局部极大值或极小值。极值只能出现在边界。

\textbf{边界唯一决定内部}：给定区域边界上的值（Dirichlet 条件），调和函数在全区域内部被唯一确定。边界上每一处扰动都会影响内部所有点——但影响光滑地衰减。绷在弯曲铁框上的鼓面（在忽略张力细节的理想化下），静止后每一点的高度近似是它邻域的平均，整个鼓面形状被边框唯一决定。要改变鼓面内部，唯一的办法是改变边框——内部没有额外的自由度。

这两条——内部无局部极值、边界锁定全局——与热方程的最大值原理同源：``无源则内部无峰''在不同方程上的不同表达。热方程多了时间方向，把``边界''切成两部分：初始条件（时间的边界）和空间边界条件。

\subsection{分类：不是背名字，是预判行为}

二阶线性 PDE 按最高阶项的代数结构分为三类：

\begin{itemize}
\tightlist
\item
  \textbf{椭圆型}（Laplace \(\Delta u=0\)）：没有时间方向，一切空间方向地位平等。解在内部分析光滑（实解析）。适定的定解数据：边界条件。给它提初始条件是类型错误——没有时间方向，``初始''没有意义。
\item
  \textbf{抛物型}（热方程 \(\partial_t u = \kappa\Delta u\)）：时间一阶，空间二阶。时间方向特殊——向前抹平、向后病态。适定的定解数据：初始条件加边界条件。从末态反推初始是经典的病态问题——倒着解热方程时，高频不是 \(e^{-\kappa k^2 t}\) 衰减而是 \(e^{+\kappa k^2 t}\) 放大，对任何微小的末态误差指数级敏感。
\item
  \textbf{双曲型}（波动方程 \(\partial_{tt}u = c^2\Delta u\)）：时间二阶，空间二阶，时间与空间对称。扰动沿特征以有限速度传播。适定的定解数据：初始位置加初始速度——速度项提供``初始运动方向''这一额外自由度。只给初值不给初速度是信息不足。
\end{itemize}

判别式 \(b^2-ac\)（对 \(au_{xx}+2bu_{xy}+cu_{yy}+\cdots=0\)）统一了这套分类：负为椭圆，零为抛物，正为双曲。一个代数条件决定了全部定性行为——给什么数据、解多光滑、扰动怎么传播、什么情况下问题会病态。

数值方法的选择也追随着分类：抛物方程用隐式格式压制稳定性（高频衰减需要 \(A\)-稳定性），双曲方程必须尊重特征速度和 \hyperref[sec:08-Numerical-Analysis/06-ODE/03]{``稳定区域与刚性方程''} 中 CFL 条件的空间版本，椭圆方程通常转化为一次全局线性系统求解。

对变系数或非线性方程，类型可能在区域中变化。跨声速流动中，亚声速区呈椭圆行为（扰动双向传播），超声速区呈双曲行为（扰动沿 Mach 锥单向传播），声速线附近方程类型退化——单一数值格式无法全域同时稳定。流体仿真的多数困难最终都追溯到类型混合。

反过来也成立：你看到的数值行为可以反推方程的类型。迭代不收敛且残差全局震荡？可能是椭圆方程用了纯显式格式。解在某个方向上一旦算错就无法挽回？可能是双曲系统没有尊重特征的来向。时间反演对微小扰动极度敏感？几乎肯定是抛物方程在倒着解。数值崩溃很少是因为实现写错了加减号——更常见的原因是方案和方程的类型不匹配。

下一节把``适定''两字拆开：存在唯一连续依赖，各自怎样在三条典型方程上成立，条件不足时各自怎样以具体方式失败。
