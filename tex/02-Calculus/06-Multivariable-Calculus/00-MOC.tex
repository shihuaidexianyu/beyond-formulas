从单变量走向多变量，看似只是把变量从标量 $x$ 换成了向量 $\mathbf{x}$，但其背后的几何图景已经发生了根本性的质变。

在单变量微积分中，你只能在一根数轴上向左或向右移动，导数只是一个简单的标量斜率。但在多元微积分中，你正站在一座高低起伏的高维山峰之上：
\begin{itemize}
    \item \textbf{方向的暴胀}：脚下有无穷多个方向可以迈步，每个方向的陡峭程度（方向导数）都不尽相同；
    \item \textbf{变化的升级}：局部的线性近似不再是一个数，而是一个切平面（线性映射）；
    \item \textbf{累积的拓展}：积分不再只是曲线下的面积，而是发生在区域、曲线与曲面上的整体效应。
\end{itemize}

这些概念升级并非学究式的推演，它们直接构成了现代机器学习与优化理论的几何基石。在阅读本单元的九篇文章时，可以对照以下几条直觉主线：

\begin{enumerate}
    \item \textbf{为什么偏导数不够用？}\par
    只沿着坐标轴切片观察（偏导数），可能会完全错过地形在对角线方向的剧烈变化。只有当“切平面”存在时（可微性），局部线性近似才对所有方向同时有效——正因如此，梯度才配被称为最速上升方向。

    \item \textbf{梯度是如何被“尺子”决定的？}\par
    “最陡的下山方向”并不是偏导数的简单堆砌，它取决于你如何定义“一步”的距离（内积）。换用不同的度量，最速方向就会改变——逐坐标自适应（如 Adam）、预条件与自然梯度的核心区别，全在于选择了怎样的空间尺子。

    \item \textbf{链式法则的几何本质}\par
    高维函数的复合，本质上是线性映射的复合。矩阵乘法只是它在坐标系下的落地形式；而在计算图里选择先乘左边还是先乘右边（结合律），就直接决定了前向模式与反向传播的计算效率差距。

    \item \textbf{高维地形里的马鞍点}\par
    在高维空间中，山顶和山谷（极值点）极其罕见，大多数梯度归零的地方都是“鞍点”——在一个方向是山谷，在另一个方向却是山脊。区分它们，需要看 Hessian 矩阵在各个方向上的弯曲曲率（特征值）。

    \item \textbf{约束与惩罚的等价性}\par
    限制在曲面上行走（约束优化），相当于把“所有方向切线平坦”削弱为“只在切向平坦”。最优点处目标梯度与约束梯度必定共线，而 Lagrange 乘子正是约束条件在目标函数上的“影子价格”。

    \item \textbf{空间扭曲与体积伸缩}\par
    坐标变换不仅改变位置，还会拉伸空间。Jacobian 行列式正是这个局部体积的伸缩因子——概率密度变换时需要除以它，生成流模型（Flow-based Models）计算对数似然时累加的就是它的对数。
\end{enumerate}

后三篇则将视角转向累积：无论是区域上的多重积分、曲线上的做功，还是曲面上的通量，它们最终汇聚到一个极其优雅的几何事实——\textbf{区域内部无数微小的局部变化累积起来，正好等于边界上观察到的净效应}。Green、Gauss 和 Stokes 公式，不过是这句话在不同维度下的数学表达。
