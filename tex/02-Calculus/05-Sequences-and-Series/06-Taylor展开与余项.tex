\section{Taylor 展开与余项：匹配局部变化信息}
\label{sec:02-Calculus/05-Sequences-and-Series/06}

在优化算法中，牛顿法试图在当前点用一个二次多项式来拟合复杂的真实函数，然后直接``跳'到这个二次模型的最小值点。

但在实际运行中，经常会出现令人尴尬的一幕：这一跳之后，目标函数值反而暴涨了。

模型在当前点匹配得完美无缺——函数值、一阶梯度、二阶 Hessian 矩阵完全对得上。问题出在\textbf{跳得太远}，远到了模型已经完全无法代表原函数的区域。

信赖域（Trust Region）方法的应对策略很直接：给每一跳设定一个上限半径 \(r\)，只在这个半径内相信模型。那么，这个上限半径到底该设多大？

这不是一个靠经验调参的问题。它背后隐藏着一个深刻的数学提问：\textbf{一个只匹配了有限阶导数的多项式，在离开中心点多远之后，还值得我们信任？}

答案，全写在``余项'里。

\subsection{系数不需要猜：局部变化的强制绑定}

线性化只用到了函数值与一阶导数：\(P_1(x)=f(a)+f'(a)(x-a)\)。

如果我们希望多项式在 \(a\) 处的二阶、三阶直至 \(n\) 阶变化完全契合 \(f(x)\)，系数就会被逐一条款死死钉牢。最终唯一确定的多项式为：
\[
P_n(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k.
\]

阶乘 \(k!\) 的来源非常直观：当构造项 \((x-a)^k\) 被连续求 \(k\) 次导数后，在 \(x=a\) 处会产生一个系数 \(k!\)。为了让 \(P_n^{(k)}(a)\) 刚好等于 \(f^{(k)}(a)\)，就必须在系数里预先除掉这个 \(k!\)。

整个构造没有任何自由度：\(n\) 阶 Taylor 多项式，就是\textbf{前 \(n\) 阶导数在局部信息上的唯一完美拟合}。

然而，拟合得再完美，也仅仅局限在 \(a\) 这一个点上。一旦离开点 \(a\)，这个多项式会有多``不靠谱'？Taylor 多项式本身并没有回答这个问题。

\subsection{余项才是可信度的真实载体}

我们写下：
\[
f(x)=P_n(x)+R_n(x).
\]
这个等式本身只是一个定义式，毫无实质内容——真正的物理与工程价值，全在于我们能否给余项 \(R_n(x)\) 戴上一个\textbf{可控的紧箍咒}。

当 \(f\) 具备 \(n+1\) 阶连续导数时，Lagrange 余项给出了余项的精确结构：
\[
R_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1},\qquad \xi\ \text{介于}\ a\ \text{与}\ x\ \text{之间}.
\]

我们虽然不知道未知数 \(\xi\) 的具体位置，但只要在关心的区域内，\(n+1\) 阶导数存在一个上限 \(\abs{f^{(n+1)}} \le M\)，就能拿到一份可落地执行的\textbf{``误差预算上限'}：
\[
\abs{R_n(x)}\le\frac{M}{(n+1)!}\abs{x-a}^{n+1}.
\]

注意右边的两个关键变量，它们的角色完全不同：
\begin{itemize}
    \item \(\abs{x-a}^{n+1}\)：\textbf{偏离距离的 \(n+1\) 次方}。这是信赖域方法可以主动掌控的``步长旋钮'；
    \item \(M\)：\textbf{高阶导数的最大规模}。这是原函数自身的固性，你无法改变它，只能去估计它。
\end{itemize}

开头的牛顿法之所以会失败，正是因为偏离距离 \(|x-a|\) 太大，导致高次项 \(\abs{x-a}^{3}\) 的误差急剧膨胀，瞬间淹没了二次模型的拟合优势。

\subsubsection*{单摆模型的误差预算}

以单摆运动为例。物理学中常将小角度下的 \(\sin\theta\) 简化为线性项 \(\theta\)。这个近似到底在多大范围内有效？

取 \(a=0\)：由于 \(\sin\theta\) 的二阶导数在原点为 0，因此它的二阶 Taylor 多项式 \(P_2(\theta)\) 依然是 \(\theta\)。我们可以直接套用 \(n=2\) 的余项：
其三阶导数为 \(-\cos\theta\)，在全域绝对值最大不超过 \(M=1\)。于是：
\[
\abs{\sin\theta-\theta} \le \frac{1}{3!} \abs{\theta}^3 = \frac{\abs{\theta}^3}{6}.
\]
相对于主导项 \(\theta\)，其相对误差不超过 \(\theta^2 / 6\)：
\begin{itemize}
    \item 当摆角 \(\abs{\theta} = 0.1\text{ rad} \approx 5.7^\circ\) 时，误差上限不超过 \(0.17\%\)；
    \item 当摆角 \(\abs{\theta} = 0.5\text{ rad} \approx 28.6^\circ\) 时，误差上限暴涨到约 \(4.17\%\)。
\end{itemize}
误差随着角度的平方按抛物线迅速攀升。这份余项预算明确告诫我们：只要摆角超出 \(30^\circ\)，线性近似就会发生明显的工程偏离。

\subsubsection*{结清旧账：交错调和级数的极限闭环}

现在，我们可以把上一节留下的悬案彻底解决。
由 \(-\ln(1-x) = \sum \frac{x^n}{n}\) 替换变量 \(x \mapsto -x\)，可得：
\[
\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots,\qquad \abs{x} < 1.
\]
端点 \(x=1\) 正好处于收敛半径的边缘，不在常规幂级数定理的保护范围内。

现在用余项直接拿下它：对于 \(f(x) = \ln(1+x)\)，其 \(n+1\) 阶导数为 \(f^{(n+1)}(x) = \frac{(-1)^n n!}{(1+x)^{n+1}}\)。在区间 \([0, 1]\) 上，其最大值发生在 \(x=0\) 处，即 \(\abs{f^{(n+1)}(x)} \le n!\)。

代入余项公式：
\[
\abs{R_n(1)} \le \frac{n!}{(n+1)!} \cdot 1^{n+1} = \frac{1}{n+1} \xrightarrow{n \to \infty} 0.
\]
随着阶数 \(n \to \infty\)，余项无可辩驳地趋于零！于是：
\[
1 - \frac12 + \frac13 - \frac14 + \cdots = \ln 2.
\]
第一节预告的等式，在此正式实现逻辑闭环。

\subsection{半径之外：形式尚在，意义全无（Runge 现象）}

阶数越高，拟合就越精确吗？直觉往往在这里遭受重创。

考虑函数 \(f(x) = \dfrac{1}{1+x^2}\)。它在整个实数轴上极其光滑，没有断点，没有尖角，导数处处存在。然而，它在 \(a=0\) 处的 Taylor 级数展开式为：
\[
1 - x^2 + x^4 - x^6 + \cdots
\]
这本质上是一个公比为 \(-x^2\) 的等比级数，其收敛半径恰好是 \(R=1\)。

在 \(\abs{x} > 1\) 的区域，继续增加阶数不仅没有改善拟合，反而加速了模型的溃败。

既然 \(f(x)\) 在实数轴上完美无瑕，这个限制死死的 \(R=1\) 究竟是从哪里冒出来的？

在实数轴上找不到答案。我们需要将视线抬升到\textbf{复平面}：分母 \(1+x^2 = 0\) 在复平面上存在两个虚数根 \(x = \pm i\)。在这两个点上，函数值直接爆掉发散。

这两个奇点到展开中心 \(a=0\) 的距离，刚好是 \(\abs{0 - (\pm i)} = 1\)。

\textbf{收敛半径的本质，度量的是展开中心到``最近奇点'的距离。} 即便这个奇点隐藏在虚数维度，它依然像一根无形的绳索，死死锁住了实数轴上的收敛边界。

\subsection{级数收敛，也可能收敛到错误的地方}

如果一个函数的 Taylor 级数收敛半径是 \(\infty\)，是否就万事大吉了？依然不行。

看下面这个著名的``平坦陷阱'反例：
\[
f(x)=
\begin{cases}
e^{-1/x^2},&x\ne0,\\
0,&x=0.
\end{cases}
\]

当 \(x \to 0\) 时，\(e^{-1/x^2}\) 衰减的速度极其恐怖，它能瞬间``压制'任何多项式分母的增长。通过极限计算可以证明，这个函数在 \(x=0\) 处的\textbf{所有阶导数全部精确地等于零}：
\[
f(0) = 0,\quad f'(0) = 0,\quad f''(0) = 0,\quad \dots,\quad f^{(n)}(0) = 0.
\]

因此，它在 \(a=0\) 处的 Taylor 级数为：
\[
0 + 0x + 0x^2 + \dots \equiv 0.
\]
这个级数的收敛半径是 \(\infty\)，在整条实轴上收敛得极度完美。但在任何 \(x \neq 0\) 的点，原函数 \(f(x) = e^{-1/x^2} > 0\)，而级数的值却永远是 \(0\)。

\textbf{级数处处收敛，但收敛到的却是一个毫无关系的错误函数！}

这个例子逼迫我们必须清醒地将三件事严格区分开来：
\begin{enumerate}
    \item \textbf{局部匹配}：\(n\) 阶 Taylor 多项式在 \(a\) 点匹配有限阶导数（永远成立）；
    \item \textbf{级数收敛}：Taylor 级数作为一个幂级数，拥有自己的收敛半径 \(R\)（由系数决定）；
    \item \textbf{真值等价}：级数在收敛点上是否等于原函数，\textbf{必须由余项 \(R_n(x) \to 0\) 单独证明}。
\end{enumerate}

我们常见的展开式——\(e^x\)、\(\sin x\)、\(\cos x\)——之所以能放心地写上等号，是因为它们的高阶导数全局有界，余项被阶乘倒数 \(\frac{1}{(n+1)!}\) 强行按倒归零，而不是因为它们的级数表面看起来收敛。

\subsection{余项界能给什么，不能给什么}

回到最开始的信赖域方法。信赖域半径的合理选择，在理论上就是求解不等式：
\[
\frac{M}{(n+1)!}\abs{x-a}^{n+1} \le \text{允许的模型误差}.
\]

但在工程算法落地时，我们几乎不可能直接去解这个不等式，因为高阶导数上限 \(M\) 在复杂高维空间中通常是无法计算的。工业级优化算法（如 Dogleg 或 Trust-Region Newton）的实际做法是：\textbf{根据``模型预测下降量'与``真实实际下降量'的比值 \(\rho\) 来动态调节半径}。本质上，这是在用运行时的实时观测值，去反推那个不可知的 \(M\)。

最后，关于余项的物理边界，有两条工程铁律必须牢记：
\begin{itemize}
    \item \textbf{余项界只管数学截断，不管浮点舍入}：高阶项系数带有阶乘倒数 \(1/n!\)，在数值上极小，很快就会跌落到浮点数精度的底线以下，与计算机舍入误差混杂在一起。超过一定阶数后，继续增加项数反而会因累加舍入而恶化精度；
    \item \textbf{余项界是高度局部的}：距离偏离项 \(\abs{x-a}^{n+1}\) 的高次幂决定了离中心稍远误差就会呈爆炸式失控。因此在实际工程计算中，必须在关心区域的\textbf{最近中心点}处重新展开。Maclaurin 级数（\(a=0\)）仅仅是特例，并没有任何特殊的工程优先权。
\end{itemize}

当我们从一维标量函数走向高维多元函数时，这套拟合与余项框架将以矩阵形式重演：函数值对应零阶，梯度向量对应一阶，Hessian 矩阵对应二阶，而多元余项将决定二次模型在高维信任椭球内的可靠边界。
