\section{正项级数的比较}
\label{sec:02-Calculus/05-Sequences-and-Series/03}

\[
\sum_{n=1}^{\infty}\frac1n=\infty,
\qquad
\sum_{n=1}^{\infty}\frac1{n^2}=\frac{\pi^2}{6}.
\]

两个级数的项都为正、都趋于零，通项的指数只差 1。前一百项的数值差异在视觉上也并不悬殊：第 100 项分别是 \(1/100\) 与 \(1/10000\)，画在同一屏幕上都是一条贴着零的线。然而，一个的部分和可以任意大，另一个却稳稳停在 1.645 附近。

这说明通项仅趋于零是不够的，\textbf{关键在于它趋于零的速度有多快}。

级数收敛与发散的分界线到底划在哪里？本节的核心目标就是找到这条线，并建立一套比较标准。

\subsection{1. 核心逻辑：正项级数收敛等价于部分和有上界}

对于一般的级数，项有正有负，部分和会上下波动；但对于\textbf{正项级数}（\(a_n \ge 0\)），部分和 \(S_N = \sum_{n=1}^N a_n\) 随着 \(N\) 的增加只会单调递增：

\[
S_1 \le S_2 \le S_3 \le \dots \le S_N \le \dots
\]

根据单调有界收敛定理，一个单调递增的数列只有两种可能：要么被某个数顶住而收敛，要么没有上界而奔向无穷。

\begin{proposition}
正项级数 \(\sum a_n\) 收敛，当且仅当它的部分和序列 \(\{S_N\}\) 有上界。
\end{proposition}

这条命题把``判断级数是否收敛'这个抽象的极限问题，简化为了``能否为部分和找到一个有限的上界''''。只要能找到一个适当的``放大参照物'盖住它，判定就完成了。

\subsection{2. 积分判别法（Integral Test）：用曲线下的面积夹住离散的和}

要找参照物，最直接的方法是用连续函数的积分来逼近离散的级数和。

假设 \(a_n = f(n)\)，其中 \(f(x)\) 在 \([1, \infty)\) 上是\textbf{正的、连续且单调递减}的函数。我们可以把每一项 \(a_n\) 看成底边长为 1、高为 \(f(n)\) 的矩形面积。

图形与曲线的包含关系直接给出了如下的双侧夹逼不等式：

\[
\int_1^{N}f(x)\,dx \;\le\; \sum_{n=1}^{N-1}f(n) \;\le\; f(1) + \int_1^{N-1}f(x)\,dx.
\]

让 \(N \to \infty\)，说明级数 \(\sum_{n=1}^\infty f(n)\) 的有限性与反常积分 \(\int_1^\infty f(x)\,dx\) 的有限性完全绑定。

\begin{theorem}[积分判别法]
设 \(f(x)\) 在 \([1,\infty)\) 上单调递减且大于零，则级数 \(\sum_{n=1}^\infty f(n)\) 与反常积分 \(\int_1^\infty f(x)\,dx\) 同敛散。
\end{theorem}

把 \(f(x) = x^{-p}\) 代入积分中计算：

\[
\int_1^\infty \frac{1}{x^p}\,dx = 
\begin{cases} 
\left. \frac{x^{1-p}}{1-p} \right|_1^\infty = \frac{1}{p-1} < \infty, & p > 1, \\[6pt]
\left. \ln x \right|_1^\infty = \infty, & p = 1, \\[6pt]
\infty, & p < 1.
\end{cases}
\]

由此立刻得到至关重要的标尺级数：

\begin{theorem}[\(p\)-级数判别法（\(p\)-Series Test）]
级数 \(\sum_{n=1}^\infty \frac{1}{n^p}\) 当且仅当 \(p > 1\) 时收敛；当 \(p \le 1\) 时发散。
\end{theorem}

有了 \(p\)-级数，我们就建立了一套精细的刻度盘：\(\sum \frac{1}{n^2}\)、\(\sum \frac{1}{n^{1.01}}\) 收敛，而 \(\sum \frac{1}{n}\)、\(\sum \frac{1}{\sqrt{n}}\) 发散。

此外，积分判别法还附赠了截断误差的估算界限。如果用前 \(N\) 项和近似无限级数，残项 \(\sum_{n=N+1}^\infty f(n)\) 满足：

\[
\int_{N+1}^{\infty}f(x)\,dx \;\le\; \sum_{n=N+1}^\infty f(n) \;\le\; \int_{N}^{\infty}f(x)\,dx.
\]

\subsection{3. 分界线的精细结构}

\(p=1\) 是多项式衰减级别的硬分界，但在 \(p=1\) 附近，衰减速度的分界比想象中更细微。

考虑引入增长极慢的对数函数 \(\ln x\)。利用换元 \(u = \ln x\)，我们比较以下两个积分：

\[
\int_2^\infty \frac{dx}{x \ln x} = \int_{\ln 2}^{\infty} \frac{du}{u} = \ln(\ln x)\Big|_{\ln 2}^\infty = \infty,
\]
\[
\int_2^\infty \frac{dx}{x \ln^2 x} = \int_{\ln 2}^{\infty} \frac{du}{u^2} = -\frac{1}{u}\Big|_{\ln 2}^\infty = \frac{1}{\ln 2} < \infty.
\]

这表明：\(\sum \frac{1}{n\ln n}\) 发散，而 \(\sum \frac{1}{n\ln^2 n}\) 收敛。

两者的通项仅仅相差一个 \(\ln n\) 因子。在 \(n = 10^6\) 时，\(\ln(10^6) \approx 13.8\)，两者的比值只有约 14 倍。这警示我们：\textbf{在临界线附近，仅靠观察前有限项的数值大小来直觉猜想敛散性是极不可靠的。}


\subsection{4. 比较判别法（Comparison Test）：将待测项对齐到标尺上}

有了 \(p\)-级数这把标尺，就可以通过``看谁大看谁小'来判定未知级数。

\subsubsection*{(1) 直接比较法}
设从某项起 \(0 \le a_n \le b_n\)：
\begin{itemize}
    \item 若较大的级数 \(\sum b_n\) 收敛，则较小的级数 \(\sum a_n\) 也收敛（上界传递）。
    \item 若较小的级数 \(\sum a_n\) 发散，则较大的级数 \(\sum b_n\) 也发散（无界传递）。
\end{itemize}

\textbf{注意方向：} 大的发散或小的收敛均得不出任何结论。例如 \(1/n^2 < 1/n\)，虽然 \(\sum 1/n\) 发散，但不能据此推出 \(\sum 1/n^2\) 的任何信息。

\subsubsection*{(2) 极限比较判别法（Limit Comparison Test）}
构造不等式往往需要技巧，但更通用的做法是看两个级数通项在 \(n \to \infty\) 时的主导阶数。若

\[
\lim_{n\to\infty} \frac{a_n}{b_n} = c \qquad (0 < c < \infty),
\]

则 \(\sum a_n\) 与 \(\sum b_n\) \textbf{同敛散}。

这是因为根据极限定义，当 \(n\) 足够大时，存在常数使 \(\frac{c}{2} b_n < a_n < 2c\, b_n\)。\(a_n\) 被夹在 \(b_n\) 的常数倍之间，而乘以非零常数不改变级数的敛散性。

例如判定 \(a_n = \frac{n+1}{n^3+2}\)：当 \(n \to \infty\) 时，分子主导项为 \(n\)，分母主导项为 \(n^3\)，整体阶数为 \(\frac{n}{n^3} = \frac{1}{n^2}\)。取 \(b_n = \frac{1}{n^2}\)，计算极限：

\[
\lim_{n\to\infty} \frac{a_n}{b_n} = \lim_{n\to\infty} \frac{n^3+n^2}{n^3+2} = 1 \in (0, \infty).
\]

因为 \(\sum \frac{1}{n^2}\) 收敛，所以原级数收敛。


\subsection{5. 比值判别法与根值判别法：换用指数尺子}

当通项中出现阶乘（\(n!\)）或指数（\(c^n, n^n\)）时，项的衰减速度远远快于任何幂函数 \(n^{-p}\)，\(p\)-级数这把标尺就不够用了。此时需要改用\textbf{几何级数（等比级数）}作为标尺。

设 \(L = \lim_{n\to\infty} \frac{a_{n+1}}{a_n}\)（比值判别法，Ratio Test）或 \(L = \lim_{n\to\infty} \sqrt[n]{a_n}\)（根值判别法，Root Test）：
\begin{itemize}
    \item 若 \(L < 1\)，级数\textbf{绝对收敛}。
    \item 若 \(L > 1\)，级数\textbf{发散}。
    \item 若 \(L = 1\)，判别法失效。
\end{itemize}

它的几何本质在于：\(L < 1\) 意味着在尾部，通项的比值被某个小于 1 的公比 \(r\)（使得 \(L < r < 1\)）从上方控制住，即 \(a_{n+1} < r a_n\)，因此它的衰减速度快于几何级数 \(\sum r^n\)。

以 \(a_n = \frac{n!}{n^n}\) 为例：

\[
\frac{a_{n+1}}{a_n} = \frac{(n+1)!}{(n+1)^{n+1}} \cdot \frac{n^n}{n!} = \frac{(n+1) \cdot n^n}{(n+1)(n+1)^n} = \left(\frac{n}{n+1}\right)^n = \frac{1}{\left(1 + \frac{1}{n}\right)^n}.
\]

取极限得 \(\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = \frac{1}{e} < 1\)，故级数收敛。


\subsection{6. 理解工具的边界：为什么 \texorpdfstring{\(L=1\)}{L=1} 会失效？}

比值检验与根值检验在 \(L=1\) 时无法给出结论。\textbf{\(L=1\) 并不是级数本身的特殊性质，而是``几何尺子'的分辨率极限。}

考虑以下两个级数：
\begin{itemize}
    \item 调和级数 \(\sum \frac{1}{n}\)（发散）：\(\lim \frac{a_{n+1}}{a_n} = \lim \frac{n}{n+1} = 1\)。
    \item \(p\)-级数 \(\sum \frac{1}{n^2}\)（收敛）：\(\lim \frac{a_{n+1}}{a_n} = \lim \frac{n^2}{(n+1)^2} = 1\)。
\end{itemize}

事实上，对于任意形如 \(a_n = \frac{1}{n^p}\) 的代数衰减级数，其相邻项的比值极限永远是 1：

\[
\lim_{n\to\infty} \frac{\frac{1}{(n+1)^p}}{\frac{1}{n^p}} = \lim_{n\to\infty} \left(1 - \frac{1}{n+1}\right)^p = 1^p = 1.
\]

几何级数是以指数变化率缩放的。在指数尺度眼中，所有的多项式代数衰减（无论 \(p=0.1\) 还是 \(p=100\)）变化速度都太慢，差异都被压缩归零到了 1。因此，\textbf{\(L=1\) 传达的信息是``该级数的衰减速度不是指数级别的'，此时应当切换回 \(p\)-级数比较法或积分判别法。}


\subsection{7. 实际应用：随机优化中的学习率条件}

在机器学习与随机逼近算法中，步长（学习率）序列 \(\alpha_t > 0\) 通常被要求同时满足以下两个条件：

\[
(1)\;\sum_{t=1}^{\infty}\alpha_t = \infty,
\qquad
(2)\;\sum_{t=1}^{\infty}\alpha_t^2 < \infty.
\]

直观理解这两个条件的物理意义：
\begin{itemize}
    \item \textbf{条件 (1) 保证算法``走得够远'}：如果步长之和收敛（有有限上界），算法从某个较远初值出发时，整条搜索轨迹的长度就会被封顶，导致永远无法到达最优解。
    \item \textbf{条件 (2) 保证算法``能够收敛'}：每一步梯度更新都包含随机噪声。步长平方和收敛确保了噪声方差的累积是有限的，算法不会在最优点附近无限震荡。
\end{itemize}

如果选取幂律步长 \(\alpha_t = t^{-p}\)，代入上述两个条件：
\begin{itemize}
    \item 由 \(\sum t^{-p} = \infty\) 得 \(p \le 1\)。
    \item 由 \(\sum t^{-2p} < \infty\) 得 \(2p > 1 \implies p > \frac{1}{2}\)。
\end{itemize}

综合可得 \(p \in (\frac{1}{2}, 1]\)。

工程中最常用的衰减步长 \(\alpha_t = \frac{1}{t}\)（对应 \(p=1\)）恰好落在临界右端点上；若取 \(\alpha_t = \frac{1}{\sqrt{t}}\)（\(p=0.5\)），则方差无法抑制，违反条件 (2)；若取 \(\alpha_t = \frac{1}{t^2}\)（\(p=2\)），则移动距离受限，违反条件 (1)。一个优化算法的调参规则，本质上就是 \(p\)-级数敛散界限的直接应用。


\subsection{8. 总结：判得出敛散，不等于算得出和}

必须强调的是，本节介绍的所有判别法都只用于回答\textbf{``级数是否收敛'}这一定性问题，并不给出级数和的具体数值。

像 \(\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}\) 这样的精确定量结果，无法通过比较判别法得到，而需要借助傅里叶级数或复分析等工具。绝大多数收敛的级数都没有初等闭式解，在实际计算中，我们正是利用积分判别法提供的双侧误差界，来确定需要累加多少项才能达到指定的计算精度。

截至目前，我们讨论的所有级数都满足 \(a_n \ge 0\)。在项的符号保持一致的前提下，部分和序列的单调性为寻找上界提供了极大的便利。如果允许级数包含正负交替的项，部分和将不再单调，收敛性可能依赖于正负项之间的相互抵消——这将引入更为复杂的绝对收敛与条件收敛问题。
