\section{交错与绝对收敛}
\label{sec:02-Calculus/05-Sequences-and-Series/04}

\[
1-\frac12+\frac13-\frac14+\frac15-\cdots=\ln 2\approx0.6931.
\]

如果我们把这些项的顺序稍微换一下，变成“两个正项搭配一个负项”的节奏：

\[
1+\frac13-\frac12+\frac15+\frac17-\frac14+\frac19+\frac1{11}-\frac16+\cdots=\frac32\ln 2\approx1.0397.
\]

请注意：\textbf{没有任何一项被修改，没有任何一项被丢弃，也没有任何一项被重复使用}——每一个分数依然只出现了一次，仅仅是改变了排队顺序，求和的结果却硬生生改变了。

更不可思议的是，$\tfrac32\ln2$ 并没有什么特殊的地位。只要换一种重排方式，我们可以让这个级数的和变成 $0$、变成 $-100$、变成 $\pi$，甚至直接让它来回震荡、根本不收敛。

为什么改变求和顺序会产生这种“魔法”？什么样的级数才能抵抗这种乱象？这一节我们就来揭开背后的机制。

\subsection{正负交替：抵消如何救活一个发散级数}

如果把符号全部去掉，调和级数 $\sum 1/n$ 是发散的；但只要加上正负交替的符号，它就收敛了。

这里的收敛，\textbf{靠的不是各项衰减得够快，而是正负项之间的“精准抵消”}。

对于交错级数 $\sum(-1)^{n-1}b_n$（其中 $b_n\ge0$），只要满足两个条件：$b_n$ 最终单调递减，并且极限趋于零（$b_n \to 0$），这个级数就一定会收敛。

要理解这个结论，不需要死记硬背，看一眼部分和在数轴上的走位就明白了：加一个正项往右跳一步，加一个负项往左跳一步。因为 $b_n$ 在不断变小，所以\textbf{每一次跳跃的距离都比上一次短}。这导致奇数次部分和（$S_1, S_3, S_5\dots$）不断自上而下递减，偶数次部分和（$S_2, S_4, S_6\dots$）不断自下而上递增，就像一把不断折叠收紧的尺子，把真正的极限死死夹在中间。

\emph{奇数项与偶数项部分和从两侧夹击极限。任何时刻，真值都被关在相邻的两个部分和之间，它们的距离刚好就是下一项的大小。}
\end{center}

将这个直观画面翻译成严密的逻辑：
\begin{enumerate}
    \item 奇数列单调递减且有下界，必有极限；
    \item 偶数列单调递增且有上界，必有极限；
    \item 两者之差恰好是下一项 $b_{N+1}$，而 $b_{N+1} \to 0$，所以两个极限完全重合。
\end{enumerate}

这种“夹击”结构还附赠了一个巨大的实用好处——\textbf{极易估计误差}。如果我们只加到前 $N$ 项，拿 $S_N$ 来近似真实和 $S$，误差绝对不会超过“被丢掉的第一项”：
\[
\abs{S-S_N}\le b_{N+1},
\]
而且误差的符号与第一个被丢掉的项相同。想要把误差控制在 $10^{-3}$ 以内？只需找到第一个小于 $10^{-3}$ 的项停下来即可。相比之下，正项级数估算误差往往需要做复杂的积分判别法，交错级数在这一点上显得格外优雅。

\subsection{绝对收敛：彻底关掉“抵消”的漏洞}

既然收敛有两种方式（一种靠自身衰减，一种靠正负抵消），我们就必须把它们区分开来：
\begin{itemize}
    \item \textbf{绝对收敛}：如果把符号全部取绝对值，级数 $\sum \abs{a_n}$ 依然收敛，我们就称 $\sum a_n$ 绝对收敛。
    \item \textbf{条件收敛}：如果原级数 $\sum a_n$ 收敛，但加了绝对值后的 $\sum \abs{a_n}$ 发散，我们就称它条件收敛（例如交错调和级数）。
\end{itemize}

绝对收敛是极为强悍的。根据 Cauchy 准则，尾段的绝对值之和可以被压得任意小：$\bigl|\sum_{k=n+1}^{m}a_k\bigr|\le\sum_{k=n+1}^{m}\abs{a_k}$，因此原级数的尾段和也必然被压住——\textbf{绝对收敛必然蕴含收敛}。

为了更深刻地理解这两者的本质区别，我们可以把任意一个级数拆成两股力量：
\[
a_n^+=\max(a_n,0),\qquad a_n^-=\max(-a_n,0),
\]
其中 $a_n^+$ 只提取正项（负项记为 0），$a_n^-$ 只提取负项的绝对值（正项记为 0）。于是原级数是“正项减负项”（$\sum a_n = \sum a_n^+ - \sum a_n^-$），而绝对值级数是“正项加负项”（$\sum \abs{a_n} = \sum a_n^+ + \sum a_n^-$）。

现在来看这两种情况的底牌：
\begin{enumerate}
    \item \textbf{绝对收敛}：$\sum a_n^+$ 与 $\sum a_n^-$ \textbf{各自都是有限的数}。正数的总量有限，负数的总量也有限，两边账目都很清晰，怎么加都不会出乱子。
    \item \textbf{条件收敛}：$\sum a_n^+$ 与 $\sum a_n^-$ \textbf{各自都是 $+\infty$}！正数储备是无穷大，负数储备也是无穷大。
\end{enumerate}

这是一个极其关键的洞察：\textbf{条件收敛的级数，本质上是在用“正无穷”去减“负无穷”}。它之所以能收敛到一个具体的数，完全取决于我们安排正负项出场的微妙顺序。这就为开头那种“重排改变求和结果”的怪象，打开了操纵的大门。

\subsection{为什么条件收敛的级数可以“操控”？}

对条件收敛级数的这种操纵，在数学上有严密的定理支撑：

\begin{theorem}[Riemann 重排定理]
若级数 \(\sum a_n\) 条件收敛，则对任意给定的实数 \(L\)，存在项的一个重排使新级数收敛到 \(L\)；也存在重排使新级数发散到 \(+\infty\)、发散到 \(-\infty\)，或者部分和振荡而无极限。
\end{theorem}

构造这个重排的过程就像玩一个简单的游戏。假设我们想让级数凑到目标值 $L$：
\begin{enumerate}
    \item \textbf{提取储备}：把非负项按原顺序抽出来记为 $p_1,p_2,\dots$（总和 $\sum p_k = +\infty$），把负项抽出来记为 $q_1,q_2,\dots$（总和 $\sum q_k = -\infty$）。
    \item \textbf{向目标靠拢}：依次取正项相加，直到部分和\textbf{第一次超过} $L$ 就停手；
    \item \textbf{拉回目标}：立刻转向，依次取负项相加（减去负项），直到部分和\textbf{第一次跌破} $L$ 再停；
    \item \textbf{反复横跳}：回去继续取正项加到超过 $L$，再切换回负项减到跌破 $L$……
\end{enumerate}

因为正负两边的储备都是无限的，这个游戏可以永远玩下去，并且\textbf{每一个项迟早都会被用到}，这确实是原级数的一个重排。

为什么它一定会精确收敛到 $L$？因为每次转向时，越过目标的“超调量”绝不会超过刚刚放进去的那一项的大小。而条件收敛要求 $a_n \to 0$，这意味着随着游戏推进，放入的项越来越小，部分和围绕目标值 $L$ 的震荡幅度也随之趋于零，最终被牢牢锁死在 $L$ 上。把目标换成移动靶，就能给出发散的重排。

\subsubsection*{那么，为什么绝对收敛就不会受影响？}

对于绝对收敛的级数，\(\sum a_n^+\) 与 \(\sum a_n^-\) 是两个独立的、有限的正项级数。正项级数的和等于所有有限子和的上确界——\textbf{上确界只取决于被加进来的项是哪些，和它们的先后顺序毫无关系}。两个上确界不动，差也不动，因此绝对收敛级数无论怎么重排，结果都稳如磐石。

\textbf{结论}：无穷级数并没有让加法的交换律失效。失效的，是我们粗暴地把“每个有限部分和都可以随意换序”直接套用到了“无穷极限”上。重排改变的不是那几个数字本身，而是部分和逼近极限的整条路径。

\subsection{从抽象数学到工程落地}

这种“顺序决定结果”的现象，绝非仅仅停留在纯数学纸面上，它在现代计算机数值计算中天天发生。

有限个浮点数相加\textbf{不满足结合律}：先把大数加完再加小数，小数会被舍入截断；反过来先累积小数，结果可能差出几位有效数字。多线程 reduce、分块 all-reduce、不同批大小下的梯度累加，都会因为求和顺序不同而给出不同的数值——同一份数据、同一段代码，仅仅换个并行度就可能复现不出上次的结果。

浮点的机制是舍入而不是重排定理，两者不能混为一谈。但它们指向同一条工程经验：
\begin{quote}
\textbf{“求和顺序不影响结果”从来不是加法自带的，它是要靠条件换来的。}
\end{quote}
在数学里的条件是\textbf{绝对收敛}，在数值计算里的条件是各项量级接近或者使用\textbf{补偿求和算法}（如 Kahan Summation）。相关的误差机制见 \hyperref[ch:061]{``浮点数与误差：计算机为什么不等于实数系统''}。

再往前一步，这种思想会在测度论里被重新提出来：Lebesgue 积分定义可积时要求 \(\int\abs f<\infty\)，理由和这里一模一样——只有正部与负部各自有限，积分的值才不依赖你从哪里开始累积。\hyperref[ch:101]{``测度、积分与条件期望：为现代概率回填地基''} 会接手这条线索。

\subsection{总结：面对一个级数，如何下手？}

以后遇到一个带有正负号的级数，可以按以下步骤排查：

\begin{enumerate}
    \item \textbf{先查 $\sum\abs{a_n}$ 是否收敛}：
    \begin{itemize}
        \item \textbf{若收敛 $\implies$ 绝对收敛}：上一节的全套正项判别法都能用上，而且此后重排、分组、与另一个绝对收敛级数逐项相乘，都不会出事。
        \item \textbf{若发散}：进入下一步。
    \end{itemize}
    \item \textbf{再查原级数 $\sum a_n$ 是否收敛}：
    \begin{itemize}
        \item \textbf{若收敛 $\implies$ 条件收敛}：此时手上的和是与特定顺序绑定的，任何改变累加次序的操作都必须重新论证。
        \item \textbf{若发散 $\implies$ 发散级数}。
    \end{itemize}
\end{enumerate}

在使用\textbf{交错级数判别法}时，务必记住：
\begin{itemize}
    \item 它只在 $b_n$ \textbf{单调递减}且\textbf{趋于零}时给结论；
    \item 它给出的误差界 $\abs{S-S_N}\le b_{N+1}$ \textbf{仅控制截断}，不控制计算机的舍入误差，更不控制把项换了顺序之后的行为。
\end{itemize}

至此讨论的都是一列固定的数。若把项写成含参数的形式（如 $c_nx^n$），同一个式子对不同的 $x$ 就会给出不同的级数，有的收敛有的发散。下一节处理这种情形，并说明为什么“形式上写得出来”和“在这一点有意义”是两件必须分开的事。
