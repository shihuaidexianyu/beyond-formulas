\section{图像变换与函数复合}
\label{sec:02-Calculus/01-Functions-and-Precalculus/02}

\subsection{一个抛物线引发的不安}

你拿到 \(f(x)=x^2-6x+5\)，想知道它的顶点在哪。配方可以解决：
\[
x^2-6x+5=(x-3)^2-4,
\]
顶点是 \((3,-4)\)。

但你隐隐觉得不对劲——每次遇到一个新抛物线都要重新配方？\(x^2\) 的图像你已经烂熟于心：顶点在原点，开口向上，左右对称。如果能把 \(x^2\) 的图像``搬''到 \((3,-4)\) 的位置，同时保持形状不变，你就不用重新分析对称轴和开口方向了。

这个念头很自然：从一个熟悉的``母函数''出发，通过平移、拉伸、翻折，生成一整族图像。你需要一套系统的方法来操控图像的位置和形状。

\subsection{纵向变换：符合直觉的那一半}

先试最简单的。从 \(y=f(x)\) 出发：

\[
y=f(x)+2.
\]

新图像上每个点的纵坐标都加了 2。\((0, f(0))\) 变成 \((0, f(0)+2)\)，\((3, f(3))\) 变成 \((3, f(3)+2)\)。整条曲线向上平移了两个单位。用具体数字感受：若 \(f(x)=x^2\)，原图像过 \((2,4)\)，新图像过 \((2,6)\)——竖着上去了，横坐标纹丝不动。

同样，\(y=f(x)-1\) 是向下平移 1。

接下来试试纵向拉伸：
\[
y=3f(x).
\]
每个输出乘以 3。\((1, f(1))\) 变成 \((1, 3f(1))\)。若 \(f(1)=1\)，新点是 \((1,3)\)——离 \(x\) 轴远了 3 倍。\(y=\frac{1}{2}f(x)\) 则是纵向压缩到原来的一半。

负数系数同时完成拉伸和翻折：
\[
y=-2f(x)
\]
先把图像纵向拉伸 2 倍，再关于 \(x\) 轴翻到对面。\(f(x)=x^2\) 过 \((2,4)\)，新图像过 \((2,-8)\)——抛物线倒扣过来，开口向下。

纵向变换的规律很顺：加就移，乘就拉，负号就翻。你的直觉不用转弯。

\subsection{横向变换：直觉撞墙的地方}

现在试横向。直觉告诉你 \(y=f(x+3)\) 应该向右移——毕竟加了个 3。

验证一下。取 \(f(x)=x^2\)，原图像过 \((0,0)\)。对于 \(y=(x+3)^2\)，想让输出也为 0，需要 \(x+3=0\)，即 \(x=-3\)。顶点出现在 \((-3,0)\)。

加了 3，顶点却向左跑了 3 个单位。

为什么反直觉？因为横向变换作用在输入上，而输入是``你喂给 \(f\) 的东西''。你想让 \(f\) 接收到和以前一样的输入值 \(u\)，但新变量 \(x\) 必须满足：
\[
x+h = u \quad\Longrightarrow\quad x = u-h.
\]
想让 \(f\) 接收到 0（原顶点），\(x\) 就得是 \(-3\)。图像上所有特征点的横坐标都减了 \(h\)，相当于整个图形沿横轴平移了 \(-h\)。写 \(y=f(x-h)\) 时，图像向右平移 \(h\)——减号对应右移，这才是正确的对应关系。

纵向道理一样，只是你习惯了从``结果''看问题：\(f(x)+k\) 加在结果上，加就往上，直觉直接对齐。横向是你喂给函数的原料，\(x-h\) 意味着你先给输入做了减法预处理。

用具体数字固定这个感觉：

\begin{itemize}
  \item \(f(x)=|x|\)，原顶点 \((0,0)\)。\(f(x-4)=|x-4|\)，顶点移到 \((4,0)\)。
  \item \(f(x)=\sqrt{x}\)，定义域 \([0,\infty)\)，起点 \((0,0)\)。\(f(x+1)=\sqrt{x+1}\)，起点移到 \((-1,0)\)——整个图像左移 1。
\end{itemize}

横向缩放同理。\(y=f(2x)\)：想让 \(f\) 接收到原始输入 \(u\)，需要 \(2x=u\)，即 \(x=u/2\)。所有横坐标减半，图像沿横轴压缩到原来的 \(1/2\)。\(y=f(x/3)\)：\(x/3=u\) 得 \(x=3u\)，图像横向拉伸 3 倍。系数和效果互为倒数——这是横向变换的标志性特征。

负数系数同时完成横向缩放和翻折：\(y=f(-x)\) 让图像关于 \(y\) 轴镜像反射。

\subsection{把六种变换打包成一条公式}

先平移还是先缩放？试试从 \(f(x)=x^2\) 出发构建 \(g(x)=-2(x-3)^2+1\)。

按运算的自然顺序（先算括号里的）逐层拆解：
\[
x \xrightarrow{\;-3\;} x-3 \xrightarrow{\;\square^2\;} (x-3)^2 \xrightarrow{\;\times(-2)\;} -2(x-3)^2 \xrightarrow{\;+1\;} -2(x-3)^2+1.
\]

对应到图像上：
\begin{enumerate}
  \item \(x\mapsto x-3\)：右移 3。顶点 \((0,0)\to(3,0)\)。
  \item 平方：保持。\((3,0)\) 仍是 \((3,0)\)。
  \item 乘以 \(-2\)：纵向拉伸 2 倍并翻转向下。\((3,0)\) 不受影响（0 乘什么都是 0），但 \((4,1^2)\) 变成 \((4,-2)\)。
  \item 加 1：上移 1。顶点最终停在 \((3,1)\)。
\end{enumerate}

这个拆解路径不是唯一的。你也可以把通用模板写成：
\[
g(x)=a\,f\bigl(b(x-h)\bigr)+k,
\]
其中：
\begin{itemize}
  \item \(h\)：横向平移（\(+h\) 右移），
  \item \(k\)：纵向平移（\(+k\) 上移），
  \item \(a\)：纵向缩放因子（\(|a|>1\) 拉伸，\(|a|<1\) 压缩，\(a<0\) 附加纵向翻折），
  \item \(b\)：横向缩放因子（图像横轴缩放 \(1/|b|\) 倍，\(b<0\) 附加横向翻折）。
\end{itemize}

信息流的方向是：输入先进横向预处理（平移 \(h\)、缩放 \(b\)），然后交给核心函数 \(f\)，输出再进纵向后处理（缩放 \(a\)、平移 \(k\)）。

但不要死记顺序。面对具体函数，逐点追踪更可靠：挑几个特征点（顶点、零点、渐近线关键位置），手动算一遍变换后的坐标。这比背诵``先横后纵、先缩放后平移''的规则更不容易出错。

\subsection{复合函数：当处理步骤串联成流水线}

图像变换的公式其实暴露了一个更大的结构：你做的事情是把函数串联起来。先对输入做点什么（减 3），再把结果喂给下一个函数（平方），再喂给下一个（乘 \(-2\)），再下一个（加 1）。每一步的输出变成下一步的输入。

这种串联在现实世界极其常见：

\begin{itemize}
  \item 传感器把温度变成电压（\(f\)：\(^\circ\)C \(\to\) mV），标定电路把电压变成显示屏读数（\(g\)：mV \(\to\) \(^\circ\)C 读数）。显示屏上的读数是 \(g(f(\text{实际温度}))\)。
  \item 商品先打八折，再加 10 元运费。设原价 \(p\)，折后价 \(f(p)=0.8p\)，加运费 \(g(q)=q+10\)。最终付款是 \(g(f(p))=0.8p+10\)。
\end{itemize}

函数复合的正式记法：
\[
(g\circ f)(x)=g\bigl(f(x)\bigr).
\]
圆圈读作``复合''。运算方向是从右往左：先执行 \(f\)，结果再交给 \(g\)。\(f: A\to B\)，\(g: B\to C\) 时，\(g\circ f: A\to C\) 才有意义——\(f\) 的输出类型必须匹配 \(g\) 的输入类型。

上面那个打折的例子：\(f(p)=0.8p\)，\(g(q)=q+10\)，\((g\circ f)(p)=0.8p+10\)。

但如果反过来呢？\((f\circ g)(p)=f(g(p))=f(p+10)=0.8(p+10)=0.8p+8\)。先加运费再打折——运费也被打了八折。这是完全不同的商业规则，得出了不同的总价。

对于 \(p=100\)：
\[
(g\circ f)(100)=0.8\times 100+10=90,\qquad
(f\circ g)(100)=0.8\times(100+10)=88.
\]

函数复合通常不可交换。顺序不是细节——它决定最终结果。

\subsection{复合函数的定义域：隐藏的约束}

\((g\circ f)(x)=g(f(x))\) 有定义，必须同时满足两个条件：
\begin{enumerate}
  \item \(x\) 在 \(f\) 的定义域内。
  \item \(f(x)\) 这个输出值，必须在 \(g\) 的定义域内。
\end{enumerate}

第一条你自然会检查——输入不能超出 \(f\) 的管辖范围。第二条容易漏：即使 \(f\) 有输出，如果那个输出值 \(g\) 不接受，整条流水线在第二步卡住。

一个典型的陷阱：
\[
h(x)=\sqrt{1-x^2}.
\]
你把它看成 \(f(x)=1-x^2\) 和 \(g(u)=\sqrt{u}\) 的复合。\(f\) 对所有实数都有定义，随便喂。但 \(g(u)=\sqrt{u}\) 只接受 \(u\ge 0\) 的输入。所以即使 \(x=2\) 让 \(f\) 有输出（\(f(2)=-3\)），这个输出喂不进 \(g\) 的嘴——\(\sqrt{-3}\) 在实数范围没意义。

复合函数的实定义域是：
\[
\{x\in\R: 1-x^2\ge 0\} = [-1,1].
\]

关键教训：不要先化简再看定义域。比如你如果把 \(\sqrt{1-x^2}\) 化简之后再问定义域，化简并不会帮你发现 \(1-x^2\ge 0\) 的限制——这个限制必须在化简之前的原始结构中检查。

\subsection{分解函数：为链式法则铺路}

复合的逆向操作是分解。面对一个复杂的函数表达式，你把它拆成一层层简单函数的嵌套。

\[
h(x)=\sin\bigl((3x-1)^2\bigr).
\]

从外往内剥：
\[
x \xmapsto{\,f\,} 3x-1 \xmapsto{\,g\,} u^2 \xmapsto{\,r\,} \sin v,
\]
其中 \(u=f(x)=3x-1\)，\(v=g(u)=u^2\)，\(h(x)=r(v)=\sin v\)。

或者写成：
\[
h(x) = r\bigl(g\bigl(f(x)\bigr)\bigr) = (r\circ g\circ f)(x).
\]

追踪每一步的中间量——\(u\)、\(v\)——是比一次写出完整表达式更清晰的思维方式。将来遇到链式法则时，求导正是沿着这条处理链逐层传递局部变化率：
\[
h'(x)=r'(v)\cdot g'(u)\cdot f'(x).
\]

现在你不需要计算导数。你需要培养的能力是：看到一个复杂表达式，立刻能辨认``谁包在谁外面''。这是链式法则的肌肉记忆的前置训练。

再练一个：
\[
k(x)=e^{\cos(x^2+1)}.
\]
剥开来看：
\[
x \xmapsto{\,+1\,} x^2+1 \xmapsto{\,\cos\,} \cos(x^2+1) \xmapsto{\,e^{(\cdot)}\,} e^{\cos(x^2+1)}.
\]
三层嵌套。最外层是指数，中间是余弦，最内层是多项式。

\subsection{对称性：用函数等式捕捉几何规律}

有些函数的图像呈现出明显的对称性。\(f(x)=x^2\) 关于 \(y\) 轴对称——左边和右边是镜像。\(f(x)=x^3\) 关于原点对称——旋转 180 度后与自身重合。

这些几何性质可以精确地写成函数等式：

\begin{itemize}
  \item \textbf{偶函数}：\(f(-x)=f(x)\) 对定义域内所有 \(x\) 成立。图像关于 \(y\) 轴对称。例如 \(f(x)=x^2\)：\(f(-3)=9=f(3)\)。\(f(x)=\cos x\)：\(\cos(-\pi/3)=1/2=\cos(\pi/3)\)。\(f(x)=|x|\)：\(|-5|=5=|5|\)。
  \item \textbf{奇函数}：\(f(-x)=-f(x)\) 对定义域内所有 \(x\) 成立。图像关于原点对称。例如 \(f(x)=x^3\)：\(f(-2)=-8=-f(2)\)。\(f(x)=\sin x\)：\(\sin(-\pi/6)=-1/2=-\sin(\pi/6)\)。
\end{itemize}

有几个微妙之处值得注意：

第一，对称性的前提是定义域本身关于 0 对称。如果定义域是 \([0,\infty)\)，\(f(-x)\) 根本没定义，讨论奇偶性就没有意义。

第二，``偶''和``奇''只是关于 0 对称的两类特殊情况，不覆盖全部函数。\(f(x)=x^2+x\) 既不是奇函数也不是偶函数——\(f(-x)=x^2-x\)，既不等于 \(f(x)\) 也不等于 \(-f(x)\)。这很正常，大多数函数不属于这两类。

第三，奇偶性可能帮你减少计算量。如果已知 \(f\) 是偶函数且在 \([0,10]\) 上的行为，那 \([-10,0]\) 上的行为自动确定——镜像过去就行，不用重新算。

\subsection{这张地图到此为止覆盖了什么}

这一节你获得的工具：

\begin{itemize}
  \item \textbf{图像变换公式} \(a\,f(b(x-h))+k\)：从母函数出发，通过平移和缩放生成一族曲线。横向变换的``反直觉''来自输入预处理——时刻记住是你在喂 \(f\) 什么值。
  \item \textbf{函数复合} \((g\circ f)(x)=g(f(x))\)：把函数串联成处理流水线。现实建模中，多步处理天然是复合。
  \item \textbf{定义域传播}：复合的定义域受内外两层共同约束。先检查原始约束，再化简。
  \item \textbf{函数分解}：看到嵌套表达式能逐层剥离。这是链式法则的前置技能。
  \item \textbf{对称性作为函数等式}：奇偶性将几何对称转化为代数条件。
\end{itemize}

但这些工具也有边界。图像变换公式只适用于线性预处理（\(b(x-h)\)）和线性后处理（\(a\cdot(\cdot)+k\)）——如果内核 \(f\) 本身也被变形了（比如 \(f(x^3)\)），模板就用不了，需要回到复合的通用框架。复合函数的定义域检查在深层嵌套时容易遗漏外层约束——三层以上的复合，建议从最内层往外逐层写约束条件。对称性是全局性质，局部的对称破缺（比如分段函数只在某些区间上对称）需要更精细的工具来描述。
