\section{积分：微小贡献的无尽累加}
\label{sec:02-Calculus/04-Integration/00-Intro}

导数回答“此刻变化有多快”，积分回答“这些微小变化攒到最后是多少”。两个问题看似朝相反的方向发问，微积分基本定理却揭示了它们的本质：\textbf{累积与变化率互为逆运算}。正因如此，寻找曲边图形面积这一原本复杂的几何难题，被降格为了一个简洁的代数查找——“找出一个导数等于被积函数的函数”。这条互逆关系是本章贯穿始终的主轴。

先看一眼这条“捷径”能省去多少麻烦。

假设一辆车的速度为 $v(t)=2t$，想知道它在 $[0,3]$ 时间段内跑出了多少位移：
\begin{itemize}
\item \textbf{硬算（按定义切片）}：把 $[0,3]$ 等分为 6 段，每段宽 $0.5$，用右端点速度 $1, 2, 3, 4, 5, 6$ 近似估算位移，得到 $(1+2+3+4+5+6) \times 0.5 = 10.5$；若继续无限加密切片，这串近似值会收敛到精确值 $9$。
\item \textbf{捷径（利用逆运算）}：如果你注意到 $t^2$ 的导数恰好是 $2t$，直接代入端点计算 $3^2 - 0^2 = 9$ 便瞬间完成。
\end{itemize}
整章要彻底说清楚的，就是第二条捷径凭什么合法、它在几何与代数上的直观机制是什么，以及在什么边界条件下它会不再合法。

对做数据与算法的人来说，积分的现实分量远比“算几何面积”重得多。在连续分布的世界里，几乎一切核心概念都是积分：
\begin{itemize}
\item \textbf{概率与期望}：概率是密度曲线下的面积，期望是加权平均的累积，配分函数（Partition Function）是归一化所必需的整体积分，累积分布函数（CDF）则是密度的变上限积分。
\item \textbf{坐标变换与生成模型}：换元法引入的“密度伸缩因子”，正是概率论中变量替换、多重积分中的 Jacobian 行列式，以及流模型（Normalizing Flows）中 $\log\abs{\det J}$ 误差修正项的同一机制。
\item \textbf{尾部行为与极端值}：反常积分（瑕积分）是否收敛，直接决定了一个重尾分布（Heavy-tailed distribution）的期望与方差究竟是存在一个有限值，还是会发散到无穷大。
\end{itemize}

\subsection{怎么读这一章}

第一节把定积分的严谨基石立起来：切细、取样、求和、取极限，并解释这个极限凭什么与具体切法无关（可积性）。第二节是全章的支点，将“累积”与“变化率”彻底焊在一起。第三、四节讲解计算技巧，但阅读时请盯住结构变换的几何与代数实质——换元法是在做坐标轴的局部伸缩，分部积分是在拿一个边界项去交换另一个更好算的积分，部分分式分解则是把复杂有理函数拆回已知的简单基底。具体题型不值得死记。第五节收口，将同一套“切片累积”的动作铺设到几何体积、概率分布与期望计算这两副面孔上。

若你只想带走最核心的定理，请聚焦第二节；若你为概率论、优化与机器学习而来，第三节的伸缩因子与第五节的累积量将对你最有启发。
