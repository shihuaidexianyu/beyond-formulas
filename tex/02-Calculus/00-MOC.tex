你盯着车速表。指针从 60 跳到 62，只用了一瞬间。那一瞬间的速度是多少？

如果你想用小学的公式“速度 = 路程 $\div$ 时间”来算，就会陷入一个尴尬的困境：所谓“一瞬间”，就是时间间隔为 0。而时间间隔为 0 时，车辆走的位移也是 0。公式变成了：
\[
\text{速度} = \frac{0}{0}
\]
算术在这一刻彻底拒绝了你——它不允许除以零。但你的直觉告诉你，那个时刻的速度确实存在：指针在动，车在加速，车速表也给了读数。

微积分处理的就是这一类困境：\textbf{你关心的量，恰好落在算术够不着的地方。}
\begin{itemize}
    \item 瞬时变化率，变成了 $0 \div 0$（导数）；
    \item 不规则图形的面积，没有“长 $\times$ 宽”的公式可用（积分）；
    \item 无限个碎片的累加，超出了普通加法一次只能加有限项的定义（级数）。
\end{itemize}

微积分给出的办法不是硬算，而是先把“逼近”本身变成一个可检验的承诺，再在这个承诺之上重建除法与加法。

这一部分因此有两条并行的线。一条是\textbf{内容线}：极限、导数、积分、级数、多元。另一条是\textbf{判断线}——每个结论各自依赖什么条件，条件塌掉时会以什么方式出错。

\subsection*{贯穿始终的五条直觉判断}

\textbf{1. 极限不是“无限接近”，是一份可检验的承诺。}
不要被抽象符号吓倒。极限的本质是一场“控制范围”的打赌：别人提出任意苛刻的误差容忍度 $\varepsilon$，你总能给出一个控制范围 $\delta$ 满足他。能永远兑现承诺，极限就存在。

\textbf{2. 导数是用“放大镜”看局部。}
把曲线放大到足够近，它看起来就是一条直线。求导不是去背一堆求导公式，而是把弯曲复杂的函数在局部用“最佳线性模型”去近似。链式法则说的是逐层放大率相乘——这句话也是神经网络反向传播的核心。

\textbf{3. 可微比偏导数更强：要求全方位平滑。}
在多维空间里，偏导数只代表你沿着坐标轴看是平整的；而可微则保证了无论你朝哪个方向看，用放大镜放大后它都是平的。梯度之所以是“最速上升方向”，全靠可微这个前提。

\textbf{4. 积分是做累加，换坐标就要调密度。}
积分就是把极其微小的碎片拼回整体。换元法看起来是计算技巧，实质是坐标伸缩带来的密度因子——无论是在概率论的变量替换，还是多重积分的 Jacobian 行列式里，它们都是同一回事。

\textbf{5. 无限项的命运由尾部决定。}
把无限多个数加起来，项趋于零远远不够。判别法不是要背的清单，而是量同一段尾巴的尺子，用来衡量衰减的速度到底够不够快。
