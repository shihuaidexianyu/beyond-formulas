\section{线性近似与极值问题}
\label{sec:02-Calculus/03-Differentiation/05}

手边没有计算器，要估算 \(\sqrt{4.1}\)。最朴素的想法是：\textbf{用一条简单的直线，去假装复杂的曲线}。

从已知锚点 \(x=4\)（\(\sqrt{4}=2\)）出发，输入往右挪了 \(0.1\)。在 \(x=4\) 处，曲线的局部斜率（导数）是 \(f'(4) = 1/4 = 0.25\)。如果假定这个变化率在 \(0.1\) 的微小范围内基本不变，那么输出变化大约就是 \(0.25 \times 0.1 = 0.025\)，预测 \(\sqrt{4.1} \approx 2.025\)。真实值是 \(2.0248457\ldots\)，相对误差不到万分之一。

上一节我们用中值定理证明过 \(|\sqrt{4.1}-2| \le 0.025\)，那是出于安全考量给出的``绝对不越界的硬约束''；而这里的线性近似给出的则是``最有可能的预测中心''。结合二阶导数对弯曲程度的控制，我们不仅能算出这个估计值，还能看清预测误差是如何产生的。

\subsection{残差按平方衰减：可信半径决定近似范围}

用切线替代曲线之所以靠谱，是因为在极近的距离内，光滑的曲线看起来就是直的。切线方程 \(L(x) = f(a) + f'(a)(x-a)\) 的偏差（残差）由二阶 Taylor 展开精准刻画：
\[
r(h) = f(a+h) - L(a+h) = \frac{f''(c)}{2!} h^2 \quad (c \text{ 介于 } a \text{ 与 } a+h \text{ 之间}).
\]
这里的关键在于：\textbf{残差与步长的平方 \(h^2\) 成正比}。

数值上可以直观验证：对于 \(f(x)=\sqrt{x}\) 在 \(a=4\) 处：
\begin{itemize}
    \item 步长 \(h=0.1\) 时，切线估算 \(\sqrt{4.1} \approx 2.025\)，与真值的残差约为 \(-1.54 \times 10^{-4}\)；
    \item 步长 \(h=0.01\) 时，切线估算 \(\sqrt{4.01} \approx 2.0025\)，与真值的残差约为 \(-1.56 \times 10^{-6}\)。
\end{itemize}
步长 \(h\) 缩小到十分之一，偏差立刻暴跌到百分之一。这种 \(O(h^2)\) 的衰减速度，就是``局部切线近似''如此高效的底层秘密。

\emph{步长翻倍，切线与曲线之间的缝隙（残差）涨到四倍。缝隙涨得有多快，全看曲率 \(|f''|\) 有多大：弯得越厉害，直线能维持精度的``可信半径''就越短。}
\end{center}

反过来，如果走出可信半径，直线就会迅速失真。比如用 \(x=1\) 处的切线去估计 \(\sqrt{4}\)，会得到 \(1 + 0.5 \times 3 = 2.5\)，离真实值 \(2.0\) 差了极远。这是因为 \(\sqrt{x}\) 在 \([1,4]\) 之间弯曲得太厉害，固定方向的直线接不住这种变化。

这形象地解释了一阶优化算法（如梯度下降法）的工作机制：我们之所以敢沿着``负梯度''方向往前走，是因为在当前点周围极小的范围里，目标函数近似于一条直线，沿着直线的陡坡往下走最快。但这个``理由''只在可信半径内有效——步子一旦迈得太宽，实际函数早已转弯，原本以为的``下坡路''反而会把你带向高处。

我们日常写的微分记号 \(dy = f'(x)dx\)，表达的也是同一个道理：输入有一个微小的变化 \(dx\)，经过局部斜率缩放后得到预测的输出变化 \(dy\)——它是一个线性模型给出的合理预测，而不是两个无穷小数在做除法。

\subsection{导数为零：只是拿到``面试资格''}

把线性近似的视角反过来用，就能帮我们找函数的山峰与谷底（极值）。

\textbf{经典例题}：用 100 米围栏靠墙围一块矩形场地，靠墙一侧不用围栏。设垂直于墙的边长为 \(x\)，则平行于墙的边长为 \(100-2x\)，面积函数为：
\[
A(x) = x(100-2x) = 100x - 2x^2, \qquad 0 \le x \le 50.
\]
求导得 \(A'(x) = 100 - 4x\)。令 \(A'(x) = 0\)，解得 \(x = 25\)，面积为 1250 平方米；而端点 \(x=0\) 和 \(x=50\) 处的面积都是 0。

这一步的理论依据是 Fermat 引理：如果函数在内部某点取得极值，且该点可导，那么该点的切线一定是水平的（\(f'=0\)）。但必须特别注意：\textbf{导数为零只是拿到极值候选点的``面试资格''，绝不等于``成功当选''}。

\emph{三种候选情形：左图切线放平且函数在此转向，是真正的谷底；中图切线虽然放平，但曲线穿过平地继续上升（如 \(x^3\)），只是水平拐点；右图最高点直接落在了边界端点上，这里的斜率根本不为零。如果只解 \(f'(x)=0\)，既会收进伪候选，也会漏掉真极值。}
\end{center}

因此，在闭区间上寻找全局最高/最低点时，完整的候选人名单必须包含三类：
\begin{enumerate}
    \item \textbf{内部驻点}：区间内部满足 \(f'(x) = 0\) 的点；
    \item \textbf{不可导点}：函数连续但有尖角的点（例如 \(f(x)=|x|\) 在原点处取得最小值）；
    \item \textbf{边界端点}：闭区间的两个端点 \(\{a, b\}\)。
\end{enumerate}
把这三类候选点处的函数值算出来比大小，最大的就是全局最大，最小的就是全局最小。围栏问题中候选点只有 \(x=25\) 和端点 \(x=0, 50\)，PK 一下胜负立判。

实际应用题最难的地方通常不是求导，而是建立模型：设什么变量、定义域在哪里。如果忘了限制 \(x \in [0, 50]\)，纯代数公式甚至会算出``负边长''这种荒谬结论。

\subsection{二阶曲率与候选点的身份判定}

一阶导数告诉你函数是在上坡还是下坡，二阶导数告诉你这个坡度本身是在变陡还是变缓。几何上看：\(f''(x) > 0\) 说明斜率递增，图像向上弯（像个碗，切线在下方）；\(f''(x) < 0\) 说明斜率递减，图像向下弯（像个盖子，切线在上方）。

对于平地候选点（\(f'(c) = 0\)）：
\begin{itemize}
    \item 若 \(f''(c) > 0\)，说明两侧斜率从负变正，这是\textbf{局部极小点}（谷底）；
    \item 若 \(f''(c) < 0\)，说明两侧斜率从正变负，这是\textbf{局部极大点}（山峰）。
\end{itemize}
在围栏问题中，二阶导数 \(A''(x) \equiv -4 < 0\)，说明图像开口向下，不用画图也能断定 \(x=25\) 是最大值点。

当 \(f''(c) = 0\) 时，二阶导数判据失效。比如 \(f(x) = x^4\) 和 \(g(x) = x^3\) 在原点处一阶、二阶导数全为零，但前者是谷底，后者只是拐点。此时必须退回一阶导数，检查两侧斜率是否真的变号：
\begin{itemize}
    \item \textbf{一阶变号判据}：斜率左负右正就是谷底，左正右负就是山峰；左右同号说明只是中途休息的平地。
    \item \textbf{拐点判定}：拐点的本质是``弯曲方向改变''（\(f''\) 改变符号），而不是单纯的 \(f''=0\)。比如 \(f(x)=x^4\) 在原点两侧都向上弯，凹凸性没变，所以不是拐点；而 \(f(x)=x^3-3x\) 的 \(f''(x)=6x\) 在原点两侧确实改变了正负，是真正的拐点。而且该点斜率为 \(-3\)，说明拐点处的切线完全可以是倾斜的。
\end{itemize}

\subsection{高维空间：鞍点才是世界的主流}

在只有一条路的``一维世界''里，像 \(x^3\) 原点这种``切线平了但不是极值''的情况，看起来像特意凑出来的特例。然而一旦到了几百、几万维的``高维空间''，这种现象反而是常态。

想象你在高维山脉里寻找平地（临界点）：
在二维空间里，平地除了山峰（四周都下坡）和谷底（四周都上坡），还有一种极其常见的地形——\textbf{马鞍}（鞍点）：前后看是谷底（两侧往上高），左右看是山峰（两侧往下低）。

在 Hessian 矩阵的语言里，判断临界点身份看的是特征值符号：
\begin{itemize}
    \item 特征值全正：四周全上坡，是真正的局部极小点；
    \item 特征值全负：四周全下坡，是真正的局部极大点；
    \item 特征值有正有负：有的方向上坡，有的方向下坡，这就是\textbf{鞍点}。
\end{itemize}

在人工智能和深度学习中，模型参数往往多达几百万甚至几亿维（\(d\) 极高）。要在这样一个几亿维度的空间里碰到一个真正的``谷底''，意味着几亿个方向必须\textbf{每一个方向同时都在往上走}。

这就像你\textbf{连续抛几亿次硬币，要求每一次全部正面朝上}，概率微乎其微！

因此在高维非凸优化中，绝大多数坡度为零的平地都是鞍点。深度神经网络训练时经常出现的``梯度停滞''——模型卡在某处走不动了，绝大多数时候并不是陷进了坏的``局部谷底''，而是走进了鞍点周围像桌面一样平坦的``马鞍平台''。模型以为自己无路可走，实际上只要顺着某些往下凹的方向轻轻推一把，就能继续下山。

\subsection{高阶展开与局部近似总结}

如果用直线近似曲线不够精确，最自然的想法就是：加上抛物线（\(f''\)）、立方线（\(f'''\)）等高阶修正项，这就是 Taylor 多项式：
\[
P_n(h) = f(a) + f'(a)h + \frac{f''(a)}{2!}h^2 + \cdots + \frac{f^{(n)}(a)}{n!}h^n.
\]
一阶切线估计只是它的起点。加上二阶抛物线修正项后，对 \(\sqrt{4.1}\) 的预测改进为：
\[
P_2(0.1) = 2 + \frac{1}{4}(0.1) - \frac{1}{16} \cdot \frac{(0.1)^2}{2!} = 2.025 - 0.0003125 = 2.0246875,
\]
与真实值 \(2.0248457\ldots\) 的误差缩小到了万分之二级别。

这种``用直线代替曲线''的思想还可以反过来用：要解方程 \(f(x)=0\)，我们在猜测点 \(x_0\) 处把复杂的 \(f\) 换成切线，直接解切线的零点，得到更新点：
\[
x_{1} = x_0 - \frac{f(x_0)}{f'(x_0)}.
\]

以 \(x_1\) 为新起点不断重复，这就是著名的 \textbf{Newton 迭代法}。把静态估值的切线，变成了动态寻找方程解的引擎，这是微积分中最具生产力的飞跃之一。

\textbf{全章底层逻辑总结}：
导数定义、求导法则、链式法则、中值定理、线性近似与极值判据，看似繁杂，背后的核心引擎只有一个——\textbf{放大局部，把弯曲的非线性函数``掰成直线''；用直线的代数性质做判断，再用残差随步长衰减的速度限定这个判断的适用范围}。

搞懂了局部如何``化曲为直''，下一个自然产生的问题就是：如果把无数个微小局部上的变化累加起来，全局总共改变了多少？这正是下一章积分学要解决的核心任务。
