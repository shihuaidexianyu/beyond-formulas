\section{从平均变化率到导数}
\label{sec:02-Calculus/03-Differentiation/01}

开车行驶在高速公路上，速度表稳稳地指在 \(100\text{km/h}\)。

这个数字究竟是怎么来的？它不可能是用``总路程除以总时间''算出来的——因为那是过去一段时间的\textbf{平均速度}，而速度表声称报告的是``这一瞬间''的\textbf{瞬时速度}。但``某一瞬间''时间间隔为零，位移也是零，计算公式直接变成了无意义的 \(\frac{0}{0}\)。

设物体的位移与时间的关系为函数 \(s(t)\)。在一段时间间隔 \(h\) 内，我们能测到的平均速度是：

\[
\bar v = \frac{s(t+h)-s(t)}{h}.
\]

麻烦在于 \(h\) 该取多少？设物体运动规律为 \(s(t)=t^2\) 米，我们想知道在第 \(t=3\) 秒这一瞬间的速度。
如果取 \(h=0.5\) 秒，算出的平均速度是 \(6.5\text{m/s}\)；
取 \(h=0.1\) 秒，算出 \(6.1\text{m/s}\)；
取 \(h=0.01\) 秒，算出 \(6.01\text{m/s}\)。

随着观察的时间窗口 \(h\) 越来越小，平均速度并没有乱跳，而是非常稳定地排队走向数字 \(6\)。这正是上一章\textbf{极限}出场的绝佳位置：我们不去问``\(h=0\) 时式子等于多少''，而是改问``当 \(h\to0\) 时，这个平均速度稳定趋近于多少''。

在代数上，只要 \(h\neq0\)，我们就可以先把式子约分化简：

\[
\frac{(t+h)^2-t^2}{h}=\frac{2th+h^2}{h}=2t+h.
\]

化简后再让 \(h\to0\) 取极限，结果就是 \(2t\)。在 \(t=3\) 时，这个极限值恰好就是 \(6\)。整个过程没有任何一步强行让 \(h=0\)，极限完美解开了分母不能为零的死结。

\subsection{几何直觉：割线变切线}

在函数的几何图像上，完全在发生同一件事。

画一条曲线 \(y=f(x)\)，你想知道它在点 \((a,f(a))\) 处的弯曲方向。如果选择邻近的另一点 \((a+h,f(a+h))\)，连结两点画出的直线叫做\textbf{割线}，它的斜率正是：

\[
k_{\text{割}} = \frac{f(a+h)-f(a)}{h}.
\]

这和刚才的平均速度是完全同一个算式。当 \(h\to0\) 时，右边的点沿着曲线不断逼近基点，割线随之旋转，最终稳定下来的那条极限位置的直线，就叫做\textbf{切线}。

  \draw[black,thick] (0.35,-0.3) -- (1.75,2.5);

\emph{当邻近点向基点靠拢（\(h\to0\)）时，割线旋转并稳定为切线；切线的斜率就是导数。}
\end{center}

物理上的瞬时速度，与几何上的切线斜率，本质上是同一个数学对象：\textbf{平均变化率在窗口收缩时的极限}。

\subsection{导数的核心：用局部直线近似曲线}

现在，我们可以正式给出导数的定义：函数 \(f\) 在点 \(a\) 处的\textbf{导数}定义为

\[
f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}{h}.
\]

记号上，\(f'(a)\) 与 \(\frac{dy}{dx}\) 表达完全相同的含义。

然而，如果只把导数理解为``切线的斜率''，就小看了它的威力。导数真正的核心思想是：\textbf{用一条简单的直线，去代替复杂的曲线}。

我们可以把导数的定义式重新改写一下：

\[
f(a+h)\approx f(a)+f'(a)h.
\]

意思是说：在点 \(a\) 附近，只要偏移量 \(h\) 足够小，复杂函数 \(f(a+h)\) 的输出值，就可以用一个常数 \(f(a)\) 加上一个线性变化量 \(f'(a)h\) 来极其精确地近似！

\emph{将曲线在同一点不断放大（窗口 \(h\) 不断缩小），实线（曲线）与虚线（切线）越来越贴合。所谓的``可导''，就是指``放大后看起来越来越像一条直线''。}
\end{center}

例如，对于 \(f(x)=x^2\)，在 \(a=1\) 处算得导数 \(f'(1)=2\)。我们可以建立极佳的直线近似模型：\(y\approx1+2(x-1)\)。
当 \(x=1.01\) 时，真实值是 \(1.01^2=1.0201\)，而用直线模型算出的近似值是 \(1+2(0.01)=1.02\)，两者仅相差 \(0.0001\)！

``切线斜率''到了高维空间或多变量函数里可能很难画出来，但``用线性模型近似复杂函数''这个思想，却能贯穿整个高等数学与机器学习（例如 \hyperref[sec:10-Matrix-Calculus/01-Derivative-Conventions/01]{``导数是最佳线性映射''}）。

\subsection{``可导''比``连续''的要求更高}

上一章我们学过，如果一个函数在某点\textbf{连续}，意味着它的图像在该点\textbf{不断开}。
但不断开就一定能求导吗？不一定。\textbf{可导不仅要求图像不断开，还要求图像在该点平滑、没有折角（尖角）。}

\begin{itemize}
\tightlist
  \item \textbf{折角导致不可导}：比如绝对值函数 \(f(x)=|x|\) 在原点 \(x=0\) 处是连续不断开的。但从右边靠近时斜率是 \(+1\)，从左边靠近时斜率是 \(-1\)。两侧的割线指向了不同的方向，无法形成唯一的切线，因此在 \(x=0\) 处不可导。
  \item \textbf{竖直切线导致不可导}：比如 \(f(x)=x^{1/3}\) 在 \(x=0\) 处，虽然图像连续，但靠近原点时切线变成了垂直于 \(x\) 轴的竖直线，斜率趋于无穷大（不是有限实数），因此也不可导。
\end{itemize}

总结来说：\textbf{可导必然连续，但连续不一定可导}。一阶优化算法（如梯度下降）需要依靠导数来指引前进的方向；如果遇到不可导的``尖角''，算法就会陷入迷茫，不知道该往哪边走（在神经网络中，处理 ReLU 函数的尖角问题时，会在 \hyperref[sec:09-Convex-Optimization/06-Optimization-Algorithms/03]{``不可微时次梯度为何仍能前进''} 中探讨）。

\subsection{局部斜率管不了远处}

最后需要强调的是：\textbf{导数只是一个``局部''性质}。

\begin{itemize}
\tightlist
  \item \(f'(a)>0\) 只说明在 \(a\) 点的极小邻域内，函数图像是向右上方倾斜的；
  \item \(f'(a)=0\) 只说明函数在该点附近的直线模型被平放了，并不代表函数在此处一定会``折返''或达到最大/最小值（例如 \(f(x)=x^3\) 在 \(x=0\) 处的导数为零，但函数一直在上升）。
\end{itemize}

千万不要以为``某一点导数为正，整个区间就一定单调递增''。要想用局部的导数信息推导出整段区间上的宏观走势，我们需要借助后文的``中值定理''。

到这里为止，手动求一个函数的导数只需要固定的三步：\textbf{写出平均变化率、在 \(h\neq0\) 的前提下化简、取 \(h\to0\) 的极限}。对简单的 \(x^2\) 走这三步很容易，但如果是像 \(x^3\sin x+e^x\cos x\) 这样复杂的组合函数，每次都从头走这三步将会是一场噩梦。下一节我们将探讨：如何利用简单函数的求导规则，快速算出复杂组合函数的导数。
