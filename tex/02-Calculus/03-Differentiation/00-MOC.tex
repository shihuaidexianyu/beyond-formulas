平均变化率要拿两个不同的点作差，瞬时变化率却要把这两个点合成一个——而差商在间隔为零时无从定义。极限解开了这个死结，但要求我们改口：导数不是``某一瞬间的比值''，是``差商在窗口收缩时稳定到的那个数''。

这一章想立起来的只有一句话：\textbf{导数是函数在一点附近最佳线性近似的系数}。切线斜率、瞬时速度、边际成本都是这句话在具体语境下的说法，但它们各自带着画面，画面到了多变量、矩阵、神经网络里就用不上了；那个系数的说法能一路走下去。

一旦接受这个视角，本章其余内容会自动排好队。求导规则不再是一张需要记忆的公式表，而是``已知零件的线性模型，求组装件的线性模型''这一个问题的几个答案；链式法则说的是嵌套结构中局部放大率逐层相乘，反向传播的全部数学内容就在这里；中值定理把逐点的导数信息兑换成跨区间的结论，梯度界推出函数变化界的 Lipschitz 论证由此起步；线性近似的误差按步长平方收缩，这条规律决定了一阶优化方法的步子能迈多大；而导数为零只给候选资格不给结论，这个在一维里显得吹毛求疵的提醒，到了高维会变成鞍点远多于极小点的日常困扰。

\subsection{五篇各自改变什么判断}

\begin{itemize}
\tightlist
\item
  \hyperref[sec:02-Calculus/03-Differentiation/01]{``从平均变化率到导数''}：把导数从``切线的斜率''改口为``最佳线性近似的系数''，并说明可导比连续严格在哪里。
\item
  \hyperref[sec:02-Calculus/03-Differentiation/02]{``求导规则从哪里来''}：证明公式表不需要背——代入线性模型、展开、丢掉高次项，规则自己会掉出来，同时暴露每条公式压在哪条极限事实上。
\item
  \hyperref[sec:02-Calculus/03-Differentiation/03]{``复合、隐式与反函数求导''}：链式法则是放大率相乘；由此解释梯度消失与梯度爆炸为何是连乘的算术后果，而非工程意外。
\item
  \hyperref[sec:02-Calculus/03-Differentiation/04]{``中值定理连接局部与整体''}：逐点的导数信息怎样被迫产生跨区间的结论，以及每条假设分别挡住哪种反例。
\item
  \hyperref[sec:02-Calculus/03-Differentiation/05]{``线性近似与极值问题''}：误差按平方收缩决定可信半径；导数为零只是候选资格，高维里绝大多数候选是鞍点。
\end{itemize}

顺序读下来最省力，前三篇尤其应连着看。若手上正卡在某个具体问题上，也可以直接翻到最接近的一篇，再沿篇内链接回补。真正需要带走的不是求导技巧——那部分早已交给自动微分——而是判断力：看得出一个函数在某点是否值得线性化，看得出线性化的结论能推多远，以及在它失效时知道该往哪个方向找替代品。
